## Requirements

<Accordions>
    <Accordion title="1. Activate trial or subscribe">
        Start a [free trial](https://cloud.tiptap.dev/v2?trial=true) or [subscribe to the Start plan](https://cloud.tiptap.dev/v2/billing) in your account.
    </Accordion>
    <Accordion title="2. Install from private registry">
        To install this frontend extension, authenticate to Tiptap's private npm registry by following the [setup guide](/docs/guides/pro-extensions).
    </Accordion>
</Accordions>

<Callout title="Consider using DOCX instead" type="info">
    The DOC format is a legacy format from Microsoft Word 97-2003. For modern use, we recommend exporting to [DOCX](/docs/conversion/export/docx/styles) instead. Use DOC only when compatibility with older systems requires it.
</Callout>

When exporting to DOC, you can define custom styles that will be applied to the exported document. This is useful when you want to have a consistent look and feel across your documents.

<Callout title="Requires Export DOCX extension" type="warning">
  Style overrides for DOC export require the `@tiptap-pro/extension-export-docx` extension to be installed and configured in your editor. The DOC export uses DOCX generation under the hood before converting to DOC. Without it, the `styleOverrides` and element override options will have no effect.
</Callout>
