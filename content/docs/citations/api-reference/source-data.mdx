Use strings, booleans, finite numbers, `null`, dense arrays, or plain objects with enumerable string keys. You can reuse the same nested value in multiple fields as long as it does not form a cycle.

Convert dates, maps, sets, and other class instances to JSON data before adding them. The collection rejects `undefined`, nonfinite numbers, bigints, functions, symbols, symbol keys, sparse arrays, extra array properties, accessors, and objects with non-enumerable properties or custom or null prototypes.

When the extension rejects a value, inspect `CitationError.details.path` to find the field, such as `data.sections.0.title` or `revision`.

These rules also apply to values returned by a [revision selector](/docs/citations/guides/sources#choose-a-revision-strategy). See [source collections](/docs/citations/api-reference/sources) for how to add and update sources.
