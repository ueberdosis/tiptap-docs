## Capabilities

The client-side AI Toolkit includes the building blocks for any custom AI functionality:

- **Tools** for building [AI agents](/docs/ai/ai-toolkit/client/agents) capable of complex tasks.
- [**Workflows**](/docs/ai/ai-toolkit/client/workflows) where the AI has a single, well-defined task: insert content, proofread the document, and more.

<Callout title="Compatible with any AI model" type="info">
  Use the AI Toolkit with any AI model capable of producing text, including open source and
  self-hosted models.
</Callout>

### AI agent tools

Build [AI agents](/docs/ai/ai-toolkit/client/agents) that can perform complex tasks by working with Tiptap documents.

<Cards>
  <Card title="AI Agent Chatbot" href="/docs/ai/ai-toolkit/client/agents/ai-agent-chatbot">
    Build a conversational AI capable of editing documents and interacting through chat.
  </Card>
  <Card title="AI agent tools" href="/docs/ai/ai-toolkit/client/api-reference/execute-tool">
    Add these tools to your AI agent to give it document-editing superpowers.
  </Card>
  <Card title="Review Changes" href="/docs/ai/ai-toolkit/client/agents/review-changes">

  </Card>
  <Card title="Tool Streaming" href="/docs/ai/ai-toolkit/client/agents/streaming">
    Stream AI tool calls in real-time to show users what the AI is doing. Improves perceived
    performance and transparency.
  </Card>
  <Card title="Selection Awareness" href="/docs/ai/ai-toolkit/client/agents/selection-awareness">

    Build an agent that works across multiple documents simultaneously. Includes document
    switching and cross-document context.
  </Card>
  <Card title="Comments" href="/docs/ai/ai-toolkit/client/agents/comments">
    Have AI insert comments and annotations into documents. Useful for feedback, suggestions, or
    collaborative editing.
  </Card>
</Cards>
