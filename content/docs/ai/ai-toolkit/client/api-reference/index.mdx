The AI Toolkit provides a set of methods that are the building blocks for your AI integrations. You can call these methods from the AI Toolkit instance:

```ts
import { Editor } from '@tiptap/core'
import { AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

// Get the AI Toolkit instance
const editor = new Editor({ extensions: [AiToolkit] })
const toolkit = getAiToolkit(editor)

// Call an AI Toolkit method
const text = toolkit.getTextRange({ from: 0, to: 100 })
```
