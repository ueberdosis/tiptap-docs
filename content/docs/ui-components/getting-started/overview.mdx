## How components are installed

The CLI copies the component and the registry files it imports into your project. It also uses your package manager to install npm dependencies. For example, run this in your project to install a formatting button.

```sh
pnpm dlx @tiptap/cli@latest add mark-button
```

Import the button from `@/components/tiptap-ui/mark-button` with the default aliases. Register the mark you want to toggle in your editor. The [mark button guide](/docs/ui-components/components/mark-button) shows how to pass it an editor instance.

Templates include the editor setup. In a new Next.js App Router project, the [Simple Editor](/docs/ui-components/templates/simple-editor) includes a page at `/simple`. For other frameworks, follow the installation guide to render the editor in your own route.

## Components and primitives

- **Components** connect a control to editor state or commands. For example, the [heading dropdown](/docs/ui-components/components/heading-dropdown-menu) lets a user apply heading levels enabled in the editor.
- **Node components** supply styles, extensions, or React views for document nodes. The [image upload node](/docs/ui-components/node-components/image-upload-node) takes an upload handler from your app.
- **Primitives** provide controls such as a [button](/docs/ui-components/primitives/button) or [popover](/docs/ui-components/primitives/popover). Use them to build your own interface.

## Design defaults

Edit the installed component files to change their markup or behavior. To change the colors shared across controls, edit the theme variables in your styles directory. The [styling guide](/docs/ui-components/getting-started/style) lists the global stylesheet paths for each framework.
