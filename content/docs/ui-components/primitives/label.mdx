Use `Label` to give a form control an accessible name.

<CodeDemo isScrollable src="https://template.tiptap.dev/preview/tiptap-ui-primitive/label" />

## Install

You can add the primitive via Tiptap CLI

```bash
npx @tiptap/cli@latest add label
```

## Usage

```tsx
import { Label } from '@/components/tiptap-ui-primitive/label'

export default function EmailField() {
  return (
    <div>
      <Label htmlFor="email">Email address</Label>
      <input id="email" type="email" />
    </div>
  )
}
```

## Props

`Label` renders a native `<label>` and accepts its HTML attributes. Set `htmlFor` to the control's `id` to focus the control when the user clicks the label.
