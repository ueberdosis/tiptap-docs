Learn more about [agent skills](https://agentskills.io/).

The skill provides your agent with:

- A strategy to search the Tiptap source code and documentation.
- Best practices for using Tiptap 3
- Framework-specific guidance (e.g. React)

## Install

Install the skill with the [skills CLI](https://skills.sh/):

```bash
npx skills add ueberdosis/tiptap
```

Or [download the SKILL.md directly from GitHub](https://github.com/ueberdosis/tiptap/blob/main/.agents/skills/tiptap/SKILL.md).

## Connect the docs to your agent

The skill tells an agent how to work with Tiptap. These endpoints give it the docs themselves.

### MCP server

The docs MCP server lets an agent search the docs, read any page as Markdown, and list features with their plans, and plan an editor. It is read-only and needs no key.

| Tool | What it does |
| --- | --- |
| `search_docs` | Finds pages by keywords and returns their titles, sections, plans, and Markdown URLs. |
| `get_page` | Returns one page as Markdown, with frontmatter that names its section, plan, and status. |
| `list_features` | Lists features by area, plan, group, or industry, with a link to each feature's docs. |
| `plan_editor` | Returns the plan, add-ons, services, npm packages, and next step for a use case or a list of features, like [Plan your editor](/configurator). |

Add it to Claude Code:

```bash
claude mcp add --transport http tiptap-docs https://tiptap.dev/docs/api/mcp
```

Add it to Cursor, VS Code, or another client that reads an `mcp.json`:

```json
{
  "mcpServers": {
    "tiptap-docs": {
      "url": "https://tiptap.dev/docs/api/mcp"
    }
  }
}
```

### Markdown and llms.txt

- **Markdown pages:** Append `.md` to any docs URL, or send an `Accept: text/markdown` header.
- **[llms.txt](https://tiptap.dev/docs/llms.txt):** Lists every page, grouped like the sidebar, with its plan.
- **[llms-full.txt](https://tiptap.dev/docs/llms-full.txt):** Holds every page in one file.
