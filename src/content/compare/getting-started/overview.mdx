## What you can do with it

- **Compare two documents.** Pass two Tiptap JSON documents and get their differences. [Compare documents](/compare/guides/compare-documents)
- **Compare versions of one document.** Compare two versions of a collaborative document. [Compare versions](/compare/guides/compare-versions)
- **Compare on the server.** The comparison needs no editor, so it runs in your backend too. [Compare documents on the server](/compare/guides/server-compare)
- **Review the differences as suggestions.** Show them as tracked changes that users accept or reject. [Compare documents with Tracked Changes](/compare/guides/tracked-changes)
- **Show both sides.** Review changes in two panes next to each other. [Split view](/compare/guides/split-view)
- **Style the result.** You decide how changes look. [Styling](/compare/api-reference/styling)

Install the package:

```bash
npm install @tiptap-pro/compare
```

Add the `Compare` extension to the editor that shows the changes:

```ts
import { Compare } from '@tiptap-pro/compare'

const editor = new Editor({
  extensions: [
    Compare,
    // …your other extensions
  ],
})
```

[Compare documents](/compare/guides/compare-documents) continues with a first comparison.
