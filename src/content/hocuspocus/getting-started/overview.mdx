## What you can do with it

- **Sync documents in real time.** Changes from every client merge without conflicts, in whatever order they arrive. [Collaborative editing](/hocuspocus/guides/collaborative-editing)
- **Work offline.** Clients keep editing without a connection and sync their changes later. [Offline support](/hocuspocus/guides/collaborative-editing#offline-support)
- **Edit with your editor of choice.** It works with Tiptap, CodeMirror, Monaco, Quill, Lexical, and Slate. [Examples](/hocuspocus/provider/examples)
- **Show who is there.** Share cursors, selections, and user details through awareness. [Awareness](/hocuspocus/guides/awareness)
- **Store documents your way.** Save them in your database, SQLite, or S3. [Persistence](/hocuspocus/guides/persistence)
- **Decide who may connect.** Check every connection in a hook. [Authentication](/hocuspocus/guides/authentication)
- **Extend the server.** Hooks and extensions add logging, throttling, webhooks, and more. [Hooks](/hocuspocus/server/hooks), [Extensions](/hocuspocus/server/extensions/overview)
- **Scale out.** Run several servers that share documents through Redis. [Scalability](/hocuspocus/guides/scalability)
- **Run where you deploy.** Node.js, Bun, Deno, and Cloudflare Workers since version 4. [Usage](/hocuspocus/server/usage)
- **Build with React.** Components and hooks manage the provider for you. [React](/hocuspocus/provider/react)

## Get started

Install the server:

```bash
npm install @hocuspocus/server
```

Start it with the built-in WebSocket server:

```js
import { Server } from '@hocuspocus/server'

const server = new Server({
  port: 1234,
})

server.listen()
```

Install the provider in your app, and connect a Yjs document to the server:

```bash
npm install yjs @hocuspocus/provider
```

```js
import * as Y from 'yjs'
import { HocuspocusProvider } from '@hocuspocus/provider'

const ydoc = new Y.Doc()

const provider = new HocuspocusProvider({
  url: 'ws://127.0.0.1:1234',
  name: 'example-document',
  document: ydoc,
})
```

Changes to the Yjs document now sync to everyone connected to it. [Collaborative editing](/hocuspocus/guides/collaborative-editing) connects it to a Tiptap editor.

## When to move to the Document Server

Hocuspocus leaves storage, authentication, a document API, and version history to you, and has no comments. The [Document Server](/collaboration/getting-started/overview) runs the same sync and includes them, with [Snapshots](/collaboration/documents/snapshot) for versions and [Comments](/comments/getting-started/overview), in [Tiptap Cloud](/hosting/cloud) or [on-premises](/hosting/on-premises). [Hosting](/hosting) compares the options.
