## What a bundle holds

- **Features for one use case.** The DOCX bundle, for example, brings pages, footnotes, cross-references, document styles, and DOCX import and export.
- **One package and one kit.** You install the bundle and register its kit. Each part can be configured or switched off, as in [StarterKit](/editor/extensions/functionality/starterkit).
- **Versions that work together.** Each bundle release pins the versions of its parts, after testing them together.
- **One license.** The bundle unlocks all its parts. The parts stay available one by one.

## Bundles, kits, and add-ons

| | What it is | Example |
| --- | --- | --- |
| Feature | One extension or service, with its own page | Footnotes, DOCX export |
| Kit | One extension that registers others, each one switchable | StarterKit, Table kit |
| Add-on | A paid capability on top of a plan | Tracked Changes |
| Bundle | Features, services, and a kit for one use case, in one package and one license | DOCX bundle |

StarterKit is a kit, not a bundle: it is free, open source, and holds editor extensions only.
