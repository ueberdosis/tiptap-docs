The board's editor emits these events. Listen with `editor.on()`, and stop with `editor.off()`.

## docChange

The document of a doc frame changed, its editing started or stopped, or its editor came or went. Use it to update a toolbar that also works in documents.

| Payload | Type     | Description                         |
| ------- | -------- | ----------------------------------- |
| `docId` | `string` | The id of the document that changed |

```js
import { getEditedDocEditor } from '@tiptap-pro/extension-whiteboard'

editor.on('docChange', ({ docId }) => {
  const isEditing = getEditedDocEditor(editor) !== null
  console.log(`The document ${docId} changed. A document is edited: ${isEditing}`)
})
```

## shapesMove

A drag moves shapes by `delta`, in board units. `delta` is `null` once the drag ends. When a drag ends, the drop changes the document before this event reports the end.

| Payload | Type                | Description                                                                  |
| ------- | ------------------- | ---------------------------------------------------------------------------- |
| `ids`   | `readonly string[]` | The ids of the dragged shapes                                                |
| `delta` | `Point \| null`     | How far the drag has moved the shapes since it began, or `null` once it ends |

Share it with other people, so [`createRemoteMoves`](/whiteboard/api-reference/utilities#createremotemoves) shows the drag on their boards:

```js
editor.on('shapesMove', ({ ids, delta }) => {
  provider.setAwarenessField('drag', delta ? { ids, delta } : null)
})
```

See [Collaboration](/whiteboard/guides/collaboration#show-what-others-select-and-drag).
