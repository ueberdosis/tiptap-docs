All editor commands of the Whiteboard extension. `WhiteboardKit` adds all of them. Shapes are found by their ids, and positions and sizes are in board units.

- **Shapes:** [`insertShape()`](#insertshape), [`updateShape()`](#updateshape), [`updateShapes()`](#updateshapes), [`moveShapes()`](#moveshapes), [`duplicateShapes()`](#duplicateshapes), [`deleteShapes()`](#deleteshapes), [`bringToFront()`](#bringtofront), [`sendToBack()`](#sendtoback) and [`insertStickyNote()`](#insertstickynote)
- **Selection:** [`selectShapes()`](#selectshapes), [`toggleShapeSelection()`](#toggleshapeselection), [`selectAllShapes()`](#selectallshapes), [`clearShapeSelection()`](#clearshapeselection), [`editShapeText()`](#editshapetext) and [`focusBoard()`](#focusboard)
- **Text:** [`selectShapeText()`](#selectshapetext), [`setTextColor()`](#settextcolor) and [`unsetTextColor()`](#unsettextcolor)
- **Tools and styles:** [`setTool()`](#settool) and [`setShapeStyle()`](#setshapestyle)
- **History:** [`undoBoard()`](#undoboard) and [`redoBoard()`](#redoboard)
- **Collaboration:** [`setRemoteSelections()`](#setremoteselections)

The other text commands come from the Tiptap extensions in the kit, like `toggleBold`, `setHighlight`, `setLink` and `toggleTaskList`. `setHighlight` takes a board color, like `setHighlight({ color: 'blue' })`.

## insertShape()

Adds a shape in front of all other shapes, with the styles from [`setShapeStyle()`](#setshapestyle) unless the options set them. Puts the caret inside when the shape holds text, and selects it otherwise.

### Options

| Option           | Type      | Description                                                            |
| ---------------- | --------- | ---------------------------------------------------------------------- |
| `type`           | `string`  | The node type of the shape, like `geo`, `freeText` or `arrow`          |
| `id`             | `string`  | Optional. An id that no shape on the board has. Generated unless given |
| Other attributes | `unknown` | The attributes of the shape, like `x`, `y` or `color`                  |

### Returns

`boolean` — `false`, and adds nothing, when an attribute is `NaN` or infinite, when the type isn't a shape, or when a shape on the board has the id already.

```js
editor.commands.insertShape({ type: 'geo', kind: 'ellipse', x: 100, y: 100 })
```

## updateShape()

Changes attributes of the shape with the given id. Like [`updateShapes()`](#updateshapes), it skips what wouldn't change.

### Parameters

| Argument | Type          | Description                                      |
| -------- | ------------- | ------------------------------------------------ |
| `update` | `ShapeUpdate` | The id of the shape and the attributes to change |

### Returns

`boolean` — `false` when nothing would change.

```js
editor.commands.updateShape({ id: 'note-1', attributes: { color: 'blue' } })
```

## updateShapes()

Changes attributes of several shapes in one step. Skips ids that are not on the board, updates that would change an id or hold `NaN` or an infinite number, attributes that a shape does not have, and shapes that already have the attributes.

### Parameters

| Argument  | Type                     | Description                                         |
| --------- | ------------------------ | --------------------------------------------------- |
| `updates` | `readonly ShapeUpdate[]` | The id of each shape, with the attributes to change |

### Returns

`boolean` — `false` when nothing would change.

```js
editor.commands.updateShapes([
  { id: 'idea', attributes: { x: 0 } },
  { id: 'plan', attributes: { x: 300 } },
])
```

## moveShapes()

Moves the shapes with the given ids. Arrows move their free ends.

### Options

| Option  | Type                | Description                          |
| ------- | ------------------- | ------------------------------------ |
| `ids`   | `readonly string[]` | The ids of the shapes                |
| `delta` | `Point`             | How far to move them, in board units |

### Returns

`boolean` — `false` when nothing would move.

```js
editor.commands.moveShapes({ ids: ['note-1', 'note-2'], delta: { x: 40, y: 0 } })
```

## duplicateShapes()

Adds copies of the shapes with new ids, moved by `offset`, in front of all other shapes, and selects them. A copied doc frame gets a copy of its document from the `docs` option.

### Options

| Option   | Type                | Description                                                                                        |
| -------- | ------------------- | -------------------------------------------------------------------------------------------------- |
| `ids`    | `readonly string[]` | The ids of the shapes                                                                              |
| `offset` | `Point`             | Optional. How far from the shapes their copies land, in board units. Defaults to 24 right and down |

### Returns

`boolean` — `false`, and adds nothing, when none of the shapes is on the board, or when the offset is `NaN` or infinite.

```js
import { getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

editor.commands.duplicateShapes({ ids: getSelectedShapeIds(editor.state) })
```

## deleteShapes()

Deletes the shapes with the given ids in one step. Arrows that connect a deleted shape stay, with a free end where they touched it.

### Parameters

| Argument | Type                | Description           |
| -------- | ------------------- | --------------------- |
| `ids`    | `readonly string[]` | The ids of the shapes |

### Returns

`boolean` — `false` when none of the shapes is on the board.

```js
editor.commands.deleteShapes(['note-1'])
```

## bringToFront()

Puts the shapes in front of all other shapes and keeps their order among each other.

### Parameters

| Argument | Type                | Description           |
| -------- | ------------------- | --------------------- |
| `ids`    | `readonly string[]` | The ids of the shapes |

### Returns

`boolean` — `false` when none of the shapes is on the board.

```js
import { getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

editor.commands.bringToFront(getSelectedShapeIds(editor.state))
```

## sendToBack()

Puts the shapes behind all other shapes and keeps their order among each other.

### Parameters

| Argument | Type                | Description           |
| -------- | ------------------- | --------------------- |
| `ids`    | `readonly string[]` | The ids of the shapes |

### Returns

`boolean` — `false` when none of the shapes is on the board.

```js
editor.commands.sendToBack(['note-1'])
```

## insertStickyNote()

Adds a sticky note in front of all other shapes and puts the caret inside it. Notes are yellow unless [`setShapeStyle()`](#setshapestyle) chose another color.

### Options

| Option   | Type     | Description                                                            |
| -------- | -------- | ---------------------------------------------------------------------- |
| `x`      | `number` | Where the note's left edge goes                                        |
| `y`      | `number` | Where the note's top edge goes                                         |
| `width`  | `number` | Optional. Defaults to the width of `stickyNoteSize`, 220               |
| `height` | `number` | Optional. Defaults to the height of `stickyNoteSize`, 160              |
| `id`     | `string` | Optional. An id that no shape on the board has. Generated unless given |

### Returns

`boolean` — `false`, and adds nothing, when an option is `NaN` or infinite, or when a shape on the board has the id already.

```js
editor.commands.insertStickyNote({ x: 100, y: 100 })
```

## selectShapes()

Selects the shapes with the given ids. Unknown ids are ignored.

### Parameters

| Argument | Type                | Description                                            |
| -------- | ------------------- | ------------------------------------------------------ |
| `ids`    | `readonly string[]` | The ids of the shapes, in the order they were selected |

### Returns

`boolean` — Always `true`.

```js
editor.commands.selectShapes(['idea', 'plan'])
```

## toggleShapeSelection()

Adds the shape to the selection, or removes it when it is already selected.

### Parameters

| Argument | Type     | Description         |
| -------- | -------- | ------------------- |
| `id`     | `string` | The id of the shape |

### Returns

`boolean` — Always `true`.

```js
editor.commands.toggleShapeSelection('idea')
```

## selectAllShapes()

Selects every shape on the board.

Takes no arguments.

### Returns

`boolean` — Always `true`.

```js
editor.commands.selectAllShapes()
```

## clearShapeSelection()

Unselects all shapes and ends text editing, so keys act on the board.

Takes no arguments.

### Returns

`boolean` — Always `true`.

```js
editor.commands.clearShapeSelection()
```

## editShapeText()

Unselects all shapes and puts the caret into the shape's text: at `pos` when it lies in that text, otherwise at the end. A doc frame starts editing its document instead.

### Options

| Option | Type     | Description                                                                                  |
| ------ | -------- | -------------------------------------------------------------------------------------------- |
| `id`   | `string` | The id of the shape                                                                          |
| `pos`  | `number` | Optional. The caret's position in the document, inside the shape's text. Defaults to the end |

### Returns

`boolean` — `false` when no shape has the id, or for shapes without text, like pen lines.

```js
editor.chain().focus().editShapeText({ id: 'note-1' }).run()
```

## focusBoard()

Focuses the board, or the text while it is edited, after the chain's transaction. Unlike `focus`, it also works while the text is read-only. For code outside a chain, like a toolbar button's click handler, call the [`focusBoard()` function](/whiteboard/api-reference/utilities#focusboard), which focuses right away.

Takes no arguments.

### Returns

`boolean` — Always `true`.

```js
editor.chain().selectShapes(['note-1']).focusBoard().run()
```

## selectShapeText()

Selects all text of the shape that holds the selection.

Takes no arguments.

### Returns

`boolean` — `false` when no shape holds the selection.

```js
editor.chain().editShapeText({ id: 'note' }).selectShapeText().run()
```

## setTextColor()

Colors the selected text with a board color. The mark stores the name of the color, so your CSS decides how it looks.

### Parameters

| Argument | Type         | Description                                   |
| -------- | ------------ | --------------------------------------------- |
| `color`  | `ShapeColor` | The name of a board color, from `shapeColors` |

### Returns

`boolean` — `false` when none of the selected text can take the mark.

```js
editor.commands.setTextColor('red')
```

## unsetTextColor()

Gives the selected text its shape's color again.

Takes no arguments.

### Returns

`boolean` — Always `true`.

```js
editor.commands.unsetTextColor()
```

## setTool()

Chooses what a press on the board does, and ends text editing, so keys act on the board. It doesn't move the focus: after a click on a toolbar button, call the [`focusBoard()` function](/whiteboard/api-reference/utilities#focusboard). A [read-only board](/whiteboard/guides/shapes-and-tools#read-only-boards) goes back to `select` from the tools that change the board. The `doc` tool needs the [`docs` option](/whiteboard/guides/doc-frames).

### Parameters

| Argument | Type   | Description                              |
| -------- | ------ | ---------------------------------------- |
| `tool`   | `Tool` | The tool, like `select`, `note` or `pen` |

### Returns

`boolean` — `false` for the `doc` tool on a board without `docs`, and `true` for every other tool.

```js
editor.commands.setTool('pen')
```

## setShapeStyle()

Gives the selected shapes, or the shape whose text is edited, the style in one step, and shapes added later get it too. Shapes that don't have the style stay as they are.

### Options

| Option  | Type                    | Description                               |
| ------- | ----------------------- | ----------------------------------------- |
| `name`  | `ShapeStyleName`        | The style, like `color` or `fontSize`     |
| `value` | `ShapeStyleValue<Name>` | The name of its value, like `blue` or `l` |

### Returns

`boolean` — Always `true`.

```js
editor.commands.setShapeStyle({ name: 'color', value: 'blue' })
```

## undoBoard()

Undoes the last change and selects the shapes it changed. Works with Tiptap's `UndoRedo` and with Collaboration.

Takes no arguments.

### Returns

`boolean` — `false` when there is nothing to undo, or when the editor has neither `UndoRedo` nor Collaboration.

```js
editor.commands.undoBoard()
```

## redoBoard()

Redoes the last undone change and selects the shapes it changed.

Takes no arguments.

### Returns

`boolean` — `false` when there is nothing to redo, or when the editor has neither `UndoRedo` nor Collaboration.

```js
editor.commands.redoBoard()
```

## setRemoteSelections()

Shows the shapes that other users select, instead of what showed before. See [Collaboration](/whiteboard/guides/collaboration#show-what-others-select-and-drag).

Colors need the form `#RRGGBB`, and a selection with another color doesn't show. When several users select a shape, the first one with a valid color shows.

### Parameters

| Argument     | Type                         | Description                                              |
| ------------ | ---------------------------- | -------------------------------------------------------- |
| `selections` | `readonly RemoteSelection[]` | The shapes that each user selects, with the user's color |

### Returns

`boolean` — Always `true`.

```js
editor.commands.setRemoteSelections([{ color: '#be185d', ids: ['idea'] }])
```
