The package exports TypeScript types for the camera, shapes, tools, styles and doc frames.

## Camera

Where the board shows in the stage: `x` and `y` in screen pixels, and `zoom`, where 1 is 100%.

```ts
type Camera = {
  x: number
  y: number
  zoom: number
}
```

## UpdateCamera

Changes the camera through an update function, like a React state setter.

```ts
type UpdateCamera = (update: (camera: Camera) => Camera) => void
```

## Point, Rect and Size

A point, with `x` to the right and `y` down. A rectangle, from its top left corner. A width and a height.

```ts
type Point = {
  x: number
  y: number
}

type Rect = {
  x: number
  y: number
  width: number
  height: number
}

type Size = {
  width: number
  height: number
}
```

## Insets

Room to keep free at each edge of the viewport, in screen pixels. Options that take insets also take one number for every edge.

```ts
type Insets = { top: number; right: number; bottom: number; left: number }
```

## ShapeAttributes

The attributes of shapes. Positions and sizes are in board units. `id` is unique on the board, and `zIndex` is a fractional index: shapes with a higher one are in front. `color` is a name from `shapeColors`, and `kind` the kind of a geometric shape, a name from `geoKinds`.

```ts
type ShapeAttributes = {
  id: string | null
  x: number
  y: number
  width: number
  height: number
  zIndex: string | null
  color: string
  kind?: GeoKind
}
```

Arrows have no box, but ends, see [`ArrowEndAttributes`](#arrowendattributes), and also the style `arrowheads`. Doc frames have no `color`, but a `docId`. Shapes with text also have the styles `fontSize`, `textAlign` and `font`, see [`ShapeStyles`](#shapestyles). Pen lines also have `points` and `strokeWidth`.

## ShapeGeometry

The box of a shape, in board units.

```ts
type ShapeGeometry = Pick<ShapeAttributes, 'x' | 'y' | 'width' | 'height'>
```

## ArrowEndAttributes

Where the ends of an arrow are. An end with the id of a shape on the board follows that shape. Otherwise it is free and sits at its point.

```ts
type ArrowEndAttributes = {
  fromId: string | null
  toId: string | null
  fromX: number
  fromY: number
  toX: number
  toY: number
}
```

## ShapeUpdate

A change to the attributes of one shape. An update can change any of a shape's attributes, except the id.

```ts
type ShapeUpdate = {
  id: string
  attributes: ShapeUpdateAttributes
}

type ShapeUpdateAttributes = Partial<
  Omit<ShapeAttributes, 'id'> &
    ArrowEndAttributes &
    ShapeStyles & { points: string; strokeWidth: number; docId: string }
>
```

`points` and `strokeWidth` are those of a pen line, and `docId` is the document of a doc frame.

## Tool and ShapeTool

What a press on the board does: select shapes, pan the board, erase pen lines, or add a shape. A `ShapeTool` adds a shape of its kind.

```ts
type Tool = 'select' | 'hand' | 'eraser' | ShapeTool

type ShapeTool = 'note' | 'text' | 'doc' | 'rectangle' | 'ellipse' | 'diamond' | 'pen' | 'arrow'
```

## GeoKind and ShapeColor

A kind of geometric shape, from `geoKinds`, and the name of a board color, from `shapeColors`.

```ts
type GeoKind = (typeof geoKinds)[number] // 'rectangle' | 'ellipse' | 'diamond' | 'triangle'

type ShapeColor = (typeof shapeColors)[number] // 'black' | 'gray' | 'red' | 'orange' | …
```

## ShapeStyles

The styles of shapes come from `shapeStyles`. `ShapeStyleName` is the name of a style, like `color` or `fontSize`, and `ShapeStyleValue` the name of a value of a style, like `blue` for `color`. `ShapeStyles` has a value for each style.

```ts
type ShapeStyleName = keyof typeof shapeStyles // 'color' | 'fontSize' | 'textAlign' | 'font' | 'arrowheads'

type ShapeStyleValue<Name extends ShapeStyleName> = (typeof shapeStyles)[Name][number]

type ShapeStyles = { [Name in ShapeStyleName]: ShapeStyleValue<Name> }
```

## ShapeElementAttributes

Returns extra attributes for the element of a shape, from the shape's node. Values become strings, and `null` or `undefined` leaves an attribute out.

```ts
type ShapeElementAttributes = (node: ProseMirrorNode) => Record<string, unknown>
```

## WhiteboardKitOptions

The options of `WhiteboardKit`. See [Extensions](/whiteboard/api-reference/extensions#whiteboardkit).

```ts
interface WhiteboardKitOptions {
  undoRedo: Partial<UndoRedoOptions> | false
  shapeElementAttributes: ShapeElementAttributes | null
  docs: BoardDocs | null
}
```

`BoardOptions`, the options of `Board`, has `shapeElementAttributes` and `docs`. `BoardStorage` is what the board keeps in `editor.storage.board`, see [Extensions](/whiteboard/api-reference/extensions#storage-boardstorage).

## BoardDocs

Where the documents of doc frames live, like local storage or Tiptap Cloud. The app provides it, so the board stays free of any storage. See [Doc frames](/whiteboard/guides/doc-frames).

```ts
interface BoardDocs {
  createEditor: (options: CreateDocEditorOptions) => Editor
  start?: (docId: string) => void
  copy: (options: CopyDocOptions) => void
}

interface CreateDocEditorOptions {
  element: HTMLElement
  docId: string
}

interface CopyDocOptions {
  fromDocId: string
  toDocId: string
}
```

- `createEditor` creates the editor of a document inside `element`, the element of the frame. The board destroys it with its frame.
- `start` starts the document of a frame that this editor adds. Runs before the frame shows, and also for a copy, after `copy`, so keep a document that `copy` gave it. Frames that other editors add don't start a document here.
- `copy` copies a document for the copy of its frame. Runs before the copy shows, and before `start`.

## RemoteSelection

The shapes that one other person selects, and their color as `#RRGGBB`. A selection with another color, like `red` or `#abc`, doesn't show.

```ts
type RemoteSelection = {
  color: string
  ids: readonly string[]
}
```

## RemoteMoves

Shows the drags of other people, until they drop their shapes. `createRemoteMoves` returns it.

```ts
interface RemoteMoves {
  show: (options: ShowRemoteMoveOptions) => void
  end: (owner: unknown) => void
}

interface ShowRemoteMoveOptions {
  owner: unknown
  ids: readonly string[]
  delta: Point
}
```

`owner` is whose drag it is, like the client id of another person. `delta` is how far the drag has moved the shapes since it began, in board units.

## FreehandShape

The box and the points of a freehand shape, as `freehandFromPoints` returns them.

```ts
type FreehandShape = ShapeGeometry & { points: string }
```

## StackPlace

Where `restackShapes` puts shapes: in front of all others, or behind them.

```ts
type StackPlace = 'front' | 'back'
```
