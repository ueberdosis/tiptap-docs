The package exports these functions and constants. All of them come from `@tiptap-pro/extension-whiteboard`. Positions and sizes on the board are in board units, and positions on the stage in screen pixels.

## Stage and camera

### attachStage()

Lets the user work with the board of `editor` in `stage`: pan and zoom, the zoom shortcuts, drawing with the shape tools and the selection box. A pan, with space held, the middle button or the hand tool, wins over drawing and selecting.

The stage needs `overflow: clip` and `touch-action: none`. The element that holds the editor sits in its top left corner, with `position: absolute`, `top: 0`, `left: 0` and `transform-origin: 0 0`. It moves with `toCssTransform(camera)`, and sets `--zoom` to the zoom.

| Option         | Type                     | Description                                                                                                                           |
| -------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `stage`        | `HTMLElement`            | The element around the board, which takes its presses and wheel turns                                                                 |
| `editor`       | `Editor`                 | The editor of the board                                                                                                               |
| `updateCamera` | `UpdateCamera`           | Moves the camera when the user pans, zooms or uses a zoom shortcut                                                                    |
| `fitInsets`    | `() => number \| Insets` | Optional. Room to keep free around shapes that Shift + 1 fits into view, like under panels. Defaults to 64 screen pixels at each edge |

#### Returns

`() => void`, a function that detaches everything again.

```js
import { attachStage } from '@tiptap-pro/extension-whiteboard'

const detach = attachStage({ stage, editor, updateCamera: setCamera })
```

### toCssTransform()

Returns the CSS transform that shows the board with the camera. The element that it moves needs `transform-origin: 0 0`.

| Argument | Type     | Description |
| -------- | -------- | ----------- |
| `camera` | `Camera` | The camera  |

#### Returns

`string`, the value for the element's `transform`.

```js
import { toCssTransform } from '@tiptap-pro/extension-whiteboard'

toCssTransform({ x: 100, y: 50, zoom: 2 }) // 'translate(100px, 50px) scale(2)'
```

### zoomAtStageCenter()

Changes the zoom around the middle of the stage, so the board stays put there.

| Option         | Type                       | Description                           |
| -------------- | -------------------------- | ------------------------------------- |
| `stage`        | `HTMLElement`              | The element around the board          |
| `updateCamera` | `UpdateCamera`             | Moves the camera                      |
| `nextZoom`     | `(zoom: number) => number` | Returns the new zoom for the zoom now |

```js
import { zoomAtStageCenter } from '@tiptap-pro/extension-whiteboard'

resetZoomButton.addEventListener('click', () => {
  zoomAtStageCenter({ stage, updateCamera: setCamera, nextZoom: () => 1 })
})
```

### stepZoom()

Returns the next zoom step in a direction, like for the zoom buttons of an app. A zoom between steps goes to the next step in that direction. The steps go from 10% to 400%.

| Option      | Type      | Description                      |
| ----------- | --------- | -------------------------------- |
| `zoom`      | `number`  | The zoom now, where 1 is 100%    |
| `direction` | `1 \| -1` | `1` to zoom in, `-1` to zoom out |

#### Returns

`number`, the next zoom.

```js
import { stepZoom } from '@tiptap-pro/extension-whiteboard'

stepZoom({ zoom: 1, direction: 1 }) // 1.25
stepZoom({ zoom: 0.8, direction: -1 }) // 0.75
```

### zoomToFitShapes()

Moves and zooms the camera so every shape is in the stage. It never zooms in beyond 100%, and does nothing on an empty board.

| Option         | Type               | Description                                                                                                                                           |
| -------------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stage`        | `HTMLElement`      | The element around the board                                                                                                                          |
| `editor`       | `Editor`           | The editor of the board                                                                                                                               |
| `updateCamera` | `UpdateCamera`     | Moves the camera                                                                                                                                      |
| `insets`       | `number \| Insets` | Optional. Room to keep free at the edges, the same at each edge or one for each, like to keep shapes out from under floating controls. Defaults to 64 |

```js
import { zoomToFitShapes } from '@tiptap-pro/extension-whiteboard'

zoomToFitShapes({ stage, editor, updateCamera: setCamera })
```

### scrollShapesIntoView()

Moves the camera as little as it can, so the shapes with the given ids are in the stage. It zooms out only when they don't fit, and does nothing when none of them are on the board.

| Option         | Type                | Description                                                                                     |
| -------------- | ------------------- | ----------------------------------------------------------------------------------------------- |
| `stage`        | `HTMLElement`       | The element around the board                                                                    |
| `editor`       | `Editor`            | The editor of the board                                                                         |
| `ids`          | `readonly string[]` | The ids of the shapes to show                                                                   |
| `updateCamera` | `UpdateCamera`      | Moves the camera                                                                                |
| `insets`       | `number \| Insets`  | Optional. Room to keep free at the edges, the same at each edge or one for each. Defaults to 64 |

```js
import { scrollShapesIntoView } from '@tiptap-pro/extension-whiteboard'

scrollShapesIntoView({ stage, editor, ids: ['note-1'], updateCamera: setCamera })
```

### fitCameraToRect()

Returns the camera that shows a part of the board in the middle of the stage, inside `insets`. It zooms out until the part fits, but never in beyond `largestZoom`, and keeps to the zoom limits `minZoom` and `maxZoom`.

| Option        | Type               | Description                                                                                     |
| ------------- | ------------------ | ----------------------------------------------------------------------------------------------- |
| `rect`        | `Rect`             | The part of the board to show, in board units                                                   |
| `viewport`    | `Size`             | The size of the stage, in screen pixels                                                         |
| `insets`      | `number \| Insets` | Optional. Room to keep free at the edges, the same at each edge or one for each. Defaults to 64 |
| `largestZoom` | `number`           | Optional. How far it may zoom in. Defaults to 1, which is 100%                                  |

#### Returns

`Camera`, the camera.

```js
import { fitCameraToRect } from '@tiptap-pro/extension-whiteboard'

const rect = { x: 0, y: 0, width: 1200, height: 800 }
const camera = fitCameraToRect({ rect, viewport: { width: 1000, height: 800 } })
```

### visibleBoardRect()

Returns the part of the board that the stage shows.

| Option     | Type     | Description                             |
| ---------- | -------- | --------------------------------------- |
| `camera`   | `Camera` | The camera of the board                 |
| `viewport` | `Size`   | The size of the stage, in screen pixels |

#### Returns

`Rect`, the part of the board, in board units.

```js
import { visibleBoardRect } from '@tiptap-pro/extension-whiteboard'

const seen = visibleBoardRect({ camera, viewport: { width: 1000, height: 800 } })
```

### clientToBoard()

Converts a point in window coordinates to board units, with the camera that the board shows.

| Option   | Type     | Description                                                                        |
| -------- | -------- | ---------------------------------------------------------------------------------- |
| `editor` | `Editor` | The editor of the board                                                            |
| `point`  | `Point`  | A point in window coordinates, like the `clientX` and `clientY` of a pointer event |

#### Returns

`Point | null`, the point in board units, or `null` while the editor shows no board, like before it is mounted or once it is destroyed.

```js
import { clientToBoard } from '@tiptap-pro/extension-whiteboard'

stage.addEventListener('pointermove', (event) => {
  const point = clientToBoard({ editor, point: { x: event.clientX, y: event.clientY } })

  if (point) {
    console.log(`The pointer is at ${point.x}, ${point.y} on the board`)
  }
})
```

### minZoom and maxZoom

The smallest zoom, `0.1` or 10%, and the largest zoom, `4` or 400%. The camera helpers never zoom out or in further.

## Content

### boardContent()

Builds the JSON of a board's document with the given shapes, for the content of an editor.

| Argument | Type            | Description                                           |
| -------- | --------------- | ----------------------------------------------------- |
| `shapes` | `JSONContent[]` | The JSON of the shapes, like from `stickyNoteContent` |

#### Returns

`JSONContent`, the JSON of the document.

```js
import { boardContent, stickyNoteContent } from '@tiptap-pro/extension-whiteboard'

editor.commands.setContent(boardContent([stickyNoteContent({ id: 'note', x: 0, y: 0 })]))
```

### stickyNoteContent()

Builds the JSON of a sticky note with one paragraph of text, for the content of a board. Without a size, the board gives the note `stickyNoteSize`. Takes the options of `textShapeContent`, without `type` and `kind`.

#### Returns

`JSONContent`, the JSON of the note.

```js
import { stickyNoteContent } from '@tiptap-pro/extension-whiteboard'

const note = stickyNoteContent({ id: 'note', x: 0, y: 0, text: 'Hello' })
```

### textShapeContent()

Builds the JSON of a shape with text, for the content of a board.

| Option      | Type                           | Description                                                        |
| ----------- | ------------------------------ | ------------------------------------------------------------------ |
| `type`      | `string`                       | The node type of the shape, like `stickyNote`, `geo` or `freeText` |
| `id`        | `string`                       | The id of the shape                                                |
| `x`, `y`    | `number`                       | Where the shape goes                                               |
| `width`     | `number`                       | Optional                                                           |
| `height`    | `number`                       | Optional                                                           |
| `zIndex`    | `string`                       | Optional                                                           |
| `color`     | `ShapeColor`                   | Optional                                                           |
| `fontSize`  | `ShapeStyleValue<'fontSize'>`  | Optional                                                           |
| `textAlign` | `ShapeStyleValue<'textAlign'>` | Optional                                                           |
| `font`      | `ShapeStyleValue<'font'>`      | Optional                                                           |
| `kind`      | `GeoKind`                      | Optional                                                           |
| `text`      | `string`                       | Optional. The text of the shape, in one paragraph                  |

#### Returns

`JSONContent`, the JSON of the shape.

```js
import { boardContent, textShapeContent } from '@tiptap-pro/extension-whiteboard'

const shape = textShapeContent({ type: 'geo', id: 'box', x: 0, y: 0, text: 'Hi' })

editor.commands.setContent(boardContent([shape]))
```

### freehandFromPoints()

Turns a line drawn in board units into the geometry of a freehand shape. The box leaves room for the stroke width, and the points are relative to its corner.

| Option        | Type               | Description                                                   |
| ------------- | ------------------ | ------------------------------------------------------------- |
| `points`      | `readonly Point[]` | The points of the line, in board units. It needs at least one |
| `strokeWidth` | `number`           | The width of the line, in board units                         |

#### Returns

`FreehandShape`, the box and the points of the freehand shape.

```js
import { freehandFromPoints } from '@tiptap-pro/extension-whiteboard'

const line = freehandFromPoints({
  points: [
    { x: 0, y: 0 },
    { x: 100, y: 40 },
  ],
  strokeWidth: 3,
})
const content = { type: 'freehand', attrs: { id: 'line', ...line, strokeWidth: 3 } }
```

### createShapeId()

Returns a new random version 4 UUID. Works off secure origins too, which have no `crypto.randomUUID`.

```js
import { createShapeId, stickyNoteContent } from '@tiptap-pro/extension-whiteboard'

const note = stickyNoteContent({ id: createShapeId(), x: 0, y: 0 })
```

## State

These functions read the state of the board's editor, `editor.state`.

### getSelectedShapeIds()

Returns the ids of the selected shapes in the order they were selected, as `readonly string[]`.

```js
import { getSelectedShapeIds } from '@tiptap-pro/extension-whiteboard'

editor.commands.bringToFront(getSelectedShapeIds(editor.state))
```

### isEditingText()

Tells whether the keyboard edits text. Otherwise it acts on the board and the selected shapes.

```js
import { isEditingText } from '@tiptap-pro/extension-whiteboard'

isEditingText(editor.state) // false while the board has the keyboard
```

### getEditedShapeId()

Returns the id of the shape whose text the keyboard edits, or `null` while the board has the keyboard.

```js
import { getEditedShapeId } from '@tiptap-pro/extension-whiteboard'

getEditedShapeId(editor.state) // 'note' while its text is edited
```

### getActiveTool()

Returns the tool that a press on the board uses: `select` unless `setTool` chose another one.

```js
import { getActiveTool } from '@tiptap-pro/extension-whiteboard'

getActiveTool(editor.state) // 'select'
```

### getNextShapeStyles()

Returns the styles that `setShapeStyle` chose for new shapes, as `Partial<ShapeStyles>`. A style that is not set keeps the default of each kind of shape.

```js
import { getNextShapeStyles } from '@tiptap-pro/extension-whiteboard'

getNextShapeStyles(editor.state).color // undefined until `setShapeStyle` chooses one
```

### getToolShapeType()

Returns the node type of the shapes that a tool adds, or `null` for a tool that adds none.

```js
import { getToolShapeType } from '@tiptap-pro/extension-whiteboard'

getToolShapeType('note') // 'stickyNote'
getToolShapeType('hand') // null
```

### isTypingTarget()

Tells whether keys pressed on a target type text: in a field, or in editable content like the edited text of a shape or the editor of a doc frame. Takes the target of a keyboard event, as `EventTarget | null`.

```js
import { isTypingTarget } from '@tiptap-pro/extension-whiteboard'

// In a keydown listener for the app's own shortcuts
if (event.key === '?' && !isTypingTarget(event.target)) showShortcuts()
```

### focusBoard()

Gives the keyboard to the board, or to the text while it is edited. Unlike ProseMirror's `focus`, it also works while the text is read-only. Takes the view of the editor.

```js
import { focusBoard } from '@tiptap-pro/extension-whiteboard'

// After a click on a button of the app
focusBoard(editor.view)
```

## Shapes

### findShapes()

Finds the shapes with the given ids.

| Option | Type                | Description                                        |
| ------ | ------------------- | -------------------------------------------------- |
| `doc`  | `Node`              | The document of the board, like `editor.state.doc` |
| `ids`  | `readonly string[]` | The ids of the shapes                              |

#### Returns

`NodeWithPos[]`, the shapes with their positions, in document order. Unknown ids are skipped.

```js
import { findShapes } from '@tiptap-pro/extension-whiteboard'

const [note] = findShapes({ doc: editor.state.doc, ids: ['note-1'] })
```

### hasBoxGeometry()

Tells whether a shape has a box from `x`, `y`, `width` and `height`. Arrows don't. Takes the node of the shape.

```js
import { findShapes, hasBoxGeometry } from '@tiptap-pro/extension-whiteboard'

const shapes = findShapes({ doc: editor.state.doc, ids })
const boxes = shapes.filter(({ node }) => hasBoxGeometry(node))
```

### docIdOf()

Returns the id of the document that a doc frame shows, from its node or the node's JSON. Frames without one use their shape id, so they still get a document of their own.

```js
import { docIdOf, findShapes } from '@tiptap-pro/extension-whiteboard'

const [frame] = findShapes({ doc: editor.state.doc, ids: ['frame'] })
const docId = frame && docIdOf(frame.node)
```

## Transactions

For code that builds its own transaction, like an AI tool. Each function makes the transaction its own undo step, and leaves dispatching it to you.

### insertShapesInFront()

Adds shapes in front of all others, from back to front in the order of `shapes`, unless their z-indexes order them otherwise.

| Option   | Type              | Description                                                  |
| -------- | ----------------- | ------------------------------------------------------------ |
| `tr`     | `Transaction`     | The transaction to add the shapes in, like `editor.state.tr` |
| `shapes` | `readonly Node[]` | The shapes to add                                            |

#### Returns

`number | null`, the position of the first shape, or `null` when it added none. Throws a `RangeError` when one of `shapes` has no id, or one that the board or another of `shapes` has.

```js
import {
  createShapeId,
  insertShapesInFront,
  stickyNoteContent,
} from '@tiptap-pro/extension-whiteboard'

const { tr, schema } = editor.state
const note = stickyNoteContent({ id: createShapeId(), x: 0, y: 0, text: 'Idea' })

insertShapesInFront({ tr, shapes: [schema.nodeFromJSON(note)] })
editor.view.dispatch(tr)
```

### removeShapes()

Deletes the shapes with the given ids. Arrows that connect a deleted shape stay, with a free end where they touched it.

| Option | Type                | Description                                                     |
| ------ | ------------------- | --------------------------------------------------------------- |
| `tr`   | `Transaction`       | The transaction to delete the shapes in, like `editor.state.tr` |
| `ids`  | `readonly string[]` | The ids of the shapes                                           |

#### Returns

`boolean`, whether any of the shapes were on the board.

```js
import { removeShapes } from '@tiptap-pro/extension-whiteboard'

const { tr } = editor.state
removeShapes({ tr, ids: ['note-1'] })
editor.view.dispatch(tr)
```

### restackShapes()

Moves the shapes with the given ids in front of or behind all other shapes, and keeps their order among each other. Only the moved shapes get new z-indexes, unless missing or invalid ones leave no room.

| Option  | Type                | Description                                                   |
| ------- | ------------------- | ------------------------------------------------------------- |
| `tr`    | `Transaction`       | The transaction to move the shapes in, like `editor.state.tr` |
| `ids`   | `readonly string[]` | The ids of the shapes                                         |
| `place` | `StackPlace`        | `front` or `back`                                             |

#### Returns

`boolean`, whether any of the shapes are on the board.

```js
import { restackShapes } from '@tiptap-pro/extension-whiteboard'

const { tr } = editor.state
restackShapes({ tr, ids: ['note-1'], place: 'back' })
editor.view.dispatch(tr)
```

### keepShapeHeights()

Keeps the heights that a transaction gives its shapes, for content that arrives later, like the document of a doc frame that an AI writes after it adds the frame. Returns the same transaction.

```js
import { keepShapeHeights } from '@tiptap-pro/extension-whiteboard'

const { tr } = editor.state
// … add a doc frame whose document arrives later
editor.view.dispatch(keepShapeHeights(tr))
```

## Doc frames

### getDocEditors()

Returns the editors of the documents that the doc frames on the board show, and none once the board's editor is destroyed. Takes the board's editor.

```js
import { getDocEditors } from '@tiptap-pro/extension-whiteboard'

const documents = getDocEditors(editor).map((docEditor) => docEditor.getJSON())
```

### getEditedDocEditor()

Returns the editor of the document that a doc frame edits, or `null` while none is edited, like once the board's editor is destroyed. Takes the board's editor.

```js
import { getEditedDocEditor } from '@tiptap-pro/extension-whiteboard'

// A bold button that works in documents too
const textEditor = getEditedDocEditor(editor) ?? editor
textEditor.commands.toggleBold()
```

## Collaboration

### createRemoteMoves()

Shows the drags of other people on the board of `editor`. Their shapes and the arrows that connect them move, but the document doesn't change: the drop of the other person changes it. Takes the board's editor.

#### Returns

`RemoteMoves`, with two functions:

- `show({ owner, ids, delta })` shows the shapes of `owner`'s drag, moved by `delta`. `owner` is whose drag it is, like the client id of another person.
- `end(owner)` ends the drag of `owner`. Its shapes show as the document has them.

```js
import { createRemoteMoves } from '@tiptap-pro/extension-whiteboard'

const moves = createRemoteMoves(editor)
moves.show({ owner: clientId, ids: ['note'], delta: { x: 40, y: 0 } })
moves.end(clientId)
```

## Constants

| Constant         | Value                                                                     | Description                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `geoKinds`       | `['rectangle', 'ellipse', 'diamond', 'triangle']`                         | The kinds of geometric shapes                                                                                                           |
| `shapeColors`    | `['black', 'gray', 'red', 'orange', 'yellow', 'green', 'blue', 'violet']` | The colors a shape can have. Shapes store the name, and styles decide how it looks                                                      |
| `shapeStyles`    | `{ color, fontSize, textAlign, font, arrowheads }`                        | The styles of shapes, with the names of their values. See [Shapes and tools](/whiteboard/guides/shapes-and-tools#styles-for-new-shapes) |
| `stickyNoteSize` | `{ width: 220, height: 160 }`                                             | The size of a sticky note that is given none                                                                                            |
| `toolKeys`       | `{ select: 'v', hand: 'h', note: 'n', … }`                                | The key that chooses each tool while the board has the keyboard                                                                         |
| `minZoom`        | `0.1`                                                                     | The smallest zoom, 10%                                                                                                                  |
| `maxZoom`        | `4`                                                                       | The largest zoom, 400%                                                                                                                  |
| `boardStyles`    | `string`                                                                  | The CSS that the board needs. See [Styling](/whiteboard/api-reference/styling#the-boards-css)                                           |

```js
import { shapeColors, toolKeys } from '@tiptap-pro/extension-whiteboard'

const swatches = shapeColors.map((color) => ({ label: color, color }))
const penTooltip = `Pen (${toolKeys.pen.toUpperCase()})`
```
