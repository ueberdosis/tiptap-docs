## Install

First, [contact our team](https://tiptap.dev/contact-sales?form=pilot-program) for access to the Whiteboard pilot program.

After gaining access, configure your package manager by following the [private registry guide](/guides/pro-extensions).

Then, install the package:

```bash
npm install @tiptap-pro/extension-whiteboard
```

<Callout title="Required Tiptap version" variant="warning" hasCalloutAfter>

The package needs `@tiptap/core` and `@tiptap/pm` 3.22.5 or later. The text extensions that shapes use come with it as dependencies: `@tiptap/extension-bold`, `-code`, `-highlight`, `-italic`, `-link`, `-list`, `-paragraph`, `-strike`, `-text` and `@tiptap/extensions`.

Recent Tiptap releases pin `@tiptap/core` to their exact version, so keep all `@tiptap/*` packages on one version. If your app stays on an older version, install these extensions at that version too, for example with `npm install @tiptap/extension-highlight@3.25.0`.

</Callout>

<Callout title="Leave out Document and StarterKit" variant="warning" hasCalloutBefore>
  `WhiteboardKit` brings its own document node, so don't add `Document` or `StarterKit` to the
  editor of a board.
</Callout>

Collaboration is optional and lives in `@tiptap-pro/extension-whiteboard/collaboration`, the only entry that needs Yjs. See [Collaboration on the board](/whiteboard/guides/collaboration).

## Basic setup

A board needs two elements on your page: the stage, which takes pointer and wheel events, and the viewport inside it, which the camera moves. Create the editor in `viewport`, and connect it to `stage` with `attachStage`:

```js
import { Editor } from '@tiptap/core'
import { attachStage, toCssTransform, WhiteboardKit } from '@tiptap-pro/extension-whiteboard'

const editor = new Editor({ element: viewport, extensions: [WhiteboardKit] })
let camera = { x: 0, y: 0, zoom: 1 }

// Pan, zoom, draw and select in the stage, the element around the board
const detach = attachStage({
  stage,
  editor,
  updateCamera: (update) => {
    camera = update(camera)
    viewport.style.transform = toCssTransform(camera)
    viewport.style.setProperty('--zoom', String(camera.zoom))
  },
})
```

`attachStage` calls `updateCamera` with a function that turns the old camera into the new one, and returns a function that detaches everything again.

The stage needs `position: relative`, `overflow: clip` and `touch-action: none`. The viewport sits in its top left corner, with `position: absolute`, `top: 0`, `left: 0` and `transform-origin: 0 0`:

```css
.stage {
  height: 32rem;
  overflow: clip;
  position: relative;
  touch-action: none;
}

.viewport {
  left: 0;
  position: absolute;
  top: 0;
  transform-origin: 0 0;
}

/* The board's origin sits in the corner of the viewport, so the editor keeps no margin */
.viewport .tiptap {
  margin: 0;
}
```
