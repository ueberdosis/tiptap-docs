Shapes are nodes, so they can carry the suggestions of [Tracked Changes](/tracked-changes/getting-started/overview), like a note that an AI agent suggests. The board shows those suggestions on the shapes, and the commands of Tracked Changes review them.

## Set up the editor

[Install Tracked Changes](/tracked-changes/getting-started/install), and add it to the board's editor. Pass `getSuggestionHTMLAttributes` from Tracked Changes as the `shapeElementAttributes` option of `WhiteboardKit`:

```ts
import { Editor } from '@tiptap/core'
import { getSuggestionHTMLAttributes, TrackedChanges } from '@tiptap-pro/extension-tracked-changes'
import { WhiteboardKit } from '@tiptap-pro/extension-whiteboard'

const editor = new Editor({
  element: viewport,
  extensions: [
    WhiteboardKit.configure({ shapeElementAttributes: getSuggestionHTMLAttributes }),
    TrackedChanges,
  ],
})
```

`shapeElementAttributes` adds attributes to the element of every shape, from the shape's node. With `getSuggestionHTMLAttributes`, the element of a shape that a suggestion changes gets `data-suggestion-*` attributes, like `data-suggestion-type` and `data-suggestion-user`.

Tracked Changes starts with `enabled: false`. Edits on the board then apply directly, and the board shows the suggestions that shapes carry.

## Show suggestions

Style the shapes that suggestions change with the attributes on their elements:

```css
/* A shape that a suggestion adds */
[data-shape][data-suggestion-type='add'] {
  outline: calc(2px / var(--zoom, 1)) dashed #2b9a66;
}

/* A shape that a suggestion deletes */
[data-shape][data-suggestion-type='delete'] {
  opacity: 0.5;
}

/* A shape that a suggestion moves or changes */
[data-shape][data-suggestion-type='attributeChange'] {
  outline: calc(2px / var(--zoom, 1)) dashed #0d74ce;
}
```

The attributes go away once the suggestion is reviewed. Suggestions in the text of a shape show like in any other document. See [Styling](/tracked-changes/api-reference/styling) for all attributes.

## Review suggestions

Find suggestions with `findSuggestions`, and accept or reject them by id:

```ts
import { findSuggestions } from '@tiptap-pro/extension-tracked-changes'

const [suggestion] = findSuggestions(editor)

if (suggestion) {
  editor.commands.acceptSuggestion({ id: suggestion.id })
}
```

A suggestion that adds shapes lists them in `insertedNodes`, like `{ type: 'stickyNote' }`. When a suggestion covers several shapes, like all the notes of one AI answer, one id accepts or rejects them all.

| Suggestion       | Accept              | Reject                   |
| ---------------- | ------------------- | ------------------------ |
| Adds a shape     | Keeps the shape     | Removes the shape        |
| Deletes a shape  | Removes the shape   | Keeps the shape          |
| Moves a shape    | Keeps the new place | Puts the shape back      |
| Changes its text | Keeps the new text  | Brings back the old text |

When a rejected suggestion removes a shape, the arrows that connected it keep a free end. Reviews work in collaborative boards too: everyone sees the suggestion, and a review applies everywhere.
