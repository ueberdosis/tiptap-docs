## What you can do with it

- **Choose a page format.** A4, A3, A5, Letter, Legal, and Tabloid come built in, or define your own size and margins. [Page format](/pages/core-concepts/page-format)
- **Add headers and footers.** Write them as text, HTML, or Tiptap JSON, with `{page}` and `{total}` placeholders. The first page and odd and even pages can differ, as in Word. [Page header and footer](/pages/core-concepts/page-header-footer)
- **Add footnotes and endnotes.** Footnotes number themselves and sit above each page's footer; endnotes collect at the end of the document. [Footnotes](/pages/core-concepts/footnotes), [Endnotes](/pages/core-concepts/endnotes)
- **Edit in place.** Double-click a header, footer, footnotes, or endnotes area to edit it in a full Tiptap editor. These editors join the same collaborative session. [Adding collaboration to Pages](/pages/guides/collaboration-with-pages)
- **Break pages.** Insert explicit page breaks, or let Pages break automatically. [PageBreak node](/pages/core-concepts/page-break-node)
- **Zoom.** Scale the view between 0.25 and 4 without changing the content or the export. [Zoom](/pages/core-concepts/zoom)
- **Paginate tables.** Tables shrink to fit the page, and tall rows split across pages. [PagesTableKit](/pages/guides/pages-tablekit), [Rows that span a page break](/pages/guides/row-fragmentation)
- **Import and export with Word.** With Conversion, imported DOCX headers, footers, footnotes, and endnotes apply themselves, and exports keep them. [From zero to print-ready](/pages/guides/zero-to-print-ready)

Pages is a layout layer and ships no schema. Install it with ConvertKit, which brings a DOCX-aware schema, and PagesTableKit, which brings tables that paginate:

```bash
npm install @tiptap-pro/extension-convert-kit \
            @tiptap-pro/extension-pages-tablekit \
            @tiptap-pro/extension-pages
```

Turn off ConvertKit's tables so PagesTableKit's take over:

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { TableKit } from '@tiptap-pro/extension-pages-tablekit'
import { Pages } from '@tiptap-pro/extension-pages'

const editor = new Editor({
  extensions: [
    ConvertKit.configure({ table: false }),
    TableKit,
    Pages.configure({
      pageFormat: 'A4',
      header: 'My document',
      footer: 'Page {page} of {total}',
    }),
  ],
})
```

[Install](/pages/getting-started/install) walks through the whole setup.

## Know the limits

- **Blocks taller than a page:** A block that can't split, such as a figure or a nested table, and is taller than a page makes the layout loop forever. [Limitations](/pages/core-concepts/limitations#oversized-non-splittable-blocks-cause-an-infinite-layout-loop) shows how to prevent it.
- **Same layout on every page:** There is no per-page styling and no page template.
- **No browser printing:** Export to PDF with [Conversion](/conversion/getting-started/overview) instead.
- **Beta:** Minor versions may break the API. Pin exact package versions.
