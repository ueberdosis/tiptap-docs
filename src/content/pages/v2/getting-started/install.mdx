Page Layout is a Pro package. Install it from Tiptap's private registry, then build an editor with `createPageLayoutEditor`.

## Set up the registry

Point your project at Tiptap's registry once. Keep the token in an environment variable and never commit it. On CI, set `TIPTAP_PRO_TOKEN` in the environment.

```ini
; .npmrc
@tiptap-pro:registry=https://registry.tiptap.dev/
//registry.tiptap.dev/:_authToken=${TIPTAP_PRO_TOKEN}
```

See [Pro extensions](/guides/pro-extensions) to get your token.

## Install the package

```bash
npm install @tiptap-pro/extension-page-layout
```

The engine brings no content types of its own. Paragraphs, headings, lists and tables come from the extensions you already register, such as `@tiptap/starter-kit`. The other packages that work with Page Layout are listed in the [overview](/pages/v2/getting-started/overview#packages).

## Build a first editor

```js
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [StarterKit, PageLayout.configure({ setup: pageSetup('A4') })],
})
```

This gives you a paginated editor on A4. Using React? Read [Page Layout in React](/pages/v2/getting-started/react).

## Options of createPageLayoutEditor

`createPageLayoutEditor` returns a Tiptap `Editor`. These options mean what they mean on `new Editor`.

| Option                                                                | What it does                                                                 |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `element`, `content`, `extensions`                                    | Required. `content` is Tiptap JSON.                                          |
| `editable`, `autofocus`                                               | Work as on any editor.                                                       |
| `injectCSS`, `injectNonce`                                            | Work as on any editor, and apply to the page rules too.                      |
| `onBeforeCreate`, `onCreate`, `onDestroy`                             | Work as on any editor.                                                       |
| `onUpdate`, `onSelectionUpdate`, `onTransaction`, `onFocus`, `onBlur` | Work as on any editor. `update` fires only when the document changes.        |
| `onChange`                                                            | Runs after every change once the pages are drawn, including a page-only one. |

Two things to know:

- `createPageLayoutEditor` does not accept `editorProps`. The pagination owns the editor's `dispatchTransaction`, and you set the scroll margin with the `scrollMargin` option of `PageLayout`.
- You cannot add pages to an editor that already exists. `PageLayout` in an editor built with `new Editor` draws no pages. Its commands answer `false`. The console then warns that `PageLayout is in an Editor that createPageLayoutEditor did not build`. An editor without an element, which loads or converts a document without showing it, does not warn.

## Move an existing editor to Page Layout

Most of an existing Tiptap integration carries over unchanged. Extensions, toolbar commands, `onUpdate`, `getJSON()` and `setContent()` keep working. Three things change:

1. Build the editor with `createPageLayoutEditor` instead of `new Editor`, or with `usePageLayoutEditor` instead of `useEditor` in React.
2. Read and write document positions through `editor.storage.pageLayout.engine.getSourceState()`, not `editor.state`.
3. Set up collaboration with the `source` option of `PageLayout`, not as an extension.

`editor.state` holds the pages the reader sees, not the document. Never save it. Save what `getJSON()` or `getHTML()` returns.

<Callout title="Collaboration extensions are refused" variant="warning">
  `createPageLayoutEditor` throws when the extensions include `collaboration`, `collaborationCaret`
  or `collaborationCursor`, before anything is shown or shared.
</Callout>
