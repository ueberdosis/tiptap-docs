Page Layout shows a Tiptap editor as real sheets, such as A4 or Letter, in portrait or landscape. Text flows from one sheet to the next as you type. The caret, selection, clipboard, IME composition and screen readers behave as they do in any Tiptap editor. This is because the pages are made of the same editable content.

</Callout>

## What gets stored

The stored document is an ordinary Tiptap document. It has no page nodes, no automatic page breaks and no continuation rows. The JSON you save, export or index is the content. Page Layout works out the pages from it each time the document opens.

```js
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [StarterKit, PageLayout.configure({ setup: pageSetup('A4') })],
})
```

`createPageLayoutEditor` returns a Tiptap `Editor` and takes the options of one, such as `onUpdate`, `onSelectionUpdate` and `editable`. Commands at the cursor, extensions and events work as they do without pages.

## What you get

- Paper, margins and orientation. Twenty-one formats are built in, and you can define any size of your own for the whole document or for a run of it.
- Page colors for the paper, the text and an accent, for the document or one section.
- Headers and footers per section, with a different first page and different odd and even pages if you want them.
- [Tables that cross a page boundary](/pages/v2/extensions/tables). A row continues on the next page, a header row repeats, and you choose per row whether it may be cut.
- [Footnotes and endnotes](/pages/v2/extensions/footnotes) that renumber as the text moves.
- Section columns, where text fills one column to the bottom of the page and carries on in the next.
- Page, column and section breaks at the cursor.
- Pageless mode, which shows the same document as one continuous column and switches at runtime.
- Zoom at a factor or fitted to the window. Zooming does not change where pages break.
- Printing from the browser, and PDF from a server, with the sheets the reader saw.
- Collaboration that shares only the document. Each person has their own pages, so page counts can differ. With `awareness` passed, each person sees the other's cursor where it lands in their own pages.

## Packages

Page Layout is the engine. The other packages add content types and work in any Tiptap editor, with pages or without them. [Extensions on pages](/pages/v2/extensions/overview) says what each one does at a page boundary.

| Package                                                                             | What it does                                                                                                          |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `@tiptap-pro/extension-page-layout`                                                 | The engine. Pages, sections, breaks, headers and footers, and how tables and lists behave at a page boundary.         |
| `@tiptap-pro/extension-page-layout-react`                                           | `usePageLayoutEditor`, the paginated editor as a React hook.                                                          |
| [`@tiptap-pro/extension-footnotes`](/pages/v2/extensions/footnotes)                 | Footnotes and endnotes.                                                                                               |
| [`@tiptap-pro/extension-outline-numbering`](/pages/v2/extensions/outline-numbering) | Numbers on headings and clauses.                                                                                      |
| [`@tiptap-pro/extension-cross-references`](/pages/v2/extensions/cross-references)   | Targets and references to them.                                                                                       |
| [`@tiptap-pro/extension-bookmark`](/pages/v2/extensions/bookmarks)                  | Bookmarks, as Word has them.                                                                                          |
| [`@tiptap-pro/extension-document-styles`](/pages/v2/extensions/document-styles)     | Named styles, their definitions stored in the document, and libraries of them.                                        |
| [`@tiptap-pro/extension-number-formats`](/pages/v2/extensions/number-formats)       | The number formats the other packages write in, and the extension that stores formats and a language in the document. |
| [`@tiptap-pro/extension-whole-blocks`](/pages/v2/extensions/whole-blocks)           | Blocks that are selected whole are deleted, cut and copied as blocks.                                                 |
| [`@tiptap-pro/extension-columns`](/pages/v2/extensions/columns)                     | Containers side by side, each with its own content.                                                                   |
