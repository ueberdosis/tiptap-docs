Every command except `toggleBookmarkVisibility` returns `false` where it would do nothing, and `editor.can()` checks without doing it. `toggleBookmarkVisibility` always returns `true`. See [bookmarks](/pages/v2/extensions/bookmarks) for what a bookmark is.

| Command                              | What it does                                                    |
| ------------------------------------ | --------------------------------------------------------------- |
| `addBookmark(options?)`              | Adds a bookmark on the selection, or a point where it is empty. |
| `removeBookmark(id?)`                | Takes the bookmark out and keeps its text.                      |
| `renameBookmark(name, id?)`          | Gives the bookmark another name and keeps its id.               |
| `goToBookmark(id)`                   | Selects the bookmark and scrolls to it.                         |
| `toggleBookmarkVisibility(visible?)` | Shows or hides the underline on every bookmark.                 |

## addBookmark(options?)

```js
editor.commands.addBookmark() // named after the selected words
editor.commands.addBookmark({ name: 'Price' })
editor.commands.addBookmark({ name: '_Ref42', hidden: true })
editor.commands.addBookmark({ name: 'Spot', from: 12, to: 12 })
```

- `name` is a name Word accepts. See [names](/pages/v2/extensions/bookmarks#names). Without one, the command names the bookmark after the selected words, or `Bookmark` where there are none.
- `hidden` says whether the name may start with `_`.
- `from` and `to` are the range. The default is the selection. An empty range is a bookmark on no text.

A name the document already has moves that bookmark here and keeps its id. The command returns `false` where the name isn't valid, or where nothing in the range can carry a bookmark, such as a horizontal rule or an image.

## removeBookmark(id?)

Removes the bookmark with that `id`, or the smallest one around the selection. Its text stays.

```js
editor.commands.removeBookmark()
```

## renameBookmark(name, id?)

Renames the bookmark with that `id`, or the one around the selection. Its id stays, so references and links by id follow. The command returns `false` where the name isn't valid, is the one it already has, or belongs to another bookmark.

```js
editor.commands.renameBookmark('Cost')
```

## goToBookmark(id)

Puts the selection on the bookmark and scrolls it into view. Where you gave the extension a `reveal` option, `reveal` runs instead.

```js
editor.commands.goToBookmark(bookmarkByName(editor.state.doc, 'Price').id)
```

## toggleBookmarkVisibility(visible?)

Shows or hides the bookmarks in the text, or switches them where you leave out `visible`. It writes nothing to the document.

```js
editor.commands.toggleBookmarkVisibility(true)
```

## Write with transactions

Each command except the last has a function that returns the transaction instead of dispatching it. It returns `null` where the command would return `false`. Use them to write to a document the editor doesn't show, or to add to the same step as something else.

| Command          | Function                                               |
| ---------------- | ------------------------------------------------------ |
| `addBookmark`    | `addBookmarkTransaction(state, options?)`              |
| `removeBookmark` | `removeBookmarkTransaction(state, id, options?)`       |
| `renameBookmark` | `renameBookmarkTransaction(state, id, name, options?)` |
| `goToBookmark`   | `goToBookmarkTransaction(state, id, options?)`         |

`options` takes `ignore`, as the read functions do. `isBookmarkNameFree(state, name, { except })` says whether a name is free. `except` is the id of a bookmark that may keep its own name.

```js
import { addBookmarkTransaction } from '@tiptap-pro/extension-bookmark'

const tr = addBookmarkTransaction(state, { name: 'Price' })
if (tr) view.dispatch(tr)
```
