A reference that names several targets reads them by a rule. You choose the rule per reference, or for every reference at once. Turn on `multiple: true` first. See [one reference, several targets](/pages/v2/extensions/cross-references#one-reference-several-targets).

The package comes with three rules:

| Rule     | Reads                                                                                                                                   |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `list`   | `3, 5 and 7`, with `listSeparator` between them and `lastSeparator` before the last. This is the default.                               |
| `commas` | `3, 5, 7`, with `listSeparator` between all of them.                                                                                    |
| `range`  | Three or more numbers that follow each other become one range, written with `rangeSeparator`. The rest is listed, as in `3 to 5 and 7`. |

```js
import { CrossReferences } from '@tiptap-pro/extension-cross-references'

CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  join: 'range', // for every reference that names no rule
})

editor.commands.insertCrossReference({
  targets: ['three', 'four', 'five'],
  show: 'number',
  join: 'commas',
})
editor.commands.setCrossReferenceOptions({ join: null }) // back to the configured rule
```

- `join` on `CrossReferences` is the rule a reference without one of its own is read by. The default is `list`.
- `join` on a reference is the id of a rule, or `null` for the configured one. It is written to HTML as `data-tt-join`. A rule nobody registered reads as the configured one.

The words between targets are [phrases](/pages/v2/extensions/cross-references#how-a-reference-is-shown). `listSeparator` is `, ` by default, `lastSeparator` is `and` and `rangeSeparator` is an en dash:

```js
CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  phrases: { lastSeparator: ' und ', rangeSeparator: ' bis ' },
})
// 3 bis 5 und 7
```

## Ranges

Two numbers follow each other where they are on the same level under the same parent and the second is one more. `3.2` follows `3.1`, and `4` follows `3`. `4.1` doesn't follow `3.9`.

The rule reads this from `counts` on the target's label, so a target whose label has no `counts` is never part of a range. A range is made of three or more. Two that follow each other read `3 and 4`.

The targets are taken in the order the reference names them. `range` makes no range of a reference that shows no number, such as its text or its page.

## Your own rule

You register a rule under an id. An id the package already has replaces its rule:

```js
CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  joins: {
    alternatives: {
      title: '3, 5 or 7',
      pieces: ({ parts, phrases }) =>
        parts.flatMap((_part, index) =>
          index === 0
            ? [index]
            : [index === parts.length - 1 ? ' or ' : phrases.listSeparator, index],
        ),
    },
  },
})

editor.commands.insertCrossReference({ targets: ['three', 'five', 'seven'], join: 'alternatives' })
// 3, 5 or 7
```

- `title` is what a picker lists it as.
- `pieces({ parts, phrases, numbered })` returns what the reference reads, in order. A number is the part at that index. A string is text between parts.

`pieces` gets these values:

- `parts` has one entry per target, in the order the reference names them: `{ text, target }`. `text` is what it reads of that target. `target` is the target as `crossReferenceTargetsIn` lists it, or `null` for one that is gone or [withheld](/pages/v2/extensions/cross-references#withheld-targets).
- `phrases` are the configured phrases.
- `numbered` says whether the reference shows a number.

Each part is read once, at its first index. An index that isn't a part, or a part named a second time, is left out. A part the rule leaves out isn't read, as with the `4` of `3 to 5`. A reference naming one target reads that target whatever its rule.

`crossReferenceJoinChoices(joins)` lists the rules a picker offers as `{ id, title }`, the built-in ones first and then yours. Pass `editor.storage.crossReferences.joins`.

## In Word

A `.docx` gets the same pieces. Each part the rule reads is a field, and the text between them is plain text, with the configured phrases. See [Word fields](/pages/v2/extensions/cross-references/docx).
