The sheets on screen are the sheets that come out. Page Layout doesn't lay anything out a second time for the printer.

## Print from the browser

Page Layout ships its own print rules, so this is all you need:

```js
window.print()
```

Each page becomes one sheet at the size it was planned for. A document whose sections use different paper prints each section on its own paper. To get a PDF, choose the PDF destination in the print dialog of the browser.

No sheet is split in two, and no page has a margin from the paper, because the margins are inside the page. A zoom the reader set is taken off for the print and put back afterwards. See [zoom](/pages/v2/core-concepts/zoom#what-page-layout-takes-care-of).

With `virtualization` on, only the sheets near the reader carry their text. Page Layout draws every sheet from `beforeprint` to `afterprint`, so the printout is the whole document. See [long documents](/pages/v2/guides/long-documents#printing).

## Mixed paper sizes

A print job has one set of page rules, so Page Layout names each sheet by its size. It writes one named `@page` rule per size and puts the name on each sheet. Two sections of the same format share a rule.

`printSheetName` returns that name for a size in pixels:

```js
import { printSheetName } from '@tiptap-pro/extension-page-layout'

printSheetName({ width: 794, height: 1123 }) // 'pl-sheet-794x1123'
```

You need it only when you address the sheets of one format yourself, for example in your own print stylesheet.

## Safari

Safari prints every sheet on the paper of the first page. A page in another format is fitted onto that paper instead. A landscape page on portrait paper is turned to lie upright, with its top at the left edge. A larger page is scaled down to fit.

The other pages keep their size, and every page still holds the same text. Nothing else changes in the pagination.

## What isn't available

- Page Layout doesn't write a PDF file. The browser does, from its print dialog.
- Safari fits pages of another format instead of printing them on their own paper. See [limitations](/pages/v2/core-concepts/limitations#printing).
