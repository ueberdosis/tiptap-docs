The `PageLayout` extension adds these commands to `editor.commands`. They chain and work with `editor.can()`.

```js
editor.commands.insertSectionBreak('nextPage')
editor.can().insertPageBreak()
```

A command that can't do anything where the cursor is returns `false` and changes nothing. Use that to disable a toolbar button.

Every command writes to the document, not to the pages. It needs an editor built with `createPageLayoutEditor`. In any other editor each command returns `false`.

Some commands read a section index or the section at the cursor. Get those from the engine:

```js
const engine = editor.storage.pageLayout.engine

engine.getSections() // sections in order, section 0 holds the document's own page setup
engine.getActiveSectionIndex() // the section at the cursor, or the one whose header or footer is open
```

## Breaks

See [breaks](/pages/v2/core-concepts/breaks).

### insertPageBreak()

Ends the page at the cursor and puts the cursor at the top of the next one.

```js
editor.commands.insertPageBreak()
```

### removePageBreak()

Removes the manual page break at the cursor or just before it.

```js
editor.commands.removePageBreak()
```

### insertColumnBreak()

Ends the column at the cursor. In a section with one column, it ends the page.

```js
editor.commands.insertColumnBreak()
```

### insertSectionBreak(kind?)

Starts a section at the cursor. `kind` is `'nextPage'` (default) or `'continuous'`. The new section starts with the setup of the one it was split from.

```js
editor.commands.insertSectionBreak('continuous')
```

## Page format and sections

See [sections](/pages/v2/core-concepts/sections).

### setPageSetup(setup)

Sets the page setup this editor shows when the document names none. `setup` is a `PageSetup` or `null` for no pages.

```js
editor.commands.setPageSetup(pageSetup('Letter'))
editor.commands.setPageSetup(null)
```

This is a setting of the editor. It is not saved, and collaborators don't see it. Passing a setup returns `false` while the editor shows pages and the document names its own page setup. Use `setSectionSetup(0, setup)` then. `null` always works, and so does a setup in an editor that has no pages.

### setSectionSetup(sectionIndex, setup)

Sets the page setup of one section.

```js
const index = engine.getActiveSectionIndex()
const current = engine.getSections()[index].setup

editor.commands.setSectionSetup(index, { ...current, orientation: 'landscape' })
```

Spread the current setup. A fresh one resets margins, colors, columns and note settings. Returns `false` for an index that doesn't exist, and in an editor without pages.

### setPageSections(sections)

Replaces all sections at once. Each entry has `startBlockIndex`, `setup` and an optional `kind`.

```js
editor.commands.setPageSections([
  { startBlockIndex: 0, setup: pageSetup('A4') },
  { startBlockIndex: 12, setup: pageSetup('A4', { orientation: 'landscape' }) },
])
```

Existing breaks are replaced. A single entry for block 0 leaves one section.

### setSectionColumns(columns)

Sets columns for the blocks the selection covers. It puts section breaks around them, or reuses the breaks already there. With only a cursor, it sets the columns of the section the cursor is in.

```js
editor.commands.setSectionColumns({ count: 3, gaps: null, rule: false, widths: null })
```

### removeSection(sectionIndex)

Removes the break of a section, so its content joins the section above. Section 0 can't be removed.

```js
editor.commands.removeSection(2)
```

### setPageNumbering(numbering)

Sets how the pages of the section at the cursor are numbered. Pass only what changes.

```js
editor.commands.setPageNumbering({ format: 'lowerRoman' })
editor.commands.setPageNumbering({ start: 1 })
editor.commands.setPageNumbering({ start: null }) // carry on from the section before
```

`format` is a number format, `start` is a number or `null`, and `chapter` is `{ level, separator }` or `null`. Returns `false` in an editor without pages, for a number format the editor can't write, and for a `chapter` when nothing numbers chapters.

## Tables, columns and lists

These act on the table, column layout or list at the cursor. They return `false` anywhere else.

### setRowBreakAcrossPages(allowed)

Sets whether the row at the cursor may split at a page boundary.

```js
editor.commands.setRowBreakAcrossPages(false)
```

### setRepeatHeaderRow(repeated)

Sets whether the header row repeats on every page the table reaches.

```js
editor.commands.setRepeatHeaderRow(true)
```

### setColumnLayoutKeepTogether(together)

Sets whether the column layout moves to the next page whole instead of being split.

```js
editor.commands.setColumnLayoutKeepTogether(true)
```

### setListKeepTogether(kept)

Sets whether the list moves to the next page whole instead of being split. A list taller than a page is split anyway.

```js
editor.commands.setListKeepTogether(true)
```

### setListBreakItems(allowed)

Sets whether a page boundary may split an item of the list. It is off by default, and independent of `setListKeepTogether`.

```js
editor.commands.setListBreakItems(true)
```

## Headers and footers

See [headers and footers](/pages/v2/core-concepts/header-and-footer).

### openFurniture(options)

Opens a header or footer for editing. `options` takes `zone` (`'header'` or `'footer'`), and optionally `pageIndex`, `slot` (`'default'`, `'first'` or `'even'`) and `reveal`.

```js
editor.commands.openFurniture({ zone: 'footer', reveal: true })
```

Without `pageIndex`, it uses the page at the cursor. `reveal` scrolls the band fully into view. `editor.can()` only says the engine is running. The command returns `false` when the section does not draw the slot.

### stepFurniture(direction)

Moves to the header or footer after (`1`) or before (`-1`) the one being edited.

```js
editor.commands.stepFurniture(1)
```

### closeFurniture()

Leaves the header or footer and puts the cursor back in the text.

```js
editor.commands.closeFurniture()
```

### unlinkFurniture()

Gives the section a header or footer of its own, instead of the one it inherits.

```js
editor.commands.unlinkFurniture()
```

### linkFurniture(source)

Makes the section follow the header or footer of another section. `source` is a section index or `'previous'`.

```js
editor.commands.linkFurniture('previous')
```

### setFurnitureFlags(sectionIndex, flags)

Turns the different first page and different odd and even pages on or off for one section. `flags` is `{ differentFirstPage, differentOddEven }`.

```js
editor.commands.setFurnitureFlags(0, { differentFirstPage: true, differentOddEven: false })
```

### setFurnitureOffsets(sectionIndex, offsets)

Sets how far the header and footer sit from the edge of the sheet, in pixels. `null` is the default of 1.25 cm.

```js
editor.commands.setFurnitureOffsets(0, { header: 96, footer: null })
```

### setFurnitureOffset(input)

Sets the distance for one header or footer only. `offset: null` falls back to the section's value.

```js
editor.commands.setFurnitureOffset({ sectionIndex: 0, zone: 'header', slot: 'first', offset: 192 })
```

## Page numbers

### insertPageNumber(kind?)

Inserts a page number field at the cursor in the header or footer being edited. `kind` is `'page'` (default), `'pages'` or `'sectionPages'`. Returns `false` anywhere else.

```js
editor.commands.insertPageNumber('pages')
```

### insertPageNumbers(options)

Adds page numbers to every header or every footer of the section. `options` is `{ zone, align, firstPage }`. `align` is `'left'`, `'center'`, `'right'`, `'inside'` or `'outside'`. With `firstPage: false` the first page has no number. Calling it again replaces the numbers.

```js
editor.commands.insertPageNumbers({ zone: 'footer', align: 'center', firstPage: true })
```

### removePageNumbers()

Removes the page numbers that `insertPageNumbers` added to the section.

```js
editor.commands.removePageNumbers()
```

## Document

### revealSourcePosition(pos, to?)

Puts the cursor at a position in the source document and scrolls its page into view. With `to`, it selects the text from `pos` to `to`. Returns `false` for a range outside the document.

```js
editor.commands.revealSourcePosition(120)
```

### onSourceDocument(command)

Runs a ProseMirror command, `(state, dispatch) => boolean`, on the document instead of on the pages.

```js
editor.commands.onSourceDocument((state, dispatch) => myCommand(state, dispatch))
```

### undo() and redo()

Undoes or redoes the last change to the source document.

```js
editor.commands.undo()
editor.commands.redo()
```
