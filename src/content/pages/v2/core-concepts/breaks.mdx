Pages break by themselves where the text reaches the bottom margin. A break you insert says "break here", however much room is left. It is the only kind of break stored in the document. Page Layout works out the automatic ones again on every change, so the same document on different paper breaks in different places.

## Three kinds of break

All three are inserted at the cursor:

- A page break ends the page and continues on the next one.
- A column break ends the current column. In a section with one column, it works like a page break.
- A section break starts a new [section](/pages/v2/core-concepts/sections), either on new paper (`'nextPage'`) or below the current section on the same sheet (`'continuous'`).

```js
editor.commands.insertPageBreak()
editor.commands.insertColumnBreak()
editor.commands.insertSectionBreak('nextPage')
editor.commands.insertSectionBreak('continuous')
```

`Mod-Enter` inserts a page break and `Mod-Shift-Enter` inserts a column break. `Mod-Enter` replaces the line break that the hard break extension binds to it.

A continuous break lets two layouts share a sheet. A two-column passage in the middle of a one-column page is a continuous section with its own [columns](/pages/v2/core-concepts/section-columns). The text carries on below it on the same page. A continuous section keeps the size, orientation and margins of the section above it, because paper can't change size halfway down a sheet.

A section break splits the block it lands in. A paragraph becomes two paragraphs. A list becomes two lists, and the second one keeps counting.

See the [commands reference](/pages/v2/api/commands#breaks).

## Remove a break

A page break is a marker in the text, not a block. It can sit between two words. Backspace at the start of the page after it removes it. A column break works the same way. A section break is a block of its own, and Backspace right after it deletes it.

From a toolbar, use [`removePageBreak`](/pages/v2/api/commands#removepagebreak) or [`removeSection`](/pages/v2/api/commands#removesectionsectionindex).

## Breaks without pages

In an editor without pages, the breaks stay in the document. Page Layout draws them as labeled dashed lines, so nothing a user inserted becomes invisible. Set `breaksWithoutPages: 'none'` if your interface draws its own.

```js
PageLayout.configure({ breaksWithoutPages: 'none' })
```

The labels read `Page break`, `Column break`, `Section break` and `Section break · 2 columns`. For another language, pass your own and name only the ones you translate. The rest keep the English text.

```js
PageLayout.configure({
  breakLabels: {
    page: 'Seitenumbruch',
    region: 'Spaltenumbruch',
    section: 'Abschnittsumbruch',
    sectionColumns: 'Abschnittsumbruch · {count} Spalten',
  },
})
```

The key is `region` and not `column` because a column break ends a region. In a section with one column, the region is the page. `{count}` stands for the number of columns and can go anywhere in the string.

## Turn breaks off

Each kind has its own switch:

```js
PageLayout.configure({ pageBreak: false, columnBreak: false, sectionBreak: false })
```

A document that already holds a node you turned off can't load. See [features](/pages/v2/api/options#features) for what this does.
