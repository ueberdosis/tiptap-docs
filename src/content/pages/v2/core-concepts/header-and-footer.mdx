A header is a band above the text column. A footer is a band below it. Page Layout draws both on every page of a section. Their content is editable rich text like any other, so a header can hold a paragraph, an image, a table or a horizontal rule.

The document stores each header once per section and slot, not once per page, inside that section's break. The pages draw copies of it, so pages can come and go without the content changing.

## Get in and out

The user double-clicks a band to edit it. Once inside, a single click on another band moves there. To leave, the user double-clicks anywhere outside the band, such as the text, the margin or the gray around the sheet, or presses Escape. An open menu or suggestion popup in the band closes first. You don't need to wire any of this.

If your interface has its own way in, turn the clicks off. This also turns off Escape:

```js
PageLayout.configure({ setup: pageSetup('A4'), furnitureClicks: false })
```

The commands below work either way.

From a toolbar button, open a band by zone:

```js
editor.commands.openFurniture({ zone: 'header' })
editor.commands.openFurniture({ zone: 'footer', reveal: true })
```

The page is the one at the cursor, so the button doesn't need to know about pages. Pass `reveal` when the button names a band the user can't see. A click on a band doesn't need it, because the user already sees what they clicked.

`openFurniture` also takes `pageIndex` and `slot` to open a particular page or slot. It returns `false` when the section doesn't draw that slot.

`stepFurniture` walks through the bands in order. A "Next header" button uses it:

```js
editor.commands.stepFurniture(1) // forwards
editor.commands.stepFurniture(-1) // backwards
```

To read which band the user is in, and to leave:

```js
const engine = editor.storage.pageLayout.engine

engine.getFurnitureTarget() // { zone, slot, sectionIndex, pageIndex } or null

editor.commands.closeFurniture()
```

Writing is always a command. Reading is always the engine in `editor.storage.pageLayout`.

While a band is open, the commands of your extensions act on it, as they would in an editor without pages. `insertTable` inserts the table into the header, and `addRowAfter` adds a row to a table in it. `editor.can()` checks the cursor in the band.

A band that has never had content isn't in the document yet. The first edit creates it.

## Different pages, different bands

Each zone has up to three variants per section, called slots:

| Slot      | Drawn on                                                                           |
| --------- | ---------------------------------------------------------------------------------- |
| `default` | Every page that no other slot covers.                                              |
| `first`   | The first page of the section, once `differentFirstPage` is on.                    |
| `even`    | The even pages, once `differentOddEven` is on. `default` then covers the odd ones. |

The two switches are per section:

```js
editor.commands.setFurnitureFlags(sectionIndex, {
  differentFirstPage: true,
  differentOddEven: false,
})

engine.getFurnitureFlags(sectionIndex) // the current pair
engine.getFurnitureSlots(sectionIndex) // which slots the section draws
```

Switching a flag off keeps the content of the slot it hides. Switch it on again and the old header is back.

A title page with no header and a running header from page two is `differentFirstPage: true` and an empty `first` slot.

`even` follows the number printed on the page. A section whose count starts again at 1 opens with the `default` slot, wherever it falls in the document.

## Inherit from the section before

A new section shows the header of the section above it until you give it one of its own. This is what a user expects of a running header. It matches Word's "Link to previous".

```js
engine.isFurnitureInherited() // is the band being edited inherited?
engine.getFurnitureSource() // { own, sourceSectionIndex, linkedSectionIndex }

editor.commands.unlinkFurniture() // give this section its own copy to edit
editor.commands.linkFurniture('previous') // follow the section above again
editor.commands.linkFurniture(2) // follow a particular section
```

Editing an inherited band edits the section it came from. A correction to a running header reaches every section that follows it. Call `unlinkFurniture()` first when this section should differ.

`linkFurniture` removes the content this section had of its own. Ask the user before you call it.

## Distance from the edge

You can set how far the header sits from the top of the sheet, and how far the footer sits from the bottom:

```js
editor.commands.setFurnitureOffsets(sectionIndex, { header: 96, footer: 96 })

engine.getFurnitureOffsets(sectionIndex) // { header, footer }, null for the default
```

`null` is the default of 1.25 cm. The text starts at the top margin or just below the header, whichever is lower on the page. A three-line header pushes the first paragraph down. A page with no header starts at the margin.

You can also set an offset per slot, for a title page whose header sits lower than the rest:

```js
editor.commands.setFurnitureOffset({
  sectionIndex,
  zone: 'header',
  slot: 'first',
  offset: 192, // null falls back to the offset of the section
})

engine.getFurnitureOffset({ sectionIndex, zone: 'header', slot: 'first' })
engine.hasFurnitureOffsetsPerMask(sectionIndex)
```

## A page number in a band

With a band open, `insertPageNumber` puts a field at the cursor. The field shows the number of the page the band is drawn on, the count of pages, or the count of pages in the section:

```js
editor.chain().insertContent('Page ').insertPageNumber('page').run()
```

[Page numbers](/pages/v2/core-concepts/page-numbers#a-page-number-in-a-header-or-footer) lists the kinds. To number every page of a section without opening a band, use `insertPageNumbers`. See [page numbers on every page](/pages/v2/core-concepts/page-numbers#page-numbers-on-every-page).

## Turn headers and footers off

```js
PageLayout.configure({ pageFurniture: false })
```

This removes the bands and the double-click, and the commands return `false`.

See the [commands reference](/pages/v2/api/commands#headers-and-footers).
