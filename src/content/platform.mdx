## The parts

| Part          | What it is                                                                  | Start with                                               |
| ------------- | --------------------------------------------------------------------------- | -------------------------------------------------------- |
| Editor        | The open source, headless editor framework, with a wide range of extensions | [Tiptap Editor](/editor/getting-started/overview)        |
| Features      | Every feature, from Bold to Comments and AI, open source or paid            | [All features](/editor/extensions/overview)              |
| Documents     | The Document Server: storage, real-time sync, an API, and snapshots         | [Documents](/collaboration/getting-started/overview)     |
| UI Components | React components and complete editor templates                              | [UI Components](/ui-components/getting-started/overview) |

All parts work on one structured document, the Tiptap document:

- **People** write and review it in the editor.
- **Your backend** reads and changes it as Tiptap JSON through the [REST API](/collaboration/documents/rest-api).
- **AI agents** read and edit it with the [AI Toolkit](/ai/ai-toolkit/overview).
- **Real-time sync** keeps every open copy of it the same, on the Document Server or Hocuspocus.

[Tiptap Document](/document-model) explains how.

## Where it runs

The editor runs in your app. The Document Server, the [AI Toolkit](/ai/ai-toolkit/overview), and [Conversion](/conversion/getting-started/overview) run in one of these places:

- **Tiptap Cloud.** Tiptap runs and scales the services for you. The fastest way to production. [Tiptap Cloud](/hosting/cloud)
- **Dedicated cloud.** Your own isolated, single-tenant server on Tiptap's infrastructure, with guaranteed uptime and an SLA. [Dedicated cloud](/hosting/cloud#dedicated-cloud)
- **On-premises.** The same services in your own infrastructure, for compliance or data residency. [On-premises](/hosting/on-premises)

For real-time sync alone, [Hocuspocus](/hocuspocus/getting-started/overview) is the free, open source server that the Document Server builds on. You run it and add storage, authentication, and an API yourself. Both use the same Collaboration extension, so moving to the Document Server later means [swapping the provider](/hosting#move-between-them).

[Hosting](/hosting) compares the three and recommends one.
