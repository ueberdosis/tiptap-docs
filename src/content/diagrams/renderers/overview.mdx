## Quick start

```ts
import { Diagrams } from '@tiptap-pro/extension-diagrams'
import { d3Renderer } from '@tiptap-pro/extension-diagrams/d3'
import { echartsRenderer } from '@tiptap-pro/extension-diagrams/echarts'

Diagrams.configure({
  renderers: [echartsRenderer(), d3Renderer()],
  defaultRenderer: 'echarts',
})
```

- The extension bundles no chart library.
- Every library is a peer dependency or a script you serve, used under its own license.
- A library not listed here can draw through a [Renderer of your own](/diagrams/renderers/custom).

## Which Renderer draws a chart

1. The Renderer the chart names (`setChartRenderer`), if it is registered and draws the
   chart type.
2. Otherwise `defaultRenderer`, if it draws the type.
3. Otherwise the first registered Renderer that draws the type.

### When a Renderer declines a chart

A Renderer can decline a chart of a type it draws, through `draws`. The Mermaid Renderer
declines a bar chart with several series and a line chart with line styles.

- **Another Renderer draws the type:** the next one in the order above draws the chart.
- **No other Renderer draws the type:** the declining Renderer draws it after all.
- **The chart** keeps the Renderer it names.
- **The chart's root** says in `data-tt-chart-renderer` which Renderer drew it.
- **`export` with an explicit `renderer` option** uses that Renderer as it is.

### When no Renderer draws the type

The chart shows what [`unavailable`](/diagrams/api-reference/options#unavailable) returns and keeps its data.

### When the Renderer changes

- **The picture** changes. Data and spec stay as they are.
- **Options a chart stores for one Renderer** under `spec.renderer[id]` are ignored by the
  others.
- **Colors and fonts** come from the same `--tt-chart-*` custom properties for every
  Renderer, so charts look alike whichever library draws them. See
  [Styling](/diagrams/guides/styling).

## Your own Renderer

A Renderer is an object with an id, the chart types it draws, `mount` to draw in the editor,
and `toSVG` or `toImage` for files. It sees the Chart Data and the Chart Spec, never the
document, so it works with every way data gets into a chart.

- [Your own Renderer](/diagrams/renderers/custom) has a complete chart Renderer, its members and what it
  receives.
- [Chart types](/diagrams/renderers/custom-chart-types) adds a chart type.
- [A Diagram Renderer](/diagrams/renderers/custom-diagrams) draws a diagram format.
