## Functions

| Function                                                                                | What it does                                                                                |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [`readText({ pos? })`](/diagrams/api-reference/storage#reading-a-charts-data)           | Returns the text of a chart or a diagram, with its format                                   |
| [`updateFromText({ text, pos? })`](/diagrams/guides/split-view#updatefromtext)          | Changes the chart or diagram from that text                                                 |
| [`highlightSource(text, format)`](/diagrams/api-reference/selectors#highlighted-source) | Returns the text as HTML with its parts colored, from `@tiptap-pro/extension-diagrams/core` |

## Reading the text

```ts
const current = editor.storage.diagrams.readText({ pos })
// { format: 'chart-syntax', text: 'bar\nMonth | Revenue\nJan | 120' }
```

- **For a chart**, `readText` returns its type line and its rows in the
  [Chart syntax](/diagrams/data/chart-syntax), split at its delimiter, as the Quick Input shows them. The
  format is `'chart-syntax'`.
- **For a diagram**, it returns the source. The format is the diagram's own: `'mermaid'`,
  `'drawio'` or `'bpmn'`.
- **Without a chart or a diagram** at `pos`, or selected, it returns `null`.

## Writing it back

### updateFromText

Changes a chart or a diagram from its text, the same text that `readText` returns.

```ts
editor.commands.updateFromText({ pos, text: 'pie\nDogs, 3\nCats, 2' })
```

| Option | Type     | Description                                                        |
| ------ | -------- | ------------------------------------------------------------------ |
| `text` | `string` | The text                                                           |
| `pos`  | `number` | The position of the chart or diagram. Defaults to the selected one |

- **A chart** reads the text as the Quick Input does. The text is rows in the Chart syntax below
  an optional type line, or a [Mermaid chart](/diagrams/charts/overview#importmermaidchart). The chart's
  data and type change. Its title, colors, axes and the rest of the Chart Spec stay.
- **A diagram** takes the text as its new source, as `updateFlowDiagram` does.
- **Text the command cannot read**, such as an unclosed quote, changes nothing, and the command
  returns `false`. Keep the text in your text field and mark it as invalid, so nothing the user
  typed is lost.
- **A chart whose data is read-only**, because it comes from a linked Data Source, returns
  `false` for new data.

## Following the selection

Read the text again when the selection moves to another chart or diagram, or when the chart
changes elsewhere. Skip the update that your own text field caused, so the text stays as the
user typed it.

```ts
const textField = document.createElement('textarea')
document.body.append(textField)

let pos = editor.storage.diagrams.listCharts()[0]?.pos ?? null
let typing = false

editor.on('transaction', ({ transaction }) => {
  // A command that changes a chart replaces its node. Mapping with -1 keeps pos at its start.
  if (pos !== null) pos = transaction.mapping.map(pos, -1)
  const { node, from } = editor.state.selection
  if (node && ['chart', 'flowDiagram'].includes(node.type.name)) pos = from
  if (!typing && pos !== null) {
    textField.value = editor.storage.diagrams.readText({ pos })?.text ?? ''
  }
})

textField.addEventListener('input', () => {
  if (pos === null) return
  typing = true
  const valid = editor.commands.updateFromText({ pos, text: textField.value })
  typing = false
  textField.toggleAttribute('data-invalid', !valid)
})
```

## Coloring the text

`highlightSource` returns the text as HTML. Each part sits in a `<span>` with a class such as
`tiptap-diagram-source-keyword`. It colors the Chart syntax and Mermaid. Leave draw.io and BPMN
XML as plain text.

```ts
import { highlightSource } from '@tiptap-pro/extension-diagrams/core'

const { delimiters, chartTypes } = editor.storage.diagrams.describeCapabilities()
code.innerHTML = highlightSource(text, 'chart-syntax', {
  delimiters,
  types: chartTypes.map((type) => type.id),
})
```

- **Put the class `tiptap-diagram-source`** on the element around the HTML. The Quick Input's
  colors then apply there too, with their light and dark values.
- **For a text field the user can edit**, lay a transparent `<textarea>` over a `<pre>` that holds
  the HTML. Give both the same font, padding and line height. The demo works that way.
- **The colors** are custom properties, listed under
  [Highlighted source](/diagrams/api-reference/selectors#highlighted-source).
- **The `sourceHighlighting` option** turns the colors off in the Quick Input and in a diagram's
  code view only. It does not affect your own text field.
