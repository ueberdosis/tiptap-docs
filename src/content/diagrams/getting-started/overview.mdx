Charts and diagrams in a Tiptap document. Everything comes from one Extension, `Diagrams`, in
the package `@tiptap-pro/extension-diagrams`. To install it and see a first chart, start with
[Getting started](/diagrams/getting-started/install).

## What it adds

| Node          | What it is                               | What the document stores  |
| ------------- | ---------------------------------------- | ------------------------- |
| `chart`       | A picture of tabular data                | Its data and its settings |
| `flowDiagram` | A flowchart, sequence diagram or process | Its source text           |

- A chart library of your choice draws the picture.
- Changing the library changes the picture, never the document.

## What you can do with it

- **Make a chart from rows.** Type `:::` in an empty paragraph, then rows such as `Jan | 2`, or
  turn a table into a chart. [Data](/diagrams/data/overview)
- **Change a chart.** Its type, title, colors and axes, at any time. [Charts](/diagrams/charts/overview)
- **Insert a diagram.** A flowchart, a sequence diagram or a process, written as text and edited
  in the picture. [Diagrams](/diagrams/flow-diagrams/overview)
- **Export.** Charts and diagrams as images, or every chart in a Word document.
  [Export](/diagrams/export)
- **Let a model work with them.** Tools to insert, read and change charts and diagrams.
  [Tools for a model](/diagrams/guides/ai)

## Words used in these pages

| Word         | Meaning                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| Chart Data   | The columns and rows a chart stores. [Data](/diagrams/data/overview)                                          |
| Chart Spec   | How a chart shows its data: type, title, colors, axes. [Charts](/diagrams/charts/overview)                    |
| Renderer     | The adapter that draws with one chart or diagram library. [Renderers](/diagrams/renderers/overview)           |

| Quick Input  | The box `:::` opens, where typed text becomes a chart or a diagram. [Quick Input](/diagrams/data/quick-input) |

## Code from the document

Code from the document never runs in the page.

- **Mermaid, draw.io and BPMN** draw in a sandboxed iframe.
- **Custom d3 code** is a function you register, and a chart names it.
