The [Diagrams demo](https://labs.tiptap.dev/diagrams) is a whole editor with charts, flow
diagrams, the Quick Input and Word export. To try it, type `:::` in an empty paragraph, then rows such as `Jan | 2`.

## What you get

The extension adds a `chart` node for bar, line, pie and other charts, and a `flowDiagram` node for
flowcharts, sequence diagrams and process models. A node is one block of a Tiptap document, such as
a paragraph or an image.

- [Data](/diagrams/data/overview): users type rows after `:::`, paste them or turn a table into a chart,
  and a chart can follow a CSV file at a URL.
- [Charts](/diagrams/charts/overview): the chart types, and the titles, colors, axes and reference lines
  users change at any time.
- [Flow diagrams](/diagrams/flow-diagrams/overview): Mermaid, draw.io and BPMN diagrams written as text. Users
  edit a Mermaid diagram's text right in the picture.
- [Renderers](/diagrams/renderers/overview): the library that draws, such as ECharts or D3 for charts and
  Mermaid or draw.io for diagrams.
- [Export](/diagrams/export): a chart or a diagram as an SVG, PNG, WebP or JPEG file, and charts in a
  Word document.
- [Tools for a model](/diagrams/guides/ai): tools that let an AI model insert, read and change charts and
  diagrams.
- [Styling](/diagrams/guides/styling): colors, dark mode and chart styles of your own.

## A first look

Diagrams is available through a pilot program.
[Contact our team](https://tiptap.dev/contact-sales?form=pilot-program) to join it, and the package
comes from Tiptap's private registry. Then install the package and ECharts, a chart library:

```bash
npm install @tiptap-pro/extension-diagrams echarts
```

With `Diagrams` registered in an editor, this command
inserts a bar chart from three typed rows. The first line, `bar`, names the type:

```ts
editor.commands.insertChartFrom({
  format: 'chart-syntax',
  content: 'bar\nMonth | Revenue\nJan | 120\nFeb | 150\nMar | 110',
})
```

[Install Diagrams](/diagrams/getting-started/install) has the registry access and the complete editor around this
call.

## What stays the same

You save, undo and share charts and diagrams like the rest of the document. `getJSON()` holds
each chart's values and settings and each diagram's text, but not the picture. So switching to
another library changes how a chart looks, and not the document.

The built-in Renderers draw text stored in a document, such as Mermaid source, in a sandboxed
iframe or a Web Worker, so it never runs as code in your page. A Diagram Renderer of your own
receives that text as well, so follow
[Keeping your web page safe](/diagrams/renderers/custom-diagrams#keeping-your-web-page-safe).
[Collaboration](/diagrams/guides/collaboration) says what every client of a shared document needs.

## Common tasks

| To                                        | Use                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------ |
| Insert a chart from rows of text          | [`insertChartFrom({ format: 'chart-syntax', content })`](/diagrams/charts/overview#insertchartfrom) |
| Insert a chart from data in code          | [`insertChart({ data, spec })`](/diagrams/charts/overview#insertchart)                              |
| Let users type a chart                    | Typing `:::` in an empty paragraph, see [Quick Input](/diagrams/data/quick-input)                 |
| Turn the table at the cursor into a chart | [`convertTableToChart({ type: 'bar' })`](/diagrams/data/tables#converttabletochart)               |
| Read a chart's data from a CSV URL        | [`linkChartSource({ provider: 'url-csv', address })`](/diagrams/data/sources#linkchartsource)     |
| Change the type or the title              | [`updateChartSpec({ spec: { type: 'line' } })`](/diagrams/charts/appearance#updatechartspec)      |
| Change an axis                            | [`updateChartAxis({ axis: 'y', changes: { min: 0 } })`](/diagrams/charts/axes#updatechartaxis)    |
| Insert a Mermaid diagram                  | [`insertFlowDiagram({ source })`](/diagrams/flow-diagrams/overview#insertflowdiagram)                    |
| Set the size of a chart or a diagram      | [`setDiagramSize({ size })`](/diagrams/guides/size-and-view#setdiagramsize)                              |
| Save a chart as a PNG file                | [`editor.storage.diagrams.export({ pos }, { format: 'png' })`](/diagrams/export#files)            |
| Put every chart into a Word document      | [`editor.storage.diagrams.exportDocx()`](/diagrams/export#word)                                   |
| Give an AI model tools for charts         | [`getChartToolDefinitions(editor)`](/diagrams/guides/ai#quick-start)                                     |

## Words these pages use

| Word             | Meaning                                                                                                              |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| Chart Data       | The values a chart stores, as columns and rows. [Data](/diagrams/data/overview)                                               |
| Chart Spec       | A chart's settings, such as its type, title, colors and axes. [Appearance](/diagrams/charts/appearance)                     |
| Chart syntax     | Rows typed as text, one per line, with cells split by `\|`, such as `Jan \| 2`. [Chart syntax](/diagrams/data/chart-syntax) |
| Quick Input      | The text field that typing `:::` opens in an empty paragraph. [Quick Input](/diagrams/data/quick-input)                     |
| Renderer         | The adapter between the extension and one chart library, such as ECharts. [Renderers](/diagrams/renderers/overview)           |
| Diagram Renderer | A Renderer that draws diagrams, such as the one for Mermaid. [Renderers](/diagrams/renderers/overview)                        |
| Data Source      | A place outside the document that a chart reads its values from, such as a CSV file. [Data Sources](/diagrams/data/sources) |
