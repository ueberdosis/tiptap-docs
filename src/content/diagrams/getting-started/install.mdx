## Install

First, [contact our team](https://tiptap.dev/contact-sales?form=pilot-program) to join the Tiptap Diagrams pilot program.

Then, configure your package manager by following the [private registry guide](/guides/pro-extensions).

Then, install the package and the library of each Renderer you use:

```bash
npm install @tiptap-pro/extension-diagrams
npm install echarts
```

| Package                      | Kind                     | Version                              |
| ---------------------------- | ------------------------ | ------------------------------------ |
| `@tiptap/core`, `@tiptap/pm` | Peer dependency          | 3.31 or later                        |
| `echarts`                    | Optional peer dependency | `^6.0.0`                             |
| `d3`                         | Optional peer dependency | `^7.9.0`                             |
| `d3-sankey`                  | Optional peer dependency | `^0.12.3`, for sankey charts with D3 |
| `mermaid`                    | Optional peer dependency | `>=11.16.1 <12`                      |
| `pele`                       | Optional peer dependency | `1.6.0`, for the Pele Renderer       |

The draw.io and BPMN Renderers load their library from a file you serve. See
[draw.io](/diagrams/renderers/drawio) and [BPMN](/diagrams/renderers/bpmn).
[Renderers](/diagrams/renderers/overview) lists every Renderer.

## A first chart

In the demo, write rows as text, insert them as a chart, then change its type:

<CodeDemo isPro viewer view="preview" path="/Extensions/DiagramsInsertChart" />

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { TableKit } from '@tiptap/extension-table'
import { Diagrams, chartStyleRules } from '@tiptap-pro/extension-diagrams'
import { echartsRenderer } from '@tiptap-pro/extension-diagrams/echarts'

const style = document.createElement('style')
style.textContent = chartStyleRules()
document.head.append(style)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    TableKit,
    Diagrams.configure({
      renderers: [echartsRenderer()],
      chart: { defaultType: 'bar' },
    }),
  ],
})

editor.commands.insertChartFrom({
  format: 'chart-syntax',
  content: 'Month | Revenue\nJan | 120\nFeb | 150\nMar | 110',
})
```

The editor now holds a bar chart with three bars, and the chart is selected.

- `chartStyleRules()` returns the stylesheet the charts need.
- `TableKit` is optional. With it, you can turn a chart into a table and back.
- `chart: { defaultType: 'bar' }` gives a new chart the type `bar`. See
  [`defaultType`](/diagrams/api-reference/options#defaulttype).
- `chart-syntax` is the [Chart syntax](/diagrams/data/chart-syntax): one row per line, with the cells
  separated by `|`.

## A second chart from the Quick Input

1. Type `:::` in an empty paragraph to open the [Quick Input](/diagrams/data/quick-input), a text field
   inside the document.
2. Enter rows such as `Apr | 130`.
3. Press Enter on an empty last line.

## A first diagram

A diagram needs a Diagram Renderer, such as the Mermaid one. Set it up with the
[diagram quick start](/diagrams/flow-diagrams/overview#quick-start), then insert a flowchart from Mermaid
source:

```ts
editor.commands.insertFlowDiagram({
  source: 'flowchart LR\n  order[Order placed] --> ship[Shipped]',
  title: 'Order flow',
})
```

## Change it

```ts
editor.commands.updateChartSpec({ spec: { type: 'line', title: 'Revenue' } })
editor.commands.updateChartAxis({ axis: 'y', changes: { title: 'EUR', min: 0 } })
```

The Chart Spec holds how a chart shows its data, such as its type, title, colors and axes. Both
commands change the selected chart, here the one from [A first chart](/diagrams/getting-started/install#a-first-chart).

Every change is a [command](/diagrams/api-reference/commands). You can undo it, collaborators receive it, and an AI
model can call it.

## Entry points

Each Renderer is its own entry point of the package. Your bundle then holds only the libraries
you use.

| Import from                                                             | What it holds                                                                                                                        |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `@tiptap-pro/extension-diagrams`                                        | `Diagrams`, its nodes and commands, Data Sources, export, styling and tools for an AI model                                          |
| `@tiptap-pro/extension-diagrams/core`                                   | The chart data types, parsers and formats, and the Word writer. It needs no Tiptap and no DOM, so it runs on a server or in a worker |
| `@tiptap-pro/extension-diagrams/export`                                 | Turning an SVG into a PNG, WebP or a download, in the browser                                                                        |
| `@tiptap-pro/extension-diagrams/theme`                                  | Reading chart and diagram colors from CSS custom properties, in the browser                                                          |
| [`@tiptap-pro/extension-diagrams/echarts`](/diagrams/renderers/echarts) | Charts drawn with ECharts                                                                                                            |
| [`@tiptap-pro/extension-diagrams/d3`](/diagrams/renderers/d3)           | Charts drawn with D3                                                                                                                 |
| [`@tiptap-pro/extension-diagrams/mermaid`](/diagrams/renderers/mermaid) | Charts and diagrams drawn with Mermaid                                                                                               |
| [`@tiptap-pro/extension-diagrams/drawio`](/diagrams/renderers/drawio)   | draw.io diagrams                                                                                                                     |
| [`@tiptap-pro/extension-diagrams/bpmn`](/diagrams/renderers/bpmn)       | BPMN process models                                                                                                                  |
| [`@tiptap-pro/extension-diagrams/pele`](/diagrams/renderers/pele)       | Mermaid diagrams drawn by Pele in a Web Worker. Pele is smaller than mermaid.js                                                      |
