## The formats

| `format`    | Source                       | Drawn by                                                               |
| ----------- | ---------------------------- | ---------------------------------------------------------------------- |
| `'mermaid'` | Mermaid text                 | mermaid.js or Pele, see [Mermaid diagrams](/diagrams/flow-diagrams/formats#mermaid-diagrams)          |
| `'drawio'`  | draw.io XML                  | The draw.io Diagram Renderer, see [draw.io diagrams](/diagrams/flow-diagrams/formats#drawio-diagrams) |
| `'bpmn'`    | BPMN 2.0 XML with its layout | The BPMN Diagram Renderer, see [BPMN diagrams](/diagrams/flow-diagrams/formats#bpmn-diagrams)         |
| Another id  | Stored as it is              | A Diagram Renderer that lists it, see [Other formats](/diagrams/flow-diagrams/formats#other-formats)  |

## Mermaid diagrams

A diagram with `format: 'mermaid'` holds Mermaid text as written, without `%%{…}%%` directives
and frontmatter (see [Source is data](/diagrams/flow-diagrams/overview#source-is-data)). Its first line names a
[Mermaid kind](/diagrams/flow-diagrams/overview#mermaid-kinds):

```ts
editor.commands.insertFlowDiagram({ source: 'flowchart LR\n  A --> B', title: 'Order process' })
```

To draw it, register [`mermaidDiagramRenderer`](/diagrams/renderers/mermaid#diagrams) or
[`peleDiagramRenderer`](/diagrams/renderers/pele).
[Next to mermaid.js](/diagrams/renderers/pele#next-to-mermaidjs) compares them. Without
either, the diagram is inserted and shows what [`unavailable`](/diagrams/api-reference/options#unavailable)
returns, by default "This diagram can't be drawn here."

## draw.io diagrams

A diagram with `format: 'drawio'` holds draw.io XML. The
[draw.io Diagram Renderer](/diagrams/renderers/drawio) draws it. The user changes it in the
draw.io editor, in an iframe you build, loaded from `embed.diagrams.net` unless you host a copy.
Its page has a demo and
[the rules for the source](/diagrams/renderers/drawio#what-a-drawio-source-is). `drawioXml` is
your XML string:

```ts
editor.commands.insertFlowDiagram({ source: drawioXml, format: 'drawio', title: 'Order process' })
```

## BPMN diagrams

A diagram with `format: 'bpmn'` holds BPMN 2.0 XML with its layout (BPMN DI, the shape positions),
stored as written. The [BPMN Diagram Renderer](/diagrams/renderers/bpmn) draws it
and connects bpmn-js, a BPMN editor.

Its page has a demo and the rules for the source. `bpmnXml` is your XML string:

```ts
editor.commands.insertFlowDiagram({ source: bpmnXml, format: 'bpmn', title: 'Payment check' })
```

## Other formats

A Diagram Renderer of your own can draw its own format. The id rules, the size limit and what
happens when no Renderer draws it are on
[A format of your own](/diagrams/renderers/custom-diagrams#a-format-of-your-own).
