## The formats

| `format`    | Source                       | Drawn by                                                                                              |
| ----------- | ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| `'mermaid'` | Mermaid text                 | mermaid.js or Pele, see [Mermaid diagrams](/diagrams/flow-diagrams/formats#mermaid-diagrams)          |
| `'drawio'`  | draw.io XML                  | The draw.io Diagram Renderer, see [draw.io diagrams](/diagrams/flow-diagrams/formats#drawio-diagrams) |
| `'bpmn'`    | BPMN 2.0 XML with its layout | The BPMN Diagram Renderer, see [BPMN diagrams](/diagrams/flow-diagrams/formats#bpmn-diagrams)         |
| Another id  | Stored as it is              | A Diagram Renderer that lists it, see [Other formats](/diagrams/flow-diagrams/formats#other-formats)  |

## Mermaid diagrams

A diagram with `format: 'mermaid'` holds Mermaid text, stored as you typed it.

```ts
editor.commands.insertFlowDiagram({ source: 'flowchart LR\n  A --> B', title: 'Order process' })
```

The source starts with a Mermaid kind, such as `flowchart` or `sequenceDiagram`.
[Mermaid kinds](/diagrams/flow-diagrams/overview#mermaid-kinds) lists every kind a diagram can hold.

Two Diagram Renderers draw Mermaid text. Register one of them for `mermaid`, because the first
registered Diagram Renderer that lists a format draws it.

| Renderer                                                         | Import from                              | Draws in                    | Looks                            |
| ---------------------------------------------------------------- | ---------------------------------------- | --------------------------- | -------------------------------- |
| [`mermaidDiagramRenderer`](/diagrams/renderers/mermaid#diagrams) | `@tiptap-pro/extension-diagrams/mermaid` | A sandboxed iframe          | As mermaid.js draws it           |
| [`peleDiagramRenderer`](/diagrams/renderers/pele)                | `@tiptap-pro/extension-diagrams/pele`    | A Web Worker, without a DOM | As Pele draws it, straight edges |

Both draw the same source, so switching changes how the diagram looks, never the document. Pele
is smaller to load, and it also draws on a server, for an export without a browser.
[Next to mermaid.js](/diagrams/renderers/pele#next-to-mermaidjs) compares the two.

Pasting Mermaid text, bare or in a ` ```mermaid ` fence, gives a Mermaid diagram.

## draw.io diagrams

A diagram with `format: 'drawio'` holds draw.io XML. The
[draw.io Diagram Renderer](/diagrams/renderers/drawio) draws it and also connects the draw.io
editor, so you can change it. Its page has a demo.

```ts
editor.commands.insertFlowDiagram({ source: drawioXml, format: 'drawio', title: 'Order process' })
```

The source is an `<mxfile>` or a bare `<mxGraphModel>`. The extension stores it as an `<mxfile>`
whose pages are plain XML, so you can read and compare the stored text:

- A bare `<mxGraphModel>` becomes a file with one page.
- A page that draw.io compressed is uncompressed. A page that cannot be uncompressed is kept as
  it is.

For anything else, and for source longer than 1,000,000 characters, `insertFlowDiagram` and
`updateFlowDiagram` return `false`. Pasting draw.io XML as text gives a draw.io diagram.

`updateFlowDiagram({ source, format })` changes a diagram's format, for example when a Mermaid
diagram comes back from the draw.io editor. A new format needs `source` in that format.

## BPMN diagrams

A diagram with `format: 'bpmn'` holds BPMN 2.0 XML with its layout, stored as written. The
[BPMN Diagram Renderer](/diagrams/renderers/bpmn) draws it and also connects the bpmn-js
modeler, so you can change it. Its page has a demo and the rules for the source.

```ts
editor.commands.insertFlowDiagram({ source: bpmnXml, format: 'bpmn', title: 'Payment check' })
```

## Other formats

A Diagram Renderer of your own can draw a format of its own. `insertFlowDiagram` and
`updateFlowDiagram` accept that format when a registered Diagram Renderer lists it in `formats`.

- The format's id has letters, digits, `_` and `-`, up to 64 characters.
- The source is stored as it is, up to 1,000,000 characters.

A document can hold a format that no registered Diagram Renderer draws. The document keeps it
unchanged, and its source survives every save. The diagram shows what
[`unavailable`](/diagrams/api-reference/options#unavailable) returns.
