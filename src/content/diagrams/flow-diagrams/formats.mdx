## The formats

| `format`    | Source                       | Drawn by                                                                                              |
| ----------- | ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| `'mermaid'` | Mermaid text                 | The Mermaid Diagram Renderer                                                                          |
| `'drawio'`  | draw.io XML                  | The draw.io Diagram Renderer, see [draw.io diagrams](/diagrams/flow-diagrams/formats#drawio-diagrams) |
| `'bpmn'`    | BPMN 2.0 XML with its layout | The BPMN Diagram Renderer, see [BPMN diagrams](/diagrams/flow-diagrams/formats#bpmn-diagrams)         |
| Another id  | Stored as it is              | A Diagram Renderer that lists it, see [Other formats](/diagrams/flow-diagrams/formats#other-formats)  |

## draw.io diagrams

A diagram with `format: 'drawio'` holds draw.io XML. It is drawn by the
[draw.io Diagram Renderer](/diagrams/renderers/drawio), which also connects the draw.io
editor for changing it. Its page has a demo.

```ts
editor.commands.insertFlowDiagram({ source: drawioXml, format: 'drawio', title: 'Order process' })
```

- **Source** is an `<mxfile>` or a bare `<mxGraphModel>`.
- **Stored** as an `<mxfile>` whose pages are plain XML, so the stored text can be read and
  compared.
- **A bare model** becomes a file with one page.
- **A page draw.io compressed** is uncompressed.
- **Anything else**, and source longer than 1,000,000 characters, makes `insertFlowDiagram` and
  `updateFlowDiagram` return `false`.
- **Pasting** draw.io XML as text gives a draw.io diagram.
- **Changing the format:** `updateFlowDiagram({ source, format })` changes it, for instance when
  a Mermaid diagram comes back from the draw.io editor. A new format needs `source` in it.

## BPMN diagrams

A diagram with `format: 'bpmn'` holds BPMN 2.0 XML with its layout. It is drawn by the
[BPMN Diagram Renderer](/diagrams/renderers/bpmn), which also connects the bpmn-js modeler
for changing it. Its page has a demo.

```ts
editor.commands.insertFlowDiagram({ source: bpmnXml, format: 'bpmn', title: 'Payment check' })
```

- **Source** is `<definitions>` in the BPMN 2.0 model namespace.
- **Stored** as written.
- **Anything else**, and source longer than 1,000,000 characters, makes `insertFlowDiagram` and
  `updateFlowDiagram` return `false`.
- **Pasting** BPMN XML as text gives a BPMN diagram.

## Other formats

- **The id** is any id of letters, digits, `_` and `-`, up to 64 characters.
- **Accepted** by `insertFlowDiagram` and `updateFlowDiagram` when a registered Diagram
  Renderer lists it in `formats`.
- **Source** is stored as it is, up to 1,000,000 characters.
- **No Renderer draws it:** a document that holds such a format keeps it unchanged. The diagram
  shows what [`unavailable`](/diagrams/api-reference/options#unavailable) returns, and its source survives every
  save.

## Pasting diagram source

Paste rows, Mermaid, draw.io XML or BPMN XML and see what each becomes:

<CodeDemo isPro path="/Extensions/DiagramsPasteDetection" />

Pasting sorts source the same way:

- Pasted Mermaid that is a chart becomes a chart, and any other [kind](/diagrams/flow-diagrams/overview#mermaid-kinds) a diagram.
- Mermaid is recognized bare, in a ` ```mermaid ` fence, or as a code block with the language
  `mermaid`.
- Bare text needs the keyword on the first line and more than one line.
- Pasting into a code block keeps the text.
- `convertCodeBlockToDiagram` turns a code block that already holds diagram source into a
  diagram.
- Diagram source, draw.io XML or BPMN XML confirmed in the chart Quick Input becomes a diagram.

### detectDiagramInput

`detectDiagramInput(text)` says what a text would become, for a field of your own that takes
anything. It returns `{ kind, source }`, or `null`.

```ts
import { detectDiagramInput } from '@tiptap-pro/extension-diagrams'

const detected = detectDiagramInput(text)
if (detected?.kind === 'mermaid-diagram')
  editor.commands.insertFlowDiagram({ source: detected.source })
```

| `kind`              | Text                                                                                                          | Command to call                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `'mermaid-chart'`   | A Mermaid chart, such as `pie` or `sankey-beta`, with at least one row                                        | `importMermaidChart({ source })`                               |
| `'mermaid-diagram'` | Any other [Mermaid kind](/diagrams/flow-diagrams/overview#mermaid-kinds), on more than one line or in a fence | `insertFlowDiagram({ source })`                                |
| `'drawio'`          | An `<mxfile>` or `<mxGraphModel>`                                                                             | `insertFlowDiagram({ source, format: 'drawio' })`              |
| `'bpmn'`            | BPMN 2.0 `<definitions>`                                                                                      | `insertFlowDiagram({ source, format: 'bpmn' })`                |
| `'chart-syntax'`    | Rows with a delimiter, as the chart syntax or CSV, with at least two columns                                  | `insertChartFrom({ format: 'chart-syntax', content: source })` |

- `source` is the text with a ` ```mermaid ` fence removed.
- A sentence, a lone Mermaid keyword and unreadable XML are `null`.
- The paste handling and `confirmDiagramInput` use the same function, so a field built on it
  agrees with them.
