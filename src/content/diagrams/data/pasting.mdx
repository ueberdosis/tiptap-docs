## What pasted text becomes

| Pasted text                                                                                   | Becomes                                                                                               |
| --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Rows, as in the [Chart syntax](/diagrams/data/chart-syntax), or CSV with at least two columns | A chart                                                                                               |
| A Mermaid chart, such as `pie` or `sankey-beta`                                               | A chart, with its data to edit ([`importMermaidChart`](/diagrams/charts/overview#importmermaidchart)) |
| Any other Mermaid kind                                                                        | A diagram ([Formats](/diagrams/flow-diagrams/formats#mermaid-diagrams))                               |
| draw.io XML or BPMN XML                                                                       | A diagram ([Formats](/diagrams/flow-diagrams/formats))                                                |
| Rows from a spreadsheet, while a chart is selected                                            | That chart's new data, see [Onto a selected chart](/diagrams/data/pasting#onto-a-selected-chart)      |
| Anything, into a code block                                                                   | The text, unchanged                                                                                   |

## How pasted text is read

The extension finds pasted Mermaid in three forms:

- Bare, which means the Mermaid text alone, with nothing around it.
- In a ` ```mermaid ` fence.
- As a code block with the language `mermaid`.

Bare Mermaid needs its kind, such as `flowchart`, on the first line, and more than one line. So
a sentence that starts with "pie" stays a sentence.

A code block that already holds diagram source becomes the diagram with
[`convertCodeBlockToDiagram`](/diagrams/flow-diagrams/overview#convertcodeblocktodiagram). Mod-Enter in a
code block does the same, see [Mod-Enter in a code block](/diagrams/data/quick-input#mod-enter-in-a-code-block).

The Quick Input reads its text with the same rules when you confirm it.

## Detecting text in a field of your own

You may have a text field of your own, outside the editor, that takes any text. To find out what
a text in it would become, call `detectDiagramInput`.

### detectDiagramInput

`detectDiagramInput(text)` returns `{ kind, source }`, or `null`.

```ts
import { detectDiagramInput } from '@tiptap-pro/extension-diagrams'

const detected = detectDiagramInput(text)
if (detected?.kind === 'mermaid-diagram')
  editor.commands.insertFlowDiagram({ source: detected.source })
```

| `kind`              | Text                                                                                                          | Command to call                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `'mermaid-chart'`   | A Mermaid chart, such as `pie` or `sankey-beta`, with at least one row                                        | `importMermaidChart({ source })`                               |
| `'mermaid-diagram'` | Any other [Mermaid kind](/diagrams/flow-diagrams/overview#mermaid-kinds), on more than one line or in a fence | `insertFlowDiagram({ source })`                                |
| `'drawio'`          | An `<mxfile>` or `<mxGraphModel>`                                                                             | `insertFlowDiagram({ source, format: 'drawio' })`              |
| `'bpmn'`            | BPMN 2.0 `<definitions>`                                                                                      | `insertFlowDiagram({ source, format: 'bpmn' })`                |
| `'chart-syntax'`    | Rows with a delimiter, as the Chart syntax or CSV, with at least two columns                                  | `insertChartFrom({ format: 'chart-syntax', content: source })` |

- `source` is the text with a ` ```mermaid ` fence removed.
- A sentence, a lone Mermaid keyword and XML that cannot be read return `null`.
- Pasting and `confirmDiagramInput` use the same function, so your field gives the same result
  as a paste.

## Onto a selected chart

Spreadsheet apps copy rows to the clipboard as lines of cells separated by tabs.

- **When a chart is selected**, the pasted rows go through
  [`updateChartFromGrid`](/diagrams/data/overview#updatechartfromgrid). They replace the chart's data and keep
  its spec.
- **When the selected chart is read-only**, the paste changes nothing.
- **Anywhere else**, the rows paste as they would without the extension.

## Commands

### insertFromText

Inserts a chart or a diagram from a text. It reads the text as a paste does, with
`detectDiagramInput`.

```ts
editor.commands.insertFromText({ text: 'Month | Sales\nJan | 2\nFeb | 3' })
```

| Option | Type     | Description                                          |
| ------ | -------- | ---------------------------------------------------- |
| `text` | `string` | The text, as it would be pasted                      |
| `pos`  | `number` | The position to insert at. Defaults to the selection |

[Mermaid chart source](/diagrams/charts/overview#importmermaidchart) and rows become a chart. Other
Mermaid, draw.io XML and BPMN XML become a diagram.

Returns `false` for text that is none of them.
