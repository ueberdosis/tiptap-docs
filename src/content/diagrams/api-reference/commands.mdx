The examples use the `editor` from [A first chart](/diagrams/getting-started/install#a-first-chart). The second
opens the Quick Input, a text field where the user types rows that become a chart.

```ts
editor.commands.updateChartSpec({ spec: { type: 'area', stacked: true } })
editor.chain().focus().insertDiagramInput({ type: 'pie' }).run()
```

## How the commands behave

You run a command with `editor.commands`, chain several with `editor.chain()` and `run()`, and ask
`editor.can()` whether one would work. A command returns `true` when it acts, even if the result
equals what was there, and `editor.can()` returns `true` when it would act, without changing the
document. When a command cannot act, it returns `false` and changes nothing.

A command that changes a chart or a diagram takes an optional `pos`, its position from
`listCharts()` or `listDiagrams()`. Without `pos`, it changes the selected chart or
diagram, the one the user clicked.

The insert commands insert at `pos`, or at the selection without it. `insertDiagramInput` takes no
`pos` and always opens at the selection, and `confirmDiagramInput` takes a position inside the open
input. `insertLinkedChart`, `linkChartToTable`, `insertDiagramFromTable` and `linkDiagramToTable`
take the table's position as `table`. The setters of the open Quick Input take a single value, such
as `setDiagramInputType('bar')`.

Reading needs no command: the reading functions are on [`editor.storage.diagrams`](/diagrams/api-reference/storage).

## Charts

| Command                                                               | What it does                                                 |
| --------------------------------------------------------------------- | ------------------------------------------------------------ |
| [`insertChart`](/diagrams/charts/overview#insertchart)                         | Inserts a chart from Chart Data and a Chart Spec             |
| [`insertChartFrom`](/diagrams/charts/overview#insertchartfrom)                 | Inserts a chart written in a registered format               |
| [`importMermaidChart`](/diagrams/charts/overview#importmermaidchart)           | Inserts a chart from Mermaid chart source, such as `pie`     |
| [`insertFromText`](/diagrams/data/pasting#insertfromtext)                    | Inserts text as a chart or a diagram, as a paste would       |
| [`convertCodeBlockToChart`](/diagrams/charts/overview#convertcodeblocktochart) | Replaces a code block of Mermaid chart source with the chart |
| [`insertDiagramInput`](/diagrams/charts/overview#insertdiagraminput)           | Opens an empty Quick Input                                   |
| [`updateChartSpec`](/diagrams/charts/appearance#updatechartspec)             | Changes fields of the Chart Spec                             |
| [`setChartRenderer`](/diagrams/charts/appearance#setchartrenderer)           | Chooses the Renderer of one chart                            |
| [`updateChartAxis`](/diagrams/charts/axes#updatechartaxis)                   | Changes one axis: title, range, lines, step, labels          |
| [`applyChartLook`](/diagrams/charts/looks#applychartlook)                    | Gives a chart the look of another one                        |
| [`convertChartToImage`](/diagrams/export#convertcharttoimage)                | Replaces a chart with an image of it                         |
| [`convertImageToChart`](/diagrams/export#convertimagetochart)                | Turns that image, which keeps the chart, back into it        |
| [`redrawChartImage`](/diagrams/export#redrawchartimage)                      | Draws that image again from the chart it keeps               |
