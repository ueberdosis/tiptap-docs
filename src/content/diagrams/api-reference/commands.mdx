```ts
editor.commands.updateChartSpec({ spec: { type: 'area', stacked: true } })
editor.chain().focus().insertDiagramInput({ type: 'pie' }).run()
```

## How every Command behaves

- **With `pos`** a Command acts on the chart or diagram at that position.
- **Without `pos`** it acts on the selected one.
- **With nothing to act on** it returns `false` and changes nothing.
- **Reading** never needs a Command. The readers are on [`editor.storage.diagrams`](/diagrams/api-reference/storage).
