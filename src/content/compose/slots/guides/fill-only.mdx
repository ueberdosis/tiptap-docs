---
title: Allow filling only
meta:
  description: Protect template content and assign individual fields with a ready-made policy.
---

Install both packages to let a user fill fields while keeping the surrounding document, Slot identities and configuration fixed.

```ts
import { Slot, createSlotFillingPolicy } from '@tiptap-pro/extension-slot'
import { ContentProtection } from '@tiptap-pro/extension-content-protection'

const extensions = [
  StarterKit,
  Slot,
  ContentProtection.configure({
    policy: createSlotFillingPolicy(),
  }),
]
```

Pass IDs to assign specific fields:

```ts
editor.commands.setContentProtectionPolicy({
  policy: createSlotFillingPolicy({
    editableSlotIds: ['summary', 'justification'],
  }),
})
```

Omitting the list allows every Slot. An empty list allows none. Nested fields are assigned independently: permission to fill a parent does not grant permission to fill its unlisted children.

The helper returns ordinary policy JSON, so you can add higher-priority rules. It does not run validation. See [the generated rules](/compose/slots/api-reference/utilities#createslotfillingpolicy).
