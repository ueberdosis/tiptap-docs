The Slot extension does not prevent users from editing content ouside the slots. To restrict what can be edited, use the ContentProtection extension.

The ContentProtection extension takes a content protection policy. You can use the [`createSlotFillingPolicy` utility](/compose/slots/api-reference/utilities#createslotfillingpolicy), it contains a ready-made policy that protects all content except slots.

```ts
import { Slot, createSlotFillingPolicy } from '@tiptap-pro/extension-slot'
import { ContentProtection } from '@tiptap-pro/extension-content-protection'

const extensions = [
  StarterKit,
  Slot,
  ContentProtection.configure({
    policy: createSlotFillingPolicy(),
  }),
]
```

To allow users to edit only certain fields, pass their IDs to the policy creator.

```ts
editor.commands.setContentProtectionPolicy({
  policy: createSlotFillingPolicy({
    editableSlotIds: ['summary', 'justification'],
  }),
})
```
