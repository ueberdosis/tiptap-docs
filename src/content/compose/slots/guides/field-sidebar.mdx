---
title: Build a field sidebar
meta:
  description: List fields, display progress and navigate to a Slot from application UI.
---

Read the Slot snapshot for labels, nesting and completion. Subscribe to document changes to refresh your sidebar:

```ts
const renderFields = ({ snapshot }) => {
  showFields(
    snapshot.slots.map((slot) => ({
      id: slot.id,
      label: slot.config?.label ?? 'Field',
      answered: !slot.empty,
      depth: slot.depth,
    })),
  )
}

editor.on('slotsUpdate', renderFields)
renderFields({ snapshot: editor.storage.slot.snapshot })
```

Navigate when a user selects an item:

```ts
editor.commands.focusSlot({ id: 'summary' })
editor.commands.focusNextSlot({ wrap: true })
```

“Answered” means the field is not empty. It does not mean its content is valid. Show validation findings after a validation request.

If Content Protection conceals fields, check readability before exposing labels, values or counts in your sidebar. Storage contains the full document.

Clean up subscriptions when your UI unmounts:

```ts
editor.off('slotsUpdate', renderFields)
```
