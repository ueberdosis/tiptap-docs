## Use the clearNodes command

The default node depends on the parent node's `content` expression at the selected block's position. For top-level blocks, the parent is your [`Document`](/editor/extensions/nodes/document), whose `content` defaults to `block+` (at least one block node). The [`Paragraph`](/editor/extensions/nodes/paragraph) node is usually the default because its priority of `1000` loads it before most other block nodes. A custom block extension with a higher priority can become the default instead. A custom wrapper can have a different default node.

```js
editor.commands.clearNodes()
```
