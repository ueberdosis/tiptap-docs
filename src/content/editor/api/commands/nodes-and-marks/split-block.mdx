`splitBlock` splits the current block at the cursor position. If text is selected, it deletes the selected content before splitting. If the current selection is not splittable, the command will be ignored.

## Parameters

`options: Record<string, any>`

- `keepMarks: boolean` - Defines if the marks should be kept or removed. Defaults to `true`.

## Use the splitBlock command

```js
// split the current node and keep marks
editor.commands.splitBlock()

// split the current node and don't keep marks
editor.commands.splitBlock({ keepMarks: false })
```
