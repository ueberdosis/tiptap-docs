See the [ProseMirror reference for NodeSelection](https://prosemirror.net/docs/ref/#state.NodeSelection).

## Parameters

`position: number`

The position the NodeSelection will be created at.

## Use the setNodeSelection command

```js
editor.commands.setNodeSelection(10)
```
