## Parameters

`name: String`

The key combination to trigger, for example `Mod-z` for undo with the Undo/Redo extension. `Mod` means `Cmd` on macOS and `Ctrl` on Windows and Linux.

## Use the keyboardShortcut command

```js
editor.commands.keyboardShortcut('Mod-z')
```
