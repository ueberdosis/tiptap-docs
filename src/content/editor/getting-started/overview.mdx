## The editor and the document

The editor is the interface for people. The content and its [schema](/editor/core-concepts/schema) belong to the [Tiptap Document](/document-model), which your application and AI agents work on as well.

- **Extensions define the schema.** Each node and mark extension adds a kind of content the document may hold. The same extensions also work without an editor, for example to [render HTML on the server](/editor/api/utilities/html). [Extensions](/editor/core-concepts/extensions)
- **The editor turns input into changes.** Typing, formatting, and [commands](/editor/api/commands) change the document and the selection.
- **Your code follows the document.** [Events](/editor/api/events) tell you when it changes, and `editor.getJSON()` returns it as Tiptap JSON. [Persistence](/editor/core-concepts/persistence)

## What you can do with it

- **Use any framework.** React, Vue, Svelte, Next.js, Nuxt, Alpine, PHP, or plain JavaScript. [Quick start](/editor/getting-started/install)
- **Add only what you need.** Extensions bring everything from bold and links to tables and slash menus; StarterKit bundles the common ones. [Features](/editor/extensions/overview), [StarterKit](/editor/extensions/functionality/starterkit)
- **Design the interface yourself.** The editor is headless; you style it and build its menus. [Styling](/editor/getting-started/style-editor), [Custom menus](/editor/getting-started/style-editor/custom-menus)
- **Start from ready-made UI.** React components and full templates give you a finished editor to customize. [UI Components](/ui-components/getting-started/overview), [Templates](/ui-components/templates/simple-editor)
- **Edit together and review.** Several people in one document, comment threads, and suggestions to accept or reject. [Collaboration](/editor/extensions/functionality/collaboration), [Comments](/comments/getting-started/overview), [Tracked Changes](/tracked-changes/getting-started/overview)
- **Build your own extensions.** Create nodes, marks, and extensions, or extend existing ones. [Custom extensions](/editor/extensions/custom-extensions)

## Open source and paid

| Part | License or plan |
| --- | --- |
| The editor, its framework packages, and the [open source extensions](/editor/extensions/overview?plan=Open%20source) | Open source under the MIT license |
| UI Components for open source extensions, and the [Simple Editor](/ui-components/templates/simple-editor) template | Open source under the MIT license |
| Real-time editing with the Collaboration extension and [Hocuspocus](/hocuspocus/getting-started/overview) | Open source under the MIT license |
| Paid features such as Comments, Tracked Changes, Snapshots, Conversion, and the AI Toolkit | A paid plan or add-on. Some also need the [Document Server](/collaboration/getting-started/overview). |

Every feature page names the plan it needs, and [Tiptap Platform](/platform) lists what each plan includes. The [trial](/resources/tiptap-trial) opens a paid plan for 30 days.
