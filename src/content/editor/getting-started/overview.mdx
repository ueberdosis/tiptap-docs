## What you can do with it

- **Use any framework.** React, Vue, Svelte, Next.js, Nuxt, Alpine, PHP, or plain JavaScript. [Quick start](/editor/getting-started/install)
- **Add only what you need.** Extensions bring everything from bold and links to tables and slash menus, so the bundle stays small and the schema under your control. [Features](/editor/extensions/overview)
- **Start with a set of basics.** StarterKit bundles the common nodes and marks. [Starter kit](/editor/extensions/functionality/starterkit)
- **Design the interface yourself.** The editor is headless; you style it and build its menus. [Styling](/editor/getting-started/style-editor), [Custom menus](/editor/getting-started/style-editor/custom-menus)
- **Start from ready-made UI.** React components and full templates give you a finished editor to customize. [UI Components](/ui-components/getting-started/overview), [Templates](/ui-components/templates/simple-editor)
- **Control it from code.** Commands change the content, and events tell you when it changes. [Commands](/editor/api/commands), [Events](/editor/api/events)
- **Build your own extensions.** Create nodes, marks, and extensions, or extend existing ones. [Build your own](/editor/extensions/custom-extensions)
- **Add Pro features.** Comments, version history, AI, and more come as paid extensions with a 30-day trial. [Pro access](/guides/pro-extensions)

## Get started

Install the core, ProseMirror, and StarterKit:

```bash
npm install @tiptap/core @tiptap/pm @tiptap/starter-kit
```

Create an editor in an element on your page:

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'

new Editor({
  element: document.querySelector('.element'),
  extensions: [StarterKit],
  content: '<p>Hello World!</p>',
})
```

[Quick start](/editor/getting-started/install) has the setup for each framework.

## How it works

The editor builds on three things:

| Part | What it does |
| --- | --- |
| [Extensions](/editor/core-concepts/extensions) | Add nodes, marks, and behavior to the editor |
| [Commands](/editor/api/commands) | Change the content and the selection |
| [Events](/editor/api/events) | Tell your code when something changes |

[Concepts](/editor/core-concepts/introduction) explains them, and the [schema](/editor/core-concepts/schema) that decides what a document may contain.
