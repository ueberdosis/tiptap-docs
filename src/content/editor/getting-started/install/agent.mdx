## Install with your agent

```text
Inspect the repository to identify its framework, language, package manager, and existing editor entry point. Choose the matching guide below, then install and mount Tiptap in that existing app. Do not scaffold a second project or replace unrelated files.

Use the install commands and configuration from the matching guide, adapted to the package manager already used in the project. If the framework is not listed, keep the current stack and use the closest integration pattern.

React: https://tiptap.dev/editor/getting-started/install/react
Next.js: https://tiptap.dev/editor/getting-started/install/nextjs
Vanilla JavaScript: https://tiptap.dev/editor/getting-started/install/vanilla-javascript
Vue 3: https://tiptap.dev/editor/getting-started/install/vue3
Vue 2: https://tiptap.dev/editor/getting-started/install/vue2
Nuxt: https://tiptap.dev/editor/getting-started/install/nuxt
Svelte: https://tiptap.dev/editor/getting-started/install/svelte
Alpine.js: https://tiptap.dev/editor/getting-started/install/alpine
PHP: https://tiptap.dev/editor/getting-started/install/php

Run relevant checks already defined in the project and summarize what you changed.
```
