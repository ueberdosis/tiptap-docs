## When you use them

- **Images and other files.** File handler calls your code when someone drops or pastes a file, for example to insert it as an image.
- **Content from office apps.** Paste handler cleans up content pasted from Microsoft Excel, Word, and Google Docs, and removes formatting artifacts of the source.

## How they work

- **File handler leaves the upload to you.** Its `onPaste` and `onDrop` callbacks receive the files. It doesn't display or upload them; you insert a node and upload the file to your server. `allowedMimeTypes` limits which files it accepts.
- **Paste handler needs no configuration.** Add it to the editor and it transforms pasted HTML. If a transformation fails, the original pasted HTML is used.
- **Paste handler requires the Team plan.** It comes from the `@tiptap-pro/extension-paste-handler` package.
- **You add them yourself.** Neither is part of the [StarterKit](/editor/extensions/functionality/starterkit).
