## Install

```bash
npm install @tiptap-pro/extension-bookmark
```

The package comes from the Tiptap Pro registry. See
[the Pro registry](/page-layout/getting-started/install#the-pro-registry)
if you have not set it up yet. Its peer dependencies are `@tiptap/core` and `@tiptap/pm`.

## Quick start

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Bookmarks, bookmarkByName } from '@tiptap-pro/extension-bookmark'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, Bookmarks],
})

editor.commands.addBookmark({ name: 'Payment_terms' }) // on the Selection

const { id } = bookmarkByName(editor.state.doc, 'Payment_terms')
editor.commands.goToBookmark(id)
```

- **A bookmark is invisible** unless bookmarks are [shown](/editor/extensions/functionality/bookmark#showing-bookmarks).
- **It adds nothing to the text.** `editor.getText()` and a copy as plain text are the same with
  or without one.

## What a bookmark is

`Bookmarks` brings two types:

| Type            | Kind             | For              | HTML                                                                                                     |
| --------------- | ---------------- | ---------------- | -------------------------------------------------------------------------------------------------------- |
| `bookmark`      | Mark             | A run of text    | `<span class="tiptap-bookmark" data-tt-bookmark="id" data-tt-bookmark-name="name">` around the text      |
| `bookmarkPoint` | Inline atom Node | A point, no text | An empty `<span class="tiptap-bookmark-point" data-tt-bookmark-point="id" data-tt-bookmark-name="name">` |

Each bookmark has two attributes:

| Attribute | Description                                                                                |
| --------- | ------------------------------------------------------------------------------------------ |
| `id`      | What a reference or a link keeps. It does not change when the bookmark is renamed or moved |
| `name`    | What a reader sees, and what a .docx stores                                                |

- **A bookmark on text may run across several paragraphs.** Every run of text with the same `id`
  is one bookmark, from the first position any of them covers to the last.
- **Bookmarks may overlap and nest.**
- **Typing at the end of a bookmark** does not widen it.

## Names

A name is one Word accepts: a letter first, then letters, digits and `_`, at most forty
characters (`BOOKMARK_NAME_LIMIT`). Names are compared without regard to case, so `Terms` and
`terms` are the same bookmark.

```js
import { isValidBookmarkName, bookmarkNameFromText } from '@tiptap-pro/extension-bookmark'

isValidBookmarkName('4th clause') // false
bookmarkNameFromText('the agreed price') // 'the_agreed_price'
bookmarkNameFromText('Price', ['price']) // 'Price_2'
```

- **A name that starts with `_` is hidden.** Word names the bookmarks it makes for itself this
  way: `_Ref…` behind a cross-reference, `_Toc…` behind a table of contents.
- **Hidden bookmarks are kept,** and `bookmarksIn` leaves them out unless you ask for them.
- **A reader cannot add a hidden name.** Code can, with `hidden: true`.
- **Without a `name`,** `addBookmark` names the bookmark after the selected words, with
  `bookmarkNameFromText`. Words that do not start with a letter get `Bookmark_` in front, and no
  words give `Bookmark`.

`isHiddenBookmarkName(name)` says whether a name starts with `_`, and `sameBookmarkName(a, b)`
compares two names without regard to case.

## Adding, moving, renaming, removing

```js
editor.commands.addBookmark({ name: 'Price' }) // on the Selection
editor.commands.renameBookmark('Cost') // the bookmark around the cursor
editor.commands.removeBookmark() // the text stays
```

- **With text selected,** the bookmark is on that text. With nothing selected, it is a point at
  the cursor.
- **Adding under a name the document already has moves that bookmark** to the Selection, as Word
  does. Its `id` stays, so every reference to it follows.
- **Renaming keeps the `id` too.** A name another bookmark has is refused.

## Going to a bookmark

```js
editor.commands.goToBookmark(id)
```

`goToBookmark` selects the bookmark and scrolls to it. An integration that reveals a position its
own way, because the place may not be drawn yet, passes `reveal`:

```js
Bookmarks.configure({
  reveal: (bookmark) => myScrollTo(bookmark.from),
})
```

- **`reveal` gets the bookmark** as `bookmarksIn` reads it, and returns whether it went there.
- **`goToBookmark` and a followed link** call it instead of selecting the bookmark.

## Links to a bookmark

A click on a link whose `href` is `#name` goes to the bookmark of that name. That is how a link
inside a document points at a place in it.

```js
import { bookmarkHref } from '@tiptap-pro/extension-bookmark'

editor
  .chain()
  .setLink({ href: bookmarkHref('Payment_terms') })
  .run()
```

- **A link to a name no bookmark has,** and every other link, is left to whatever else handles
  links, Tiptap's Link Extension included.
- **`bookmarkNameOfHref(href)`** reads the name back, or returns `null` for an `href` that is not
  `#name`.
- **`followLinks: false`** leaves every link alone.

## Showing bookmarks

This is Word's _Show bookmarks_. The text of every bookmark gets a dashed underline, across
paragraphs and pages, and a thin bar marks a bookmark on no text. Hidden bookmarks are not shown.

```js
Bookmarks.configure({ showBookmarks: true })
editor.commands.toggleBookmarkVisibility() // on, off
editor.commands.toggleBookmarkVisibility(false) // off
```

- **Neither takes room or covers a character.** No line rewraps when they appear.
- **Showing bookmarks writes nothing** to the document.
- **`areBookmarksShown(state)`** says whether they are shown.

The package brings their stylesheet as a function, for a page without a build step for CSS:

```js
import { mountBookmarkStyles, bookmarkStyleRules } from '@tiptap-pro/extension-bookmark'

mountBookmarkStyles(document) // once; a second call does nothing
```

| Option  | Type     | Default                    | Description                                  |
| ------- | -------- | -------------------------- | -------------------------------------------- |
| `id`    | `string` | `'tiptap-bookmark-styles'` | The id of the `style` element                |
| `nonce` | `string` | —                          | The nonce a Content Security Policy asks for |

Under a Content Security Policy, pass the nonce you give the editor as `injectNonce`. Where the
policy admits no `style` element, load `bookmarkStyleRules()` from a file instead.

The underlined text is `.tiptap-bookmark-shown`, with the bookmark's name as its `title`. The bar
is `.tiptap-bookmark-point-marker`. These custom properties change them:

| Property              | Default   | Changes                               |
| --------------------- | --------- | ------------------------------------- |
| `--tt-bookmark-color` | `#8a8a8a` | The line and the bar                  |
| `--tt-bookmark-line`  | `dashed`  | The line, any `text-decoration-style` |

## Copy and paste

A name is one bookmark:

- **Pasting text whose bookmark the document already has,** by the same `id` or another bookmark
  of that name, pastes the text without it. The bookmark stays where it was.
- **Pasting what was cut** moves the bookmark, and so does dragging text to another place.

## Reading the bookmarks

```js
import {
  bookmarksIn,
  bookmarkById,
  bookmarkByName,
  bookmarkAround,
} from '@tiptap-pro/extension-bookmark'

bookmarksIn(editor.state.doc) // in the order they begin
bookmarksIn(editor.state.doc, { sort: 'name' }) // as Word's dialog sorts them
bookmarksIn(editor.state.doc, { hidden: true }) // Word's own as well
bookmarkByName(editor.state.doc, 'price') // without regard to case
bookmarkAround(editor.state.doc, from, to) // the smallest one around a range
```

Each bookmark is `{ id, name, hidden, from, to, point }`:

| Field    | Type      | Description                                   |
| -------- | --------- | --------------------------------------------- |
| `id`     | `string`  | The bookmark's id                             |
| `name`   | `string`  | Its name                                      |
| `hidden` | `boolean` | Whether the name starts with `_`              |
| `from`   | `number`  | Where it begins                               |
| `to`     | `number`  | Where it ends. The same as `from` for a point |
| `point`  | `boolean` | Whether it is a bookmark on no text           |

`bookmarksInBlock(block, blockPos)` reads the bookmarks that begin in one top-level block, at
their positions in the document.

### Leaving Nodes out

Every reader takes `ignore`, a function of a Node:

- **`true`** skips the Node, with everything in it.
- **`'descend'`** reads inside the Node. Use it for a Node that holds the document's own content
  without being part of it.

An editor that draws copies of content standing elsewhere passes `ignore` once to the Extension,
and every Command uses it:

```js
Bookmarks.configure({ ignore: (node) => node.attrs.isCopy === true })
```

## Referring to a bookmark

The cross-reference package reads bookmarks through a source. See
[Sources](/editor/extensions/functionality/cross-references/sources#inside-the-document). Neither package
depends on the other.

## Word

A .docx holds a bookmark as a name between a `w:bookmarkStart` and a `w:bookmarkEnd`. For a
converter, two functions work on that shape:

```js
import { bookmarkRangesIn, addImportedBookmarksTransaction } from '@tiptap-pro/extension-bookmark'

const ranges = bookmarkRangesIn(editor.state.doc) // [{ name, from, to }]

const tr = addImportedBookmarksTransaction(editor.state, rangesFromTheFile)
if (tr) editor.view.dispatch(tr)
```

- **`bookmarkRangesIn`** lists every bookmark as `{ name, from, to }`, hidden ones included.
- **`addImportedBookmarksTransaction`** puts ranges read out of a file onto the document. It
  keeps Word's hidden names. An empty range is a bookmark on no text.
- **It skips** a name the document already has, a name Word would not accept, a range with no
  text that can carry a bookmark, and the second of two ranges under one name.

Text copied in Word and pasted keeps its bookmarks under their names, hidden ones included:

- **Each lands as a bookmark on no text** where it begins, because the clipboard does not say
  where a bookmark ends.
- **A name the document already has** is dropped, as with any paste.

## Options

| Option          | Type                                     | Default | Description                                                                                         |
| --------------- | ---------------------------------------- | ------- | --------------------------------------------------------------------------------------------------- |
| `showBookmarks` | `boolean`                                | `false` | Whether bookmarks are [shown](/editor/extensions/functionality/bookmark#showing-bookmarks) at first |
| `followLinks`   | `boolean`                                | `true`  | Whether a click on a link to `#name` goes to the bookmark                                           |
| `ignore`        | `(node) => boolean \| 'descend' \| null` | `null`  | See [Leaving Nodes out](/editor/extensions/functionality/bookmark#leaving-nodes-out)                |
| `reveal`        | `((bookmark) => boolean) \| null`        | `null`  | See [Going to a bookmark](/editor/extensions/functionality/bookmark#going-to-a-bookmark)            |

## Commands

Every Command except `toggleBookmarkVisibility` returns `false` where it would do nothing, so a
toolbar can disable a button with `editor.can()`.

### addBookmark

Adds a bookmark on the Selection, or a point where the Selection is empty.

```js
editor.commands.addBookmark() // named after the selected words
editor.commands.addBookmark({ name: 'Price' })
editor.commands.addBookmark({ name: '_Ref42', hidden: true })
editor.commands.addBookmark({ name: 'Spot', from: 12, to: 12 })
```

| Option   | Type      | Description                                                                                        |
| -------- | --------- | -------------------------------------------------------------------------------------------------- |
| `name`   | `string`  | A [name](/editor/extensions/functionality/bookmark#names) Word accepts. Default the selected words |
| `hidden` | `boolean` | Whether the name may start with `_`. Default `false`                                               |
| `from`   | `number`  | Where the bookmark begins. Default the start of the Selection                                      |
| `to`     | `number`  | Where it ends. Default the end of the Selection. Equal to `from` for a point                       |

A name the document already has moves that bookmark here, and keeps its id.

Returns `false` for a name that is not valid, and where nothing in the range can carry a
bookmark, such as a horizontal rule or an image.

### removeBookmark

Removes a bookmark. Its text stays.

```js
editor.commands.removeBookmark()
```

| Argument | Type     | Description                                                 |
| -------- | -------- | ----------------------------------------------------------- |
| `id`     | `string` | The bookmark. Default the smallest one around the Selection |

Returns `false` where there is no such bookmark.

### renameBookmark

Gives a bookmark another name. Its id stays, so references and links by id follow.

```js
editor.commands.renameBookmark('Cost')
```

| Argument | Type     | Description                                                 |
| -------- | -------- | ----------------------------------------------------------- |
| `name`   | `string` | The new name                                                |
| `id`     | `string` | The bookmark. Default the smallest one around the Selection |

Returns `false` where there is no such bookmark, and for a name that is not valid, is the one it
has, or is another bookmark's.

### goToBookmark

Selects a bookmark and scrolls it into view, or calls `reveal` where the Extension has one.

```js
editor.commands.goToBookmark(bookmarkByName(editor.state.doc, 'Price').id)
```

| Argument | Type     | Description       |
| -------- | -------- | ----------------- |
| `id`     | `string` | The bookmark's id |

Returns `false` where no bookmark has that id, and where `reveal` returns `false`.

### toggleBookmarkVisibility

Shows or hides the bookmarks in the text. It writes nothing to the document.

```js
editor.commands.toggleBookmarkVisibility(true)
```

| Argument  | Type      | Description                                         |
| --------- | --------- | --------------------------------------------------- |
| `visible` | `boolean` | Shown or hidden. Default the opposite of what it is |

Always returns `true`.

## Writing without a command

Each Command but the last has a function that returns the Transaction instead of dispatching it,
or `null` where the Command returns `false`. Use it to write to a document the editor does not
show, or to add to the same step as something else.

| Command          | Function                    | Arguments                   |
| ---------------- | --------------------------- | --------------------------- |
| `addBookmark`    | `addBookmarkTransaction`    | `state, options?`           |
| `removeBookmark` | `removeBookmarkTransaction` | `state, id, options?`       |
| `renameBookmark` | `renameBookmarkTransaction` | `state, id, name, options?` |
| `goToBookmark`   | `goToBookmarkTransaction`   | `state, id, options?`       |

```js
import { addBookmarkTransaction } from '@tiptap-pro/extension-bookmark'

const tr = addBookmarkTransaction(state, { name: 'Price' })
if (tr) view.dispatch(tr)
```

- **`options` takes `ignore`,** as the readers do.
- **`renameBookmarkTransaction` also takes `hidden`,** for a hidden name.
- **`isBookmarkNameFree(state, name, { except })`** says whether a name is free. `except` is the
  id of a bookmark that may keep its own.

`Bookmark` and `BookmarkPoint` are the two types on their own, and `BOOKMARK_MARK_NAME` and
`BOOKMARK_POINT_NODE_NAME` their names.

## Limitations

- **A .docx file does not carry these bookmarks yet.** Convert's import and export use a
  zero-width `bookmark` Node of their own, from `@tiptap-pro/extension-convert-kit`. An import
  places it where a bookmark begins, and loses the range it covered.
- **That Node has the name of this package's Mark.** In an editor with `Bookmarks`, pass
  `bookmark: false` to `ConvertKit`. A schema cannot have a Node and a Mark of one name.
- **A paste from Word** gives each bookmark as a point where it begins.
- **A paste as plain text** has no bookmarks.

With [Page Layout](/page-layout/getting-started/overview), pass its `ignoreLayoutArtifacts`
as `ignore`. See
[Bookmarks in Page Layout](/page-layout/paginating-extensions#bookmarks).
