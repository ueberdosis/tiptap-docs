The Page Layout extension shows a Tiptap editor as pages: A4, Letter, landscape or a size of your
own, with the text flowing from one sheet to the next as it is typed. What you save stays an
ordinary Tiptap document, with no pages in it.

<Callout title="More details" variant="hint">
  For installation, every feature and every Command, visit the [Page Layout
  section](/page-layout/getting-started/overview).
</Callout>

<Callout title="Alpha" variant="info">
  This extension is under active development. The API may change in future releases.
</Callout>
