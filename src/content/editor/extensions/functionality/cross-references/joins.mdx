A reference naming several targets reads them by a rule, chosen per reference or for every
reference at once. Set `multiple: true` to let a reference name several targets. Three rules
come with the package:

| Rule     | Reads        | How                                                                                                   |
| -------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| `list`   | `3, 5 and 7` | `listSeparator` between them, `lastSeparator` before the last. The default                            |
| `commas` | `3, 5, 7`    | `listSeparator` between all of them                                                                   |
| `range`  | `3–5 and 7`  | Three or more numbers that follow each other are one range, with `rangeSeparator`. The rest is listed |

```js
import { CrossReferences } from '@tiptap-pro/extension-cross-references'

CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  join: 'range', // for every reference that names no rule
})

editor.commands.insertCrossReference({
  targets: ['three', 'four', 'five'],
  show: 'number',
  join: 'commas',
})
editor.commands.setCrossReferenceOptions({ join: null }) // back to the configured rule
```

- **`join` on `CrossReferences`** is the rule a reference without one of its own is read by.
  `list` by default.
- **`join` on a reference** is the id of a rule, or `null` for the configured one. It is written
  to HTML as `data-tt-join`.
- **A rule nobody registered** reads as the configured one.

The words are [phrases](/editor/extensions/functionality/cross-references#phrases): `listSeparator` (`, `), `lastSeparator` (`and`)
and `rangeSeparator` (`–`):

```js
CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  phrases: { lastSeparator: ' und ', rangeSeparator: ' bis ' },
})
// 3 bis 5 und 7
```

## Ranges

Two numbers follow each other where they are on the same level under the same parent, and the
second is one more: `3.2` after `3.1` and `4` after `3`, but not `4.1` after `3.9`.

- **It is read from `counts`** on the target's label. A target whose label has no `counts` is
  never part of a range.
- **A range is three numbers or more.** Two that follow each other read `3 and 4`.
- **The targets are taken in the order the reference names them.**
- **A reference that shows no number,** its text or its page, has no range.

## Your own rule

A rule is registered under an id. An id the package has replaces its rule:

```js
CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  joins: {
    alternatives: {
      title: '3, 5 or 7',
      pieces: ({ parts, phrases }) =>
        parts.flatMap((_part, index) =>
          index === 0
            ? [index]
            : [index === parts.length - 1 ? ' or ' : phrases.listSeparator, index],
        ),
    },
  },
})

editor.commands.insertCrossReference({ targets: ['three', 'five', 'seven'], join: 'alternatives' })
// 3, 5 or 7
```

| Field    | Type                                                     | Description                                                                                            |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `title`  | `string`                                                 | What a picker lists it as                                                                              |
| `pieces` | `({ parts, phrases, numbered }) => (number \| string)[]` | What the reference reads, in order. A number is the part at that index, a string is text between parts |

`pieces` gets:

| Field      | Description                                                               |
| ---------- | ------------------------------------------------------------------------- |
| `parts`    | One per target, in the order the reference names them: `{ text, target }` |
| `phrases`  | The configured phrases                                                    |
| `numbered` | Whether the reference shows a number                                      |

- **`text`** of a part is what the reference reads of that target.
- **`target`** of a part is the target as `crossReferenceTargetsIn` lists it, or `null` for one
  that is gone or [withheld](/editor/extensions/functionality/cross-references#withheld-targets).
- **Each part is read once,** at its first index. An index that is not a part, or a part named a
  second time, is left out.
- **A part the rule leaves out is not read,** as the `4` of `3–5`.
- **A reference naming one target** reads that target, whatever its rule.

`crossReferenceJoinChoices(joins)` lists the rules a picker offers, as `{ id, title }`: the
built-in ones, then yours. Pass `editor.storage.crossReferences.joins`.

## In Word

A .docx gets the same pieces: a field for each part the rule reads, and the text between them as
plain text, with the configured phrases. See [Word fields](/editor/extensions/functionality/cross-references/docx).
