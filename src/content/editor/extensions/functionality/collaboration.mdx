## Install

```bash
npm install @tiptap/extension-collaboration @tiptap/y-tiptap yjs y-protocols
```

The extension syncs the editor with a Yjs document. A provider connects that document to a server, so every user works on the same one. Use the [Document Server](/collaboration/getting-started/overview), which runs in Tiptap Cloud or on-premises and stores your documents, or the open source [Hocuspocus](/hocuspocus/getting-started/overview), which you run yourself. [Hosting](/hosting) compares the two.

### Connect to the Document Server

The provider comes from Tiptap's [private registry](/guides/pro-extensions) and needs the Start plan.

```bash
npm install @tiptap-pro/provider
```

```js
import { Editor } from '@tiptap/core'
import Collaboration from '@tiptap/extension-collaboration'
import StarterKit from '@tiptap/starter-kit'
import { TiptapCollabProvider } from '@tiptap-pro/provider'
import * as Y from 'yjs'

const doc = new Y.Doc()

new TiptapCollabProvider({
  name: 'document-name', // The document to sync
  appId: 'your-app-id', // From the Cloud dashboard, or baseUrl for on-premises
  token: 'your-jwt',
  document: doc,
})

new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    // Collaboration brings its own undo and redo
    StarterKit.configure({ undoRedo: false }),
    Collaboration.configure({ document: doc }),
  ],
})
```

[Install](/collaboration/getting-started/install) walks through authentication and the dashboard.

### Connect to Hocuspocus

```bash
npm install @hocuspocus/provider
```

```js
import { Editor } from '@tiptap/core'
import Collaboration from '@tiptap/extension-collaboration'
import StarterKit from '@tiptap/starter-kit'
import { HocuspocusProvider } from '@hocuspocus/provider'
import * as Y from 'yjs'

const doc = new Y.Doc()

new HocuspocusProvider({
  url: 'ws://127.0.0.1:1234', // Your Hocuspocus server
  name: 'document-name',
  document: doc,
})

new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit.configure({ undoRedo: false }),
    Collaboration.configure({ document: doc }),
  ],
})
```

[Collaborative editing](/hocuspocus/guides/collaborative-editing) sets up the server side.

## Settings

### document

An initialized Y.js document.

Default: `null`

```js
Collaboration.configure({
  document: new Y.Doc(),
})
```

### field

Name of a Y.js fragment, can be changed to sync multiple fields with one Y.js document.

Default: `'default'`

```js
Collaboration.configure({
  document: new Y.Doc(),
  field: 'title',
})
```

### fragment

A raw Y.js fragment, can be used instead of `document` and `field`.

Default: `null`

```js
Collaboration.configure({
  fragment: new Y.Doc().getXmlFragment('body'),
})
```

## Commands

The `Collaboration` extension comes with its own history extension. Make sure to disable the `UndoRedo` extension, if you’re working with the `StarterKit`.

### undo()

Undo the last change.

```js
editor.commands.undo()
```

### redo()

Redo the last change.

```js
editor.commands.redo()
```

## Usage with UniqueID

If you are using the [UniqueID extension](/editor/extensions/functionality/uniqueid) together with Collaboration, make sure to mount the editor only after the collaboration provider has synced. Incorrect initialization order can cause persistent empty paragraphs in the document. See [UniqueID: Usage with Collaboration](/editor/extensions/functionality/uniqueid#usage-with-collaboration) for details.
