## When you use them

- **Dragging content.** Dropcursor shows a cursor where dragged content will be dropped.
- **Reaching gaps.** Gapcursor lets the cursor stop where no regular selection is possible, for example after a table at the end of a document.
- **Showing the current node.** Focus adds a class to the node that has the cursor, `has-focus` by default.
- **Keeping the selection visible.** Selection adds a class to the selection while the editor is blurred, `selection` by default.

## How they work

- **They are extensions.** They don't add nodes or marks to the document; they change how the cursor and the selection behave and look. [Extensions](/editor/core-concepts/extensions)
- **Two come with the StarterKit.** Dropcursor and Gapcursor are part of the [StarterKit](/editor/extensions/functionality/starterkit); Focus and Selection you add yourself.
- **You style them.** Focus and Selection only add a CSS class, and the styling is up to you. Dropcursor needs CSS too, and has settings for its color, width, and class.
