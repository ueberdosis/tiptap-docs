## When you use them

- **Code samples.** Code block adds fenced code blocks, wrapped in `pre` and `code` tags.
- **Highlighted code.** Code block lowlight adds code blocks with syntax highlighting from the lowlight library.
- **Formulas.** Mathematics inserts LaTeX formulas, inline in a line of text or as a block, and renders them with KaTeX.

## How they work

- **They are nodes.** Code blocks and math formulas are nodes in the document. Mathematics adds two of them, one for inline math and one for block math. [Nodes and marks](/editor/core-concepts/nodes-and-marks)
- **Code block comes with the StarterKit.** Code block is part of the [StarterKit](/editor/extensions/functionality/starterkit); Code block lowlight and Mathematics you add yourself.
- **Highlighting is separate.** Code block has no styling and no syntax highlighting. Code block lowlight highlights code, and you pass it the `lowlight` module with the languages you load.
- **Mathematics needs KaTeX.** You install `katex` with the extension and import the KaTeX styles.
- **Markdown shortcuts.** Typing three backticks and a space starts a code block. Add a language after the backticks, such as `css`, to set it.
