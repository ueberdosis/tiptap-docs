## When you use them

- **Data in rows and columns.** Table inserts a table, three by three with a header row by default, and adds or deletes rows and columns.
- **Headers.** Table header adds header cells. Commands turn the current row, column, or cell into a header.
- **Merged cells.** Table merges the selected cells into one and splits a merged cell again.
- **Cell attributes.** `setCellAttribute()` sets an attribute you defined on Table cell, for example a background color.

## How they work

- **A table is four nodes.** Table holds Table rows, and each row holds Table cells and Table headers. Table cell, Table header, and Table row each require Table. [Nodes and marks](/editor/core-concepts/nodes-and-marks)
- **The Table kit bundles them.** The [Table kit](/editor/extensions/functionality/table-kit) holds Table, Table cell, Table header, and Table row. Tables aren't part of the [StarterKit](/editor/extensions/functionality/starterkit).
- **Commands do the editing.** Table's commands, such as `addRowAfter()` and `mergeCells()`, change the table, and `goToNextCell()` and `goToPreviousCell()` move between cells.
- **Headers are optional.** To allow no headers, change the `content` of Table row so it holds only cells.
