The Details extension enables you to use the `<details>` HTML tag in the editor. This is great to show and hide content.

<CodeDemo path="/Nodes/Details" />

## Install

```bash
npm install @tiptap/extension-details
```

## Install with your agent

```text
Add the DetailsContent extension to the Tiptap editor in this project.

Add the content node required inside Details. Register it with Details and DetailsSummary so the full disclosure schema remains valid.

Install the required packages with the project’s package manager: npm install @tiptap/extension-details.

Use this guide for the exact imports and options: https://tiptap.dev/editor/extensions/nodes/details-content

Inspect the existing framework and editor setup first. Change only the editor integration needed for this extension, preserve current behavior, and run the project’s available checks.
```

## Usage

```js
import { Details, DetailsSummary, DetailsContent } from '@tiptap/extension-details'

const editor = new Editor({
  extensions: [Details, DetailsSummary, DetailsContent],
})
```

## Settings

### HTMLAttributes

Custom HTML attributes that should be added to the rendered HTML tag.

```js
DetailsContent.configure({
  HTMLAttributes: {
    class: 'my-custom-class',
  },
})
```
