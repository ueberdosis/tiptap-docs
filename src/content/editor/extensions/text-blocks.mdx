## When you use them

- **Structure.** Heading adds headings of up to six levels, and Paragraph holds running text.
- **Quotes.** Blockquote shows a quote, rendered as a `blockquote` tag.
- **Collapsible sections.** Details shows and hides content behind a summary, with the HTML `details` tag.
- **Breaks.** Hard break forces a line break inside a block, and Horizontal rule draws a line that separates content.

## How they work

- **They are nodes.** Document is the top node that holds all other nodes, and Text holds plain text. Every editor needs Document, and you need Text for text of any kind and Paragraph for paragraphs. [Nodes and marks](/editor/core-concepts/nodes-and-marks)
- **Most come with the StarterKit.** Blockquote, Document, Hard break, Heading, Horizontal rule, Paragraph, and Text are part of the [StarterKit](/editor/extensions/functionality/starterkit); Details you add yourself.
- **Details needs two more nodes.** Details works together with Details summary and Details content, which come in the same package.
- **Markdown shortcuts.** Typing `# ` at the start of a line starts a heading, `> ` a blockquote, and `---` a horizontal rule. [Keyboard shortcuts](/editor/core-concepts/keyboard-shortcuts)
