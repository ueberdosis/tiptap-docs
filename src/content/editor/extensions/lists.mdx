## When you use them

- **Bullet points.** Bullet list adds unordered lists, rendered as `ul` tags.
- **Numbered steps.** Ordered list adds numbered lists, rendered as `ol` tags.
- **To-dos.** Task list and Task item add tasks, each with a checkbox that people check off.
- **Editing lists.** List keymap changes backspace at the start of a list item, so it lifts the content into the list item above.

## How they work

- **A list is two nodes.** Bullet list and Ordered list hold List items, and Task list holds Task items. Each list needs its item node. [Nodes and marks](/editor/core-concepts/nodes-and-marks)
- **The List kit bundles them.** The [List kit](/editor/extensions/functionality/list-kit) holds Bullet list, List item, Ordered list, Task item, Task list, and List keymap.
- **The StarterKit has the basics.** Bullet list, List item, Ordered list, and List keymap are part of the [StarterKit](/editor/extensions/functionality/starterkit); Task list and Task item are not.
- **Shortcuts.** Typing `- ` at the start of a line starts a bullet list, `1. ` an ordered list, and `[ ] ` a task list. <kbd>Tab</kbd> nests a list item and <kbd>Shift</kbd> + <kbd>Tab</kbd> lifts it out. [Keyboard shortcuts](/editor/core-concepts/keyboard-shortcuts)
