Commands return `true` on success. Expected failures return `false` and call `onError` if configured. Use `editor.can()` to validate without editing the document or calling `onError`.

| Command on `editor.commands` | Effect | Expected failures |
| --- | --- | --- |
| `createCitation({ sourceId, position })` | Cites the current text or node selection, or the node at `position`, and records the initial confirmed reference and creator. | Unknown source, unsupported selection or position, schema restriction, or invalid user. |
| `approveCitation(id)` | Confirms the current text and source revision and records the approver. | Unknown citation, missing source, or invalid user. |
| `revertCitation(id)` | Restores confirmed text for an inline citation and reevaluates affected citations. | Unknown citation, node citation, unsupported restoration, schema restriction, or invalid user. |
| `removeCitation(id)` | Removes the specified citation, keeping the cited content, source, and other citations. | Unknown citation. |

`CreateCitationOptions` requires a string `sourceId`. The optional numeric `position` is the ProseMirror position immediately before a node and overrides the current selection. Review commands take a citation ID string directly.
