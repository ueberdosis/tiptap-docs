| Export | Result |
| --- | --- |
| `getCitation({ editor, id })` | A `Citation` snapshot or `undefined` if the ID is absent. |
| `getCitations({ editor, filter })` | A frozen `readonly Citation[]` ordered by first range position, then ID. The optional `CitationFilter` combines `status` and `sourceId` when both are supplied. |
| `getSources(editor)` | A frozen `readonly SourceSnapshot[]` in insertion order. |
| `subscribeCitations({ editor, listener })` | An unsubscribe function. The listener receives a `CitationChange` with read-only `changedIds` and `removedIds` arrays. |

Listeners run after citation changes, including changes to ranges. Cursor movement alone does not notify. Destroying the editor detaches listeners. Smart Citations reports listener errors in a microtask after notifying the other listeners.

### Export collaborative JSON

Use `getCollaborativeCitationJSON(options)` to export ProseMirror JSON with merged node citations. `GetCollaborativeCitationJSONOptions` takes the `fragment: XmlFragment` used by Tiptap Collaboration. A plain Yjs fragment export can omit node citations merged from other collaborators.

```ts
import { getCollaborativeCitationJSON } from '@tiptap-pro/extension-smart-citations/collaboration'

const json = getCollaborativeCitationJSON({ fragment: ydoc.getXmlFragment('default') })
```
