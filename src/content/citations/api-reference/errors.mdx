`CitationError` extends `Error` with `code` and `details`. Details can include `sourceId`, `citationId`, `from`, `to`, `nodeType`, `markType`, or `path`. Invalid configuration, source operations, and queries throw.

| Code | What to check |
| --- | --- |
| `unknownSource` | Add the source before citing, updating, or removing it. |
| `unknownCitation` | Refresh the review UI and use a current citation ID. |
| `duplicateSourceId` | Update the existing source or use a different ID. |
| `unsupportedSelection` | Select a node or text in one textblock, or give the position before a node. Restore only inline citations within one textblock. |
| `markNotAllowed` | Check whether the node or an existing mark prevents the citation mark. |
| `sourceMissing` | Load the missing source before approving. |
| `unsupportedRevisionInput` | Inspect `details.path` and use supported JSON data. |
| `missingExtension` | Use an editor configured with `SmartCitations` and subscribe before destroying it. |
| `invalidSource` | Check the source shape, update fields, and revision strategy. |
| `invalidUser` | Supply a nonempty string ID and optional string name. |
