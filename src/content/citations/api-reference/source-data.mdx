Use strings, booleans, finite numbers, `null`, dense arrays, or plain objects with enumerable string keys. Cycles, accessors, `undefined`, and class instances are invalid.

These rules also apply to values returned by a [revision selector](/citations/guides/sources#choose-a-revision-strategy). See [source collections](/citations/api-reference/sources) for how to add and update sources.
