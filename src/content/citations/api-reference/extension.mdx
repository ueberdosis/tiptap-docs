Import `SmartCitations`, `createSources`, `defaultShouldReviewCitation`, citation queries, and types from `@tiptap-pro/extension-smart-citations`. Call citation commands on `editor.commands`.

The runtime extension name is `smartCitations`. Inline citations use the `citation` mark. Node citations use the `smartCitations` node attribute, an array of `CitationAttributes` serialized to HTML as `data-node-citations`.

## Configuration

The configuration type for `SmartCitations` is `SmartCitationsOptions`.

| Option | Type | Required or default |
| --- | --- | --- |
| `sources` | `SourceCollection` | Required. The application-owned collection. |
| `user` | `CitationUser \| (() => CitationUser)` | Required. Provide a nonempty string `id` and optional string `name`. |
| `shouldReviewCitation` | `ShouldReviewCitation` | Optional. Defaults to [`defaultShouldReviewCitation`](#text-review-rule). |
| `renderCitation` | `(context: CitationRenderContext) => CitationRenderResult` | Defaults to the source label or `Missing source`. See [reference rendering](/citations/guides/rendering). |
| `formatCopiedReference` | `(context: CopiedReferenceContext) => string \| null` | Formats copied references as ` [Label]` by default. See [copy and paste](/citations/guides/copy-and-paste). |
| `onCitationClick` | `(context: CitationClickContext) => void` | Optional. See [references and clicks](/citations/guides/rendering). |
| `onError` | `(error: CitationError) => void` | Optional. Receives expected command failures. |

Keep the `user` callback synchronous and free of side effects. Smart Citations reads it on setup, local edits, and validation for creation, approval, and restoration. If it returns an invalid user during an edit, Smart Citations keeps the edit and prior attribution and reports `invalidUser`.

### Text review rule

`ShouldReviewCitation` is `(context: CitationReviewContext) => boolean`. Smart Citations calls it when inline cited text differs from the text at creation or last approval. The context has four readonly fields.

| Field | Type | Meaning |
| --- | --- | --- |
| `text` | `string` | Current cited text. |
| `confirmedText` | `string` | Text at creation or last approval. |
| `citation` | `Readonly<Omit<Citation, 'status' \| 'invalidReasons'>>` | Current citation before status and invalid reasons are calculated. |
| `source` | `SourceSnapshot \| undefined` | Current source, if present. |

Returning `true` adds `textChanged`. Returning `false` skips that reason and keeps the confirmed text for future comparisons. A changed or missing source can still invalidate either kind of citation.

`defaultShouldReviewCitation` accepts an object with `text` and `confirmedText`. It trims both strings and collapses each run of whitespace to one space before comparing them. If the confirmed text is `10 samples`, `10  samples` needs no text review. Both `12 samples` and `10samples` require review.

Keep the callback synchronous and free of side effects. Use the same rule across collaborating editors so they derive the same citation status.

### Copied reference format

`CopiedReferenceContext` contains the readonly fields `citation: Citation` and `label: string`. The label is the plain text of the displayed reference. Return the full string to append, including any spacing, or `null` to omit the label. The format applies to both plain-text and HTML clipboard content.
