Select a node and run `createCitation`, or pass the position immediately before the node to cite it without changing the selection.

The examples use the [Smart Citations setup](/citations/getting-started/install).

```ts
editor.chain().setNodeSelection(nodePosition).createCitation({ sourceId: 'manual' }).run()

// Or cite the node without changing the selection.
editor.commands.createCitation({ sourceId: 'manual', position: nodePosition })
```

A node can carry several citations. Queries return `kind: 'node'` and a range that covers the node. Use `setNodeSelection(range.from)` to navigate to it. Use `setTextSelection(range)` for `kind: 'inline'`.

Node citations need review when their source changes or goes missing. Edits to the node update attribution, including changes to its text or attributes. Metadata from Smart Citations, Comments, and Tracked Changes does not count as an edit. Custom nodes must render the supplied HTML attributes to preserve citations in HTML exports.
