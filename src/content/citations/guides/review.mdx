Each citation saves the text and source revision at creation or last approval. Its status is `valid` when it has no invalid reasons. Users decide whether the source supports the passage.

The examples use the [Smart Citations setup](/citations/getting-started/install).

| Invalid reason | Meaning |
| --- | --- |
| `textChanged` | Inline cited text differs from the confirmed text and the [text review rule](/citations/api-reference/extension#text-review-rule) requires review. |
| `sourceChanged` | The current source revision differs from the confirmed revision. |
| `sourceMissing` | The source ID is absent from the local collection. |

A citation can have multiple reasons. Each clears when its condition clears.

### Customize text review

Use `shouldReviewCitation` to decide which inline text changes require review. This example reviews every change for the source with ID `statute`. For other sources, it ignores changes in capitalization and extra whitespace. If the confirmed text is `10 samples`, `10 Samples` needs no text review for those sources.

```ts
import { SmartCitations, defaultShouldReviewCitation } from '@tiptap-pro/extension-smart-citations'

const citations = SmartCitations.configure({
  sources,
  user: { id: 'author' },
  shouldReviewCitation: ({ text, confirmedText, source }) => {
    if (source?.id === 'statute') return text !== confirmedText
    return defaultShouldReviewCitation({
      text: text.toLowerCase(),
      confirmedText: confirmedText.toLowerCase(),
    })
  },
})
```

## Text selections, overlaps, and restoration

- **Creation.** Select nonempty text within one textblock. Formatted text works wherever the schema allows citation marks. Non-text inline nodes are unsupported.
- **Overlaps.** Citations can overlap or cover identical ranges, even for the same source. Deleting all cited text removes its citation.
- **Restoration.** Restoring text preserves uncited gaps and uses current formatting. The confirmed source revision stays the same. Across textblocks, only approval and removal work.

Use the [review commands](/citations/api-reference/commands) to approve, restore, or remove a citation.
