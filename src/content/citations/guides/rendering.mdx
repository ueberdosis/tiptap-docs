Smart Citations displays one reference after each citation's final range. It orders references by end position, then by citation ID.

The examples use the [Smart Citations setup](/citations/getting-started/install).

Use `firstSourceIndex` to refer to the first earlier citation of the same source. For Smith, Jones, then Smith again, the last reference displays `Smith, supra note 1`.

```ts
SmartCitations.configure({
  sources,
  user: { id: 'ada' },
  renderCitation: ({ defaultLabel, firstSourceIndex }) =>
    firstSourceIndex === undefined
      ? defaultLabel
      : `${defaultLabel}, supra note ${firstSourceIndex + 1}`,
  onCitationClick: ({ citations }) => {
    console.log(citations.map(citation => citation.id))
  },
})
```

`CitationRenderContext` provides `citation`, `source`, `previousCitation`, a zero-based `index`, and `defaultLabel`. The source and previous citation can be `undefined`. It also provides `firstSourceCitation` and `previousSourceCitation`, their zero-based document reference indices `firstSourceIndex` and `previousSourceIndex`, and `previousSourceCount`. With no earlier same-source reference, the citations and indices are `undefined` and the count is `0`.

Return plain text, an `HTMLElement`, or `null` to hide the reference. Hidden references count toward the index and same-source history. Return `{ element, destroy }` to run cleanup when the extension replaces or removes the element or destroys the editor.

`CitationClickContext` provides the mouse `event` and a read-only `citations` array. A reference click returns one citation. A click on overlapping text can return several. Custom references can suppress the callback with `preventDefault()` or `stopPropagation()`. Use a button or link for keyboard access.

| Selector | What it targets |
| --- | --- |
| `[data-citation-id]` | Persisted mark with its citation ID. |
| `[data-node-citations]` | Persisted citation metadata on a cited node. |
| `[data-node-citation-ids]` | Space-separated citation IDs on a decorated node. |
| `.citation-text` | Decorated cited text or node. |
| `.citation-invalid` | Text or a node with at least one invalid citation. |
| `.citation-reference` or `[data-citation-reference]` | Reference wrapper. |
| `[data-citation-status]` | Derived status on a text decoration, cited node, or reference wrapper. |
