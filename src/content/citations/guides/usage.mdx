Start with [Install Smart Citations](/citations/getting-started/install) to set up an editor and source collection.

- [Review](/citations/guides/review). Review changes to cited text or sources and choose which edits need approval.
- [Sources](/citations/guides/sources). Supply source data, publish updates, and choose how revisions are tracked.
- [Rendering](/citations/guides/rendering). Customize citation labels, styles, and click handling.
- [Review sidebar](/citations/guides/review-sidebar). Use citation queries and subscriptions to keep a review sidebar up to date.
- [Cite nodes](/citations/guides/cite-nodes). Attach sources to whole nodes and navigate to node citations.
- [Copy and paste](/citations/guides/copy-and-paste). Control copied reference labels and handle pasted citation metadata.
- [Collaboration](/citations/guides/collaboration). Set up Smart Citations with Yjs and persist collaborative citation data.
