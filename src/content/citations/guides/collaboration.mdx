Save the document with its `citation` marks and `smartCitations` node attributes. Store source records separately and reload them with the same IDs and revision strategy. Smart Citations derives status and positions when you open the document.

The examples use the [Smart Citations setup](/citations/getting-started/install).

Collaboration is optional. For a shared editor, follow the [Tiptap Collaboration setup](/collaboration/getting-started/install#integrate-yjs-and-the-collaboration-extension), then add Smart Citations to the same editor. Use the Yjs document connected to your provider and disable StarterKit history.

```ts
import Collaboration from '@tiptap/extension-collaboration'

const extensions = [
  StarterKit.configure({ undoRedo: false }),
  Collaboration.configure({ document: ydoc }),
  SmartCitations.configure({ sources, user: () => currentUser }),
]
```

- **Citations.** Yjs syncs inline marks and merges concurrent node citation changes by citation ID. Save the full Yjs document to persist the shared citation records. A mounted editor includes merged node citations in `getCitations`, `editor.getJSON()`, and `editor.getHTML()`. For server-side JSON, use [the collaborative export](/citations/api-reference/queries#export-collaborative-json).
- **Sources.** Each client checks validity against its local collection. To share sources, sync them in your app through an API or a Yjs map.
- **Attribution.** Remote edits keep the originating user's attribution when available. Undo and redo restore text and citation metadata.
- **Concurrent review.** Approval confirms what the reviewer saw. Unseen edits can leave the merged citation invalid. Removal applies to the marks the reviewer saw, so a concurrent attributed edit can survive.
