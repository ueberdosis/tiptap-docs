Render the list once, then refresh it when citations change. Unsubscribe when the panel unmounts.

The examples use the [Smart Citations setup](/citations/getting-started/install).

```ts
import { getCitations, subscribeCitations } from '@tiptap-pro/extension-smart-citations'
import type { Citation } from '@tiptap-pro/extension-smart-citations'

function watchReviewQueue(render: (citations: readonly Citation[]) => void) {
  const refresh = () => render(getCitations({ editor, filter: { status: 'invalid' } }))
  refresh()
  return subscribeCitations({ editor, listener: refresh })
}
```

Read fresh ranges with `getCitation({ editor, id })` before navigating to a citation. Pass the citation ID to the [review commands](/citations/api-reference/commands). Several citations can share a source ID.

Use [citation clicks](/citations/guides/rendering) to open the relevant review item when a user clicks a citation.
