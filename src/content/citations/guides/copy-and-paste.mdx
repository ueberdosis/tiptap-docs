Copied text and HTML include visible reference labels, such as `[Editor manual]`. Select a whole node to copy its citations. Use `formatCopiedReference` to change the label format or return `null` to omit it.

The examples use the [Smart Citations setup](/citations/getting-started/install).

```ts
SmartCitations.configure({
  sources,
  user: { id: 'author' },
  formatCopiedReference: ({ label }) => ` (${label})`,
})
```

When pasted into a Smart Citations editor, HTML that retains citation metadata creates independent citations with new IDs and preserves confirmed references and attribution. The editor removes the clipboard labels and renders its own references. Plain-text paste keeps the labels as text. A partial paste can need review. Drag-and-drop moves and `setContent()` keep IDs.

See [`formatCopiedReference`](/citations/api-reference/extension#copied-reference-format) for the callback fields.
