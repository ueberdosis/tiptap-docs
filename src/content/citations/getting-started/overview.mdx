Citations links selected text to sources your app supplies. It shows a source label after the text and flags changes to the text or source. Users can approve the current version, restore the last confirmed text, or remove the citation.

## Try Citations

Select text, choose a source, and click **Add Citation**. Edit the cited text to see what needs review.
