Smart Citations links selected text or a node to a source your app supplies. It shows a source label after the cited content and flags changes to inline cited text or any citation's source. Users can approve or remove either kind of citation and restore the last confirmed text of an inline citation.

Smart Citations is in alpha and available through the pilot program.

- [Install Smart Citations](/citations/getting-started/install) and create your first citation. The install guide includes a copyable prompt for coding agents.
- [Guides](/citations/guides/usage) cover source revisions, review panels, reference rendering, and Yjs collaboration.
- [API reference](/citations/api-reference) covers configuration, commands, queries, source collections, and errors.
