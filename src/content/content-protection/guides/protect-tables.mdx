---
title: Protect table structure
meta:
  description: Keep table columns and headings fixed while allowing row and cell edits.
---

Protect each row's direct child sequence to prevent column insertion, removal and reordering. Protect header content separately:

```ts
const rules = [
  {
    selector: { target: 'children', node: { types: ['tableRow'] } },
    permissions: { edit: false },
    reason: 'Keep the existing columns.',
  },
  {
    selector: { target: 'content', node: { types: ['tableHeader'] } },
    permissions: { edit: false },
    reason: 'Column headings belong to the template.',
  },
]
```

Cell text remains editable. Adding or removing a whole row remains possible because the table's child sequence is not protected.

Add a `node` rule for `tableHeader` if header cells themselves must remain. When composing these rules with a template allow, give the structural restrictions a higher priority than that allow.
