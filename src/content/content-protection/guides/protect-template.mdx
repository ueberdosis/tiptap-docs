---
title: Protect a template
meta:
  description: Keep a document fixed while allowing edits inside selected semantic regions.
---

Start with a document-wide deny, then add a higher-priority allow for editable regions:

```ts
const policy = {
  version: 1,
  rules: [
    {
      selector: { target: 'content', node: { types: ['doc'] } },
      permissions: { edit: false },
    },
    {
      priority: 10,
      selector: { target: 'content', node: { types: ['blockquote'] } },
      permissions: { edit: true },
    },
  ],
}
```

This allows content edits inside blockquotes. Add `target: 'node'` to preserve a region's existence, or `target: 'attribute'` to protect its configuration. Each target governs a different kind of change.

By default, content is allowed. The highest explicit priority wins; a deny wins ties. Rule IDs are optional labels for diagnostics.

For Slot templates, use [the filling policy helper](/composable-documents/slots/guides/fill-only) instead of assembling these rules yourself.
