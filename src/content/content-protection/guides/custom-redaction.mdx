---
title: Customize hidden content
meta:
  description: Render your own accessible replacement for content hidden by a protection policy.
---

Use `renderRedaction` to replace the complete placeholder UI. The factory receives a neutral label, text, layout hint and opaque key; it receives no hidden content.

```ts
ContentProtection.configure({
  policy,
  renderRedaction: ({ label, inline }) => {
    const dom = document.createElement(inline ? 'span' : 'div')
    dom.className = 'restricted-content'
    dom.textContent = `🔒 ${label}`
    return { dom }
  },
})
```

The extension makes the returned element noneditable and gives it the accessible label. You can include application controls or mount a framework component. Return `destroy()` to unmount it when the placeholder is removed:

```ts
renderRedaction: props => {
  const dom = document.createElement('span')
  const root = createRoot(dom)
  root.render(<HiddenContent label={props.label} />)
  return { dom, destroy: () => root.unmount() }
}
```

Clipboard and readable text exports use `redactionText`, independently of this UI. Do not derive labels from concealed content.

See [renderer types, updates and lifecycle](/content-protection/api-reference/rendering) for the complete contract.
