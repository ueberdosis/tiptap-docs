## Where they are stored

- **A block of no height.** The formats and the language are kept in a block on no page.
- **Nothing to wire.** Page numbers, footnotes and outline numbers read them without being told.

## Writing them

`setNumberFormat` and `setNumberLanguage` write the document, not the pages. A Transaction of your
own goes through the engine:

```js
import { setNumberLanguageTransaction } from '@tiptap-pro/extension-number-formats'

const engine = editor.storage.pageLayout.engine
const transaction = setNumberLanguageTransaction(engine.getSourceState().tr, 'de')

engine.applySourceTransaction(transaction, { addToHistory: true })
```
