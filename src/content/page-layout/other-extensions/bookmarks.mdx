## Setting it up

The pages are drawn from copies of what stands in the document. Pass `ignoreLayoutArtifacts` as
`ignore`, so those copies are not read as bookmarks of their own:

```js
import { Bookmarks } from '@tiptap-pro/extension-bookmark'
import { ignoreLayoutArtifacts } from '@tiptap-pro/extension-page-layout'

Bookmarks.configure({ ignore: ignoreLayoutArtifacts })
```

`ignoreLayoutArtifacts` is described under
[Packages that work without pages](/page-layout/other-extensions/overview#packages-that-work-without-pages).

## Commands on pages

- **Written to the document.** `addBookmark`, `renameBookmark`, `removeBookmark` and
  `goToBookmark` write the document, not the pages.
- **`can()`** answers from the document too.
- **`toggleBookmarkVisibility`** acts on the editor.
- **Ids** a command takes are the same on the document and the pages.

## Going to a bookmark on another page

`goToBookmark` and a followed link to `#name` draw the page the bookmark is on if it was not drawn
yet, select what it covers and scroll to it.

From a button, focus the editor first. It scrolls to the selection only while it has the focus:

```js
editor.view.focus()
editor.commands.goToBookmark(id)
```

## Shown bookmarks

Shown bookmarks change no measurement, so a page breaks in the same place with them shown.
