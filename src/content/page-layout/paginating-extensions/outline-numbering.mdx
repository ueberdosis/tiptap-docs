## Setting it up

Tell outline numbering what to leave out, and tell Page Layout where a heading's number is drawn
from:

```js
import { defineNodeLayout, ignoreLayoutArtifacts } from '@tiptap-pro/extension-page-layout'
import { OUTLINE_NUMBER_ATTRIBUTE, OutlineNumbering } from '@tiptap-pro/extension-outline-numbering'

defineNodeLayout('heading', { labelAttribute: OUTLINE_NUMBER_ATTRIBUTE })

OutlineNumbering.configure({
  types: { heading: { level: (node) => node.attrs.level } },
  ignore: ignoreLayoutArtifacts,
})
```

- **`ignore`** leaves the pages out. See
  [Packages that work without pages](/page-layout/paginating-extensions#packages-that-work-without-pages).
- **`labelAttribute`** lets Page Layout measure a number again when it gets a digit longer.
- **Call `defineNodeLayout`** before `createPageLayoutEditor`.

## Headings across pages

- **A heading cut across two pages** is numbered once, on the page it begins on.
- **The scheme** a document stores is a block of no height, on no page.
- **The chapter number in front of a page number**, such as _2-7_, follows the headings without
  any of this. With a function it follows the outline instead. See
  [Chapter numbers](/page-layout/features/page-numbers/chapter-numbers).

## Writing the outline

- **Commands.** `setOutlineLevels`, `setOutlineLevel` and `setOutlineList` write the document,
  not the pages, and `can()` answers from it. `refreshOutlineNumbers` acts on the editor.
- **Positions.** `outlineListAt` and `outlineNumberAt` take positions in the document the engine
  keeps, `editor.storage.pageLayout.engine.getSourceDocument()`.

## Lists of clauses across pages

A [list of clauses](/editor/extensions/functionality/outline-numbering#lists-as-clauses) cut
by a page goes on counting on the next one.

- **No `defineNodeLayout` needed.** Its numbers stand in the margin.
- **An item cut inside its text** is numbered on the page it begins on.
- **The rest of the item** on the next page draws neither a number nor the list's own marker.
