## Setting it up

Pass the reader that leaves the pages out, and the page a target is on:

```js
import { CrossReferences } from '@tiptap-pro/extension-cross-references'
import { ignoreLayoutArtifacts, pageLabelAt } from '@tiptap-pro/extension-page-layout'

CrossReferences.configure({
  targets,
  ignore: ignoreLayoutArtifacts,
  pageOf: ({ doc, pos }) => pageLabelAt(doc, pos),
})
```

`targets` is configured as on the [cross-references page](/editor/extensions/functionality/cross-references#registering-targets).

## Leaving the pages out

On pages, a heading cut across two pages is two Nodes, and the header or footer being edited is a
Node too. `ignoreLayoutArtifacts` leaves both out. Pass the same one to
[outline numbering](/page-layout/supported-extensions/outline-numbering); see
[Packages that work without pages](/page-layout/supported-extensions#packages-that-work-without-pages).

- **A target cut across two pages** is read from its first page. A `title` that is the Node's
  text reads only the part of the heading on that page.
- **The items of a list cut by a page** are targets on whichever page they stand.

## Commands on pages

Every command of the package works on a paginated editor and writes the document, not the pages,
F9 included. `can()` answers from the document too, so a dialog can disable a button by it:

```js
editor.commands.insertCrossReference({ target: pos, show: 'fullNumber' })
editor.can().updateCrossReferences()
```

- **Positions are the document's.** A target named by position, and the reference
  `resetCrossReference(pos)` resets, are positions in
  `editor.storage.pageLayout.engine.getSourceDocument()`. The positions of `editor.state.doc`
  are the pages'.
- **Ask the document.** `crossReferenceTypesIn` and `crossReferenceAround` should be asked of
  the same document.
- **One id per heading.** The pass that keeps ids apart runs on the document, so a heading cut
  across two pages is never taken for two headings with one id. Turning `repair` off turns it off
  there.
- **A reference's text** is measured with the line it stands in, so a number that gets a digit
  longer moves the text after it.

## Going to a target on another page

Following a reference, with Cmd/Ctrl+click by default, goes to its target without `reveal` being
set. Page Layout runs
[`goToCrossReferenceTarget`](/editor/extensions/functionality/cross-references#gotocrossreferencetarget)
on the document.

- **The page is drawn** if it was not drawn yet, and scrolled to.
- **The caret** lands at the start of the heading, or in the text of a footnote.
- **A `reveal` of your own** replaces that.

## See page N

`pageOf` is where the page number comes from. Page Layout brings two readers:

| Function       | Arguments  | Returns                                                                           |
| -------------- | ---------- | --------------------------------------------------------------------------------- |
| `pageLabelAt`  | `doc, pos` | The page as that page writes its number, such as `iv` in a roman preface, or null |
| `pageNumberAt` | `doc, pos` | The page as a number, for a reference that formats it itself, or null             |

- **On the document too.** Both answer for the document the engine keeps. A command that stores a
  reference's text asks them there: an insert or a reset in `'manual'` mode, or an update.
- **As last laid out.** They answer for the document as it was last paginated. Asked of a
  document that has changed since, they return `null`.
- **Pageless**, they return `null`.
- **Following the target.** A reference showing `page` follows its target when an edit moves it
  to another page.
- **A footnote target** is on the page its note is drawn on.

### A reference that moves its own target

"Page 9" becoming "page 10" can wrap a line and push the target back to page 9.

- **The pages settle.** The layout keeps the room the longer text needed, instead of alternating.
- **The reference reads** the page its target ended up on. Its line may be laid out a little
  shorter than it needs to be.
- **After an undo** that brings back a shorter number, the same happens until the paragraph is
  edited again.
