## How commands behave

Page Layout's commands chain with your own. The examples run on an `editor` built as [A first editor](/page-layout/getting-started/install#a-first-editor) shows:

```js
editor.chain().focus().insertPageBreak().run()
```

`editor.can().insertPageBreak()` asks whether a page break may go at the cursor, without changing anything. A command returns `true` when it acted. It returns `false` and changes nothing, instead of throwing, when:

- the cursor is not where the command acts, such as `setRepeatHeaderRow()` outside a table or `setListKeepTogether()` outside a list,
- the document does not allow it, such as a page break inside a code block,
- it would remove section `0`, the first [section](/page-layout/features/sections), which holds the document's own paper,
- the node it needs is switched off on `PageLayout`, such as `pageBreak: false` for `insertPageBreak()`.

Methods of the engine, `editor.storage.pageLayout.engine`, which lays out the pages, throw instead when their feature is off.

## A toolbar

A toolbar works as without pages: a button runs a command, and its state comes from `editor.can()` and `editor.isActive()`. Here, `button` and `boldButton` are buttons of your toolbar:

```js
button.addEventListener('click', () => editor.commands.insertPageBreak())

function render() {
  button.disabled = !editor.can().insertPageBreak()
  boldButton.classList.toggle('is-active', editor.isActive('bold'))
}

editor.on('transaction', render)
```

A command acts on the whole node at the cursor, even where a page end cuts it: `addRowAfter()` of the table extension adds the row to the whole table.

`editor.can()` asks the same document, for Page Layout's own commands too, so a button that `can()` disables is disabled exactly where its command would do nothing.

[Where the cursor is](/page-layout/getting-started/document-and-pages/reading#where-the-cursor-is) shows how a toolbar reads the cursor's page, section and open header or footer.

## Keeping the focus in the editor

A button that takes the focus loses the cursor a command placed, so after `insertPageBreak()` the cursor jumps back to the foot of the page before. Prevent the default of `mousedown` on the toolbar's buttons, which still get the `click`:

```js
toolbar.addEventListener('mousedown', (event) => {
  if (event.target.closest('button')) {
    event.preventDefault()
  }
})
```

## In a header or footer

While a header or footer is open, the toolbar acts there: a table, list, mark or footnote goes into it, and `can()` and `isActive()` answer for its cursor. `editor.commands.closeFurniture()` leaves it. To hide a button that belongs only in the text while one is open:

```js
textButton.hidden = editor.storage.pageLayout.engine.getFurnitureTarget() !== null
```

## Every command

Each command links to the page with its arguments. Commands of packages that go with Page Layout, such as `insertFootnote()`, are on [their own pages](/page-layout/getting-started/install#the-packages).

| Command                                      | What it does                                                                                                                                                                             |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `setPageSetup(setup)`                        | [Sets the paper of a document that stores none, or `null` for no pages.](/page-layout/features/page-format#setpagesetup)                                                                 |
| `setSectionSetup(sectionIndex, setup)`       | [Sets and saves the paper of one section.](/page-layout/features/page-format#setsectionsetup)                                                                                            |
| `insertPageBreak()`                          | [Ends the page at the cursor.](/page-layout/features/breaks#insertpagebreak)                                                                                                             |
| `removePageBreak()`                          | [Removes the last page break before the cursor in its block.](/page-layout/features/breaks#removepagebreak)                                                                              |
| `insertColumnBreak()`                        | [Ends the column at the cursor, or the page in a section with one column.](/page-layout/features/breaks#insertcolumnbreak)                                                               |
| `insertSectionBreak(kind?)`                  | [Starts a section at the cursor, on the next page or this one.](/page-layout/features/sections#insertsectionbreak)                                                                       |
| `setPageSections(sections)`                  | [Replaces all sections at once.](/page-layout/features/sections#setpagesections)                                                                                                         |
| `removeSection(sectionIndex)`                | [Folds a section into the one before it.](/page-layout/features/sections#removesection)                                                                                                  |
| `setSectionColumns(columns)`                 | [Sets columns for the selected blocks, adding section breaks as needed.](/page-layout/features/section-columns#setsectioncolumns)                                                        |
| `openFurniture(options)`                     | [Opens a header or footer for editing.](/page-layout/features/header-and-footer#openfurniture)                                                                                           |
| `stepFurniture(direction)`                   | [Moves to the previous (`-1`) or next (`1`) header or footer.](/page-layout/features/header-and-footer#stepfurniture)                                                                    |
| `closeFurniture()`                           | [Leaves the header or footer for the text.](/page-layout/features/header-and-footer#closefurniture)                                                                                      |
| `setFurnitureFlags(sectionIndex, flags)`     | [Sets a different first page, and odd and even pages, for a section.](/page-layout/features/header-and-footer#setfurnitureflags)                                                         |
| `setFurnitureOffsets(sectionIndex, offsets)` | [Sets how far a section's header and footer sit from the sheet's edge.](/page-layout/features/header-and-footer#setfurnitureoffsets)                                                     |
| `setFurnitureOffset(input)`                  | [Sets how far one header or footer sits from the edge.](/page-layout/features/header-and-footer#setfurnitureoffset)                                                                      |
| `unlinkFurniture()`                          | [Gives a section its own header or footer instead of the inherited one.](/page-layout/features/header-and-footer#unlinkfurniture)                                                        |
| `linkFurniture(source)`                      | [Makes a header or footer follow a section's, or the one before (`'previous'`).](/page-layout/features/header-and-footer#linkfurniture)                                                  |
| `insertPageNumbers(options)`                 | [Puts a page number into the headers or the footers of a section.](/page-layout/features/page-numbers#insertpagenumbers)                                                                 |
| `removePageNumbers()`                        | [Takes out the page numbers `insertPageNumbers()` put in.](/page-layout/features/page-numbers#removepagenumbers)                                                                         |
| `insertPageNumber(kind?)`                    | [Puts a page number at the caret in the open header or footer.](/page-layout/features/page-numbers#insertpagenumber)                                                                     |
| `setPageNumbering(numbering)`                | [Sets how the section at the cursor numbers its pages.](/page-layout/features/page-numbers/numbering#setpagenumbering)                                                                   |
| `setRowBreakAcrossPages(allowed)`            | [Sets whether the end of a page may cut the table row at the cursor.](/page-layout/extension-behavior/tables#setrowbreakacrosspages)                                                     |
| `setRepeatHeaderRow(repeated)`               | [Sets whether the header row repeats on every page of the table.](/page-layout/extension-behavior/tables#setrepeatheaderrow)                                                             |
| `setListKeepTogether(kept)`                  | [Sets whether the list at the cursor moves to the next page whole.](/page-layout/extension-behavior/lists#setlistkeeptogether)                                                           |
| `setListBreakItems(allowed)`                 | [Sets whether the end of a page may cut a paragraph in a list item.](/page-layout/extension-behavior/lists#setlistbreakitems)                                                            |
| `setColumnLayoutKeepTogether(together)`      | [Sets whether the column layout at the cursor is kept whole.](/page-layout/extension-behavior/columns#setcolumnlayoutkeeptogether)                                                       |
| `revealSourcePosition(pos, to?)`             | [Puts the caret at a document position and scrolls its page into view.](/page-layout/getting-started/document-and-pages/reading#revealsourceposition)                                    |
| `revealPage(pageIndex)`                      | [Puts the caret at the first text on a page, counting from 0, and scrolls to it.](/page-layout/getting-started/document-and-pages/reading#revealpage)                                    |
| `onSourceDocument(command)`                  | [Runs a function `(state, dispatch) => boolean`, a ProseMirror command, on the document instead of the pages.](/page-layout/getting-started/document-and-pages/writing#onsourcedocument) |
| `undo()`                                     | [Takes back the last edit to the document.](/page-layout/getting-started/install/existing-editor#undo)                                                                                   |
| `redo()`                                     | [Applies the last undone edit again.](/page-layout/getting-started/install/existing-editor#redo)                                                                                         |
