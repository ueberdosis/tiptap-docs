## Custom properties you set

Set only the ones you want different, on the editor or an element around it:

| Custom property                  | Default                                                                | Description                                                                                                 |
| -------------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `--tt-page-paper`                | `white`                                                                | Paper color of a document that saves none. Its text then takes the color it inherits.                       |
| `--tt-page-sheet-shadow`         | `0 1px 2px rgba(15, 23, 42, 0.14), 0 10px 24px rgba(15, 23, 42, 0.08)` | Shadow under a sheet, the element a page is drawn on.                                                       |
| `--tt-page-sheet-gap`            | `24px`, none with `sheetAppearance: 'none'`                            | Space between sheets, as any CSS length. [Fit to width](/page-layout/features/zoom#fit-to-width) counts it. |
| `--tt-page-selection-fill`       | `Highlight`, the system selection color                                | Fill of a selection drawn across a page boundary in a table row.                                            |
| `--tt-page-column-rule-color`    | `rgba(15, 23, 42, 0.22)`                                               | Color of the line between columns.                                                                          |
| `--tt-page-column-rule-width`    | `1px`                                                                  | Its width.                                                                                                  |
| `--tt-remote-caret-width`        | `2px`                                                                  | Width of a colleague's caret, see [Remote cursors](/page-layout/guides/collaboration#remote-cursors).       |
| `--tt-remote-caret-label-color`  | `white`                                                                | Text color of the name above a colleague's caret.                                                           |
| `--tt-remote-caret-label-size`   | `10px`                                                                 | Its font size.                                                                                              |
| `--tt-remote-caret-label-radius` | `3px`                                                                  | Its corners.                                                                                                |
| `--tt-remote-selection-opacity`  | `28%`                                                                  | How much of the colleague's color their selection shows.                                                    |
| `--tt-page-break-line-color`     | `rgba(15, 23, 42, 0.28)`                                               | Color of the line that shows a break in a pageless document, one continuous column without pages.           |
| `--tt-page-break-label-color`    | `rgba(15, 23, 42, 0.45)`                                               | Color of its label.                                                                                         |
| `--tt-page-break-label-size`     | `8px`                                                                  | Font size of its label.                                                                                     |
| `--tt-page-break-line-space`     | `1.75rem`                                                              | Room above and below it.                                                                                    |
| `--tt-page-clip-margin`          | `8px`                                                                  | How far outside the text area content still paints.                                                         |

## What the engine publishes

Page Layout sets each measurement, in pixels, as a custom property on its element, so a ruler or overlay of yours can read it:

```js
const sheet = document.querySelector('[data-tt-page]')
const width = parseFloat(getComputedStyle(sheet).getPropertyValue('--tt-page-width'))
```

A sheet, `[data-tt-page]`, has:

- `--tt-page-width` and `--tt-page-height`, the size of the sheet.
- `--tt-page-margin-top`, `--tt-page-margin-right`, `--tt-page-margin-bottom` and `--tt-page-margin-left`.
- `--tt-page-content-top` and `--tt-page-content-bottom`, where the text begins and ends once a header or footer outgrew its margin.
- `--tt-page-header-offset` and `--tt-page-footer-offset`, how far the header or footer sits from the edge.
- `--tt-page-background`, `--tt-page-text` and `--tt-page-accent`, the [page colors](/page-layout/features/page-colors), where the document saves any.

A tier, `[data-tt-page-tier]`, is the part of a sheet that one [section](/page-layout/features/sections) fills, so a section that starts on a sheet adds a second tier.

A tier has `--tt-page-columns`, the number of columns, and `--tt-page-column-tracks`, the CSS grid tracks of its columns and gaps. `--tt-page-column-rule-1` to `--tt-page-column-rule-5` give the distance of each line between columns from the left of the text area.

The note area with a sheet's footnotes, `[data-tt-page-notes]`, has `--tt-page-notes-height`, and `--tt-page-notes-top` when the notes sit directly below the text.

A colleague's caret, its name label and the colleague's selection have `--tt-remote-caret-color`, the color of that user from [collaboration](/page-layout/guides/collaboration#remote-cursors).

These attributes store a setting of the document, and they are in what `getHTML()` returns:

| Attribute                                                  | On                                  | Meaning                                                                          |
| ---------------------------------------------------------- | ----------------------------------- | -------------------------------------------------------------------------------- |
| `data-tt-break-across-pages`                               | Table row                           | `false` when the row may not be cut at the end of a page.                        |
| `data-tt-repeat-header-row`                                | Table                               | `true` when the header row repeats on each page the table goes on to.            |
| `data-tt-keep-together`, `data-tt-break-items`             | List, column layout                 | `true` when the list or layout moves whole, and when a list item may be cut.     |
| `data-tt-page-furniture`, `data-tt-zone`, `data-tt-offset` | Header or footer in a section break | A stored header or footer, `header` or `footer`, and its distance from the edge. |
| `data-tt-page-number`                                      | Page number field                   | `page`, `pages` or `sectionPages`.                                               |

Page Layout adds two `style` elements to the web page, shared by every editor on it: `style[data-tt-page-layout-styles]` with the layout rules, and `style[data-tt-page-layout-sheets]` with the paper sizes for printing. An editor with another `injectNonce` gets elements of its own. See [A Content Security Policy](/page-layout/guides/styling#a-content-security-policy).

## What the engine writes either way

Page Layout writes these rules with `sheetAppearance: 'paper'` and `'none'` alike, because it measures the pages with them, see [The boxes are the engine's](/page-layout/guides/styling#the-boxes-are-the-engines):

- A sheet: width and height from the paper, padding from the margins, a fixed height and clipping.
- The space between blocks: the larger of two margins, and none above the lower half of a split paragraph.
- A tier: a grid of the section's columns and gaps. The last on a sheet gets the room left and clips the rest.
- A text area: it fills its column, clips, and does not grow past its measured width.
- A header or footer: its position and height, and no margins on its content.
- A note area: its box, at the foot of the sheet or under the text, and its height.
- A break that ends a page or column: hidden there, so it adds no empty line.
- A drawn selection: placed pieces that let clicks through. While a header or footer is edited, the page text cannot be selected.
- Print: one whole sheet per printed page at its size, with no margin around it and no shadow. Break lines, drawn selections, colleagues' carets and selections, and zoom are removed.
