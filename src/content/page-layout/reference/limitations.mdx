## Using new Editor

An editor not built with `createPageLayoutEditor` draws no pages, and its `PageLayout` commands return `false`.

## Passing editorProps

`createPageLayoutEditor` does not accept `editorProps`. Set the scroll margin with the `scrollMargin` option, and keyboard shortcuts in an extension.

## Saving editor.state

`editor.state` holds the pages, not the document. Save what `getJSON()` returns, and read positions through `editor.storage.pageLayout.engine`. See [The document and the pages](/page-layout/getting-started/document-and-pages).

## Adding Collaboration

`createPageLayoutEditor` throws for `@tiptap/extension-collaboration`. Pass the shared document to the `source` option. See [Collaboration](/page-layout/guides/collaboration#setting-it-up).

## Very tall blocks

A block that cannot be cut runs past the bottom of its sheet, the element the page is drawn on. A list or column layout kept together is cut anyway. See [Keep together is a preference](/page-layout/extension-behavior#keep-together-is-a-preference).

## Keeping lines together

There is no widow and orphan control: a paragraph is cut wherever the page runs out, even after its first line.

## Keeping headings with the next block

Nothing ties a heading to the next block, so it can end a page. Return `keepWithNext` from the `blockBreaksOf` option, or set it for a node type with `defineNodeLayout`. See [Keeping a block with the next](/page-layout/extension-behavior/your-own-extension/layout-rules#keeping-a-block-with-the-next).

## Nested tables

The header row of a table inside a table cell does not repeat on the next page. See [A table inside a table cell](/page-layout/extension-behavior/tables#a-table-inside-a-table-cell).

## Unequal columns

Section columns are balanced exactly only when they are equal. See [Balanced columns](/page-layout/features/section-columns#balanced-columns).

## Dragging a column edge

No handle drags a column edge, so set the widths with `setSectionColumns()`.

## Footnotes in columns

The notes at the foot of a page have no columns of their own.

## A note across paper sizes

A footnote continued onto a page of another paper size reserves more room than it needs.

## A symbol for one note

A single note cannot have a mark of its own, the number or symbol at its reference. See [Footnotes in Page Layout](/page-layout/extension-behavior/footnotes).

## Searching a long document

Only the sheets near the visible area hold their text in the DOM, so the browser's find and screen readers reach only those, unless you switch `virtualization` off. See [What only sees the drawn sheets](/page-layout/guides/long-documents#what-only-sees-the-drawn-sheets).

## Printing from Safari

Safari prints every sheet on the paper of the first page, and fits other formats onto it. See [Printing in Safari](/page-layout/features/printing#printing-in-safari).

## Pasting from Word

A pasted Word field arrives as the text Word last showed, and a pasted section's paper is not taken. See [Pasting from Word](/page-layout/guides/word#pasting-from-word).
