```js
PageLayout.configure({
  setup: pageSetup('A4'),
  scrollMargin: { top: 64 },
})
```

Pass a whole setup. `configure` merges what it is given into the options, so a partial `margins`
keeps the values it leaves out from before. `pageSetup` builds a whole one; see
[Page format](/page-layout/core-concepts/page-format#what-a-setup-holds).

## The page

| Option            | Type                     | Default                        | Description                                                                                                                                                                                                               |
| ----------------- | ------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `setup`           | `PageSetup \| null`      | None: no pages                 | The paper, margins and colors a new document starts on. A document that stores its own paper keeps it. See [Page format](/page-layout/core-concepts/page-format)                                                          |
| `sections`        | `readonly PageSection[]` | None                           | Section breaks written into the document when the editor is created: the block from which another setup applies, and that setup. See [Sections](/page-layout/core-concepts/sections)                                      |
| `chapterNumberOf` | `ChapterNumberOf`        | `chapterNumbersFromHeadings()` | The chapter a page number is written with, as in 2-1, 2-2. See [Page numbers](/page-layout/core-concepts/page-numbers)                                                                                                    |
| `blockBreaksOf`   | `BlockBreaksOf`          | None: only the Node type rules | Per top-level block: keep it with the next one, keep it together, start a page in front of it, as a paragraph style says in Word. See [Custom Node types](/page-layout/guides/custom-nodes#keeping-a-block-with-the-next) |

## Features

Each feature is on by default. `false` switches it off and takes its Node or attributes out of the
schema; see [Switching features off](/page-layout/getting-started/overview#switching-features-off).

| Option              | Type    | Default | Description                                                                                                                |
| ------------------- | ------- | ------- | -------------------------------------------------------------------------------------------------------------------------- |
| `pageBreak`         | `false` | On      | Manual page breaks. See [Breaks](/page-layout/core-concepts/breaks)                                                        |
| `columnBreak`       | `false` | On      | Manual column breaks. See [Breaks](/page-layout/core-concepts/breaks)                                                      |
| `sectionBreak`      | `false` | On      | Section breaks. See [Breaks](/page-layout/core-concepts/breaks)                                                            |
| `pageFurniture`     | `false` | On      | Headers and footers. See [Header and footer](/page-layout/core-concepts/header-and-footer)                                 |
| `pageNumber`        | `false` | On      | The page number a header or footer can hold. See [Page numbers](/page-layout/core-concepts/page-numbers)                   |
| `tablePagination`   | `false` | On      | Whether a row may break across pages, and a repeated header row. See [Tables across pages](/page-layout/extensions/tables) |
| `columnsPagination` | `false` | On      | Keeping a column layout on one page. See [Column layout on pages](/page-layout/extensions/overview#column-layout)          |
| `listPagination`    | `false` | On      | Keeping a list on one page. See [Keeping a list on one page](/page-layout/extensions/overview#keeping-a-list-on-one-page)  |

## Drawing

| Option               | Type                   | Default                   | Description                                                                                                                                                                                                          |
| -------------------- | ---------------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sheetAppearance`    | `'paper' \| 'none'`    | `'paper'`                 | Whether the engine draws the paper. `'none'` leaves the appearance to your own CSS. See [Styling the pages](/page-layout/core-concepts/styling)                                                                      |
| `breaksWithoutPages` | `'lines' \| 'none'`    | `'lines'`                 | Whether a break is drawn in an editor without pages. `'none'` draws nothing. See [Breaks without pages](/page-layout/core-concepts/breaks#breaks-without-pages)                                                      |
| `breakLabels`        | `Partial<BreakLabels>` | Word's names, in English  | What each break is called beside its line, for a document in another language. See [Breaks](/page-layout/core-concepts/breaks)                                                                                       |
| `scrollMargin`       | `ScrollMargin`         | `{ top: 48, bottom: 48 }` | Room in pixels left at the edges of the viewport whenever something is scrolled into view, for a toolbar over the pages. See [A toolbar over the pages](/page-layout/core-concepts/styling#a-toolbar-over-the-pages) |
| `virtualization`     | `boolean`              | `true`                    | Whether only the sheets near the reader are drawn. See [Long documents](/page-layout/guides/long-documents)                                                                                                          |
| `layoutHint`         | `LayoutHintStore`      | None                      | Where what was measured last time is kept, so a long document opens on its pages. See [Opening on the same pages](/page-layout/guides/long-documents#opening-on-the-same-pages)                                      |

## Clicks

| Option            | Type    | Default                               | Description                                                                                                                                                                                                        |
| ----------------- | ------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `furnitureClicks` | `false` | On, unless `pageFurniture` is `false` | Double-click a header or footer to edit it, and the text or Escape to go back. `false` leaves the way in to your own UI. See [Getting in and out](/page-layout/core-concepts/header-and-footer#getting-in-and-out) |

## The document

| Option                    | Type                               | Default                            | Description                                                                                                                                                                    |
| ------------------------- | ---------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `source`                  | `SourceDocumentOptions`            | None                               | Collaboration, history and plugins for the document. See [Collaboration](/page-layout/guides/collaboration)                                                                    |
| `onCommandOnPages`        | `(report: CommandOnPages) => void` | A console warning once per command | Told when a command of an extension wrote something to the pages that could not be carried back to the document. See [Custom Node types](/page-layout/guides/custom-nodes)     |
| `experimentalSourceState` | `boolean`                          | `false`                            | Experimental. `editor.state` holds the document rather than the pages. See [editor.state as the document](/page-layout/getting-started/components#editorstate-as-the-document) |
