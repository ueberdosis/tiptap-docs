| Command                                                                                     | What it does                                                                      | Page                                                                           |
| ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [setPageSetup](/page-layout/core-concepts/page-format#setpagesetup)                         | Sets the paper of a document that stores none, or `null` for no pages             | [Page format](/page-layout/core-concepts/page-format)                          |
| [setSectionSetup](/page-layout/core-concepts/page-format#setsectionsetup)                   | Sets the paper of one section, and saves it in the document                       | [Page format](/page-layout/core-concepts/page-format)                          |
| [insertPageBreak](/page-layout/core-concepts/breaks#insertpagebreak)                        | Ends the page at the cursor                                                       | [Breaks](/page-layout/core-concepts/breaks)                                    |
| [removePageBreak](/page-layout/core-concepts/breaks#removepagebreak)                        | Removes the manual page break the cursor is at or just past                       | [Breaks](/page-layout/core-concepts/breaks)                                    |
| [insertColumnBreak](/page-layout/core-concepts/breaks#insertcolumnbreak)                    | Ends the column at the cursor, or the page in a section with one column           | [Breaks](/page-layout/core-concepts/breaks)                                    |
| [insertSectionBreak](/page-layout/core-concepts/sections#insertsectionbreak)                | Starts a section at the cursor, on the next page or on this one                   | [Sections](/page-layout/core-concepts/sections)                                |
| [setPageSections](/page-layout/core-concepts/sections#setpagesections)                      | Replaces all sections at once                                                     | [Sections](/page-layout/core-concepts/sections)                                |
| [removeSection](/page-layout/core-concepts/sections#removesection)                          | Folds a section back into the one before it                                       | [Sections](/page-layout/core-concepts/sections)                                |
| [setSectionColumns](/page-layout/core-concepts/section-columns#setsectioncolumns)           | Sets columns for the blocks the selection covers, adding section breaks as needed | [Section columns](/page-layout/core-concepts/section-columns)                  |
| [setPageNumbering](/page-layout/core-concepts/page-numbers#setpagenumbering)                | Sets how the pages of the section at the cursor are numbered                      | [Page numbers](/page-layout/core-concepts/page-numbers)                        |
| [insertPageNumbers](/page-layout/core-concepts/page-numbers#insertpagenumbers)              | Puts a page number into every header or every footer of a section                 | [Page numbers](/page-layout/core-concepts/page-numbers)                        |
| [removePageNumbers](/page-layout/core-concepts/page-numbers#removepagenumbers)              | Takes out the page numbers `insertPageNumbers` put in                             | [Page numbers](/page-layout/core-concepts/page-numbers)                        |
| [insertPageNumber](/page-layout/core-concepts/page-numbers#insertpagenumber)                | Puts a page number at the caret in the header or footer being edited              | [Page numbers](/page-layout/core-concepts/page-numbers)                        |
| [revealSourcePosition](/page-layout/core-concepts/page-numbers#revealsourceposition)        | Puts the caret at a position of the document and scrolls its page into view       | [Page numbers](/page-layout/core-concepts/page-numbers)                        |
| [openFurniture](/page-layout/core-concepts/header-and-footer#openfurniture)                 | Opens a header or footer for editing                                              | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [stepFurniture](/page-layout/core-concepts/header-and-footer#stepfurniture)                 | Moves to the previous or next header or footer                                    | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [closeFurniture](/page-layout/core-concepts/header-and-footer#closefurniture)               | Leaves the header or footer and puts the caret back in the text                   | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [setFurnitureFlags](/page-layout/core-concepts/header-and-footer#setfurnitureflags)         | Sets a different first page and different odd and even pages for one section      | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [setFurnitureOffsets](/page-layout/core-concepts/header-and-footer#setfurnitureoffsets)     | Sets how far the header and footer sit from the edge of the sheet in one section  | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [setFurnitureOffset](/page-layout/core-concepts/header-and-footer#setfurnitureoffset)       | Sets one header's or footer's distance from the edge                              | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [unlinkFurniture](/page-layout/core-concepts/header-and-footer#unlinkfurniture)             | Gives a section a header or footer of its own instead of the one it inherits      | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [linkFurniture](/page-layout/core-concepts/header-and-footer#linkfurniture)                 | Makes a header or footer follow another section's, or the one before              | [Header and footer](/page-layout/core-concepts/header-and-footer)              |
| [setRowBreakAcrossPages](/page-layout/extensions/tables#setrowbreakacrosspages)             | Sets whether the row at the cursor may be cut by a page boundary                  | [Tables across pages](/page-layout/extensions/tables)                          |
| [setRepeatHeaderRow](/page-layout/extensions/tables#setrepeatheaderrow)                     | Sets whether the header row is repeated on every page the table reaches           | [Tables across pages](/page-layout/extensions/tables)                          |
| [setListKeepTogether](/page-layout/extensions/overview#setlistkeeptogether)                 | Sets whether the list at the cursor moves to the next page whole                  | [Other extensions on pages](/page-layout/extensions/overview)                  |
| [setListBreakItems](/page-layout/extensions/overview#setlistbreakitems)                     | Sets whether a list item may be cut mid-line at a page boundary                   | [Other extensions on pages](/page-layout/extensions/overview)                  |
| [setColumnLayoutKeepTogether](/page-layout/extensions/overview#setcolumnlayoutkeeptogether) | Sets whether the column layout at the cursor moves whole rather than being cut    | [Other extensions on pages](/page-layout/extensions/overview)                  |
| [onSourceDocument](/page-layout/getting-started/components#onsourcedocument)                | Runs an editor view command on the document rather than on the pages              | [Components that change the document](/page-layout/getting-started/components) |
| [undo](/page-layout/getting-started/install#undo)                                           | Takes back the last edit to the document                                          | [Getting started](/page-layout/getting-started/install)                        |
| [redo](/page-layout/getting-started/install#redo)                                           | Applies the last undone edit again                                                | [Getting started](/page-layout/getting-started/install)                        |

Commands of the packages that go with Page Layout, such as `insertFootnote`, are on those packages'
pages; see [Packages](/page-layout/getting-started/packages#the-packages-that-work-without-pages).
