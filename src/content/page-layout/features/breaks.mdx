## Quick start

Each break has a command that inserts it at the cursor. `editor` is an editor from `createPageLayoutEditor`, as in [Page format](/page-layout/features/page-format#quick-start):

```js
editor.commands.insertPageBreak()
editor.commands.insertColumnBreak()
editor.commands.insertSectionBreak('nextPage')
editor.commands.insertSectionBreak('continuous')
```

A toolbar disables a break button where `can()` answers `false`, as in `editor.can().insertPageBreak()`.

## Page, column and section breaks

The three breaks differ in what they end:

| Break         | Ends                                                                 | Shortcut          |
| ------------- | -------------------------------------------------------------------- | ----------------- |
| Page break    | The page                                                             | `Mod-Enter`       |
| Column break  | The column, or the page in a section with one column                 | `Mod-Shift-Enter` |
| Section break | The section. The next starts on a new page or below, on the same one | None              |

`Mod` is Cmd on macOS and Ctrl elsewhere, and `Shift-Enter` still inserts a line break. A code block holds neither break, so both shortcuts do nothing there.

Page Layout stores only the breaks you insert, so on other paper a document breaks in other places, but always at yours. A page or column break sits in the text, so it can stand between two words. Two page breaks in a row make a blank page.

For section breaks, see [Sections](/page-layout/features/sections#section-breaks). A continuous one puts two formats on one page, such as a two-column passage, see [Section columns](/page-layout/features/section-columns).

## Removing a break

To remove a page break, press Backspace at the start of the page after it, or call [removePageBreak()](/page-layout/features/breaks#removepagebreak). [removeSection()](/page-layout/features/sections#removesection) removes a section break.

## Breaks without pages

In a [pageless](/page-layout/features/page-format#pageless) editor, which shows one continuous column, the breaks stay in the document, and you can still insert page and column breaks. Page Layout draws each break as a labeled dashed line.

To draw them yourself, set `breaksWithoutPages` from `'lines'` to `'none'`, so Page Layout adds no styles to them:

```js
import { PageLayout } from '@tiptap-pro/extension-page-layout'

PageLayout.configure({ breaksWithoutPages: 'none' })
```

Style each line by its class `tiptap-page-layout-break-marker-line`. `data-tt-break-unit` says which break it is, `page`, `region` (a column break) or `section`, and `data-tt-break-label` holds its label. See [Styling the pages](/page-layout/guides/styling).

## Labels in another language

`breakLabels` names the lines. Name only the labels you translate, and the rest keep the English of `DEFAULT_BREAK_LABELS`:

```js
import { PageLayout } from '@tiptap-pro/extension-page-layout'

PageLayout.configure({
  breakLabels: {
    page: 'Seitenumbruch',
    region: 'Spaltenumbruch',
    section: 'Abschnittsumbruch',
    sectionColumns: 'Abschnittsumbruch · {count} Spalten',
  },
})
```

The keys and their defaults are:

| Key              | Default                           |
| ---------------- | --------------------------------- |
| `page`           | `Page break`                      |
| `region`         | `Column break`                    |
| `section`        | `Section break`                   |
| `sectionColumns` | `Section break · {count} columns` |

`sectionColumns` labels the break of a section with columns, and its first `{count}` becomes the number of columns.

## Switching them off

Each break has its own switch in `PageLayout.configure()`. `pageBreak: false` and `columnBreak: false` turn off their break, and `sectionBreak: false` turns sections and section breaks off. The commands of a switched-off break return `false`:

```js
import { PageLayout } from '@tiptap-pro/extension-page-layout'

PageLayout.configure({ pageBreak: false, columnBreak: false, sectionBreak: false })
```

## Commands

The break commands chain and answer `can()`.

### insertPageBreak()

`insertPageBreak()` ends the page at the cursor and puts the cursor at the top of the next:

```js
editor.commands.insertPageBreak()
```

It takes no arguments, and returns `false` when `pageBreak` is switched off. It also returns `false` where the cursor's block cannot hold a break, such as a code block.

### removePageBreak()

`removePageBreak()` removes the last page break before the cursor in the cursor's block:

```js
editor.commands.removePageBreak()
```

It takes no arguments, and returns `false` when no page break comes before the cursor in its block, and when `pageBreak` is switched off.

### insertColumnBreak()

`insertColumnBreak()` ends the column at the cursor, or the page in a one-column section, so offer it even where no section has columns yet:

```js
editor.commands.insertColumnBreak()
```

It takes no arguments, and returns `false` when `columnBreak` is switched off. It also returns `false` where the cursor's block cannot hold a break, such as a code block.
