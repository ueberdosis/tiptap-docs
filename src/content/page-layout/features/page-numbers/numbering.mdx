## Format and start

`pageNumbering` in a section's page setup holds the format and the number to start at:

```js
import { pageSetup } from '@tiptap-pro/extension-page-layout'

pageSetup('A4', { pageNumbering: { format: 'lowerRoman', start: 1 } }) // i, ii, iii
pageSetup('A4', { pageNumbering: { format: 'decimal', start: null } }) // continues the count
```

[`setPageNumbering()`](/page-layout/features/page-numbers/numbering#setpagenumbering) changes it for the section at the cursor. Its fields are:

| Field     | Type                       | Default     | Description                                                                                                                                 |
| --------- | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `format`  | `NumberFormat`             | `'decimal'` | How the number is written, such as `'upperRoman'` or `'lowerAlpha'`. See [Number formats](/editor/extensions/functionality/number-formats). |
| `start`   | `number \| null`           | `null`      | The number of the section's first page. `null` continues the count of the section before.                                                   |
| `chapter` | `ChapterNumbering \| null` | `null`      | `{ level, separator }` for the [chapter](/page-layout/features/page-numbers/chapter-numbers) in front, or `null` for the number alone.      |

The document's first page is 1 unless the first section names a `start`. `start: 0` is allowed, for a title page counted as none, and shows `0` in every format.

## Where a count starts

A page is numbered by the section it begins in. A section after a continuous [section break](/page-layout/features/sections#section-breaks) begins in the middle of a page, so its count starts on the next page.

Odd and even pages follow the number the user sees. So a section that starts again at 1 on the fourth page opens with the [odd-page header](/page-layout/features/header-and-footer#a-different-first-page-odd-and-even-pages).

## Commands

The command returns `false` and changes nothing when it cannot act, as [How commands behave](/page-layout/reference/commands#how-commands-behave) explains.

### setPageNumbering()

Sets the numbering of the section at the cursor, or of the section whose header or footer is open:

```js
editor.commands.setPageNumbering({ format: 'lowerRoman' }) // i, ii, iii
editor.commands.setPageNumbering({ start: 1 }) // start again at 1
editor.commands.setPageNumbering({ start: null }) // continue from the section before
```

Takes any of the fields of `pageNumbering` and changes only those. The format may be one the document defines itself, and a format another client stored stays even when this client cannot write it.

Returns `false`, under `can()` too, while [pageless](/page-layout/features/page-format#pageless), where the document is one continuous column without pages. It returns `false` as well with `sectionBreak: false`, which turns sections and section breaks off.

It also returns `false` for a format this client cannot write, and for a `chapter` when nothing numbers chapters, as [A rule of your own](/page-layout/features/page-numbers/chapter-numbers#a-rule-of-your-own) explains.
