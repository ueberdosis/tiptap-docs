## Quick start

`insertPageNumbers` puts a number into every footer of the section at the cursor:

```js
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, PageLayout.configure({ setup: pageSetup('A4') })],
})

editor.commands.insertPageNumbers({ zone: 'footer', align: 'center', firstPage: true })
```

## Page numbers on every page

`insertPageNumbers` gives every header or every footer of a section a page number. The section is
the one whose header or footer is open, or else the one at the cursor.

```js
editor.commands.insertPageNumbers({ zone: 'footer', align: 'outside', firstPage: false })
editor.commands.removePageNumbers()
```

| Alignment                       | Sits                                    |
| ------------------------------- | --------------------------------------- |
| `'left'`, `'center'`, `'right'` | At that side of the band, on every page |
| `'outside'`                     | Right on odd pages, left on even ones   |
| `'inside'`                      | Left on odd pages, right on even ones   |

- **Odd and even** are read from the number the page shows. A section that starts again at 1
  opens on the right with `'outside'`.
- **`firstPage: false`** leaves the section's first page without a number. It switches on the
  section's different first page, whose band is left as it was apart from the number.
- **The pages do not move.** The number stands beside the first line of the band and does not
  make the band taller.
- **What the band already says stays** and runs around the number. It sits to the number's right
  when the number is on the left, and breaks before it when the number is on the right.
- **From the second line on**, the band's text has the full width again.
- **A first line that no longer fits** beside the number wraps, and the band grows by that line.
- **A centered number** lies over the line, and text under it is covered.
- **Every band of the zone** gets the number, the first page and even pages included where the
  section has them.
- **A section that shows another section's header** gets the number in the section the band
  comes from.
- **Asking again** replaces the numbers rather than adding more.
- **Text around the number**, such as `Page ` in front of it, is written by opening the band.

`getPageNumbers` reads the numbers back as the options that put them there, or `null` where the
section has none. A control can show the current alignment from it:

```js
const engine = editor.storage.pageLayout.engine

engine.getPageNumbers() // { zone: 'footer', align: 'outside', firstPage: false }
```

`removePageNumbers` takes the numbers out of both zones again. It leaves page numbers written
into a band's text with `insertPageNumber`.

## A page number in a header or footer

While a header or footer is open for editing, `insertPageNumber` puts a page number at the caret:

```js
editor.commands.openFurniture({ zone: 'footer', slot: 'default', pageIndex: 0 })

editor
  .chain()
  .insertContent('Page ')
  .insertPageNumber('page')
  .insertContent(' of ')
  .insertPageNumber('pages')
  .run()
```

| Kind             | Reads                                                                            |
| ---------------- | -------------------------------------------------------------------------------- |
| `'page'`         | The number printed on the page, in its section's format: `iv`, `12`. The default |
| `'pages'`        | How many pages the document has, in digits                                       |
| `'sectionPages'` | How many pages begin in the page's section, in digits                            |

- **The document stores which number stands there**, never the number. Every page the footer is
  drawn on shows its own, and adding a page changes all of them without an edit.
- **The field is one character** to the caret. Backspace removes it whole.
- **Only headers and footers read it.** A field pasted into the text shows nothing, since the
  text is not drawn once per page. The number of the page a position is on is `pageNumberAt`. See
  [From a Decoration](/page-layout/getting-started/document-and-pages/reading#from-a-decoration).
- **A header is as tall on every page of its mask.** Its height is measured once, so a number
  that makes a line wrap on page 100 and not on page 99 does not make that header taller.

## Number formats and chapters

- **The format and the count** of a section, such as roman numerals for a preface and a count
  that starts again at 1, are on [Numbering per section](/page-layout/features/page-numbers/numbering).
- **The chapter in front of the number**, as in `2-1`, is on [Chapter numbers](/page-layout/features/page-numbers/chapter-numbers).

## Your own value per page

The field above is built on a rule any Node can have: what it reads on the page it is drawn on.
Give a Node of yours a `pageText` and a `labelAttribute`, and each page of a header holding it
writes the text into that attribute:

```js
import { defineNodeLayout } from '@tiptap-pro/extension-page-layout'

defineNodeLayout('pageVariable', {
  labelAttribute: 'page-variable-text',
  pageText: (node, page) => `${page.label} / ${page.pageCount}`,
})
```

Draw it with your own stylesheet, from the attribute:

```css
[page-variable-text]::after {
  content: attr(page-variable-text);
}
```

`page` holds:

| Field               | Description                                 |
| ------------------- | ------------------------------------------- |
| `value`             | The number printed on the page              |
| `label`             | That number in its section's format         |
| `pageIndex`         | The position of the sheet, from zero        |
| `pageCount`         | How many sheets there are                   |
| `sectionPageNumber` | Which page of its section this is, from one |
| `sectionPageCount`  | How many pages begin in that section        |
| `sectionIndex`      | The section the page begins in, from zero   |

- **Return `null`** to write nothing.
- **A Node without a `labelAttribute`** gets nothing written.
- **Only headers and footers are asked**, as with the field.
- **Register the rule before the editor is created.** See [Your own extension](/page-layout/paginating-extensions/your-own-extension).

## Switching it off

```js
PageLayout.configure({ pageNumber: false })
```

No page number field, and `insertPageNumber`, `insertPageNumbers` and `removePageNumbers` return
`false`.

## Commands

### insertPageNumbers

Puts a page number into every header or every footer of a section.

```js
editor.commands.insertPageNumbers({ zone: 'footer', align: 'outside', firstPage: false })
```

| Option      | Type                                                     | Description                                                                                                                        |
| ----------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `zone`      | `'header' \| 'footer'`                                   | The band the numbers go into                                                                                                       |
| `align`     | `'left' \| 'center' \| 'right' \| 'inside' \| 'outside'` | Where on the line the number sits. See [Page numbers on every page](/page-layout/features/page-numbers#page-numbers-on-every-page) |
| `firstPage` | `boolean`                                                | `false` leaves the section's first page without a number                                                                           |

Returns `false` while pageless, and with `pageNumber: false` or `pageFurniture: false`.

### removePageNumbers

Takes the numbers `insertPageNumbers` put into the section's headers and footers out again.

```js
editor.can().removePageNumbers()
editor.commands.removePageNumbers()
```

Returns `false` where the section has none, and with `pageNumber: false`.

### insertPageNumber

Puts a page number at the caret in the header or footer being edited.

```js
editor.commands.insertPageNumber('page')
editor.can().insertPageNumber('page') // false while no header or footer is open
```

| Argument | Type                                  | Description                                                                                                                         |
| -------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `kind`   | `'page' \| 'pages' \| 'sectionPages'` | See [A page number in a header or footer](/page-layout/features/page-numbers#a-page-number-in-a-header-or-footer). Default `'page'` |

Returns `false`, and `can()` too, while no header or footer is open, with the caret in the text,
in a block that cannot hold the field, and with `pageNumber: false`.
