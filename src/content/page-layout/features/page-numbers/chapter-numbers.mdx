## The chapter in front of the number

```js
editor.commands.setPageNumbering({ chapter: { level: 1, separator: 'hyphen' } })
editor.commands.setPageNumbering({ chapter: null }) // the number alone again
```

| Separator  | Reads |
| ---------- | ----- |
| `'hyphen'` | `2-1` |
| `'period'` | `2.1` |
| `'colon'`  | `2:1` |
| `'emDash'` | `2—1` |
| `'enDash'` | `2–1` |

- **`level`** is the heading level a chapter begins with, 1 to 9.
- **A `level` outside 1 to 9** is dropped without an error. The Command returns `true`, and the
  pages show their number alone.
- **The chapter of a page** is the first heading of that level on it. On a page with none, it is
  the last one before it, which is Word's rule.
- **A page in front of the first such heading** shows its number alone.
- **A heading** is Tiptap's `heading`, at its `level`, and any Node whose
  [layout rule](/page-layout/paginating-extensions/your-own-extension/layout-rules#chapters) names a `chapterLevel`.
- **Its number** is the heading counted as an outline counts it: `2` for the second level 1
  heading, `2.3` for the third level 2 heading under it.
- **Only the number changes.** Page `2-4` is still an even page, and `pageLabelAt` and
  [the page map](/page-layout/getting-started/document-and-pages/reading#the-page-map) give `'2-4'`.

The Command is [setPageNumbering](/page-layout/features/page-numbers/numbering#setpagenumbering).

## Numbers the headings carry

Where the headings carry a number of their own, give it with `chapterNumbersFromHeadings`:

```js
import { chapterNumbersFromHeadings, PageLayout } from '@tiptap-pro/extension-page-layout'
import { outlineNumberAt } from '@tiptap-pro/extension-outline-numbering'

PageLayout.configure({
  chapterNumberOf: chapterNumbersFromHeadings({
    // 'Article IV' where the outline numbers the heading; the count where it returns null
    label: ({ doc, pos }) =>
      outlineNumberAt(doc, editor.storage.outlineNumbering, pos)?.fullLabel || null,
  }),
})
```

`label` is given the document, the heading Node, its position, its `level` and `counted`, the
number it would get otherwise.

## A rule of your own

For another rule altogether, `chapterNumberOf` takes any function of the page:

```js
PageLayout.configure({
  chapterNumberOf: ({ doc, from, to, level }) => {
    // the number of the chapter heading on this page, or of the last one before it
    return '2'
  },
})
```

- **`from` and `to`** are the positions the page's text begins and ends at. They are equal on a
  page with no text.
- **Return `null`** for a page before the first chapter, which then shows its number alone.
- **With neither** a `chapterNumberOf` nor a Node that has a `chapterLevel` in the schema,
  `setPageNumbering` with a `chapter` returns `false`.
