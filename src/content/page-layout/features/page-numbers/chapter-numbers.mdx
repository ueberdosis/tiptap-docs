## The chapter in front of the number

`setPageNumbering()` with a `chapter` turns chapter numbers on for the section at the cursor, and `chapter: null` turns them off:

```js
editor.commands.setPageNumbering({ chapter: { level: 1, separator: 'hyphen' } })
editor.commands.setPageNumbering({ chapter: null })
```

`level` is the heading level a chapter begins with, from 1 to 9. A `level` outside that range is dropped without an error: the command returns `true`, and the pages show the number alone.

`separator` goes between the numbers: `'hyphen'` reads `2-1`, `'period'` `2.1`, `'colon'` `2:1`, and `'emDash'` and `'enDash'` put an em dash or an en dash there.

A page's chapter is the first heading of that level on the page. On a page without one, it is the last one before it, as in Word. A page before the first such heading shows its number alone.

A heading is Tiptap's `heading` node, or any node whose [layout rule](/page-layout/extension-behavior/your-own-extension/layout-rules#chapters) names a `chapterLevel`.

The chapter number is counted as an outline counts. With `level: 1`, the second level 1 heading is chapter `2`. With `level: 2`, the third level 2 heading under it is `2.3`, and its pages read `2.3-1`.

Only the label changes, so page `2-4` is still an even page. `pageLabelAt` and the [page map](/page-layout/getting-started/document-and-pages/reading#the-page-map) give `'2-4'` for it.

## Numbers the headings carry

When your headings carry numbers of their own, such as `Article IV` from [Outline numbering](/page-layout/extension-behavior/outline-numbering), pass `chapterNumbersFromHeadings({ label })` as `chapterNumberOf`. `label` runs once the editor exists, so it can read `editor`, the editor you create with this extension:

```js
import { chapterNumbersFromHeadings, PageLayout } from '@tiptap-pro/extension-page-layout'
import { outlineNumberAt } from '@tiptap-pro/extension-outline-numbering'

PageLayout.configure({
  chapterNumberOf: chapterNumbersFromHeadings({
    label: ({ doc, pos }) =>
      outlineNumberAt(doc, editor.storage.outlineNumbering, pos)?.fullLabel || null,
  }),
})
```

`label` gets `doc`, the heading `node`, its `pos`, its `level`, and `counted`, the number it would otherwise get. Where it returns `null` or `''`, the counted number is used.

Without a `chapterNumberOf`, Page Layout uses `chapterNumbersFromHeadings()` with no `label`. Then `setPageNumbering()` with a `chapter` returns `false` when the schema has no heading.

## A rule of your own

`chapterNumberOf` takes any function that returns a page's chapter number. This one letters chapters A, B, C by the last heading before the page ends:

```js
import { PageLayout } from '@tiptap-pro/extension-page-layout'

PageLayout.configure({
  chapterNumberOf: ({ doc, to, level }) => {
    let count = 0
    doc.nodesBetween(0, to, (node) => {
      if (node.type.name === 'heading' && node.attrs.level === level) count += 1
    })
    return count ? String.fromCharCode(64 + count) : null
  },
})
```

`from` and `to` are positions in `doc`, the document, where the page's text begins and ends, equal on a page without text. `level` is the section's chapter level. Returning `null` or `''` shows the number alone. Page Layout calls it only for pages of a section with a `chapter`.
