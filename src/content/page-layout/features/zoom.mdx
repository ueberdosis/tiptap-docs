## Quick start

To zoom, call `setZoom()` on the engine, the object at `editor.storage.pageLayout.engine` that lays out the pages. `editor` is an editor from `createPageLayoutEditor`, as in [Page format](/page-layout/features/page-format#quick-start). No markup of yours is needed:

```js
const engine = editor.storage.pageLayout.engine

engine.setZoom(0.75) // three quarters
engine.setZoom('fit') // the largest size that fits the width
engine.setZoom(1) // full size
```

Which levels to offer, and where the control sits, is up to you.

## Fit to width

`setZoom('fit')` shows the widest sheet, the element a page is drawn on, at the largest size that fits the width, never above full size. So a landscape section does not hang off the side. Page Layout fits again when the width changes.

Put the editor in the element that scrolls. The width is that of the nearest ancestor with `overflow` set to `auto`, `scroll` or `overlay`, less its padding, even before its content scrolls. Without one, it is the window's width.

While [pageless](/page-layout/features/page-format#pageless), where the document is one continuous column without pages, a fit is `1`.

The second argument is how many sheets fit side by side:

```js
engine.setZoom('fit') // one sheet
engine.setZoom('fit', 2) // two sheets side by side
```

It defaults to `1`, is rounded down to a whole number of at least 1, and stays until you pass another.

Two sheets leave room for the gap between them, `--tt-page-sheet-gap`, so a wider gap makes the fit smaller. The gap may be any CSS length and counts as 24 px where it is not set.

## Engine methods

The zoom methods belong to the engine and are not commands:

| Method                                 | Returns     | Description                                                                       |
| -------------------------------------- | ----------- | --------------------------------------------------------------------------------- |
| `engine.setZoom(level, sheetsAcross?)` | `void`      | Shows the pages at `level`, a factor or `'fit'`. A factor of 0 or less means `1`. |
| `engine.getZoom()`                     | `ZoomLevel` | The level you set. `1` before any zoom.                                           |
| `engine.getScale()`                    | `number`    | The factor in force, which is what `'fit'` comes out as.                          |
| `engine.getSheetsAcross()`             | `number`    | How many sheets a fit puts across. `1` until you pass another count.              |
| `engine.getWidestPageWidth()`          | `number`    | The widest sheet's width in CSS pixels. `0` while pageless.                       |
| `engine.setScale(scale)`               | `void`      | Tells Page Layout the factor your own transform applies.                          |

`ZoomLevel`, a number or `'fit'`, is exported. A toolbar shows the selected level from `getZoom()`, and from `getSheetsAcross()` when it offers one and two sheets. The count stays while the level is a factor, because `setZoom('fit')` without a count fits that many again:

```js
const twoSheets = engine.getZoom() === 'fit' && engine.getSheetsAcross() === 2
```

A ruler or overlay that lines up with the pages reads `getScale()`. When a fit changes its scale by itself, Page Layout calls the [`onChange` option](/page-layout/getting-started/install) of `createPageLayoutEditor`. It does not call it for `setZoom()`, so read `getScale()` after that call.

If your app scales the pages with a CSS transform of its own, such as a pan-and-zoom canvas, call `setScale()` with that factor. Otherwise Page Layout measures the scaled pages, and they break in the wrong places.

## What a zoom takes care of

A zoom does not change where pages end, because Page Layout divides what it measures by the zoom and so lays out at full size. Page Layout also corrects the height of the element the editor is mounted in, so the scroll range fits what the user sees.

Printing is at full size, and the zoom comes back afterwards. A PDF from a headless browser is at full size too, because the print rules remove the zoom without a print event. See [Printing](/page-layout/features/printing).

`data-tt-page-zoom` on the editor's element holds the factor, for anything drawn beside the pages, and is not set at full size.

## The room around the pages

The scrolling element the sheets lie in is yours to style. `--tt-page-sheet-gap` is the space between two sheets. See [Styling the pages](/page-layout/guides/styling).
