## Quick start

Insert a section break at the caret, then turn the second section landscape:

```js
editor.commands.insertSectionBreak()

const engine = editor.storage.pageLayout.engine
const [, second] = engine.getSections()

editor.commands.setSectionSetup(1, { ...second.setup, orientation: 'landscape' })
```

## What a section holds

Each of these belongs to a section, not to a single sheet:

| Setting                       | Page                                                                     |
| ----------------------------- | ------------------------------------------------------------------------ |
| Format, orientation, margins  | [Page format](/page-layout/features/page-format)                         |
| Columns                       | [Section columns](/page-layout/features/section-columns)                 |
| Page colors                   | [Page colors](/page-layout/features/page-colors)                         |
| Page numbering                | [Numbering per section](/page-layout/features/page-numbers/numbering)    |
| Headers and footers           | [Header and footer](/page-layout/features/header-and-footer)             |
| Footnote and endnote settings | [Footnotes in Page Layout](/page-layout/paginating-extensions/footnotes) |

A document with a landscape table in the middle of an upright report has three sections:

```
Section 1  A4 portrait     Introduction, the text before the table
Section 2  A4 landscape    The wide table
Section 3  A4 portrait     Everything after it
```

## Section breaks

Each section after the first begins at a section break: a Node in the document, between two
blocks.

- **It travels with the text.** Insert a paragraph above it, and the break stays in front of
  the same content.
- **It divides the block it lands in.** A paragraph becomes two paragraphs, and a list becomes
  two lists that carry on counting.
- **A new section copies the one it was cut out of.** Inserting a break changes nothing about
  the layout until something about the new section is set.
- **`'nextPage'`** starts the section on new paper. It is the default.
- **`'continuous'`** starts the section below the one above, on the same sheet. It keeps the
  paper size, orientation and margins of the section above. Its columns and colors are its own.
- **Section zero** always starts on new paper, since nothing is above it.

Page and column breaks, and the breaks of a pageless editor, are on [Breaks](/page-layout/features/breaks).

## The document's own format

The first section's setup is stored as a section break in front of the first block.

- **A document without that break** is shown in the setup `PageLayout` is configured with.
  Two editors with different setups show it on different paper.
- **A second section stores the first one's format too.** Inserting a section break, setting
  a section's format or columns, or replacing the sections writes the first section's setup
  as it is shown at that moment. Nothing on screen moves.
- **From then on**, the document comes out on the same paper wherever it is opened.
- **Undo** takes both breaks back together.
- **A document you build yourself**, from a converter or a template, starts with that break
  when it has more than one section. [Word documents](/page-layout/guides/word#sections) has the
  function that does this for a .docx.

## Changing one section

```js
const engine = editor.storage.pageLayout.engine
const index = engine.getActiveSectionIndex()
const current = engine.getSections()[index].setup

editor.commands.setSectionSetup(index, { ...current, orientation: 'landscape' })
```

- **Spread the current setup.** A fresh one resets everything else along with the one field.
- **Some settings follow the selection.** `setSectionColumns` gives columns to the blocks the
  selection covers and adds the section breaks around them. Select three paragraphs, ask for
  two columns, and get a section holding exactly those. See
  [Section columns](/page-layout/features/section-columns).

`setSectionSetup` is described on [Page format](/page-layout/features/page-format#setsectionsetup).

## Reading the sections at runtime

```js
const engine = editor.storage.pageLayout.engine

engine.getSetup() // the setup of the document's first section
engine.getSections() // every section: startBlockIndex, setup, kind
engine.getActiveSectionIndex() // the section the cursor is in, or whose header is open
engine.getPageCount()
```

- **Always current.** A toolbar that shows "Section 2 of 3 · A4 landscape" reads it from
  here, and it is up to date after every change.
- **`startBlockIndex` counts every top-level block, the section breaks included.** A section
  that starts at a break reports the index of the break. `setPageSections` counts without
  the breaks; `engine.contentIndexOfBlock(index)` converts one into the other.
- **Pageless**, `getSections()` returns an empty list.
- **Without an editor**, `sectionsDeclaredBy(doc)` reads the sections from a document's JSON.
  See [Where the paper is stored](/page-layout/features/page-format#where-the-paper-is-stored).

## Commands

### insertSectionBreak

Starts a new section at the cursor.

```js
editor.commands.insertSectionBreak() // 'nextPage'
editor.commands.insertSectionBreak('nextPage') // on new paper
editor.commands.insertSectionBreak('continuous') // below this one, same sheet
```

| Option | Type           | Description                                          |
| ------ | -------------- | ---------------------------------------------------- |
| `kind` | `SectionStart` | `'nextPage'` or `'continuous'`. Default `'nextPage'` |

Returns `false` where a section already starts at the cursor, while pageless in a document
that stores no format of its own, and when `sectionBreak` is switched off.

### setPageSections

Replaces every section at once, for restoring a saved arrangement or a "reset to one format"
button.

```js
editor.commands.setPageSections([
  { startBlockIndex: 0, setup: pageSetup('A4') },
  { startBlockIndex: 12, setup: pageSetup('A4', { orientation: 'landscape' }) },
  { startBlockIndex: 18, setup: pageSetup('A4'), kind: 'continuous' },
])
```

| Option     | Type            | Description                                                 |
| ---------- | --------------- | ----------------------------------------------------------- |
| `sections` | `PageSection[]` | Each a `startBlockIndex`, a `setup` and optionally a `kind` |

- **`startBlockIndex`** counts the top-level blocks without the section breaks, unlike the
  `startBlockIndex` of `engine.getSections()`. Pass a section read from there through
  `engine.contentIndexOfBlock(section.startBlockIndex)`.
- **The caret stays at the text it was at.**
- **A single entry for block zero** removes every other break.
- **A break that stays in front of the same block** keeps its headers and footers, and its
  `kind` when the entry names none.
- **One step.** Undo reverses the whole rewrite.

Returns `false` when `sectionBreak` is switched off. While pageless it changes nothing.

### removeSection

Removes a section's break, so its content joins the section above it.

```js
editor.commands.removeSection(2)
```

| Option         | Type     | Description                        |
| -------------- | -------- | ---------------------------------- |
| `sectionIndex` | `number` | An index of `engine.getSections()` |

Returns `false` for section `0`, which is the document's own format, for an index with no
section, while pageless, and when `sectionBreak` is switched off.
