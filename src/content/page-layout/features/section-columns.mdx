## Quick start

Give the selected blocks two columns:

```js
editor.commands.setSectionColumns({ count: 2, gaps: null, rule: false, widths: null })
```

Containers side by side, each with content of its own, are a different thing: a
column layout from [Columns](/editor/extensions/functionality/columns), and on pages
[Columns in Page Layout](/page-layout/supported-extensions/columns).

## How columns work

- **The text stays one sequence in the document.** Only its picture is divided.
- **Selecting across a column boundary** selects the text between the two points.
- **The clipboard** gets a continuous passage.
- **Search** finds a phrase that is broken across two columns.
- **Columns belong to a [section](/page-layout/features/sections).** A column count cannot change half
  way down a page. Giving a passage columns sections the document around it, and
  `setSectionColumns` does that for you.

## Setting columns

`setSectionColumns` applies to the blocks the selection covers.

- **A selection** of three paragraphs gets exactly those three paragraphs in two columns.
- **Section breaks** are added around them where needed. They are continuous, so nothing
  starts a new sheet.
- **Whole blocks.** A selection that starts or ends inside a block takes the whole block.
  Nothing is divided.
- **A selection across a section break** keeps that section and its paper. Only the columns
  change.
- **With nothing selected**, the section the cursor is in takes the columns.

### The four fields

| Field    | Type               | Description                                                                                                  |
| -------- | ------------------ | ------------------------------------------------------------------------------------------------------------ |
| `count`  | `number`           | How many columns the text flows through. At least `1`, which is an undivided page                            |
| `gaps`   | `number[] \| null` | The space after each column but the last, in pixels. `null` while every gap is the default half inch (48 px) |
| `rule`   | `boolean`          | A vertical line drawn in each gap                                                                            |
| `widths` | `number[] \| null` | A share of the text area per column. `null` for equal columns                                                |

- **`gaps` has one entry fewer than there are columns.** Three columns can be spaced two
  different ways.
- **A gap is a measure.** It stays the same on A5 as on A4. `DEFAULT_COLUMN_GAP` is the half
  inch.
- **A width is a share.** The same section in landscape, or with wider margins, keeps the split
  the author chose.
- **`rule` takes no width from the columns.** The line is drawn inside the gap, so switching it
  on does not reflow the text.

### Widths without doing the arithmetic

Two presets and the way back to one column:

```js
import {
  NARROW_COLUMN_FIRST,
  NARROW_COLUMN_LAST,
  SINGLE_COLUMN,
} from '@tiptap-pro/extension-page-layout'

editor.commands.setSectionColumns({ count: 2, gaps: null, rule: true, widths: NARROW_COLUMN_FIRST })
editor.commands.setSectionColumns(SINGLE_COLUMN)
```

| Preset                | Value                                               |
| --------------------- | --------------------------------------------------- |
| `NARROW_COLUMN_FIRST` | Widths 1:2, the narrow column first                 |
| `NARROW_COLUMN_LAST`  | Widths 2:1, the narrow column last                  |
| `SINGLE_COLUMN`       | A whole `PageColumns` with one column, the way back |

For widths an author typed in any unit, convert them with `columnSharesFromWidths`:

```js
import { columnSharesFromWidths } from '@tiptap-pro/extension-page-layout'

// Two fields in centimeters, from a dialog.
const widths = columnSharesFromWidths([4.5, 11.5])
```

It normalizes what it is given. It returns `null` when the numbers cannot describe a division:
an empty list, a number that is not positive, or one that is not finite. Equal columns are the
answer then.

## A column break

A column break ends the column at the cursor, and the text continues at the top of the next
one.

- **In a section with one column**, a column is the page, so the break ends the page. Offer it
  even where no section has columns yet.
- **It is a marker in the document**, like a manual page break, and stays where the author put
  it.

`insertColumnBreak` is on [Breaks](/page-layout/features/breaks#insertcolumnbreak).

## Reading what is in force

A dialog shows which preset a section is on and what its gaps are. Neither can be read off the
setup directly:

- **`widths` is `null`** for equal columns.
- **`gaps` is `null`** while they are the default.
- **Either may hold a list** left over from a different count.

These functions answer what is in force:

```js
import { columnGaps, columnShares, hasEqualGaps } from '@tiptap-pro/extension-page-layout'

const engine = editor.storage.pageLayout.engine
const section = engine.getSections()[engine.getActiveSectionIndex()]
const { columns } = section.setup

columnShares(columns) // [0.3333…, 0.6666…] — always one entry per column
columnGaps(columns) // [48] — always one fewer than there are columns
hasEqualGaps(columns) // whether one field is enough to show them
```

| Function          | Argument      | Returns                                                                                |
| ----------------- | ------------- | -------------------------------------------------------------------------------------- |
| `columnShares`    | `PageColumns` | The share of each column, one entry per column                                         |
| `columnGaps`      | `PageColumns` | The gap after each column but the last, in pixels                                      |
| `hasEqualGaps`    | `PageColumns` | Whether every gap is the same                                                          |
| `hasEqualColumns` | `PageColumns` | Whether every column is the same width                                                 |
| `columnWidths`    | `PageSetup`   | The width of each column in pixels, for a surface that draws its own rules or measures |

In a section with columns, the text is laid out in a fraction of the text area, not in the
whole of it.

## What columns do to the pages

- **A column is filled to the bottom of the page** before the next one begins.
- **A paragraph too tall for what is left of a column** continues at the top of the next one,
  on the same sheet.
- **A page break** ends the page, not the column.
- **A table** breaks between its rows inside the column it is in.
- **A footnote** is drawn at the foot of the sheet, not at the foot of the column.
- **The count is the section's.** A two-column page whose text ran out half way shows one
  filled column and one empty track.

### Balanced columns

- **A continuous section break at the end of a section** balances its columns: they are filled
  so the arrangement is as short as possible.
- **A section that runs to the end of the document**, or to a next-page break, fills its first
  column to the foot of the sheet.
- **To balance the last page** of a two-column document, insert a continuous section break at
  the end.

## What is not supported

- **Balancing is exact for equal columns only.** In a section that divides its area unequally,
  a block lands in a column narrower than the one it was measured in and is taller there. The
  result can be a line or two off the shortest arrangement, with all the content there.
- **Columns in the footnote area.** Word's _Footnote Layout · Columns_ is a separate setting and
  is not there. Notes are drawn in one box across the width of the text area.
- **Dragging a column edge.** Widths are set through `setSectionColumns`. There is no handle on
  the page.

## Commands

### setSectionColumns

Gives the blocks the selection covers these columns, adding section breaks around them where
the selection does not line up with a section.

```js
editor.commands.setSectionColumns({ count: 3, gaps: null, rule: false, widths: null })
```

| Option    | Type          | Description                                                                                            |
| --------- | ------------- | ------------------------------------------------------------------------------------------------------ |
| `columns` | `PageColumns` | The whole column setting. See [The four fields](/page-layout/features/section-columns#the-four-fields) |

Returns `false` while pageless and when `sectionBreak` is switched off. `can()` answers `true`
while pageless all the same.
