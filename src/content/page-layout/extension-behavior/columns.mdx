It is a different thing from [section columns](/page-layout/features/section-columns), which one run of
text flows through.

## Setting it up

Register `Columns` next to `PageLayout`. Nothing else needs to be configured.

## At the bottom of a page

- **One cut through every column.** A `columnLayout` is cut at one height through all of its
  columns at once.
- **Each column** carries on at the top of the next page.
- **A column that ended above the cut** is empty on the next page.

## Keeping a layout on one page

```js
editor.commands.setColumnLayoutKeepTogether(true)

editor.storage.pageLayout.engine.getColumnLayoutContext()
// { layout, layoutPosition, keepTogether } for the innermost layout, or null outside one
```

- **Moved whole.** The layout moves to the next page whole.
- **A preference.** A layout taller than a page is cut anyway. See
  [Keep together is a preference](/page-layout/extension-behavior#keep-together-is-a-preference).
- **Stored as `keepTogether`** on the layout, `false` by default, and as
  `data-tt-keep-together="true"` in HTML. A copied layout keeps it.
- **`PageLayout.configure({ columnsPagination: false })`** takes the setting away.

`getColumnLayoutContext()` returns `null` outside a layout, otherwise:

| Field            | Type      | Description                           |
| ---------------- | --------- | ------------------------------------- |
| `layout`         | `Node`    | The innermost layout around the caret |
| `layoutPosition` | `number`  | Where it starts                       |
| `keepTogether`   | `boolean` | Whether it is held on one page        |

## In a .docx

A column layout is written to a .docx as a table of one row. See
[Column layouts](/page-layout/guides/word#column-layouts).

## Commands on pages

### setColumnLayoutKeepTogether

Keeps the column layout at the cursor on one page, or lets it be cut again.

```js
editor.commands.setColumnLayoutKeepTogether(true)
```

| Argument   | Type      | Description                                    |
| ---------- | --------- | ---------------------------------------------- |
| `together` | `boolean` | `true` moves the layout to the next page whole |

Returns `false` when the cursor is not in a column layout.
