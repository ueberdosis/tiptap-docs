## Quick start

Register `Columns` next to `PageLayout`, with nothing else to set up, and insert a layout with [`insertColumns`](/editor/extensions/functionality/columns#insertcolumns). With the cursor in one, `setColumnLayoutKeepTogether(true)` keeps it on one page:

```js
import { Columns } from '@tiptap-pro/extension-columns'
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [StarterKit, Columns, PageLayout.configure({ setup: pageSetup('A4') })],
})

editor.commands.setColumnLayoutKeepTogether(true)
```

## At the bottom of a page

When a page cuts a column layout, each column carries on at the top of the next page, or is empty there if its content ended above the cut.

## Keeping a layout on one page

A layout kept together moves to the next page whole, unless it is taller than a page, see [Keep together is a preference](/page-layout/extension-behavior#keep-together-is-a-preference). The setting is the attribute `keepTogether`, `false` by default and in HTML `data-tt-keep-together="true"` only when on. A copied layout keeps it. `PageLayout.configure({ columnsPagination: false })` removes it.

`editor.storage.pageLayout.engine.getColumnLayoutContext()` returns `null` outside a layout. In one, it returns `{ layout, layoutPosition, keepTogether }`: the innermost layout around the cursor, where it starts in the document, and its setting.

## In a .docx

A .docx holds a column layout as a table of one row, see [Word documents](/page-layout/guides/word#column-layouts).

## Commands

The command also returns `false` in an editor without a Page Layout engine, such as one made with `new Editor`.

### setColumnLayoutKeepTogether()

Keeps the column layout at the cursor on one page, or lets a page cut it again.

```js
editor.commands.setColumnLayoutKeepTogether(true)
```

Takes one argument, `together` (`boolean`). Returns `false` outside a column layout.

The engine has the same method. To make this change without an editor, see [On a server](/page-layout/guides/on-a-server).
