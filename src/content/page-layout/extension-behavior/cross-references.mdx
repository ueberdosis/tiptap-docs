## Quick start

Configure Cross-references with `ignore: ignoreLayoutArtifacts`, which leaves out what the pages add, and `pageOf`, which reads a target's page. `targets: { heading: {} }` makes headings targets with the default [settings](/editor/extensions/functionality/cross-references#registering-targets). Here `pos` is a heading's position in the document, `engine.getSourceDocument()`:

```js
import { CrossReferences } from '@tiptap-pro/extension-cross-references'
import {
  createPageLayoutEditor,
  ignoreLayoutArtifacts,
  PageLayout,
  pageLabelAt,
  pageSetup,
} from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [
    StarterKit,
    CrossReferences.configure({
      targets: { heading: {} },
      ignore: ignoreLayoutArtifacts,
      pageOf: ({ doc, pos }) => pageLabelAt(doc, pos),
    }),
    PageLayout.configure({ setup: pageSetup('A4') }),
  ],
})

editor.commands.insertCrossReference({ target: pos, show: 'page' })
```

`pageOf` gets `{ node, pos, doc }` of a target and returns its page as text, or `null`.

## Leaving the pages out

With `ignoreLayoutArtifacts`, a heading cut across pages is a target on its first page. A title taken from its text has only the part on that page. The items of a list cut by a page are targets on whichever page they stand. Pass the same function to [Outline numbering](/page-layout/extension-behavior/outline-numbering).

## Commands on pages

Cross-references commands, F9's `updateCrossReferences` included, write the document, and `can()` answers from it. The two exceptions are `refreshCrossReferences` and `setCrossReferenceUpdate`, which act on this editor only. Their arguments are in the [Cross-references commands](/editor/extensions/functionality/cross-references#commands).

A target, given as an id or a position, and the position `resetCrossReference(pos)` takes, are in the document, not in `editor.state.doc`. Pass the document to `crossReferenceTypesIn` and `crossReferenceAround` too.

The check that keeps target ids unique runs on the document, so a cut heading never counts as two headings with one id. `repair: false` turns it off there too.

A reference's text takes room in its line, so a number that grows by a digit moves the text after it. A page never cuts through a reference.

## Going to a target on another page

On pages, Cmd/Ctrl+click on a reference goes to its target without a `reveal` option: Page Layout runs [`goToCrossReferenceTarget`](/editor/extensions/functionality/cross-references#gotocrossreferencetarget) on the document. It draws the target's page if needed and scrolls to it.

The caret lands at the start of the heading, or in the text of a footnote. A `reveal` of your own replaces this.

## See page N

`pageLabelAt(doc, pos)` returns the page a position is on as that page writes its number, such as `iv` in a Roman-numbered preface. `pageNumberAt(doc, pos)` returns it as a number. Both answer for the document, which commands read when they store a reference's text, and for `editor.state.doc`. They return `null`:

- **For a document changed since it was last laid out.**
- **In [Pageless](/page-layout/features/page-format#pageless) mode**, where the document is one continuous column without pages.
- **For a position outside the document.**

A reference that shows `page` follows its target when an edit moves the target to another page. A footnote target is on the page its note is drawn on.

### A reference that moves its own target

When "page 9" becomes "page 10" and the longer text pushes the target back to page 9, Page Layout keeps the room the longer text needed. So the reference shows the target's final page instead of switching back and forth.

Any change to the document, an undo included, measures the line again.
