## Quick start

Configure Outline numbering with `ignore: ignoreLayoutArtifacts`, which leaves out what the pages add. Before `createPageLayoutEditor`, tell `defineNodeLayout` which attribute holds a heading's number, so Page Layout measures the heading again when its number grows by a digit:

```js
import { OUTLINE_NUMBER_ATTRIBUTE, OutlineNumbering } from '@tiptap-pro/extension-outline-numbering'
import {
  createPageLayoutEditor,
  defineNodeLayout,
  ignoreLayoutArtifacts,
  PageLayout,
  pageSetup,
} from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

defineNodeLayout('heading', { labelAttribute: OUTLINE_NUMBER_ATTRIBUTE })

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [
    StarterKit,
    OutlineNumbering.configure({
      types: { heading: { level: (node) => node.attrs.level } },
      ignore: ignoreLayoutArtifacts,
    }),
    PageLayout.configure({ setup: pageSetup('A4') }),
  ],
})
```

## Headings across pages

A heading cut across two pages is numbered once, on the page where it begins. The numbering scheme a document stores is on no page.

The chapter in front of a page number, such as the 2 in 2-7, follows the headings without this setup. To make it follow the outline, pass a function as the `chapterNumberOf` option of `PageLayout`, see [Chapter numbers](/page-layout/features/page-numbers/chapter-numbers).

## Writing the outline

`setOutlineLevels`, `setOutlineLevel` and `setOutlineList` write the document, and `can()` answers from it. `refreshOutlineNumbers` acts on the editor. See the [Outline numbering commands](/editor/extensions/functionality/outline-numbering#commands). `outlineListAt(doc, pos)` and `outlineNumberAt(doc, registry, pos)` take positions in `engine.getSourceDocument()`, and `registry` is `editor.storage.outlineNumbering`.

## Lists of clauses across pages

A [list of clauses](/editor/extensions/functionality/outline-numbering#lists-as-clauses) cut by a page goes on counting on the next one. It needs no `defineNodeLayout`, because its numbers stand in the margin, in the list's indent.

A page clips what reaches past its margin. If numbers are clipped, set `--tt-outline-list-indent` (`2.5em` by default) wider on `.tiptap` in your stylesheet.

An item cut inside its text is numbered on the page where it begins, and its rest draws neither a number nor a list marker.
