Page Layout reads some fields once, while it builds the editor, before any node exists. So `parallelCutNode`, `viewContent`, `ignoredMutation`, `viewCommands`, `sourceCommands` and the option fields take a value, never a function of the node.

`splitDepth` is read then too, so a type becomes one that may be cut only through a rule in place by then. A function counts as one that may cut, even if it answers `'none'` for every node.

`viewCommands`, `sourceCommands`, `ignoredMutation` and the option fields are looked up by the extension's name, which for a node is its type name.

The types `NodeEdit`, `NodeLayout`, `NodeLayoutRule`, `NodeLayouts`, `PageContext`, `ParallelCutRank`, `SplitDepth`, `NodeChildSpan`, `NodeFragmentAdapter`, `ForcedCutUnit` and `RenderRepeatedLeadOptions` are exported.

## parallelChildKeys

`parallelChildKeys` gives one key per child, in order, such as `row => row.children.map(cell => cell.attrs.id)`. The caret or a cell selection that crosses a cut then finds the matching child on the other part.

You need it only with a `fragmentAdapter`, which adds children at a cut and so shifts the indexes of the others. Without keys, both parts keep the same children in the same order. A child whose key is `null`, missing or used twice has no match.

## viewOptionDefaults

`viewOptionDefaults` fills an option of the extension on the pages where it is `null` or `undefined`, so an option you set is kept. Use it for a click handler or another option left to your app.

Each entry gets a getter that returns the editor, or `null` before it is built. `glossary` is your extension:

```js
import { defineNodeLayout } from '@tiptap-pro/extension-page-layout'

defineNodeLayout('glossary', {
  viewOptionDefaults: { onTermClick: (editor) => () => editor()?.commands.focus() },
})
```

## fragmentAdapter

`fragmentAdapter` builds the parts of a cut node that each need children of their own, such as a cell per part of a merged cell, and joins them again. Only the table has one, which is not exported, so a type of yours cannot reuse its merged cells.
