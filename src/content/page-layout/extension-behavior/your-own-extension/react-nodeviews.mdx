## Quick start

Put the `ref` of `usePageLayoutEditor` on the element the pages are drawn into, and render `nodeViews` in the same component. A node rendered with `ReactNodeViewRenderer` needs nothing more:

```jsx
import { Node } from '@tiptap/core'
import { NodeViewWrapper, ReactNodeViewRenderer } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'
import { PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import { usePageLayoutEditor } from '@tiptap-pro/extension-page-layout-react'

function Callout() {
  return <NodeViewWrapper className="callout">A callout</NodeViewWrapper>
}

const CalloutNode = Node.create({
  name: 'callout',
  group: 'block',
  atom: true,
  addNodeView() {
    return ReactNodeViewRenderer(Callout)
  },
})

function MyEditor({ content }) {
  const { ref, nodeViews } = usePageLayoutEditor({
    content,
    extensions: [StarterKit, CalloutNode, PageLayout.configure({ setup: pageSetup('A4') })],
  })

  return (
    <>
      <div ref={ref} />
      {nodeViews}
    </>
  )
}
```

[The hook](/page-layout/getting-started/install/react#the-hook) explains the rest of `usePageLayoutEditor`.

## Where the components are rendered

`nodeViews` is a React element, and your components are rendered where it is, with its React context. Without it, a node with a React NodeView is drawn empty, and the console warns once.

## A component on pages

When a component's height changes, Page Layout lays the pages out again. Without `ResizeObserver` in the browser, call [`measureAgain`](/page-layout/extension-behavior/your-own-extension/when-no-rule-fits#heights-that-arrive-late).

`updateAttributes` and `deleteNode` change the whole node once, from any page, and can be undone. A node cut by a page end has one component per page, and `node` is the part on that page. `getPos()` is a position in the pages, as dragging and the `selected` prop need.

When something before the node grows and moves it to another page, its component mounts again and loses its state. It does not mount again when the user types elsewhere.

Keep state in the node's attributes or outside the component, and do not write to the document on every mount, or the component loops.

## The node behind a component

`engine.sourceNodeOfView(getPos())` returns the node of the document behind a component, and which part of it the component draws. This one shows "part 1 of 2" for a cut node:

```jsx
function Callout({ editor, getPos }) {
  const drawn = editor.storage.pageLayout.engine.sourceNodeOfView(getPos())
  const label =
    drawn && drawn.piece.count > 1 ? `part ${drawn.piece.index + 1} of ${drawn.piece.count}` : null

  return <div>{label}</div>
}
```

`pos` and `node` are the same on every page, and the call returns `null` while the pages are drawn again. [From the screen to the document and back](/page-layout/getting-started/document-and-pages/reading#from-the-screen-to-the-document-and-back) has the details.
