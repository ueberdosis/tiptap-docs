## The editor

- **It has to be built with `createPageLayoutEditor`.** `PageLayout` in an editor built with
  `new Editor` draws no pages, and its Commands return `false`. See
  [Building the editor](/page-layout/getting-started/install#building-the-editor).
- **`editorProps` is not accepted.** See
  [Building the editor](/page-layout/getting-started/install#building-the-editor).
- **`editor.state` holds the pages, not the document.** Save what `getJSON()` returns, and read
  positions through the engine. See [Positions](/page-layout/getting-started/install#positions).
- **Collaboration is set up through `PageLayout`, not as an extension.** Adding
  `@tiptap/extension-collaboration` to the editor shares one reader's pages. See
  [Collaboration](/page-layout/guides/collaboration).

## Pagination

- **A block taller than a page runs past it.** A block that cannot be cut and is taller than a page
  runs past the bottom of its sheet.
- **Keep together gives way.** A `keepTogether` list or column layout taller than a page is cut
  anyway. See
  [Keep together is a preference](/page-layout/extensions/overview#keep-together-is-a-preference).
- **No widow and orphan control, and no keep with next.** A paragraph is cut wherever the page runs
  out, and a heading can be the last line on a page. See
  [What is not supported](/page-layout/extensions/overview#what-is-not-supported).
- **Nested tables** are not supported at a page boundary. See
  [Tables across pages](/page-layout/extensions/tables#what-is-not-supported).

## Section columns

- **Balancing** is exact for equal columns only.
- **The note area** has no columns of its own.
- **A column edge** cannot be dragged on the page.

See [Section columns](/page-layout/core-concepts/section-columns#what-is-not-supported).

## Footnotes

- **The note area** has no columns of its own.
- **A note continued across a change of paper size** reserves more room than it needs.
- **A single note** cannot have a mark of its own.

See [Footnotes on pages](/page-layout/extensions/footnotes/on-pages#what-is-not-supported).

## Long documents

- **The browser's find and a screen reader reach the drawn sheets only.** Only the sheets near the
  reader carry their text in the DOM. See
  [Long documents](/page-layout/guides/long-documents#what-only-sees-the-drawn-sheets).

## Printing and PDF

- **Safari prints every sheet on the paper of the first page.** A page in another format is fitted
  onto that paper. See [Printing in Safari](/page-layout/guides/printing-and-pdf#printing-in-safari).
- **Server-side pagination and a PDF made on a server** are not available as a package yet. See
  [Packages](/page-layout/getting-started/packages#the-packages).

## Pasting from Word

- **Fields arrive as the text Word last showed for them.**
- **The paper of a pasted section is not taken.**

See [Pasting from Word](/page-layout/guides/word#pasting-from-word).
