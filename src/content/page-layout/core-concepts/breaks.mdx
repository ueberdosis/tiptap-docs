## Quick start

```js
editor.commands.insertPageBreak()
editor.commands.insertColumnBreak()
editor.commands.insertSectionBreak('nextPage')
editor.commands.insertSectionBreak('continuous')
```

## Three kinds

All three are inserted at the cursor.

| Break   | What it does                                                                                                         | Shortcut          |
| ------- | -------------------------------------------------------------------------------------------------------------------- | ----------------- |
| Page    | Ends the page here and continues on the next one                                                                     | `Mod-Enter`       |
| Column  | Ends the current column. In a section with one column, the same as a page break                                      | `Mod-Shift-Enter` |
| Section | Starts a new [section](/page-layout/core-concepts/sections), on new paper or below the current one on the same sheet | —                 |

The shortcuts are Word's.

## Inserted and automatic breaks

- **Only an inserted break is kept in the document.** The automatic ones are worked out again on
  every change.
- **The same document on different paper** breaks in different places, except at the breaks
  an author inserted.
- **A page or column break is a marker in the text**, not a block, so it can sit between two
  words.
- **Two page breaks in a row** make a blank page.
- **A code block** cannot hold a page or column break.
- **A section break divides the block it lands in.** A paragraph becomes two paragraphs, and a
  list becomes two lists that carry on counting.

## Two formats on one sheet

A continuous section break is how two formats share a sheet. A two-column passage in the middle
of a one-column page is a continuous section with [columns](/page-layout/core-concepts/section-columns) of
its own, and the text carries on below it on the same page.

## Removing one

- **Backspace** at the start of the page after a page break removes the break.
- **From a toolbar**, `removePageBreak` does the same, and
  [`removeSection`](/page-layout/core-concepts/sections#removesection) removes a section break.

## Breaks without pages

In a [pageless](/page-layout/core-concepts/page-format#pageless) editor, the breaks stay in the document.
Page and column breaks can still be inserted there.

- **Drawn as labeled dashed lines**, so nothing an author inserted becomes invisible.
- **`breaksWithoutPages: 'none'`** draws nothing, for a surface that draws its own. The default
  is `'lines'`.

```js
PageLayout.configure({ breaksWithoutPages: 'none' })
```

### Labels in another language

`breakLabels` names the lines. Name only the ones you translate. The rest keep the English.

```js
PageLayout.configure({
  breakLabels: {
    page: 'Seitenumbruch',
    region: 'Spaltenumbruch',
    section: 'Abschnittsumbruch',
    sectionColumns: 'Abschnittsumbruch · {count} Spalten',
  },
})
```

| Key              | Default                           | Used for                                  |
| ---------------- | --------------------------------- | ----------------------------------------- |
| `page`           | `Page break`                      | A page break                              |
| `region`         | `Column break`                    | A column break                            |
| `section`        | `Section break`                   | A section break                           |
| `sectionColumns` | `Section break · {count} columns` | A section break whose section has columns |

`{count}` is where the number of columns goes, and it may sit wherever the language needs it.
`DEFAULT_BREAK_LABELS` holds the defaults.

## Switching them off

```js
PageLayout.configure({ pageBreak: false, columnBreak: false, sectionBreak: false })
```

Each kind is its own switch. See [Switching features off](/page-layout/getting-started/overview#switching-features-off)
for what that does to documents that already hold one.

## Commands

### insertPageBreak

Ends the page at the cursor and puts the caret at the top of the next one.

```js
editor.commands.insertPageBreak()
```

Returns `false` in a code block and when `pageBreak` is switched off.

### removePageBreak

Removes the manual page break the cursor is at or just past, in the block the cursor is in.

```js
editor.commands.removePageBreak()
```

Returns `false` when no page break comes before the cursor in its block, and when `pageBreak`
is switched off.

### insertColumnBreak

Ends the current column and continues in the next one. In a section with one column it ends
the page, so it is worth offering where no section has columns yet.

```js
editor.commands.insertColumnBreak()
```

Returns `false` in a code block and when `columnBreak` is switched off.

`insertSectionBreak` is on [Sections](/page-layout/core-concepts/sections#insertsectionbreak).
