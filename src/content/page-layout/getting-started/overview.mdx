## What you get

Each part of Page Layout has its own page:

- [Page format](/page-layout/features/page-format): 21 built-in paper sizes and sizes of your own, portrait or landscape, with margins. Or no pages at all: pageless, where the document is one continuous column without pages.
- [Sections](/page-layout/features/sections): a different page setup for part of a document, such as a landscape table in an upright report.
- [Breaks](/page-layout/features/breaks): page, column and section breaks at the cursor.
- [Section columns](/page-layout/features/section-columns): text that fills one column to the bottom of the page and goes on in the next.
- [Header and footer](/page-layout/features/header-and-footer): per section, with a different first page and different odd and even pages.
- [Page numbers](/page-layout/features/page-numbers): in a header or footer, with a number format and a start per section.
- [Printing](/page-layout/features/printing): the sheets the user sees, from the browser's print dialog, or as a PDF.
- [Page colors](/page-layout/features/page-colors): paper, text and accent colors for the document or one section.
- [Zoom](/page-layout/features/zoom): a factor, or the pages fitted to the window, without changing where pages end.
- [Extension behavior](/page-layout/extension-behavior): what tables, lists, footnotes, cross-references and other extensions do at the end of a page.
- [Your own extension](/page-layout/extension-behavior/your-own-extension): how a node type of yours behaves when a page ends inside it, also with [React NodeViews](/page-layout/extension-behavior/your-own-extension/react-nodeviews).
- [Styling the pages](/page-layout/guides/styling), [Collaboration](/page-layout/guides/collaboration), [Word documents](/page-layout/guides/word), [Long documents](/page-layout/guides/long-documents) and [On a server](/page-layout/guides/on-a-server) explain how Page Layout works in each of these settings.
- [Options](/page-layout/reference/options), [Commands](/page-layout/reference/commands) and [Limitations](/page-layout/reference/limitations) list everything in one place.

## Quick start

Install `@tiptap-pro/extension-page-layout` from Tiptap's private registry, as [Install Page Layout](/page-layout/getting-started/install) shows. Then build the editor with `createPageLayoutEditor` instead of `new Editor`. In this example, `save` stands for your own function that stores the document:

```js
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [StarterKit, PageLayout.configure({ setup: pageSetup('A4') })],
  onUpdate: ({ editor }) => save(editor.getJSON()),
})
```

The result is an editor on A4 sheets. In React, use the hook from [Page Layout in React](/page-layout/getting-started/install/react) instead.

## What stays the same, and what changes

`createPageLayoutEditor` returns a Tiptap `Editor`. Your extensions, toolbar commands, `can()` and `isActive()` work as before, and each Page Layout command behaves like any Tiptap command, as [How commands behave](/page-layout/reference/commands#how-commands-behave) explains.

You save what `getJSON()` or `getHTML()` returns, never `editor.state.doc`, because `editor.state` holds the pages. The pages are drawn from the document and never stored. So positions, undo and redo, collaboration and `editorProps` work differently from a plain editor. [The document and the pages](/page-layout/getting-started/document-and-pages) explains each of them.

## Common tasks

The table names the call for each task and the page that explains it. A call without a prefix is a command and runs on `editor.commands`, as in `editor.commands.insertPageBreak()`.

`engine` is `editor.storage.pageLayout.engine`. `pageAt`, `defineNodeLayout`, `PAGE_FORMATS` and `MARGIN_PRESETS` are imported from `@tiptap-pro/extension-page-layout`.

The first argument `0` is the index of a section, and section `0` is the whole document unless you add sections. The commands call headers and footers "furniture":

| Task                                         | Call                                                                                                                           | Page                                                                                                           |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Letter paper instead of A4                   | `setSectionSetup(0, { ...engine.getSetup(), format: PAGE_FORMATS.Letter })`                                                    | [Page format](/page-layout/features/page-format)                                                               |
| Landscape                                    | `setSectionSetup(0, { ...engine.getSetup(), orientation: 'landscape' })`                                                       | [Page format](/page-layout/features/page-format)                                                               |
| Narrower margins                             | `setSectionSetup(0, { ...engine.getSetup(), margins })`, with `margins` from `MARGIN_PRESETS`                                  | [Margins](/page-layout/features/page-format#margins)                                                           |
| One endless column                           | `setPageSetup(null)`                                                                                                           | [Pageless](/page-layout/features/page-format#pageless)                                                         |
| A chapter on a fresh page                    | `insertPageBreak()`                                                                                                            | [Breaks](/page-layout/features/breaks)                                                                         |
| A landscape table in an upright report       | `insertSectionBreak('nextPage')`, then `setSectionSetup()` on the new section                                                  | [Sections](/page-layout/features/sections)                                                                     |
| Two columns for a few paragraphs             | `setSectionColumns({ count: 2, gaps: null, rule: true, widths: null })`                                                        | [Section columns](/page-layout/features/section-columns)                                                       |
| Page numbers in the footer                   | `insertPageNumbers({ zone: 'footer', align: 'center', firstPage: true })`                                                      | [Page numbers](/page-layout/features/page-numbers)                                                             |
| A different header on the first page         | `setFurnitureFlags(0, { differentFirstPage: true, differentOddEven: false })`                                                  | [Header and footer](/page-layout/features/header-and-footer)                                                   |
| A header row on each page of a table         | `setRepeatHeaderRow(true)`                                                                                                     | [Tables in Page Layout](/page-layout/extension-behavior/tables)                                                |
| A table row that is not cut in half          | `setRowBreakAcrossPages(false)`                                                                                                | [Tables in Page Layout](/page-layout/extension-behavior/tables)                                                |
| A list that stays on one page                | `setListKeepTogether(true)`                                                                                                    | [Lists in Page Layout](/page-layout/extension-behavior/lists)                                                  |
| A footnote at the foot of its page           | `insertFootnote()`, from the Footnotes extension                                                                               | [Footnotes in Page Layout](/page-layout/extension-behavior/footnotes)                                          |
| A node of yours that is not cut in half      | `defineNodeLayout('card', { splitDepth: 'betweenChildren', keepTogether: true })`                                              | [Keeping a node whole](/page-layout/extension-behavior/your-own-extension/layout-rules#keeping-a-node-whole)   |
| The page the cursor is on                    | `engine.getActivePageIndex()`                                                                                                  | [Where the cursor is](/page-layout/getting-started/document-and-pages/reading#where-the-cursor-is)             |
| The page a position is on                    | `pageAt(engine.getPageMap(), position)`                                                                                        | [The page a position is on](/page-layout/getting-started/document-and-pages/reading#the-page-a-position-is-on) |
| A jump to a heading from a table of contents | `revealSourcePosition(pos)`                                                                                                    | [Going to a position](/page-layout/getting-started/document-and-pages/reading#going-to-a-position)             |
| Pages fitted to the window                   | `engine.setZoom('fit')`                                                                                                        | [Zoom](/page-layout/features/zoom)                                                                             |
| Print what the user sees                     | `window.print()`                                                                                                               | [Printing](/page-layout/features/printing)                                                                     |
| Two people editing one document              | the `source` option of `PageLayout`, with `createSourceCollaboration()` from `@tiptap-pro/extension-page-layout/collaboration` | [Collaboration](/page-layout/guides/collaboration)                                                             |

## Words these pages use

The pages of these docs explain these words where they use them. This list is the place to look one up:

| Word              | What it means                                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Document          | What the user writes and you save. It has no pages. The code calls it the source document, as in `getSourceDocument()`.                                 |
| Page              | A part of the document as it is laid out on paper. Page Layout works the pages out from the document and never stores them.                             |
| Sheet             | The element a page is drawn on, on screen and in print.                                                                                                 |
| Page setup        | The paper size, orientation and margins of the pages, and their colors, columns and numbering. `pageSetup()` builds one.                                |
| Section           | A run of blocks with a page setup of its own, started by a section break. Every document with pages has at least section `0`.                           |
| Header and footer | Content at the top or bottom of every page of a section. Their commands call them furniture, as in `openFurniture()`.                                   |
| Engine            | The object that lays out the pages, at `editor.storage.pageLayout.engine`. You read pages and positions from it, and change the document with commands. |
| Pageless          | The same document as one continuous column, without pages.                                                                                              |
| Layout rule       | What Page Layout knows about a node type, such as where a page may end inside it.                                                                       |
