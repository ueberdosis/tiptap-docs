**Coming from `Pages`?** Page Layout is not the `Pages` extension of `@tiptap-pro/extension-pages`.
To move an editor from it, see [Migrate from Pages](/page-layout/getting-started/migrate-from-pages).

## Quick start

Install `@tiptap-pro/extension-page-layout` and its peer dependencies from Tiptap's registry, as
[Install Page Layout](/page-layout/getting-started/install) shows. Then build the editor with
`createPageLayoutEditor`:

```js
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [StarterKit, PageLayout.configure({ setup: pageSetup('A4') })],
  onUpdate: ({ editor }) => save(editor.getJSON()),
})
```

- **It is a Tiptap `Editor`.** It takes the options of one, such as `onUpdate`,
  `onSelectionUpdate` and `editable`. Commands at the cursor, extensions and events work as they
  do without pages.
- **Editing works as in any Tiptap editor.** The caret, text selection, clipboard, IME composition
  and screen readers behave the same, because the pages are made of the same editable content.
- **Saving works as before.** Save what `getJSON()` or `getHTML()` returns. Neither has a page in
  it. Never save `editor.state.doc`: it holds the pages the reader sees. See
  [Saving the document](/page-layout/getting-started/install/existing-editor#saving-the-document).
- **Nothing of the pages is stored.** The document holds no page Nodes, no automatic page breaks
  and no continuation rows. The pages are worked out from it each time it is opened.
- **`update` is emitted once per change to the document**, and not when only the pages are laid
  out again. See
  [When you hear about a change](/page-layout/getting-started/document-and-pages#when-you-hear-about-a-change).
- **Undo and redo** are this package's `editor.commands.undo()` and `editor.commands.redo()`. They
  take back the reader's edit, never the pagination that followed it. See
  [Undo and redo](/page-layout/getting-started/install/existing-editor#undo-and-redo).
- **Every Command works as any Tiptap Command.** It chains, answers `can()`, and returns `false`
  without changing anything when it cannot act. See
  [How Commands behave](/page-layout/reference/commands#how-commands-behave).
- **Positions and collaboration change.** Anything that works with a position in the document
  changes, and collaboration is set up through `PageLayout`. See
  [Add Page Layout to your editor](/page-layout/getting-started/install/existing-editor) and
  [The document and the pages](/page-layout/getting-started/document-and-pages).

## What you get

- **Paper, margins and orientation.** 21 built-in sizes and any size of your own. See
  [Page format](/page-layout/features/page-format).
- **Sections.** Their own paper for a run of blocks, such as a landscape table in an upright
  report. See [Sections](/page-layout/features/sections).
- **Page colors.** The paper, the text and an accent, for the document or one section. See
  [Page colors](/page-layout/features/page-colors).
- **Headers and footers** per section, on every page, with a different first page and different odd
  and even pages if you want them. See [Header and footer](/page-layout/features/header-and-footer).
- **Page numbers.** How each section numbers its pages, and a number in a header or footer. See
  [Page numbers](/page-layout/features/page-numbers).
- **Tables across pages.** A row cut at the boundary and continued on the next page, a repeated
  header row, and per-row control over whether a row may be cut. See
  [Tables in Page Layout](/page-layout/extension-behavior/tables).
- **Footnotes and endnotes.** A note's text at the foot of the page its reference is on,
  renumbered as the text moves. See [Footnotes in Page Layout](/page-layout/extension-behavior/footnotes).
- **Section columns.** Text that fills one column to the bottom of the page and carries on at the
  top of the next, with gaps, widths and a line between. See
  [Section columns](/page-layout/features/section-columns).
- **Manual breaks.** Page, column and section breaks at the cursor. See [Breaks](/page-layout/features/breaks).
- **Pageless.** The same document as one continuous column, switchable at runtime. See
  [Pageless](/page-layout/features/page-format#pageless).
- **Zoom.** At a factor or fitted to the window, without the pagination changing. See
  [Zoom](/page-layout/features/zoom).
- **Printing** from the browser's print dialog, with the sheets the reader saw. See
  [Printing](/page-layout/features/printing).
- **Collaboration.** Only the document is shared. Two people can see different page counts of the
  same text, and each sees the other's cursor where it lands in their own pages. See
  [Collaboration](/page-layout/guides/collaboration).

## Common tasks

`engine` is `editor.storage.pageLayout.engine`.

| Task                                         | Call                                                                              | Page                                                                                                         |
| -------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| A landscape table in an upright report       | `insertSectionBreak('nextPage')`, then `setSectionSetup` on the new section       | [Sections](/page-layout/features/sections)                                                                   |
| Narrower margins                             | `setSectionSetup(0, …)` with `margins` from `MARGIN_PRESETS`                      | [Margins](/page-layout/features/page-format#margins)                                                         |
| A different header on the first page         | `setFurnitureFlags(0, { differentFirstPage: true, differentOddEven: false })`     | [Header and footer](/page-layout/features/header-and-footer)                                                 |
| A chapter on a fresh sheet                   | `insertPageBreak()`                                                               | [Breaks](/page-layout/features/breaks)                                                                       |
| A table row that is not cut in half          | `setRowBreakAcrossPages(false)`                                                   | [Tables in Page Layout](/page-layout/extension-behavior/tables)                                              |
| A header row on every page                   | `setRepeatHeaderRow(true)`                                                        | [Tables in Page Layout](/page-layout/extension-behavior/tables)                                              |
| Two columns for a few paragraphs             | `setSectionColumns({ count: 2, gaps: null, rule: true, widths: null })`           | [Section columns](/page-layout/features/section-columns)                                                     |
| A list that stays on one page                | `setListKeepTogether(true)`                                                       | [Lists in Page Layout](/page-layout/extension-behavior/lists)                                                |
| A Node of yours that is not cut in half      | `defineNodeLayout('card', { splitDepth: 'betweenChildren', keepTogether: true })` | [Keeping a Node whole](/page-layout/extension-behavior/your-own-extension/layout-rules#keeping-a-node-whole) |
| A footnote at the foot of its page           | `insertFootnote()`, or `insertFootnote({ placement: 'endnote' })`                 | [Footnotes in Page Layout](/page-layout/extension-behavior/footnotes)                                        |
| The page the cursor is on                    | `pageAt(engine.getPageMap(), engine.getSourceState().selection.from)`             | [The page map](/page-layout/getting-started/document-and-pages/reading#the-page-map)                         |
| A jump to a heading from a table of contents | `revealSourcePosition(pos)`                                                       | [Going to a position](/page-layout/getting-started/document-and-pages/reading#going-to-a-position)           |
| Print what the reader sees                   | `window.print()`                                                                  | [Printing](/page-layout/features/printing#quick-start)                                                       |
| One endless column                           | `setPageSetup(null)`                                                              | [Pageless](/page-layout/features/page-format#pageless)                                                       |
| Pages fitted to the window                   | `engine.setZoom('fit')`                                                           | [Zoom](/page-layout/features/zoom)                                                                           |
| Two people editing one document              | The `source` option, with `createSourceCollaboration`                             | [Collaboration](/page-layout/guides/collaboration)                                                           |
