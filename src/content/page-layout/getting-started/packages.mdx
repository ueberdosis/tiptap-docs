## The packages

| Package                                   | License | What it is                                                                                                                                |
| ----------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `@tiptap-pro/extension-page-layout`       | Pro     | The engine: pages, sections, breaks, headers and footers, and how tables and lists behave at a page boundary                              |
| `@tiptap-pro/extension-page-layout-react` | Pro     | `usePageLayoutEditor`, the editor on pages as a React hook. See [React](/page-layout/getting-started/install#react)                       |
| `@tiptap-pro/extension-footnotes`         | Pro     | Footnotes and endnotes                                                                                                                    |
| `@tiptap-pro/extension-outline-numbering` | Pro     | Numbers on headings and clauses                                                                                                           |
| `@tiptap-pro/extension-cross-references`  | Pro     | Targets and references to them                                                                                                            |
| `@tiptap-pro/extension-bookmark`          | Pro     | Bookmarks, as Word has them                                                                                                               |
| `@tiptap-pro/extension-document-styles`   | Pro     | Named styles, their definitions kept in the document, and libraries of them                                                               |
| `@tiptap-pro/extension-number-formats`    | Pro     | The number formats the other packages write in, and the Extension that stores formats and a language in the document. Installed with them |
| `@tiptap-pro/extension-whole-blocks`      | Pro     | Blocks selected whole are deleted, cut and copied as blocks                                                                               |
| `@tiptap-pro/extension-columns`           | Pro     | Containers side by side, each with content of its own                                                                                     |

Server-side pagination and a PDF of the pages are not available as a package yet. See
[Printing and PDF](/page-layout/guides/printing-and-pdf) for printing from the browser.

## The packages that work without pages

Each of these pages is complete without Page Layout, and links to what changes with it.

| Page                                                           | What it covers                                                                                                                                     |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Columns](/page-layout/extensions/columns)                     | Containers side by side, each with content of its own                                                                                              |
| [Footnotes and endnotes](/page-layout/extensions/footnotes)    | A reference and its text, numbering, and titles                                                                                                    |
| [Outline numbering](/page-layout/extensions/outline-numbering) | Numbers on headings and clauses, 1.1.1 or Article I / Section 1.01 / (a), derived from where they stand                                            |
| [Cross-references](/page-layout/extensions/cross-references)   | Targets, references to them, and what a reference shows. Also [Commands](/page-layout/extensions/cross-references/commands)                        |
| [Bookmarks](/page-layout/extensions/bookmarks)                 | A name on a run of text or on a point: to go to, to link to with `#name`, to refer to. Also [Commands](/page-layout/extensions/bookmarks/commands) |
| [Document Styles](/page-layout/extensions/document-styles)     | Named paragraph and character styles, defined in the document, which everything referring to them follows                                          |
| [Number formats](/page-layout/extensions/number-formats)       | 1, 01, a, i, \*, first: the built-in formats, your own, and the document's                                                                         |
| [Whole blocks](/page-layout/extensions/whole-blocks)           | A paragraph or heading selected whole is deleted, cut and copied as a block, not left behind empty                                                 |

What each of them does on pages is in [Other extensions on pages](/page-layout/extensions/overview).

## The Pro registry

Every package here comes from Tiptap's registry rather than from npm's. Point the project at it
once, with your token:

```ini
; .npmrc
@tiptap-pro:registry=https://registry.tiptap.dev/
//registry.tiptap.dev/:_authToken=YOUR_TOKEN
```

Keep the token in the environment on CI rather than in a committed file.
