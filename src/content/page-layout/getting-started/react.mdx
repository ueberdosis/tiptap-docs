## Installing

```bash
npm install @tiptap-pro/extension-page-layout-react @tiptap-pro/extension-page-layout @tiptap/react
```

Both packages come from Tiptap's registry; see
[The Pro registry](/page-layout/getting-started/packages#the-pro-registry).

## What it exports

| Export                       | What it does                                                                                                                                                                    |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `usePageLayoutEditor`        | Builds the editor once its element is mounted. Returns the `editor` (null until then), the `ref` for the element the pages are drawn into, and `nodeViews` to render beside it. |
| `UsePageLayoutEditorOptions` | The options the hook takes.                                                                                                                                                     |
| `UsePageLayoutEditorResult`  | What the hook returns.                                                                                                                                                          |

How to use it, and how React NodeViews behave on pages, is on the pages of Page Layout:

- [React](/page-layout/getting-started/install#react)
- [React NodeViews](/page-layout/getting-started/install#react-nodeviews)
