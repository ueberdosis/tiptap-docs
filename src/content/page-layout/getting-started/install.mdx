## The Pro registry

Every package of Page Layout comes from Tiptap's registry rather than from npm's. Point the project
at it once:

```ini
; .npmrc
@tiptap-pro:registry=https://registry.tiptap.dev/
//registry.tiptap.dev/:_authToken=${TIPTAP_PRO_TOKEN}
```

- **Keep the token in the environment.** Set `TIPTAP_PRO_TOKEN` in your shell and on CI. Never
  commit it.
- **Your token** is in your Tiptap account. See
  [Pro extensions](https://tiptap.dev/docs/guides/pro-extensions).

## Installing

```bash
npm install @tiptap-pro/extension-page-layout @tiptap/core @tiptap/pm yjs y-prosemirror
```

The engine brings no content types of its own. Paragraphs, headings, lists and tables are the
Extensions you already register, such as `@tiptap/starter-kit`.

### Peer dependencies

| Package         | Version    |
| --------------- | ---------- |
| `@tiptap/core`  | `^3.29.2`  |
| `@tiptap/pm`    | `^3.29.2`  |
| `yjs`           | `^13.6.31` |
| `y-prosemirror` | `^1.3.7`   |

- **Install all four.** `yjs` and `y-prosemirror` are marked optional, so no package manager
  installs them for you.
- **They are needed without collaboration too.** The package imports them when it loads.
- **`@tiptap-pro/extension-number-formats`** is a dependency, and is installed with it.

## A first editor

```js
import { createPageLayoutEditor, PageLayout, pageSetup } from '@tiptap-pro/extension-page-layout'
import StarterKit from '@tiptap/starter-kit'

const editor = createPageLayoutEditor({
  element: document.querySelector('#editor'),
  content: { type: 'doc', content: [{ type: 'paragraph' }] },
  extensions: [StarterKit, PageLayout.configure({ setup: pageSetup('A4') })],
})
```

That is an editor on A4 pages. Go on with [Page format](/page-layout/features/page-format) for the paper and
the margins, and [Styling the pages](/page-layout/features/styling) for how the sheets look. In React, see
[Page Layout in React](/page-layout/getting-started/react).

## Options of the editor

`createPageLayoutEditor` returns a Tiptap `Editor`. It takes these options, and they mean what they
mean on `new Editor` unless the table says otherwise:

| Option                                                                | Description                                                                                                                            |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `element`, `content`, `extensions`                                    | Required. `content` is Tiptap JSON                                                                                                     |
| `editable`, `autofocus`                                               | As on any editor                                                                                                                       |
| `injectCSS`, `injectNonce`                                            | As on any editor, and for the page rules too. See [A Content Security Policy](/page-layout/features/styling#a-content-security-policy) |
| `onBeforeCreate`, `onCreate`, `onDestroy`                             | As on any editor                                                                                                                       |
| `onUpdate`, `onSelectionUpdate`, `onTransaction`, `onFocus`, `onBlur` | `update` is emitted only when the document changes. See [Events](/page-layout/getting-started/positions-and-events#events)             |
| `onChange`                                                            | Called with the editor after every change once the pages are drawn, including a change of the pages alone                              |

`editorProps` is not accepted. What a Tiptap editor built with `new Editor` does with `PageLayout` is
in [Building the editor](/page-layout/getting-started/existing-editor#building-the-editor). Everything about the pages is an option of
`PageLayout`; see [Options](/page-layout/reference/options).

## The packages

| Package                                                                                         | What it is                                                                                                                                   |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `@tiptap-pro/extension-page-layout`                                                             | The engine: pages, sections, breaks, headers and footers, and how tables and lists behave at a page boundary                                 |
| `@tiptap-pro/extension-page-layout-react`                                                       | `usePageLayoutEditor`, the editor on pages as a React hook. See [Page Layout in React](/page-layout/getting-started/react)                   |
| [`@tiptap-pro/extension-footnotes`](/editor/extensions/functionality/footnotes)                 | Footnotes and endnotes: a reference and its text, numbering, and titles                                                                      |
| [`@tiptap-pro/extension-outline-numbering`](/editor/extensions/functionality/outline-numbering) | Numbers on headings and clauses, 1.1.1 or Article I / Section 1.01 / (a), derived from where they stand                                      |
| [`@tiptap-pro/extension-cross-references`](/editor/extensions/functionality/cross-references)   | Targets, references to them, and what a reference shows.                                                                                     |
| [`@tiptap-pro/extension-bookmark`](/editor/extensions/functionality/bookmark)                   | Bookmarks, as Word has them: a name on a run of text or on a point.                                                                          |
| [`@tiptap-pro/extension-document-styles`](/editor/extensions/functionality/document-styles)     | Named paragraph and character styles, their definitions kept in the document, and libraries of them                                          |
| [`@tiptap-pro/extension-number-formats`](/editor/extensions/functionality/number-formats)       | 1, 01, a, i, \*, first: the number formats the other packages write in, and the Extension that stores formats and a language in the document |
| [`@tiptap-pro/extension-whole-blocks`](/editor/extensions/functionality/whole-blocks)           | A paragraph or heading selected whole is deleted, cut and copied as a block, not left behind empty                                           |
| [`@tiptap-pro/extension-columns`](/editor/extensions/functionality/columns)                     | Containers side by side, each with content of its own                                                                                        |

- **All of them are Pro**, and come from the registry above.
- **Every package but the engine and React works without pages.** Its page is complete without
  Page Layout. What it does on pages is in [Other extensions on pages](/page-layout/other-extensions/overview).
- **Server-side pagination and a PDF of the pages** are not available as a package yet. See
  [Printing and PDF](/page-layout/guides/printing-and-pdf) for printing from the browser.
