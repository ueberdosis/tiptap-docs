```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { WholeBlocks } from '@tiptap-pro/extension-whole-blocks'

const editor = new Editor({
  extensions: [StarterKit, WholeBlocks],
})
```

`@tiptap-pro/extension-whole-blocks` works in any editor, with or without pages. A block is any textblock: a
paragraph, a heading, a code block.

## What changes

- **Backspace or Delete** over a selection that covers whole blocks removes them, and the caret
  lands at the start of the block that followed.
- **Cut** does the same, and **copy** and **cut** put whole blocks on the clipboard, so a paste
  inserts them as blocks of their own instead of pouring their text into the block at the
  cursor.
- A selection from the first character of a block into a later one removes the blocks it
  covers, and what is left of the last keeps that block's type.
- **Typing** over such a selection replaces the text and keeps the block.

A selection that starts after the first character is left as it is in any Tiptap editor: the
text goes, the block stays.

A block that is the only content of a list item takes the list item along. One that is the only
content of a table cell, or of anything else `isolating`, leaves the cell with an empty
paragraph, as does the only block of the document.

## Options

```js
WholeBlocks.configure({ ignore: (node) => node.attrs.isCopy === true })
```

- **`ignore`** — a function of a Node, `null` by default. A textblock it answers `true` or
  `'descend'` for is a piece of a block drawn somewhere else. A selection starting in one, or
  ending where one carries on, is left to the default. A container it answers `'descend'` for —
  the rest of a list drawn somewhere else — holds whole blocks: a block ending right before one
  is whole.

With [Page Layout](/page-layout/getting-started/overview), pass its `ignoreLayoutArtifacts`; see
[Whole blocks on pages](/page-layout/extensions/overview#whole-blocks).

## Switching it off

Leave it out of the Extensions. There is no option that turns it off while it is registered.

## As Transactions

```js
import {
  blockCoverOf,
  deleteWholeBlocksTransaction,
  wholeBlockSlice,
} from '@tiptap-pro/extension-whole-blocks'

blockCoverOf(editor.state, null) // what the selection covers, or null
deleteWholeBlocksTransaction(editor.state, null) // the deletion, or null
wholeBlockSlice(editor.state, null) // what a copy puts on the clipboard, or null
```

The second argument is `ignore`. `null` from any of them means the selection does not cover whole
blocks, and the default applies.
