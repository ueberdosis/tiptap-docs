| Command                              | What it does                                               |
| ------------------------------------ | ---------------------------------------------------------- |
| `addBookmark(options?)`              | A bookmark on the Selection, or a point where it is empty. |
| `removeBookmark(id?)`                | The bookmark taken out, its text staying.                  |
| `renameBookmark(name, id?)`          | Another name, the same id.                                 |
| `goToBookmark(id)`                   | The Selection on the bookmark, scrolled to.                |
| `toggleBookmarkVisibility(visible?)` | Brackets around every bookmark, on or off.                 |

## addBookmark(options?)

```js
editor.commands.addBookmark() // named after the selected words
editor.commands.addBookmark({ name: 'Price' })
editor.commands.addBookmark({ name: '_Ref42', hidden: true })
editor.commands.addBookmark({ name: 'Spot', from: 12, to: 12 })
```

- **`name`** — a name Word accepts; see [Names](/page-layout/extensions/bookmarks#names). Without one, the bookmark is
  named after the selected words, or `Bookmark` where there are none.
- **`hidden`** — whether the name may start with `_`.
- **`from`, `to`** — the range, the Selection by default. An empty range is a bookmark on no text.

A name the document already has moves that bookmark here and keeps its id. `false` where the name
is not valid, or nothing in the range can carry a bookmark — a horizontal rule, an image.

## removeBookmark(id?)

The bookmark of `id`, or the smallest one around the Selection. Its text stays.

```js
editor.commands.removeBookmark()
```

## renameBookmark(name, id?)

The bookmark of `id`, or the one around the Selection, under another name. Its id stays, so
references and links by id follow. `false` where the name is not valid, is the one it has, or is
another bookmark's.

```js
editor.commands.renameBookmark('Cost')
```

## goToBookmark(id)

The Selection on the bookmark, scrolled into view — or `reveal` where the Extension was given one.

```js
editor.commands.goToBookmark(bookmarkByName(editor.state.doc, 'Price').id)
```

## toggleBookmarkVisibility(visible?)

Shows or hides the bookmarks in the text, or switches them where `visible` is left out. Writes nothing to the
document.

```js
editor.commands.toggleBookmarkVisibility(true)
```

## As Transactions

Each Command but the last has a function that returns the Transaction instead of dispatching it,
or `null` where the Command would answer `false` — for writing to a document the editor does not
show, or adding to the same step as something else:

| Command          | Function                                               |
| ---------------- | ------------------------------------------------------ |
| `addBookmark`    | `addBookmarkTransaction(state, options?)`              |
| `removeBookmark` | `removeBookmarkTransaction(state, id, options?)`       |
| `renameBookmark` | `renameBookmarkTransaction(state, id, name, options?)` |
| `goToBookmark`   | `goToBookmarkTransaction(state, id, options?)`         |

`options` takes `ignore`, as the readers do. `isBookmarkNameFree(state, name, { except })` says
whether a name is free, `except` being the id of a bookmark that may keep its own.

```js
import { addBookmarkTransaction } from '@tiptap-pro/extension-bookmark'

const tr = addBookmarkTransaction(state, { name: 'Price' })
if (tr) view.dispatch(tr)
```
