A reference naming several targets reads them by a rule, chosen per reference or for every
reference at once. Three come with the package:

| Rule     | Reads                                                                                                                |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| `list`   | `3, 5 and 7` — `listSeparator` between them, `lastSeparator` before the last. The default.                           |
| `commas` | `3, 5, 7` — `listSeparator` between all of them.                                                                     |
| `range`  | `3–5 and 7` — three or more numbers that follow each other are one range, with `rangeSeparator`; the rest is listed. |

```js
import { CrossReferences } from '@tiptap-pro/extension-cross-references'

CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  join: 'range', // for every reference that names no rule
})

editor.commands.insertCrossReference({
  targets: ['three', 'four', 'five'],
  show: 'number',
  join: 'commas',
})
editor.commands.setCrossReferenceOptions({ join: null }) // back to the configured rule
```

- **`join`** on `CrossReferences` — the rule a reference without one of its own is read by.
  `list` by default.
- **`join`** on a reference — the id of a rule, or `null` for the configured one. It is written
  to HTML as `data-tt-join`. A rule nobody registered reads as the configured one.

The words are [phrases](/page-layout/extensions/cross-references#how-a-reference-is-shown): `listSeparator` (`, `),
`lastSeparator` (`and`) and `rangeSeparator` (`–`):

```js
CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  phrases: { lastSeparator: ' und ', rangeSeparator: ' bis ' },
})
// 3 bis 5 und 7
```

## Ranges

Two numbers follow each other where they are on the same level under the same parent and the
second is one more: `3.2` after `3.1`, `4` after `3`, but not `4.1` after `3.9`. That is read from
`counts` on the target's label, so a target whose label has no `counts` is never part of a range.
A range is made of three or more; two that follow each other read `3 and 4`. The targets are
taken in the order the reference names them, and `range` makes no range of a reference that
shows no number — its text or its page.

## Your own rule

A rule is registered under an id, and an id the package has replaces its rule:

```js
CrossReferences.configure({
  targets: { heading: {} },
  multiple: true,
  joins: {
    alternatives: {
      title: '3, 5 or 7',
      pieces: ({ parts, phrases }) =>
        parts.flatMap((_part, index) =>
          index === 0
            ? [index]
            : [index === parts.length - 1 ? ' or ' : phrases.listSeparator, index],
        ),
    },
  },
})

editor.commands.insertCrossReference({ targets: ['three', 'five', 'seven'], join: 'alternatives' })
// 3, 5 or 7
```

- **`title`** — what a picker lists it as.
- **`pieces({ parts, phrases, numbered })`** — what the reference reads, in order: a number is the
  part at that index, a string is text between parts.
  - `parts` — one per target, in the order the reference names them: `{ text, target }`. `text`
    is what it reads of that target; `target` is the target as `crossReferenceTargetsIn` lists
    it, or `null` for one that is gone or [withheld](/page-layout/extensions/cross-references#withheld-targets).
  - `phrases` — the configured phrases.
  - `numbered` — whether the reference shows a number.

Each part is read once, at its first index: an index that is not a part, or a part named a second
time, is left out. A part the rule leaves out is not read, as the `4` of `3–5`. A reference naming
one target reads that target whatever its rule.

**`crossReferenceJoinChoices(joins)`** lists the rules a picker offers, `{ id, title }`: the
built-in ones, then yours. Pass `editor.storage.crossReferences.joins`.

## In Word

A .docx gets the same pieces: a field for each part the rule reads and the text between them as
plain text, with the configured phrases. See [Word fields](/page-layout/extensions/cross-references/docx).
