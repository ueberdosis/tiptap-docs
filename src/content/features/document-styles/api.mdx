## Commands

A command of Document styles returns `false` when it would change nothing, so `editor.can()` tells
a toolbar which commands apply. Changing only the marks stored for the text typed next at the
caret counts as a change.

A command that would change a definition a library brings returns `false`, because a library is
read only. Each command is one step of the history.

| Command                                        | What it does                                                                            | Page                                                                      |
| ---------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `applyStyle(styleId, options?)`                | Puts a style on the block at the selection, or on the selected text                     | [applyStyle()](/features/document-styles/applying#applystyle)                                    |
| `removeStyle()`                                | Takes the style and every override off what is selected                                 | [removeStyle()](/features/document-styles/applying#removestyle)                                  |
| `setStyleOverride(prop, value)`                | Sets one value of what is selected apart from its style                                 | [setStyleOverride()](/features/document-styles/applying#setstyleoverride)                        |
| `unsetStyleOverride(prop)`                     | Takes one override off                                                                  | [unsetStyleOverride()](/features/document-styles/applying#unsetstyleoverride)                    |
| `clearStyleOverrides()`                        | Takes every override off                                                                | [clearStyleOverrides()](/features/document-styles/applying#clearstyleoverrides)                  |
| `detachStyle(options?)`                        | Takes the style off, and with `keepFormatting` keeps how it looks as overrides          | [detachStyle()](/features/document-styles/applying#detachstyle)                                  |
| `clearInlineStyles()`                          | Takes character styles, overrides and Tiptap's own formatting off the selected text     | [clearInlineStyles()](/features/document-styles/applying#clearinlinestyles)                      |
| `adoptDirectFormatting()`                      | Turns Tiptap's own formatting in the selection into overrides that look the same        | [adoptDirectFormatting()](/features/document-styles/applying#adoptdirectformatting)              |
| `expressAsDirectFormatting()`                  | Turns the overrides in the selection into Tiptap's own formatting where a rule says how | [expressAsDirectFormatting()](/features/document-styles/applying#expressasdirectformatting)      |
| `setStyleDefinition(definition)`               | Stores a definition in the document, replacing the document's own of its id             | [setStyleDefinition()](/features/document-styles/definitions#setstyledefinition)                 |
| `renameStyle(styleId, name)`                   | Gives one of the document's styles a new name, keeping its id                           | [renameStyle()](/features/document-styles/definitions#renamestyle)                               |
| `duplicateStyle(styleId, newStyleId, name?)`   | Copies a style, the document's or a library's, into a new style of the document's own   | [duplicateStyle()](/features/document-styles/definitions#duplicatestyle)                         |
| `deprecateStyle(styleId, replacementStyleId?)` | Marks one of the document's styles deprecated, pointing to a replacement                | [deprecateStyle()](/features/document-styles/definitions#deprecatestyle)                         |

| `setDocumentTheme(theme)`                      | Stores the document's theme, or takes it off with `null`                                | [setDocumentTheme()](/features/document-styles/themes#setdocumenttheme)                          |
| `setNamedColor(key, color)`                    | Stores a named color in the document's theme                                            | [setNamedColor()](/features/document-styles/themes#setnamedcolor)                                |
| `removeNamedColor(key)`                        | Takes a named color off the document's theme                                            | [removeNamedColor()](/features/document-styles/themes#removenamedcolor)                          |

| `replaceMissingStyles(replacementStyleId)`     | Points every reference to a style nothing defines at one that exists                    | [replaceMissingStyles()](/features/document-styles/cleanup#replacemissingstyles)                 |

## Readers

`editor.storage.documentStyles` reads a document with the editor's options. Its functions take
the document, usually `editor.state.doc`, and fill in what the options leave out, such as `types`,
from that document's schema:

```js
const styles = editor.storage.documentStyles.stylesOf(editor.state.doc)
styles.getStyle('body')
```

[Install](/features/document-styles/install) has the complete editor. The storage has these readers:

| Reader                  | Arguments           | Returns                                                                             | Page                                                                                    |
| ----------------------- | ------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `stylesOf`              | `doc`               | A `StyleLookup` of every style the document can use, its own and its libraries'     | [Which definition wins](/features/document-styles/libraries#which-definition-wins)                             |
| `catalogOf`             | `doc, options?`     | The styles a style list shows, in its order. `options` is `{ gallery?, hidden? }`   | [A style picker](/features/document-styles/applying#a-style-picker)                                            |
| `defaultStylesOf`       | `doc`               | `DefaultStyles`, the default style of each node type                                | [The default style](/features/document-styles/definitions#the-default-style)                                   |
| `defaultStyledBlocksOf` | `doc`               | `DefaultStyledBlocks[]`, the blocks of `types` drawn in a default, grouped by style | [Writing the defaults onto the blocks](/features/document-styles/cleanup#writing-the-defaults-onto-the-blocks) |
| `outlineLevelsOf`       | `doc`               | `StyleOutlineLevels`, a map from style id to outline level, `null` for body text    | [Outline levels](/features/document-styles/definitions#outline-levels)                                         |
| `wordBuiltInStylesOf`   | `doc`               | `WordBuiltInStyles`, which style stands for which of Word's built-in styles         | [Word's built-in name](/features/document-styles/definitions#words-built-in-name)                              |
| `themeOf`               | `doc`               | The `ResolvedTheme` the document is drawn in                                        | [Which theme a document is drawn in](/features/document-styles/themes#which-theme-a-document-is-drawn-in)      |
| `locationsOf`           | `doc, styleId`      | `StyleLocation[]`, every place drawn in a style, defaults counted                   | [Where a value or a style is drawn](/features/document-styles/values#where-a-value-or-a-style-is-drawn)        |
| `valueLocationsOf`      | `doc, props, value` | `StyleLocation[]`, every place drawn in a value of the given properties             | [Where a value or a style is drawn](/features/document-styles/values#where-a-value-or-a-style-is-drawn)        |

`valueLocationsOf` uses the editor's default styles, `tableTypes`, `continuesNode` and
`directFormatting`. `stylesOf` builds a new lookup on every call. `defaultStylesOf`,
`outlineLevelsOf` and `wordBuiltInStylesOf` return the same object until a definition changes.

A `StyleLookup` answers with these methods:

| Method                | Returns                                                                                                                                              |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `styles.getStyles()`  | Every style, each id once. The document's own come first unless `precedence` is `'libraries'`, and among libraries the first that defines an id wins |
| `styles.getStyle(id)` | The definition of `id`, or `null`                                                                                                                    |
| `styles.originOf(id)` | `'document'`, `'library'` or `null`                                                                                                                  |

A library's definitions carry the library's `scope` in the lookup, and the document's own carry
`scope: 'document'`, unless a definition sets a scope of its own.

The other functions of the storage return objects of these shapes:

| Type                  | Shape                                                                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `DefaultStyles`       | `{ entries, of(node) }`. `of` returns the default style id of a node, or `null`                                                                |
| `DefaultStyledBlocks` | `{ styleId, positions }`                                                                                                                       |
| `WordBuiltInStyles`   | `{ builtInOf(styleId), styleIdOf(builtIn) }`, each returning `null` where nothing matches                                                      |
| `StyleLocation`       | `{ from, to, kind, via, styleId }`. `kind` is `'node'` or `'mark'`, and `via` is `'style'`, `'default'`, `'table'`, `'override'` or `'direct'` |

## Functions without an editor

Each function of the storage has a counterpart for code that holds no editor, such as a server. These functions see
only the libraries you pass them. Word's built-in styles are a library the editor adds from the
`wordStyles` option, so pass `wordStyleLibrary()` among the libraries to include them.

`libraries` defaults to `[]` and `precedence` to `'document'` wherever a function takes them.
`defaultStyles`, `styleOutlineLevels`, `stylePaginations`, `wordBuiltInStyles` and
`styleLanguages` return the same object until a definition changes.

## Transactions

Each function writes into a transaction you pass and returns it, for code that holds no editor. It
throws `The schema has no "styleDefinitions" Node: add the DocumentStyles Extension` when the
schema lacks the node. `setStyleDefinitionTransaction` throws for something that is not a
definition, and `setDocumentThemeTransaction` for something that is not a theme, where the
commands return `false`.

| Function                               | Arguments                                      | Page                                                                            |
| -------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------- |
| `setStyleDefinitionTransaction`        | `transaction, definition`                      | [Without an editor](/features/document-styles/definitions#without-an-editor)                           |
| `removeStyleDefinitionTransaction`     | `transaction, styleId`                         | [Without an editor](/features/document-styles/definitions#without-an-editor)                           |
| `replaceStyleReferencesTransaction`    | `transaction, styleId, replacementStyleId`     | [Without an editor](/features/document-styles/cleanup#without-an-editor)                               |
| `removeStyleReferencesTransaction`     | `transaction, styleId`                         | [Without an editor](/features/document-styles/cleanup#without-an-editor)                               |
| `freezeStyleReferencesTransaction`     | `transaction, styleId, lookup`                 | [Without an editor](/features/document-styles/cleanup#without-an-editor)                               |
| `mapStyleReferencesTransaction`        | `transaction, change`                          | [Without an editor](/features/document-styles/cleanup#without-an-editor)                               |
| `applyDefaultStylesTransaction`        | `transaction, defaults, types, styleId?`       | [Without an editor](/features/document-styles/cleanup#without-an-editor)                               |
| `replaceStyleValueTransaction`         | `transaction, props, from, to, rules?`         | [Replacing a value](/features/document-styles/values#replacing-a-value)                                |
| `adoptDirectFormattingTransaction`     | `transaction, from, to, { rules?, markType }`  | [Tiptap's own formatting](/features/document-styles/applying#tiptaps-own-formatting)                   |
| `expressAsDirectFormattingTransaction` | `transaction, from, to, { rules?, markTypes }` | [Tiptap's own formatting](/features/document-styles/applying#tiptaps-own-formatting)                   |
| `setDocumentThemeTransaction`          | `transaction, theme`                           | [setDocumentTheme()](/features/document-styles/themes#setdocumenttheme)                                |
| `setNamedColorTransaction`             | `transaction, key, color`                      | [Named colors](/features/document-styles/themes#named-colors)                                          |
| `repairStyleDefinitionsTransaction`    | `transaction`                                  | [Saving, undo and collaboration](/features/document-styles/how-it-works#saving-undo-and-collaboration) |

`repairStyleDefinitionsTransaction` merges a second `styleDefinitions` node into the first, for a
server that changes stored documents without an editor. With one such node or none, it returns
the transaction unchanged.
