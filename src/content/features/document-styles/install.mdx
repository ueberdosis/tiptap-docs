1. Configure your package manager for Tiptap's private registry. The
   [private registry guide](https://tiptap.dev/docs/guides/pro-extensions) explains where to
   get a registry token. Add these lines to the `.npmrc` file in your project's root,
   with the token in the environment variable `TIPTAP_PRO_TOKEN`:

   ```ini
   @tiptap-pro:registry=https://registry.tiptap.dev/
   //registry.tiptap.dev/:_authToken=${TIPTAP_PRO_TOKEN}
   ```

2. Install the extension, TextStyle for styles on text, and the extensions of the example:

   ```bash
   npm install @tiptap-pro/extension-document-styles @tiptap/extension-text-style @tiptap/core @tiptap/pm @tiptap/starter-kit
   ```

3. Add `DocumentStyles` to the editor, define a style of your own, and apply styles:

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { TextStyle } from '@tiptap/extension-text-style'
import { DocumentStyles } from '@tiptap-pro/extension-document-styles'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, TextStyle, DocumentStyles],
  content: '<p>Annual report</p><p>Sales grew in every region.</p>',
})

// One of Word's built-in styles, on the first paragraph
editor.chain().setTextSelection(1).applyStyle('title').run()

// A style of your own, stored in the document, on the second paragraph
editor.commands.setStyleDefinition({
  id: 'lead',
  name: 'Lead',
  kind: 'paragraph',
  basedOn: 'normal',
  props: { fontSize: 19, color: 'theme:accent1' },
})
editor.chain().setTextSelection(16).applyStyle('lead').run()
```

`setTextSelection` puts the cursor at a position, which counts characters and paragraph
boundaries. Position 1 is the start of the first paragraph's text, and 16 the start of the
second's. In your editor, the user's cursor takes their place.

The first paragraph is drawn large in Word's Title style. The second has a font size of 19 pixels,
since a number is in pixels, and the color `#156082`, the first accent color of the default
theme. `editor.getJSON()` holds both references and the definition of Lead.

[What a style can set](/features/document-styles/definitions#what-a-style-can-set) lists the other properties a style can
set.

## What the extension needs

| Package                                 | Kind            | Why                                                                          |
| --------------------------------------- | --------------- | ---------------------------------------------------------------------------- |
| `@tiptap-pro/extension-document-styles` | Dependency      | The extension                                                                |
| `@tiptap/core`, `@tiptap/pm`            | Peer dependency | Version 3.29.2 or later                                                      |
| `@tiptap/extension-text-style`          | Optional        | The mark a character style goes on. Without it, styles go on blocks only     |
| `@tiptap/starter-kit`                   | Optional        | Paragraphs, headings and blockquotes, the node types styles go on by default |
| `@tiptap/extension-table`               | Optional        | Tables, for [table styles](/features/document-styles/tables)                                        |

The extension styles the `paragraph`, `heading`, `blockquote` and `table` node types and the
`textStyle` mark of your schema, and skips any your editor does not have. The `types` and
`markTypes` [options](/features/document-styles/options) choose others.
