## Choose the language

A language is named by its language tag, such as `en`, `de` or `de-AT`. Pass it in the context of
`formatNumber`, or store it in the document so that every count there uses it:

```js
import { formatNumber } from '@tiptap-pro/extension-number-formats'

formatNumber(21, 'cardinalText', { language: 'de' }) // 'einundzwanzig'
formatNumber(3, 'ordinalText', { language: 'en' }) // 'third'
formatNumber(4, 'ordinal', { language: 'de' }) // '4.'
formatNumber(3, 'ordinalText', { language: 'de-AT' }) // 'dritte'
```

- **Without a language**, words are English.
- **A regional tag** such as `de-AT` is looked up as itself, then as `de`.
- **A language this app has no words for** is written in the format's fallback, decimal for the
  built-in formats.
- **`isNumberLanguageTag(value)`** tells whether a value is a language tag.
- **`numberLanguages()`** lists every language this app has words for, the built-in ones first.

To store the language in the document, call `editor.commands.setNumberLanguage('de')`, as
[setNumberLanguage()](/features/number-formats/stored-in-the-document#setnumberlanguage) describes.

## A language of your own

`defineNumberLanguage(tag, language)` adds a language under its tag. The language is plain data,
the words and the rules that join them:

```js
import { defineNumberLanguage, formatNumber } from '@tiptap-pro/extension-number-formats'

defineNumberLanguage('nl', {
  units: [
    '',
    'een',
    'twee',
    'drie',
    'vier',
    'vijf',
    'zes',
    'zeven',
    'acht',
    'negen',
    'tien',
    'elf',
    'twaalf',
    'dertien',
    'veertien',
    'vijftien',
    'zestien',
    'zeventien',
    'achttien',
    'negentien',
  ],
  tens: [
    '',
    '',
    'twintig',
    'dertig',
    'veertig',
    'vijftig',
    'zestig',
    'zeventig',
    'tachtig',
    'negentig',
  ],
  tensAndUnits: { order: 'unitsFirst', join: 'en' },
  hundred: 'honderd',
  thousand: 'duizend',
  join: '',
  ordinal: { words: { een: 'eerste', drie: 'derde' }, suffix: 'ste', unitSuffix: 'de' },
  ordinalNumber: { suffix: 'e' },
})

formatNumber(21, 'cardinalText', { language: 'nl' }) // 'eenentwintig'
formatNumber(3, 'ordinal', { language: 'nl' }) // '3e'
```

- **Call it at startup in each place that opens the document**: in the browser, and on a server
  that lays out or exports it. Put the call at the top of the module that lists your extensions,
  which both import. The document stores only the tag, not the words.
- **Then name the tag** like a built-in one, in `setNumberLanguage('nl')` or `{ language: 'nl' }`.
- **Defining `en` or `de` again** replaces the built-in words.

## The fields of a language

A language holds these fields. `NumberLanguage` is its type:

| Field              | Type                                             | Description                                                                                                                       |
| ------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `units`            | `string[]`                                       | The words for 1 to 19, each at its own index. Index 0 is not read                                                                 |
| `tens`             | `string[]`                                       | The words for 20, 30, … 90, at index 2 to 9                                                                                       |
| `tensAndUnits`     | `{ order, join }`                                | How a ten and a unit make 21. `'tensFirst'` with `'-'` is `twenty-one`, `'unitsFirst'` with `'und'` is `einundzwanzig`            |
| `hundred`          | `string`                                         | The word for a hundred                                                                                                            |
| `thousand`         | `string`                                         | The word for a thousand                                                                                                           |
| `join`             | `string`                                         | What stands between the other words of a count: `' '` in `one hundred two`, `''` in `einhundertzwei`                              |
| `unitsInCompounds` | `Record<number, string>`, optional               | A unit as it reads before another word. German `{ 1: 'ein' }` writes `einhundert` and `einundzwanzig`, where `units[1]` is `eins` |
| `ordinal`          | `{ words?, endings?, suffix, unitSuffix? }`      | How the last word of a count becomes an ordinal. See [Ordinals](/features/number-formats/words#ordinals)                                                        |
| `ordinalNumber`    | `{ suffix, byLastDigit?, exceptLastTwoDigits? }` | How digits become an ordinal. See [Ordinals](/features/number-formats/words#ordinals)                                                                           |

A hundred and a thousand always follow their word from `units`, also for one: `one hundred`,
`einhundert`, `eenhonderd`.

`defineNumberLanguage` throws for a tag that is not a language tag. It also throws when `units`
lacks a word for one of 1 to 19, `tens` lacks one for 20 to 90, or `hundred`, `thousand`,
`ordinal.suffix` or `ordinalNumber.suffix` is missing.

## Ordinals

An ordinal in words, as `'ordinalText'` writes it, changes only the last word of a count:
`twenty-one` becomes `twenty-first`. This holds also when `join` is `''` and the words run
together. The first of these rules that matches the last word applies:

1. **`ordinal.words`** gives a word its own ordinal, such as `{ one: 'first', three: 'third' }`.
2. **`ordinal.endings`** replaces an ending, as pairs such as `[['y', 'ieth']]` for `twenty` to
   `twentieth`. The longest matching ending wins.
3. **`ordinal.unitSuffix`** is added when the last word comes from `units`, the words for 1 to 19,
   as German `te` in `vierte`.
4. **`ordinal.suffix`** is added to any other word, as `th` in `hundredth` or German `ste` in
   `zwanzigste`. A language without `unitSuffix` uses `suffix` for 1 to 19 too.

An ordinal in digits, as `'ordinal'` writes it, adds an ending to the digits:

- **`ordinalNumber.suffix`** is the ending, as `th` in `4th` or `.` in German `4.`.
- **`ordinalNumber.byLastDigit`** is the ending where the last digit asks for another, such as
  `{ 1: 'st', 2: 'nd', 3: 'rd' }`.
- **`ordinalNumber.exceptLastTwoDigits`** lists the last two digits that keep `suffix` even where
  `byLastDigit` names another ending, such as `[11, 12, 13]` for `11th`.

## Limits

- **Words go up to 999 999.** A larger count is written in the format's fallback, decimal for the
  built-in formats.
- **`join` stands between all the words.** A word between a hundred and the rest only, such as the
  British `one hundred and two`, cannot be written.
- **Words know no grammar.** A language whose ordinals change with the noun gets one form, such as
  German `dritte`.
- **A document stores the tag, not the words.** A document in a language this app was never given
  is written in the fallback until the language is defined here too.
