## Install

1. Set up Tiptap's private registry. The
   [private registry guide](https://tiptap.dev/docs/guides/pro-extensions) explains how.
2. Install the package and the editor packages this example uses:

   ```bash
   npm install @tiptap-pro/extension-number-formats @tiptap/core @tiptap/pm @tiptap/starter-kit
   ```

If you use Footnotes, Outline numbering or Page Layout, this package is already installed, because
they depend on it. Naming a format in their options needs nothing more. Add the package to your own
dependencies when your code imports from it.

## A first editor

This editor registers the `NumberFormats` extension, stores German as the document's language and
writes a count the way the document does:

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import {
  formatNumber,
  NumberFormats,
  numberFormatContextOf,
} from '@tiptap-pro/extension-number-formats'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, NumberFormats],
  content: '<p>Chapter three</p>',
})

editor.commands.setNumberLanguage('de')

const context = numberFormatContextOf(editor.state.doc)
console.log(formatNumber(3, 'ordinalText', context)) // 'dritte'
```

When it works, the console shows `dritte`, and `editor.getHTML()` ends with a hidden `div` that
has `data-tt-number-formats="true"` and `data-tt-language="de"`. That block is how the document
carries its language to every collaborator and server that opens it.

The functions alone need no editor and no extension. `formatNumber(4, 'upperRoman')` returns
`'IV'` anywhere. Register `NumberFormats` only to store formats or a language in the document.

## What you need

| Package                                | Kind            | Version             |
| -------------------------------------- | --------------- | ------------------- |
| `@tiptap-pro/extension-number-formats` | Dependency      | Latest              |
| `@tiptap/core`                         | Peer dependency | 3.29.2 or later 3.x |
| `@tiptap/pm`                           | Peer dependency | 3.29.2 or later 3.x |
| `@tiptap/starter-kit`                  | Optional        | 3.x                 |

StarterKit gives the example its paragraphs. Any schema works where the end of the document, or of
its last container, takes a block node.

Two installed versions of the package, such as an older one that a dependency brings, share the
formats and languages defined in either. A format defined through one is written by the other.
