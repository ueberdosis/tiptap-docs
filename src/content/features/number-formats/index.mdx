You can add formats and languages of your own, and store them in the document so that every
collaborator and server writes the same numbers. The package works in any Tiptap editor, with or
without Page Layout. [Install Number formats](/features/number-formats/install) builds a first editor.

## What you get

- **[Built-in formats](/features/number-formats/built-in-formats):** 29 formats, such as `1, 2, 3`, `i, ii, iii`,
  `a, b, c`, `*, †, ‡`, Greek letters and enclosed numbers, and the functions that write a count in
  them.
- **[Counts in words](/features/number-formats/words):** `one`, `first` and `1st` in English and German, and in any
  language you add as data.
- **[Your own formats](/features/number-formats/your-own-formats):** a format such as `§ 1` or `001`, defined once and
  accepted wherever a format name is.
- **[Formats stored in the document](/features/number-formats/stored-in-the-document):** the document's own formats and
  language, so it is numbered the same way wherever it opens.
- **[Word files](/features/number-formats/docx):** Word's own name for each format, for code that reads or writes DOCX.

## A first look

The package comes from Tiptap's private registry, so set that up first, as
[Install Number formats](/features/number-formats/install) shows. Then install the package:

```bash
npm install @tiptap-pro/extension-number-formats
```

`formatNumber` writes a count in a format. It needs no editor:

```js
import { formatNumber } from '@tiptap-pro/extension-number-formats'

formatNumber(4, 'upperRoman') // 'IV'
formatNumber(3, 'ordinalText', { language: 'de' }) // 'dritte'
```

[Install Number formats](/features/number-formats/install) builds an editor that stores its language in the document.

## With Page Layout

Page Layout writes page numbers in these formats. A document stores its own formats in a hidden
block at its end, and Page Layout puts that block on no page.

The commands work in a Page Layout editor as they are. Only a transaction you build yourself goes
through Page Layout's document, as
[Number formats in Extension behavior](/features/page-layout/extension-behavior#number-formats)
shows.

## Common tasks

| Task                                        | Call or page                                                                                                                                                                 |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Write a count in a format                   | `formatNumber(4, 'upperRoman')`, see [Write a count](/features/number-formats/built-in-formats#write-a-count)                                                                                      |
| Fill a format picker                        | `numberFormatNames()` and `numberFormatSample(name)`, see [Fill a format picker](/features/number-formats/built-in-formats#fill-a-format-picker)                                                   |
| Write a count in German words               | `formatNumber(3, 'ordinalText', { language: 'de' })`, see [Counts in words](/features/number-formats/words)                                                                                        |
| Add a language                              | `defineNumberLanguage('nl', words)`, see [A language of your own](/features/number-formats/words#a-language-of-your-own)                                                                           |
| Add a format such as `§ 1`                  | `defineNumberFormat('clause', definition)`, see [Your own formats](/features/number-formats/your-own-formats)                                                                                      |
| Store the document's language               | `editor.commands.setNumberLanguage('de')`, see [setNumberLanguage()](/features/number-formats/stored-in-the-document#setnumberlanguage)                                                            |
| Store a format in the document              | `editor.commands.setNumberFormat('clause', definition)`, see [setNumberFormat()](/features/number-formats/stored-in-the-document#setnumberformat)                                                  |
| Write a count as the document does          | `formatNumber(4, 'clause', numberFormatContextOf(editor.state.doc))`, see [Write a count as the document does](/features/number-formats/stored-in-the-document#write-a-count-as-the-document-does) |
| Read the formats of stored JSON on a server | `numberFormatContextOf(Node.fromJSON(schema, json))`, see [On a server](/features/number-formats/stored-in-the-document#on-a-server)                                                               |
| Write a format into a Word file             | `toOoxmlNumberFormat('lowerAlpha')`, see [Word files](/features/number-formats/docx)                                                                                                               |

`words`, `definition`, `schema` and `json` stand for the objects the linked sections describe.

## Words these pages use

| Word         | Meaning                                                                                                                                  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Count        | The number a format writes, such as the number of a page, a note or a heading. Counts start at 1                                         |
| Format       | How a count is written, named by a string such as `'lowerRoman'`                                                                         |
| Definition   | A plain object that says how a format writes a count. You give it to `defineNumberFormat` or store it in the document                    |
| Fallback     | The format a count is written in when its own format cannot write it. Decimal unless a definition names another                          |
| Language tag | The name of a language, such as `en`, `de` or `de-AT`. It decides the words of `'cardinalText'`, `'ordinalText'` and `'ordinal'`         |
| Context      | What a document stores, its formats and its language. `formatNumber` takes it to write a count as the document does                      |
| This app     | The app or server your code runs in. It knows the built-in formats, the ones its own code defines, and the ones the open document stores |
| OOXML value  | The name a Word file gives a format, such as `lowerLetter` for `'lowerAlpha'`                                                            |
