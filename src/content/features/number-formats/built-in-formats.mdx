This page shows how to write a count, how to fill a format picker and which formats there are.

On these pages, "this app" is the app or server your code runs in. It writes the built-in formats,
the ones its own code defines, and the ones the open document stores.

## Write a count

`formatNumber(value, format, context?)` returns the count written in a format, as a string. It
needs no editor:

```js
import { formatNumber } from '@tiptap-pro/extension-number-formats'

formatNumber(4, 'upperRoman') // 'IV'
formatNumber(4, 'lowerAlpha') // 'd'
formatNumber(4, 'decimalZero') // '04'
```

- **A count below 1** is written as 1, so `formatNumber(0, 'decimal')` is `'1'`.
- **A count the format cannot write**, such as 21 in `'decimalEnclosedCircle'`, is written in the
  format's fallback. That is decimal for every built-in format, so the result is `'21'`. A format of
  your own can name another fallback, as
  [What a definition holds](/features/number-formats/your-own-formats#what-a-definition-holds) shows.
- **A format name this app does not know** is written in decimal, and `formatNumber` does not
  throw. [A format this app does not know](/features/number-formats/stored-in-the-document#a-format-this-app-does-not-know)
  says when that happens.

`context` is what a document stores, its formats and its language, as `{ formats?, language? }`.
Without it, `formatNumber` uses the built-in formats and the ones your code defines, and writes
words in English. [Write a count as the document does](/features/number-formats/stored-in-the-document#write-a-count-as-the-document-does)
shows how to get the context of a document.

## Fill a format picker

`numberFormatNames()` lists every format name this app can write, and `numberFormatSample()` gives
each a label of its first counts. Together they fill a `<select>` that lets the user pick a format:

```js
import { numberFormatNames, numberFormatSample } from '@tiptap-pro/extension-number-formats'

const select = document.querySelector('#format')

for (const name of numberFormatNames()) {
  select.add(new Option(`${name}: ${numberFormatSample(name)}`, name))
}
// decimal: 1, 2, 3, …
// lowerRoman: i, ii, iii, …
```

The two functions take these arguments:

| Function             | Arguments                      | Returns                                                                                                                                          |
| -------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `numberFormatNames`  | `context?`                     | The format names this app writes: the built-in ones in the order of the table on this page, then the document's, then the ones your code defines |
| `numberFormatSample` | `format`, `count?`, `context?` | The first `count` counts in the format, joined as `'①, ②, ③, …'`. `count` defaults to 3                                                          |

The labels start with the format names, such as `decimalZero`. Put a name of your own before the
sample when the user needs one.

To list the formats stored in the document too, pass the document's context to both functions. With
an editor as in [Install Number formats](/features/number-formats/install#a-first-editor), that is
`numberFormatNames(numberFormatContextOf(editor.state.doc))`.

## The built-in formats

Each built-in format has a fixed name that every package accepts:

| Format                      | Reads                                                           |
| --------------------------- | --------------------------------------------------------------- |
| `'decimal'`                 | `1`, `2`, … `10`                                                |
| `'decimalZero'`             | `01`, `02`, … `10`                                              |
| `'lowerAlpha'`              | `a`, `b`, … `z`, `aa`, `ab`                                     |
| `'upperAlpha'`              | `A`, `B`, … `Z`, `AA`, `AB`                                     |
| `'lowerRoman'`              | `i`, `ii`, `iii`, `iv`                                          |
| `'upperRoman'`              | `I`, `II`, `III`, `IV`                                          |
| `'numberInDash'`            | `- 1 -`, `- 2 -`, … `- 10 -`                                    |
| `'symbols'`                 | `*`, `†`, `‡`, `§`, then `**`, `††`, `‡‡`, `§§`, then `***`     |
| `'cardinalText'`            | `one`, `two`, … `twenty-one`, in the document's language        |
| `'ordinalText'`             | `first`, `second`, … `twenty-first`, in the document's language |
| `'ordinal'`                 | `1st`, `2nd`, `3rd`, `4th`, in the document's language          |
| `'decimalFullWidth'`        | `１`, `２`, … `１０`                                            |
| `'decimalEnclosedCircle'`   | `①`, `②`, … `⑳`, then `21`                                      |
| `'decimalEnclosedParen'`    | `⑴`, `⑵`, … `⒇`, then `21`                                      |
| `'decimalEnclosedFullstop'` | `⒈`, `⒉`, … `⒛`, then `21`                                      |
| `'lowerGreek'`              | `α`, `β`, … `ω`, `αα`                                           |
| `'upperGreek'`              | `Α`, `Β`, … `Ω`, `ΑΑ`                                           |
| `'russianLower'`            | `а`, `б`, … `я`, `аа`                                           |
| `'russianUpper'`            | `А`, `Б`, … `Я`, `АА`                                           |
| `'hebrew'`                  | `א`, `ב`, … `טו`, `טז`, … up to 999, then decimal               |
| `'armenian'`                | `Ա`, `Բ`, … up to 9999, then decimal                            |
| `'arabicIndic'`             | `١`, `٢`, … `١٠`                                                |
| `'persian'`                 | `۱`, `۲`, … `۱۰`                                                |
| `'devanagari'`              | `१`, `२`, … `१०`                                                |
| `'bengali'`                 | `১`, `২`, … `১০`                                                |
| `'thai'`                    | `๑`, `๒`, … `๑๐`                                                |
| `'cjkDecimal'`              | `一`, `二`, … `一〇`                                            |
| `'hiragana'`                | `あ`, `い`, `う`, …                                             |
| `'katakana'`                | `ア`, `イ`, `ウ`, …                                             |

The document's language is English unless the document stores another one.
[Counts in words](/features/number-formats/words) explains the three formats that depend on it.

## Check a format name

`isNumberFormat()` tells whether this app can write a format, and `isNumberFormatName()` whether a
value can be a format name at all:

```js
import { isNumberFormat, isNumberFormatName } from '@tiptap-pro/extension-number-formats'

isNumberFormat('lowerGreek') // true
isNumberFormat('clause') // false until defineNumberFormat('clause', …) ran
isNumberFormatName('clause') // true: a name a document can store
isNumberFormatName('two words') // false
```

A format name is a letter, followed by letters, digits and hyphens, up to 64 characters.

Use `isNumberFormat()` before you let the user choose a format, so a typo is not stored.

Use `isNumberFormatName()` when your code checks a format name it reads from a stored document. A
name that a collaborator's code defined then stays in the document, although this app cannot write
it. Both functions take these arguments:

| Function             | Arguments           | Returns                                             |
| -------------------- | ------------------- | --------------------------------------------------- |
| `isNumberFormat`     | `value`, `context?` | `true` when this app can write the format           |
| `isNumberFormatName` | `value`             | `true` when the value has the form of a format name |

## Types and constants

- **`NUMBER_FORMATS`** lists the built-in names in the order of the table on this page.
- **`BuiltInNumberFormat`** is the type of a built-in name.
- **`NumberFormat`** is the type of any format name, the built-in ones and any other string.
- **`NumberFormatContext`** is the type of `context`.
