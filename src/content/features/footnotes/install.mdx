## Install

The package comes from Tiptap's private registry, not from npm's:

1. Set up access to the registry, as
   [The Pro registry](/features/page-layout/getting-started/install#the-pro-registry)
   shows.
2. Install the extension:

   ```bash
   npm install @tiptap-pro/extension-footnotes
   ```

3. If the project has no Tiptap editor yet, install Tiptap and StarterKit for the example:

   ```bash
   npm install @tiptap/core @tiptap/pm @tiptap/starter-kit
   ```

## A first editor with footnotes

The example needs an element for the editor and a button in your HTML:

```html
<button id="insert-footnote">Insert footnote</button>
<div id="editor"></div>
```

This script creates the editor, adds the stylesheet, and lets the button insert a footnote:

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Footnotes, mountFootnoteStyles } from '@tiptap-pro/extension-footnotes'

mountFootnoteStyles(document)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    // Before StarterKit, so saved HTML loads its notes as notes and not as ordered lists
    Footnotes.configure({ defaultPlacement: 'footnote' }),
    StarterKit,
  ],
  content: '<p>Click into this sentence and insert a footnote.</p>',
})

document.querySelector('#insert-footnote').addEventListener('click', () => {
  editor.chain().focus().insertFootnote().run()
})
```

The order matters only for HTML you load into the editor. JSON loads in either order, as
[Notes in the document](/features/footnotes/document#save-as-json-or-html) explains.

`Footnotes` is the only extension of the package you register. It brings the nodes, the commands
and the paste from Word. Without `defaultPlacement: 'footnote'`, `insertFootnote()` inserts an
endnote. Without `mountFootnoteStyles`, no number shows, because the document stores none.

## What you see

A click on Insert footnote puts a raised 1 at the cursor and adds a numbered list of notes, with a
line above it, at the end of the document. The cursor moves into note 1, so the user types the
note's text next.

A note inserted before another one renumbers the notes after it.

## What you need

These packages make up the example, in the versions the extension asks for:

| Package                                | Kind                      | Version   | What it is for                                                         |
| -------------------------------------- | ------------------------- | --------- | ---------------------------------------------------------------------- |
| `@tiptap-pro/extension-footnotes`      | The extension             | `0.1.0`   | Footnotes and endnotes                                                 |
| `@tiptap-pro/extension-number-formats` | Dependency                | `0.1.0`   | Spells each number as 1, i, a or another format. Installed with it     |
| `@tiptap/core`                         | Peer dependency           | `^3.29.2` | The editor                                                             |
| `@tiptap/pm`                           | Peer dependency           | `^3.29.2` | ProseMirror, the library Tiptap is built on                            |
| `@tiptap/starter-kit`                  | Optional, for the example | `^3.29.2` | Common nodes. Any schema with a block node, such as a paragraph, works |

A number format your document defines itself, such as one that cycles through † and ‡, also needs
the `NumberFormats` extension of
[Number formats](/features/number-formats) in the editor.
