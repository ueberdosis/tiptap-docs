Everything on this page is imported from `@tiptap-pro/extension-footnotes`. The functions take a
document, such as `editor.state.doc`, or a state, such as `editor.state`, so they work without an
editor too.

## Read the notes of a document

This example lists every reference in reading order with the text of its note:

```js
import { footnoteAt, footnoteReferences } from '@tiptap-pro/extension-footnotes'

const doc = editor.state.doc

for (const { footnoteId } of footnoteReferences(doc)) {
  console.log(footnoteId, footnoteAt(doc, footnoteId)?.node.textContent)
}
```

A collection is the numbered list of notes at the end of the document. A numbering scope is the
part of the document between two numbering breaks. These functions read a whole document:

| Function                    | Arguments         | Returns                                                                                                       |
| --------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------- |
| `footnoteAtSelection`       | `selection`       | The note at the cursor, or `null`. See [Find the note at the cursor](/features/footnotes/notes#find-the-note-at-the-cursor) |
| `footnoteReferences`        | `doc`             | `{ footnoteId, pos }` of every reference with an id in the text, not in notes, in reading order               |
| `footnoteAt`                | `doc, footnoteId` | `{ node, pos }` of the note with that id, or `null`                                                           |
| `footnoteCollectionsIn`     | `doc`             | `{ node, pos }` of every collection, in document order                                                        |
| `footnoteCollectionFor`     | `doc, placement`  | `{ node, pos }` of the first collection of that placement, or `null`                                          |
| `numberingBreaksIn`         | `doc`             | `{ node, pos }` of every numbering break, also inside other blocks and notes                                  |
| `noteNumbers`               | `doc, options?`   | A `Map` from each `footnoteId` to its number as text, such as `'iv'`                                          |
| `footnoteNumberDecorations` | `doc, options?`   | The numbers as a `DecorationSet`, the way the editor draws them                                               |
| `scopeBoundaries`           | `doc, reader?`    | The sorted positions between top-level blocks where the scopes end, from `reader` or the breaks               |
| `scopeOfPosition`           | `boundaries, pos` | The index of the scope a position is in, from 0. A boundary belongs to the scope it opens                     |
| `schemaHasFootnotes`        | `doc`             | Whether the schema has the `footnote` and `footnoteCollection` nodes                                          |

Details:

- **`footnoteCollectionFor`** returns only the first collection. With numbering breaks, each scope
  has its own, so filter `footnoteCollectionsIn(doc)` with `placementOf` to get all of them.
- **`noteNumbers` and `footnoteNumberDecorations`** do not read the editor's options. Pass
  `sequences` or `counter`, as [Numbering](/features/footnotes/numbering#show-the-numbers-outside-the-editor)
  shows.
- **`footnoteReferences`** can list one `footnoteId` twice right after a paste, until the repair
  pass gives the copy its own id.
- **With [Page Layout](/features/page-layout/getting-started/overview)**, `editor.state.doc` holds
  the pages. Read the document instead, as
  [Footnotes in Page Layout](/features/page-layout/extension-behavior/footnotes#writing-and-reading-notes)
  shows.

### Read one node

These functions take one node, such as the `node` that `footnoteAt` returns:

| Function                   | Arguments    | Returns                                                                                |
| -------------------------- | ------------ | -------------------------------------------------------------------------------------- |
| `isFootnoteReference`      | `node`       | Whether the node's type is `footnoteReference`                                         |
| `isFootnote`               | `node`       | Whether the node's type is `footnote`                                                  |
| `isFootnoteCollection`     | `node`       | Whether the node's type is `footnoteCollection`                                        |
| `isFootnoteNumberingBreak` | `node`       | Whether the node's type is `footnoteNumberingBreak`                                    |
| `footnoteIdOf`             | `node`       | The `footnoteId` of a reference or a note, or `null` when it is missing or empty       |
| `placementOf`              | `node`       | `'footnote'` when the placement is `'footnote'`, otherwise `'endnote'`                 |
| `noteStrandTitle`          | `collection` | The title above the notes of a collection, or `null`                                   |
| `numberingBreakSequence`   | `node, kind` | The format and start a numbering break sets for `'footnote'` or `'endnote'`, or `null` |

## Write without a command

Each command that changes the document has a function that returns the change as a transaction
without dispatching it, so you can add steps first. It returns `null` where the command returns
`false`:

| Function                              | Arguments                      | Command                                                                |
| ------------------------------------- | ------------------------------ | ---------------------------------------------------------------------- |
| `insertFootnoteTransaction`           | `state, options?`              | [insertFootnote()](/features/footnotes/notes#insertfootnote)                         |
| `deleteFootnoteTransaction`           | `state, footnoteId`            | [deleteFootnote()](/features/footnotes/notes#deletefootnote)                         |
| `setFootnotePlacementTransaction`     | `state, footnoteId, placement` | [setFootnotePlacement()](/features/footnotes/notes#setfootnoteplacement)             |
| `insertNoteNumberingBreakTransaction` | `state, options?`              | [insertNoteNumberingBreak()](/features/footnotes/numbering#insertnotenumberingbreak) |

The functions do not read the extension's options. `insertFootnoteTransaction` makes an endnote
without `placement`, writes no title without `titles`, and reads the scopes from the numbering
breaks without `scopes`. It leaves the cursor in the new note.

The repair pass, the step after each change that keeps notes and references paired, runs when you
dispatch in an editor with `Footnotes`. Without it, `setFootnotePlacementTransaction` leaves the
note in its old collection. `deleteFootnoteTransaction` then leaves an empty note when it deletes
the last note of a collection.

## Parts for an editor without Footnotes

For an editor or a state you put together yourself, the parts of `Footnotes` are exported one by
one:

| Export                         | Kind     | What it is                                                                                                     |
| ------------------------------ | -------- | -------------------------------------------------------------------------------------------------------------- |
| `FootnoteReference`            | Node     | The reference, `footnoteReference`                                                                             |
| `Footnote`                     | Node     | The note, `footnote`                                                                                           |
| `FootnoteCollection`           | Node     | The collection, `footnoteCollection`                                                                           |
| `FootnoteNumberingBreak`       | Node     | The numbering break, `footnoteNumberingBreak`                                                                  |
| `footnotesRepairPlugin`        | Plugin   | `footnotesRepairPlugin(options?)`, the repair pass, with the key `footnotesRepair`                             |
| `repairTransaction`            | Function | `repairTransaction(tr, doc, options?)`, the repair pass written into `tr`, or `null` when nothing needs repair |
| `footnoteReferenceClickPlugin` | Plugin   | `footnoteReferenceClickPlugin(onClick)`, like the `onReferenceClick` option                                    |
| `noteMarkClickPlugin`          | Plugin   | `noteMarkClickPlugin(onClick)`, like the `onNoteMarkClick` option                                              |
| `markZoneOf`                   | Function | `markZoneOf(noteElement)`, the area of a note's number on the screen                                           |
| `isOnNoteMark`                 | Function | `isOnNoteMark(zone, x, y)`, whether a point is on that area                                                    |
| `createFootnoteId`             | Function | `createFootnoteId()`, a new `footnoteId`                                                                       |

Copying a reference with its note comes only with `Footnotes`. `WordFootnotePaste` and its
functions are on [Word documents](/features/footnotes/word), and `mountFootnoteStyles` and `footnoteStyleRules`
on [Styling](/features/footnotes/styling#the-stylesheet).

Details:

- **`repairTransaction`** reads positions from `doc`, so pass a transaction with no steps yet:
  `repairTransaction(state.tr, state.doc)`.
- **`RepairOptions`** takes `titles` and `scopes`. Without `titles`, the pass writes no title for
  a collection it creates. Without `scopes`, it reads the numbering breaks.
- **`markZoneOf`** returns `{ left, right, top, bottom }` in viewport coordinates. The area runs
  from the note's left edge to its first text, on that line. An empty note gives `null`.
- **`isOnNoteMark`** is `true` when `left <= x < right` and `top <= y <= bottom`, and `false` for
  `null`.
- **`createFootnoteId`** returns `footnote-` and `crypto.randomUUID()`, or a random string where
  that is missing.

## Constants

The extension exports the names of its nodes and HTML attributes, and its defaults:

| Constant                             | Value                                | What it is                                                |
| ------------------------------------ | ------------------------------------ | --------------------------------------------------------- |
| `FOOTNOTE_REFERENCE_NODE_NAME`       | `'footnoteReference'`                | The name of the reference node                            |
| `FOOTNOTE_NODE_NAME`                 | `'footnote'`                         | The name of the note node                                 |
| `FOOTNOTE_COLLECTION_NODE_NAME`      | `'footnoteCollection'`               | The name of the collection node                           |
| `FOOTNOTE_NUMBERING_BREAK_NODE_NAME` | `'footnoteNumberingBreak'`           | The name of the numbering break node                      |
| `FOOTNOTE_REFERENCE_ATTRIBUTE`       | `'data-tt-footnote-reference'`       | The `footnoteId` of a reference, in HTML                  |
| `FOOTNOTE_ATTRIBUTE`                 | `'data-tt-footnote'`                 | The `footnoteId` of a note, in HTML                       |
| `FOOTNOTE_PLACEMENT_ATTRIBUTE`       | `'data-tt-footnote-placement'`       | The placement of a note or a collection, in HTML          |
| `FOOTNOTE_COLLECTION_ATTRIBUTE`      | `'data-tt-footnote-collection'`      | Marks a collection in HTML, with the value `true`         |
| `FOOTNOTE_NUMBERING_BREAK_ATTRIBUTE` | `'data-tt-footnote-numbering-break'` | Marks a numbering break in HTML, with the value `true`    |
| `FOOTNOTE_NUMBER_ATTRIBUTE`          | `'data-tt-footnote-number'`          | The drawn number, in the editor's DOM, not in `getHTML()` |
| `DEFAULT_FOOTNOTE_PLACEMENT`         | `'endnote'`                          | The placement of a note without one                       |
| `DEFAULT_FOOTNOTE_SEQUENCE`          | `{ format: 'decimal', start: 1 }`    | How footnotes are numbered by default                     |
| `DEFAULT_ENDNOTE_SEQUENCE`           | `{ format: 'lowerRoman', start: 1 }` | How endnotes are numbered by default                      |
| `DEFAULT_NOTE_SEQUENCES`             | `{ footnote, endnote }`              | Both default sequences, of the type `NoteSequences`       |

## Types

The package exports the TypeScript types of its options, arguments and results. `StrandTitles`
and `noteStrandTitle` say "strand", and `NoteMark` says "mark", where these pages say collection
and number:

| Type                            | Shape                                                                 |
| ------------------------------- | --------------------------------------------------------------------- |
| `FootnotesOptions`              | The options of `Footnotes`, on [Options](/features/footnotes/api-reference/options)                  |
| `FootnotePlacement`             | `'footnote' \| 'endnote'`                                             |
| `InsertFootnoteOptions`         | The options of `insertFootnote()`                                     |
| `InsertNumberingBreakOptions`   | The options of `insertNoteNumberingBreak()`                           |
| `FootnoteAtSelection`           | `{ footnoteId: string, in: 'note' \| 'reference' }`                   |
| `FootnoteReferenceAt`           | `{ footnoteId: string, pos: number }`                                 |
| `NodeAt`                        | `{ node, pos: number }`, a node and its position                      |
| `StrandTitles`                  | `{ node: string \| null, footnote: string, endnote: string }`         |
| `NoteSequence`                  | `{ format, start: number }`, how one placement is numbered            |
| `NoteSequences`                 | `{ footnote: NoteSequence, endnote: NoteSequence }`                   |
| `NumberingOptions`              | `{ sequences?: NoteSequences, counter?: NoteCounter \| null }`        |
| `NoteCounter`                   | `(doc) => ReadonlyMap<string, NoteMark>`                              |
| `NoteMark`                      | `{ ordinal: number, format }`, the count and format of one note       |
| `NoteScopeReader`               | `(doc) => readonly number[]`, where the numbering scopes end          |
| `FootnoteReferenceClick`        | `{ footnoteId: string, pos: number, event: MouseEvent }`              |
| `FootnoteReferenceClickHandler` | `(click: FootnoteReferenceClick) => boolean`                          |
| `NoteMarkClick`                 | `{ footnoteId: string, noteElement: HTMLElement, event: MouseEvent }` |
| `NoteMarkClickHandler`          | `(click: NoteMarkClick) => boolean`                                   |
| `MarkZone`                      | `{ left: number, right: number, top: number, bottom: number }`        |
| `RepairOptions`                 | `{ titles?: StrandTitles, scopes?: NoteScopeReader \| null }`         |
| `FootnoteIdFactory`             | `() => string`                                                        |
| `WordNote`, `ParseWordNote`     | For notes pasted from Word, on [Word documents](/features/footnotes/word)           |
