## How the commands behave

The commands work like other Tiptap commands. Call one on its own, or in a chain. The examples
use the `editor` of the complete example in [Install Footnotes](/features/footnotes/install):

```js
editor.commands.insertFootnote({ placement: 'footnote' })
editor.chain().focus().insertFootnote({ placement: 'footnote' }).run()
```

A command returns `false` and changes nothing when it cannot act, such as `insertFootnote()`
inside a note or `deleteFootnote()` with an id that no note has. Otherwise it returns `true`.

`editor.can()` asks the same question without changing the document, so a toolbar uses it to
enable a button:

```js
const canInsert = editor.can().insertFootnote()
```

`can()` applies the same rule as the command, because it builds the whole change and then
discards it.

In a chain, a later command that returns `false` does not undo an earlier one. For example,
`editor.chain().insertFootnote().insertFootnote().run()` returns `false` but still inserts one
note, because the second call finds the cursor in the new note and refuses.

With [Page Layout](/features/page-layout/getting-started/overview), which shows the editor as
printed pages, the commands and `can()` act on the document, not on the pages. An `at` position
you pass to `insertFootnote()` or `insertNoteNumberingBreak()` is a position in the document.
[Footnotes in Page Layout](/features/page-layout/extension-behavior/footnotes#writing-and-reading-notes)
has more.

## The six commands

Each command links to its description:

| Command                                                                           | What it does                                                                   |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| [`insertFootnote(options?)`](/features/footnotes/notes#insertfootnote)                          | Inserts a reference at the cursor and a note for it                            |
| [`deleteFootnote(footnoteId)`](/features/footnotes/notes#deletefootnote)                        | Deletes a note and every reference to it                                       |
| [`setFootnotePlacement(footnoteId, placement)`](/features/footnotes/notes#setfootnoteplacement) | Turns a footnote into an endnote, or back                                      |
| [`focusFootnote(footnoteId)`](/features/footnotes/notes#focusfootnote)                          | Puts the cursor at the start of a note's text                                  |
| [`focusFootnoteReference(footnoteId)`](/features/footnotes/notes#focusfootnotereference)        | Puts the cursor in front of a note's reference                                 |
| [`insertNoteNumberingBreak(options?)`](/features/footnotes/numbering#insertnotenumberingbreak)  | Inserts a numbering break, after which notes are numbered from the start again |

The four commands that change the document also exist as functions that return the change
without applying it. [Functions and names](/features/footnotes/api-reference/functions#write-without-a-command) lists them.
