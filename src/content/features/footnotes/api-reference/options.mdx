This example sets the options most editors change:

```js
import { Footnotes } from '@tiptap-pro/extension-footnotes'

Footnotes.configure({
  defaultPlacement: 'footnote',
  footnoteNumbers: { format: 'lowerAlpha', start: 1 },
  titleNode: 'heading',
  onReferenceClick: ({ footnoteId }) => editor.commands.focusFootnote(footnoteId),
})
```

`editor` stands for the editor that `new Editor()` returns, as in
[Install Footnotes](/features/footnotes/install). The handler runs only when the user clicks, after the editor
exists, so it can use that variable. The type of all options is exported as `FootnotesOptions`.

## Inserting notes

| Option             | Type                              | Default | Description                                                                                                                                   |
| ------------------ | --------------------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `defaultPlacement` | `'footnote' \| 'endnote' \| null` | `null`  | What [`insertFootnote()`](/features/footnotes/notes#insertfootnote) inserts when it is not told. `null` inserts an endnote, and a footnote with Page Layout |

## Numbering

| Option            | Type           | Default                              | Description                                                                                                |
| ----------------- | -------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `footnoteNumbers` | `NoteSequence` | `{ format: 'decimal', start: 1 }`    | The format and first number of footnotes. See [Numbering](/features/footnotes/numbering#change-the-format-and-the-start) |
| `endnoteNumbers`  | `NoteSequence` | `{ format: 'lowerRoman', start: 1 }` | The format and first number of endnotes. Setting one sequence keeps the default of the other               |
| `numbering`       | `boolean`      | `true`                               | `false` draws no numbers, for an integration that draws its own                                            |

`NoteSequence` is `{ format, start }`, where `format` names one of the
[Number formats](/features/number-formats).

## Titles

| Option          | Type             | Default       | Description                                                                                                               |
| --------------- | ---------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `titleNode`     | `string \| null` | `null`        | The node type of a title above each list of notes. `null` adds none. See [Styling](/features/footnotes/styling#a-title-above-the-notes) |
| `footnoteTitle` | `string`         | `'Footnotes'` | The words of a new title above footnotes                                                                                  |
| `endnoteTitle`  | `string`         | `'Endnotes'`  | The words of a new title above endnotes                                                                                   |

## Clicks

| Option             | Type                                    | Default | Description                                                                                                                                                   |
| ------------------ | --------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `onReferenceClick` | `FootnoteReferenceClickHandler \| null` | `null`  | Called when the user clicks a reference. See [Insert and edit notes](/features/footnotes/notes#clicks-on-a-reference-and-on-a-notes-number)                                 |
| `onNoteMarkClick`  | `NoteMarkClickHandler \| null`          | `null`  | Called when the user clicks the number, or mark, at the start of a note. See [Insert and edit notes](/features/footnotes/notes#clicks-on-a-reference-and-on-a-notes-number) |

## For an editor that shows the document as something else

Page Layout sets these options, because its editor shows pages rather than the document you save.
Leave them at their defaults in an editor that shows the document as it is.

| Option          | Type                                         | Default | Description                                                                              |
| --------------- | -------------------------------------------- | ------- | ---------------------------------------------------------------------------------------- |
| `counter`       | `NoteCounter \| null`                        | `null`  | Decides the number of each note. See [counter](/features/footnotes/api-reference/options#counter)                                 |
| `scopes`        | `NoteScopeReader \| null`                    | `null`  | Decides where each numbering scope ends. See [scopes](/features/footnotes/api-reference/options#scopes)                           |
| `repair`        | `boolean`                                    | `true`  | Whether the repair pass runs in this editor. See [repair](/features/footnotes/api-reference/options#repair)                       |
| `notesDocument` | `((editor: Editor) => Node \| null) \| null` | `null`  | The document a copied reference takes its note from. See [notesDocument](/features/footnotes/api-reference/options#notesdocument) |

### counter

A `counter` takes the document and returns a `Map` from each `footnoteId` to a `NoteMark`,
`{ ordinal, format }`, which the extension spells, so `{ ordinal: 4, format: 'lowerRoman' }` shows
iv. A note missing from the `Map` gets no number. While `counter` is set, `footnoteNumbers`,
`endnoteNumbers` and [numbering breaks](/features/footnotes/numbering#number-again-from-1-in-each-chapter) change
no number.

### scopes

A numbering scope is a part of the document whose notes are numbered from the start and listed
together, such as a chapter. Without `scopes`, the
[numbering breaks](/features/footnotes/numbering#number-again-from-1-in-each-chapter) in the text divide the
scopes.

A `scopes` function replaces them: it takes the document and returns an array of document
positions, one where each scope ends, and each scope's notes are listed before that position.

`scopes` moves only the lists. The numbers follow `counter`, and without it they still start again
at every numbering break. So set `counter` and `scopes` together, or neither.

### repair

The repair pass is the step after each change that keeps notes and references paired, as
[Notes in the document](/features/footnotes/document#how-each-note-stays-with-its-reference) explains. Set
`false` only in an editor that shows something other than the document you save, as Page Layout
does.

### notesDocument

A copied reference carries its note, and `notesDocument` returns the document to take the whole
note from, because pages may show a note twice or cut in two. `null`, from the option or from the
function, means the editor's own document.
