## What you get

A note has two parts: the reference, which is the number in the text, and the note's own text.
The extension adds a node for each of them. A node is one piece of a Tiptap document, such as a
paragraph or an image.

- [Insert and edit notes](/features/footnotes/notes): insert a footnote or an endnote, go from the reference to
  the note and back, turn a footnote into an endnote, and delete a note.
- [Numbering](/features/footnotes/numbering): footnotes numbered 1, 2, 3 and endnotes i, ii, iii, other formats,
  and numbers that start again at 1 in each chapter.
- [Notes in the document](/features/footnotes/document): what the document stores, saving as JSON or HTML, and
  how each note stays with its reference.
- [Styling](/features/footnotes/styling): the stylesheet that shows the numbers, custom properties, and a title
  above the notes.
- [Word documents](/features/footnotes/word): notes pasted from Word, and notes in .docx files.

## A first look

The package comes from Tiptap's private registry. With access to it set up, install the package:

```bash
npm install @tiptap-pro/extension-footnotes
```

With `Footnotes` registered in an editor, this command inserts a footnote at the cursor. It moves
the cursor into the new note, so the user types the note's text next:

```js
editor.chain().focus().insertFootnote({ placement: 'footnote' }).run()
```

[Install Footnotes](/features/footnotes/install) has the registry access and the complete editor around this call.

## Footnotes and endnotes without pages

A Tiptap editor shows the document as one long page, so the extension keeps every note at the end
of the document. The footnotes stand in one numbered list and the endnotes in a second list after
it.

Without pages, a footnote and an endnote differ only in their numbers: 1, 2, 3 for footnotes and
i, ii, iii for endnotes.

[Page Layout](/features/page-layout/getting-started/overview) shows the editor as printed pages. With
it, each footnote is drawn at the foot of the page that refers to it.
[Footnotes in Page Layout](/features/page-layout/extension-behavior/footnotes)
says what else changes.

## What stays the same

You save, undo and share notes like the rest of the document. `getJSON()` holds every reference
and every note, but no numbers, because the extension works them out again each time.
[Notes in the document](/features/footnotes/document) says what is stored.

## Common tasks

| To                                          | Use                                                                                                   |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Insert a footnote                           | [`insertFootnote({ placement: 'footnote' })`](/features/footnotes/notes#insertfootnote)                                |
| Insert an endnote                           | [`insertFootnote({ placement: 'endnote' })`](/features/footnotes/notes#insertfootnote)                                 |
| Insert footnotes when no placement is given | [`defaultPlacement: 'footnote'`](/features/footnotes/api-reference/options)                                            |
| Go from a reference to its note             | [`focusFootnote(footnoteId)`](/features/footnotes/notes#focusfootnote)                                                 |
| Go from a note back to its reference        | [`focusFootnoteReference(footnoteId)`](/features/footnotes/notes#focusfootnotereference)                               |
| Find the note at the cursor                 | [`footnoteAtSelection(editor.state.selection)`](/features/footnotes/notes#find-the-note-at-the-cursor)                 |
| Turn a footnote into an endnote             | [`setFootnotePlacement(footnoteId, 'endnote')`](/features/footnotes/notes#setfootnoteplacement)                        |
| Delete a note and its reference             | [`deleteFootnote(footnoteId)`](/features/footnotes/notes#deletefootnote)                                               |
| Number footnotes a, b, c                    | [`footnoteNumbers: { format: 'lowerAlpha', start: 1 }`](/features/footnotes/numbering#change-the-format-and-the-start) |
| Number notes from 1 again in a chapter      | [`insertNoteNumberingBreak()`](/features/footnotes/numbering#insertnotenumberingbreak)                                 |
| Show the numbers                            | [`mountFootnoteStyles(document)`](/features/footnotes/styling#the-stylesheet)                                          |

## Words these pages use

| Word            | Meaning                                                                                                                                    |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Reference       | The number in the text that points to a note: the `footnoteReference` node                                                                 |
| Note            | The text of a footnote or an endnote: the `footnote` node                                                                                  |
| Placement       | Whether a note is a footnote or an endnote: `'footnote'` or `'endnote'`                                                                    |
| Number          | What marks a note at its reference and at the start of its text, such as 1, iv or \*. Some names in the code call it a mark                |
| Collection      | The numbered list of notes at the end of the document, one for footnotes and one for endnotes: the `footnoteCollection` node               |
| `footnoteId`    | The id that pairs a reference with its note. Commands that act on one note take it                                                         |
| Numbering break | A point in the document after which notes are numbered from the start again. [Numbering](/features/footnotes/numbering#number-again-from-1-in-each-chapter) |
| Numbering scope | The part of the document between two numbering breaks, or the whole document without them                                                  |
