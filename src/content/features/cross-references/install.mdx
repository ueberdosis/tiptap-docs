## Install

Install the package from Tiptap's private registry:

1. Set up Tiptap's private registry, because the package is published there and not on npm.
   Add these lines to the `.npmrc` file in the project's root:

   ```ini
   @tiptap-pro:registry=https://registry.tiptap.dev/
   //registry.tiptap.dev/:_authToken=${TIPTAP_PRO_TOKEN}
   ```

   `TIPTAP_PRO_TOKEN` is an environment variable that holds your registry token, which you find
   in your Tiptap account. Set it in your shell and on your CI, and do not commit the token. The
   [private registry guide](https://tiptap.dev/docs/guides/pro-extensions) has the details.

2. Install the package, and StarterKit for the headings and paragraphs of the example:

   ```bash
   npm install @tiptap-pro/extension-cross-references @tiptap/starter-kit
   ```

The package does not need StarterKit. Any schema works, because you tell the extension which
of your node types are targets.

## A first editor

This editor makes every heading a target, which is a node a reference can point at. It adds
the stylesheet that colors references and types "See " into the empty last paragraph. There it
inserts a reference that reads the title of the heading "Scope of work":

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import {
  CrossReferences,
  crossReferenceTargetsIn,
  mountCrossReferenceStyles,
} from '@tiptap-pro/extension-cross-references'

mountCrossReferenceStyles(document)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, CrossReferences.configure({ targets: { heading: {} } })],
  content: '<h2>Scope of work</h2><p>The Provider builds the website.</p><p></p>',
})

const [scope] = crossReferenceTargetsIn(editor.state.doc, editor.storage.crossReferences)

editor
  .chain()
  .focus('end')
  .insertContent({ type: 'text', text: 'See ' })
  .insertCrossReference({ target: scope.pos, show: 'title' })
  .run()
```

- **`targets: { heading: {} }`** registers headings as targets, with every field of the
  registration at its default. [Registering targets](/features/cross-references/targets#registering-targets) lists
  the fields.
- **`CrossReferences`** brings the reference node, `crossReference`, so you do not add it
  separately. A reference is an inline node that stores the ids of the targets it names.
- **`mountCrossReferenceStyles`** puts the stylesheet into the web page once. It colors
  references and marks the ones that cannot read their target. [Styling](/features/cross-references/styling) has a
  way to load the rules from a stylesheet of your own instead.
- **`crossReferenceTargetsIn`** lists the targets of the document in reading order, each with
  the position where it starts and its id. A picker of yours lists them the same way, see
  [Build a reference picker](/features/cross-references/picker).
- **`insertCrossReference`** inserts the reference at the selection. It takes a target by the
  position where it starts, or by its id.
- **`show: 'title'`** makes the reference read the heading's text. The headings of this
  editor have no numbers, and a reference inserted without `show` reads the full number, so
  it would read `?`. [What a reference shows](/features/cross-references/displays) lists the other choices.

## What you see

The last paragraph reads "See Scope of work", with "Scope of work" in the color of a reference.
Change the heading's text, and the reference changes with it.

When the reference is inserted, the heading gets the id `scope-of-work`, made from its title.
It keeps the id in the attribute `crossReferenceId`, which is saved with the document, so the
reference finds its heading again after a reload.

The demo on the [overview](/features/cross-references) shows the same with numbered clauses.

## What you need

An empty version means any version that installs with the peer dependencies:

| Package                                   | Kind                                           | Version   |
| ----------------------------------------- | ---------------------------------------------- | --------- |
| `@tiptap-pro/extension-cross-references`  | Dependency, from the private registry          |           |
| `@tiptap/core`                            | Peer dependency                                | `^3.29.2` |
| `@tiptap/pm`                              | Peer dependency                                | `^3.29.2` |
| `@tiptap/starter-kit`                     | For the headings and paragraphs of the example |           |
| `@tiptap-pro/extension-outline-numbering` | Optional: numbers for headings and clauses     |           |
