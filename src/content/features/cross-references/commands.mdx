Some commands depend on these options and words:

- **`update`**: with `'live'`, the default, an empty reference follows its targets. With
  `'manual'`, references keep stored text until an update. See
  [Updating references](/features/cross-references/references#updating-references).
- **`holdsText`**: with `false`, a reference never holds text of its own, so the commands that
  write text into references return `false`.
- **Withheld target**: a target a reference points at without showing anything of it, see
  [Withheld targets](/features/cross-references/targets#withheld-targets).
- **Source**: a provider of targets that are not nodes, such as bookmarks, see
  [Sources](/features/cross-references/sources).

## How the commands behave

A command returns `false` and changes nothing when it cannot act. So a toolbar can ask
`editor.can()` and disable a button that would do nothing:

```js
const canReset = editor.can().resetCrossReference()
```

A command that acts on one reference takes the reference's position as an optional argument.
Without it, the command acts on the reference at the cursor: the one the caret is inside, or the one
selected as a whole. A caret right beside a reference finds none.

With [Page Layout](/features/page-layout/getting-started/overview), the commands write the document,
not the pages, see
[Cross-references in Page Layout](/features/page-layout/extension-behavior/cross-references#commands-on-pages).

## Command overview

| Command                                   | What it does                                                |
| ----------------------------------------- | ----------------------------------------------------------- |
| `insertCrossReference(options)`           | Inserts a reference at the selection                        |
| `setCrossReferenceOptions(options, pos?)` | Changes how a reference reads its targets                   |
| `setCrossReferenceShow(pos, show)`        | Changes what one reference shows                            |
| `resetCrossReference(pos?)`               | Gives a reference back to its targets                       |
| `updateCrossReferences()`                 | Writes what the targets say into the references, as F9 does |
| `setCrossReferenceLocked(locked, pos?)`   | Sets whether an update leaves a reference alone             |
| `setCrossReferenceUpdate(update)`         | Switches between live and manual updates                    |
| `convertCrossReferenceToText(pos?)`       | Replaces a reference by the text it reads                   |
| `convertCrossReferencesToText()`          | Replaces every reference by the text it reads               |
| `removeCrossReference(pos?)`              | Takes a reference out of the text                           |
| `goToCrossReferenceTarget(targetId)`      | Puts the caret at a target and scrolls to it                |
| `refreshCrossReferences()`                | Reads every reference again, without writing                |

### insertCrossReference()

Inserts a reference at the selection and replaces what is selected, see
[Inserting a reference](/features/cross-references/references#inserting-a-reference).

```js
editor.commands.insertCrossReference({ target: 'scope-of-work', show: 'title' })
```

`'scope-of-work'` is the id of a heading. `crossReferenceTargetsIn` lists every target with its
position and its id, which is `null` until the first reference to it gives it one, see
[Build a reference picker](/features/cross-references/picker). The command takes an options object:

| Option            | Type                   | Default        | Description                                                                                          |
| ----------------- | ---------------------- | -------------- | ---------------------------------------------------------------------------------------------------- |
| `target`          | `string \| number`     |                | One target, by its id or by the position where it starts. See [Sources](/features/cross-references/sources) for `source:id`  |
| `targets`         | `(string \| number)[]` |                | Several targets, only with `multiple: true`. Wins over `target`. A target named twice is stored once |
| `show`            | `string`               | `'fullNumber'` | What the reference reads. See [What a reference shows](/features/cross-references/displays)                                  |
| `hyperlink`       | `boolean`              | `true`         | Whether the reference can be followed to its target                                                  |
| `aboveBelow`      | `boolean`              | `false`        | Whether `above` or `below` follows the text                                                          |
| `numberSeparator` | `string \| null`       | `null`         | What separates the parts of a number                                                                 |
| `join`            | `string \| null`       | `null`         | How it reads several targets. See [Several targets in one reference](/features/cross-references/joins)                       |

With [`update: 'manual'`](/features/cross-references/references#updating-references), the reference stores what its
targets say from the start, and the caret is placed after it.

Returns `true` when it inserted the reference, and `false` when:

- No target has the id, or the node at the position is not a registered target. See
  [Targets](/features/cross-references/targets).
- The target has no id yet and the extension may not give it one, because the id attribute belongs
  to another extension. See [Using an id another extension defines](/features/cross-references/targets#using-an-id-another-extension-defines).
- No target is named, or several are named without `multiple: true`.
- The selection is not in text, or a reference cannot replace what is selected.

### setCrossReferenceOptions()

Changes how a reference reads its targets. A choice you leave out stays as it is, and text the
reference holds is kept. See [What a reference stores](/features/cross-references/references#what-a-reference-stores).

```js
editor.commands.setCrossReferenceOptions({ show: 'page', aboveBelow: true })
```

The command takes these arguments:

| Argument  | Type     | Description                                                                                                                          |
| --------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `options` | `object` | Any of `show`, `hyperlink`, `aboveBelow`, `numberSeparator` and `join`, and `targetIds` to replace the targets without checking them |
| `pos`     | `number` | Optional. The reference's position, by default the reference at the cursor                                                           |

Returns `false` if there is no reference or nothing changes.

### setCrossReferenceShow()

Sets what the reference at `pos` shows. The position is required:

```js
editor.commands.setCrossReferenceShow(pos, 'title')
```

The command takes these arguments:

| Argument | Type     | Description                                                                 |
| -------- | -------- | --------------------------------------------------------------------------- |
| `pos`    | `number` | The reference's position                                                    |
| `show`   | `string` | What it reads, such as `'title'`. See [What a reference shows](/features/cross-references/displays) |

Returns `false` if there is no reference at `pos` or it shows that already.

### resetCrossReference()

Gives a reference back to its targets, also when it is locked, see
[Resetting a reference](/features/cross-references/references#resetting-a-reference).

```js
editor.commands.resetCrossReference()
```

Takes an optional `pos`. With `holdsText: false`, or in `'manual'` mode for a withheld target, it
empties the reference.

Returns `false` if there is no reference or it already reads what its targets say.

### updateCrossReferences()

Writes what the targets say now into the references, as the F9 key does, which is the key Word
updates its fields with. See
[Updating references](/features/cross-references/references#updating-references).

```js
editor.commands.updateCrossReferences()
```

Takes no arguments.

Returns `false` when no reference changes, and with `holdsText: false`.

### setCrossReferenceLocked()

Sets whether an update leaves a reference alone, see
[Locking a reference](/features/cross-references/references#locking-a-reference).

```js
editor.commands.setCrossReferenceLocked(true)
```

The command takes these arguments:

| Argument | Type      | Description                                                                |
| -------- | --------- | -------------------------------------------------------------------------- |
| `locked` | `boolean` | Whether the reference is locked                                            |
| `pos`    | `number`  | Optional. The reference's position, by default the reference at the cursor |

Returns `false` if there is no reference or it is locked or unlocked already.

### setCrossReferenceUpdate()

Switches the `update` mode of this editor, without changing a reference or the document, see
[Switching the mode while the editor runs](/features/cross-references/references#switching-the-mode-while-the-editor-runs).

```js
editor.commands.setCrossReferenceUpdate('manual')
```

Takes one argument, `'live'` or `'manual'`.

Returns `false` if the mode is that already, and for `'manual'` with `holdsText: false`.

### convertCrossReferenceToText()

Replaces a reference by the words it reads, as plain text, see
[Converting a reference to text](/features/cross-references/references#converting-a-reference-to-text).

```js
editor.commands.convertCrossReferenceToText()
```

Takes an optional `pos`.

Returns `false` when:

- There is no reference, or it names a withheld target.
- The reference is empty and cannot read its targets.
- `holdsText` is `false`.

### convertCrossReferencesToText()

Replaces every reference in the document by the words it reads, see
[Converting a reference to text](/features/cross-references/references#converting-a-reference-to-text).

```js
editor.commands.convertCrossReferencesToText()
```

Takes no arguments.

Returns `false` when there is nothing to convert, and with `holdsText: false`.

### removeCrossReference()

Takes a reference out of the text, with whatever it holds, and scrolls the selection into view.

```js
editor.commands.removeCrossReference()
```

Takes an optional `pos`.

Returns `false` when there is no reference.

### goToCrossReferenceTarget()

Puts the caret at the start of a target's text and scrolls to it, see
[Going to the target](/features/cross-references/references#going-to-the-target). It does not focus the editor:

```js
editor.view.focus()
editor.commands.goToCrossReferenceTarget('payment')
```

Takes one argument, the target's id as a reference stores it, `source:id` for a target of a source.

Returns `false` for an id no target carries, and for a target outside the document.

### refreshCrossReferences()

Reads every reference again and writes nothing, for when data behind targets changed outside the
document. See [Refreshing the references](/features/cross-references/sources#refreshing-the-references).

```js
editor.commands.refreshCrossReferences()
```

Takes no arguments. Returns `true`.

## Writing without a command

Each command that writes the document has a function that returns the transaction instead of
dispatching it, or `null` where the command returns `false`. Use one in a transaction of your own or
on a server. This example resets the reference at the cursor:

```js
import {
  crossReferenceAround,
  resetCrossReferenceTransaction,
} from '@tiptap-pro/extension-cross-references'

const { state } = editor
const reference = crossReferenceAround(state.doc, state.selection.from, state.selection.to)
const tr =
  reference && resetCrossReferenceTransaction(state, editor.storage.crossReferences, reference.pos)

if (tr) {
  editor.view.dispatch(tr)
}
```

The functions need the reference's position, such as the one `crossReferenceAround` returns. A
position that is not the start of a reference makes them return `null`. `registration` is your
configuration of the extension, `editor.storage.crossReferences` in an editor (see
[The registration](/features/cross-references/reading#the-registration)):

| Command                        | Function                                  | Arguments                       |
| ------------------------------ | ----------------------------------------- | ------------------------------- |
| `insertCrossReference`         | `insertCrossReferenceTransaction`         | `state, registration, options`  |
| `setCrossReferenceOptions`     | `setCrossReferenceOptionsTransaction`     | `state, pos, options`           |
| `setCrossReferenceShow`        | `setCrossReferenceShowTransaction`        | `state, pos, show`              |
| `resetCrossReference`          | `resetCrossReferenceTransaction`          | `state, registration, pos`      |
| `updateCrossReferences`        | `updateCrossReferencesTransaction`        | `state, registration`           |
| `setCrossReferenceLocked`      | `setCrossReferenceLockedTransaction`      | `state, pos, locked`            |
| `convertCrossReferenceToText`  | `convertCrossReferenceToTextTransaction`  | `state, registration, pos`      |
| `convertCrossReferencesToText` | `convertCrossReferencesToTextTransaction` | `state, registration`           |
| `removeCrossReference`         | `removeCrossReferenceTransaction`         | `state, pos`                    |
| `goToCrossReferenceTarget`     | `goToCrossReferenceTargetTransaction`     | `state, registration, targetId` |

Without an editor, `registration` is any object with `targets`. The other fields default to
`update: 'live'`, `holdsText: true`, `assignsIds: true`, the default phrases with `pageOf: null` in
`labels`, and `createId: newTargetId`. `createId(title, taken)` makes the id a target without one
gets, where `taken` is the set of ids already in the document.
