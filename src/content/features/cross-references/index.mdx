## What you get

The extension adds the reference, an inline node, to your editor. It takes its targets from the
node types you already have:

- **References that stay right.** A reference stores which target it names, and reads that
  target's number, title or page each time the document changes. See [References](/features/cross-references/references).
- **Targets from your own schema.** Headings, numbered list items, footnotes or any other node
  type you register. A target's number comes from code that counts, such as Outline numbering.
  See [Targets](/features/cross-references/targets).
- **The choices of Word's cross-reference dialog.** A reference reads the number, the full
  number, the title, the page, or whether the target comes above or below. What it reads is
  called its display, and you can add displays of your own. See
  [What a reference shows](/features/cross-references/displays).
- **Several targets in one reference**, read as `3, 5 and 7` or `3–5 and 7`. See
  [Several targets in one reference](/features/cross-references/joins).
- **Targets that are not nodes**, such as bookmarks, statutes or clauses in another document.
  See [Sources](/features/cross-references/sources).
- **Word fields.** A reference translates to and from the `REF`, `PAGEREF` and `NOTEREF` fields
  of a .docx file. See [Word fields](/features/cross-references/docx).

## A first look

Install the package from Tiptap's private registry, which needs a token (see
[Install Cross-references](/features/cross-references/install#install)):

```bash
npm install @tiptap-pro/extension-cross-references
```

Add `CrossReferences` to the editor with the node types that are targets, put its stylesheet into
the page, and insert a reference at the selection. `pos` stands for the position where a heading
starts:

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { CrossReferences, mountCrossReferenceStyles } from '@tiptap-pro/extension-cross-references'

mountCrossReferenceStyles(document)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [StarterKit, CrossReferences.configure({ targets: { heading: {} } })],
})

editor.commands.insertCrossReference({ target: pos, show: 'title' })
```

[Install Cross-references](/features/cross-references/install#a-first-editor) has the complete example, with content and
the position of a heading.

## What stays the same, and what changes

A reference is an inline node in the document, and you save it with `getJSON()` or `getHTML()`
like the rest of the content. It stores the ids of its targets, not their numbers. A target
keeps its id in the attribute `crossReferenceId`, which the extension adds to the node types you
register.

The number, title or page a reference shows is drawn each time the document changes. So the
stored document stays the same when a number changes, and two people editing it do not overwrite
each other's references.

With [Page Layout](/features/page-layout/getting-started/overview), Tiptap's extension that shows a
document on pages, a reference can also read the page its target is drawn on. See
[Cross-references in Page Layout](/features/page-layout/extension-behavior/cross-references).

## Common tasks

Options go into `CrossReferences.configure()`, see [Options](/features/cross-references/options):

| Task                                    | How                                                                         | Page                                                 |
| --------------------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------- |
| Make headings targets                   | `CrossReferences.configure({ targets: { heading: {} } })`                   | [Targets](/features/cross-references/targets#registering-targets)            |
| Number the headings                     | A `label` function in `targets.heading`, from Outline numbering             | [Targets](/features/cross-references/targets#numbering-targets)              |
| Insert a reference                      | `editor.commands.insertCrossReference({ target: pos, show: 'fullNumber' })` | [References](/features/cross-references/references#inserting-a-reference)    |
| Show the title, the page or above/below | `show: 'title'`, `'page'` or `'aboveBelow'`                                 | [What a reference shows](/features/cross-references/displays)                |
| List the targets for a picker           | `crossReferenceTargetsIn(editor.state.doc, editor.storage.crossReferences)` | [Build a reference picker](/features/cross-references/picker)                |
| Refer to several targets at once        | Option `multiple: true`, then `insertCrossReference({ targets: [...] })`    | [Several targets in one reference](/features/cross-references/joins)         |
| Refer to footnotes                      | `targets.footnote` with `idAttribute: 'footnoteId'`                         | [Targets](/features/cross-references/targets#footnotes-as-targets)           |
| Go to the target on Cmd/Ctrl+click      | The `reveal` option                                                         | [References](/features/cross-references/references#going-to-the-target)      |
| Update only on F9, as Word's fields do  | Option `update: 'manual'`, then `editor.commands.updateCrossReferences()`   | [References](/features/cross-references/references#updating-references)      |
| Change the color of references          | `--tt-cross-reference-color`                                                | [Styling](/features/cross-references/styling)                                |
| Find references whose target is gone    | `crossReferenceLabelsIn`, then `unresolved === 'target'`                    | [Reading the document](/features/cross-references/reading#broken-references) |
| Refer to a bookmark                     | A source with `inBlock`                                                     | [Sources](/features/cross-references/sources#inside-the-document)            |
| Export to Word                          | `crossReferenceToFields`                                                    | [Word fields](/features/cross-references/docx#export)                        |

## Words these pages use

| Word         | Meaning                                                                                      |
| ------------ | -------------------------------------------------------------------------------------------- |
| Target       | What a reference points at: a node of a type you register, or a target of a source           |
| Reference    | The inline node `crossReference`, which names one or more targets by id                      |
| Display      | What a reference reads of its target, set by its `show` attribute, such as `title`           |
| Label        | A target's number, as the `label` function of its registration returns it                    |
| Join         | The rule a reference reads several targets by, such as `3, 5 and 7`                          |
| Source       | A provider of targets that are not nodes, such as bookmarks                                  |
| Registration | Your `targets`, `sources` and other options, as `editor.storage.crossReferences` holds them  |
| Unresolved   | A reference with nothing to show, which reads `?`                                            |
| Withheld     | A target a reference points at without showing anything of it, such as a confidential clause |
