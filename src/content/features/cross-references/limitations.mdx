## Pasting a cross-reference from Word

A cross-reference pasted from Word is plain text, the text Word last showed for it, because the
extension reads a reference only from its own HTML. To keep Word's references, import the .docx file
and translate its fields, as [Word fields](/features/cross-references/docx#import) describes.

## Reading or writing a .docx file

The extension does not read or write .docx files. Its Word fields helpers translate one field at a
time, and the converter that reads or writes the file places the bookmarks. See
[Word fields](/features/cross-references/docx).

## Joining several Word fields into one reference

Several fields imported from Word stay several references, even when they stand side by side as in
`3, 5 and 7`. Joining them into one reference with several targets is the importer's job. See
[Several targets in one reference](/features/cross-references/joins).

## Referring to captions and equations

Captions and equations are targets only once your schema has a node type for them, which you then
register like any other. See [Registering targets](/features/cross-references/targets#registering-targets).

## Converting a reference whose target is gone

An empty reference whose target is gone stays a reference when references are converted to text, so
nothing turns into a `?`. Delete it or point it at another target first. See
[Converting a reference to text](/features/cross-references/references#converting-a-reference-to-text).

## Showing the page or place of a target outside the document

A target a source resolves from outside the document, such as a statute, has no page and no
position. So `show: 'page'` reads `?` for it, `aboveBelow` adds nothing, and its number is written
whole. See [Sources](/features/cross-references/sources).

## Seeing a source's data change

The editor does not see a change to the data behind a source's targets. Call
[`refreshCrossReferences()`](/features/cross-references/commands#refreshcrossreferences) after the data changed.

## Showing the page a target is on

Without pages, `show: 'page'` reads `?`. With [Page Layout](/features/page-layout/getting-started/overview),
a reference reads the page its target is drawn on, see
[Cross-references in Page Layout](/features/page-layout/extension-behavior/cross-references).
