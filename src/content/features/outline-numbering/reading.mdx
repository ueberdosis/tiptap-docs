## Every number

`outlineNumbersIn(doc, registry)` returns every number in the document, in reading order. The
registry is `editor.storage.outlineNumbering`:

```js
import { outlineNumbersIn } from '@tiptap-pro/extension-outline-numbering'

const contents = outlineNumbersIn(editor.state.doc, editor.storage.outlineNumbering).map(
  ({ pos, level, label, node }) => ({ pos, level, label, text: node.textContent }),
)
```

Each item is an `OutlineNumber`:

| Field       | Type                   | Description                                                                                   |
| ----------- | ---------------------- | --------------------------------------------------------------------------------------------- |
| `node`      | `Node`                 | The numbered node                                                                             |
| `pos`       | `number`               | Where it starts                                                                               |
| `level`     | `number`               | Its level                                                                                     |
| `counts`    | `number[]`             | The count at each level down to its own, the outermost first, such as `[1, 1, 2]` for `1.1.2` |
| `label`     | `string`               | The number it shows, such as `(a)`                                                            |
| `fullLabel` | `string`               | The number that names it from anywhere, such as `1.01(a)`                                     |
| `marker`    | `'inline' \| 'gutter'` | Where its type draws the number                                                               |

A level whose template is `''` is in the list too, with the `label` `''`.

## The number at a position

`outlineNumberAt(doc, registry, pos)` returns the `OutlineNumber` of the node that starts at
`pos`, or `null` where no numbered node starts:

```js
import { outlineNumberAt } from '@tiptap-pro/extension-outline-numbering'

const number = outlineNumberAt(editor.state.doc, editor.storage.outlineNumbering, pos)
```

`pos` stands for a position of your own, such as one from `outlineNumbersIn`.

## The registry

`editor.storage.outlineNumbering` holds the options the numbers depend on: `types`, `levels`,
`ignore`, `lookupOf` and `skippedLevel`. `OutlineNumberingStorage` and `OutlineRegistry` are its
types. Both functions count a document once per registry, so asking again for the same document
costs nothing.

`outlineLevelOf(types, node, context?)` returns what a node's registration in `types` says: a
level, `'nested'`, or `null` for a type that is not registered and for a node that is not
numbered. Pass `{ ancestors }`, the nodes that contain it, as `context` when its `level`
function reads them.

## When a number changes without an edit

The numbers are counted again whenever the document changes. When your `level` or `ignore`
function returns something else for another reason, such as a setting outside the document, count
them again with [refreshOutlineNumbers()](/features/outline-numbering/reading#refreshoutlinenumbers).

### refreshOutlineNumbers()

Counts the numbers again with the document unchanged.

```js
editor.commands.refreshOutlineNumbers()
```

Takes no arguments, and returns `true`. The same in a transaction of your own is the meta
`tr.setMeta(outlineLabelsKey, 'refresh')`, where `outlineLabelsKey` is a `PluginKey` the package
exports.
