## What you get

The `OutlineNumbering` extension numbers the node types you register, such as StarterKit's
heading. A node is one block of a Tiptap document, such as a paragraph or a heading.

- [Levels and templates](/features/outline-numbering/levels): numbers such as `1.1.1`, `Article I` or `(a)`, from a template
  per level or from one of Word's numbering schemes.
- [Lists as clauses](/features/outline-numbering/clauses): items of a numbered list that go on from the heading before them,
  as `(a)`, `(b)` under `Section 1.01`.
- [A scheme stored in the document](/features/outline-numbering/scheme): a numbering the document carries along, so
  collaborators and other editors with the extension draw the same numbers, and the user can
  switch it.
- [Choose what is numbered](/features/outline-numbering/what-is-numbered): other node types, paragraphs numbered by their
  style, and nodes left out.
- [Numbers in the editor](/features/outline-numbering/display): how the numbers are drawn and styled, and what deleting,
  copying and pasting a numbered heading do.
- [Reading the numbers](/features/outline-numbering/reading): every heading with its number, for a table of contents.

## A first look

The package comes from Tiptap's private registry, which
[Install outline numbering](/features/outline-numbering/install#install) sets up. Then install it:

```bash
npm install @tiptap-pro/extension-outline-numbering
```

The code below registers StarterKit's heading, whose level is in `node.attrs.level`, and numbers the
headings with Word's legal scheme. `mountOutlineStyles` adds the CSS that draws the numbers:

```js
import {
  mountOutlineStyles,
  OUTLINE_PRESETS,
  OutlineNumbering,
} from '@tiptap-pro/extension-outline-numbering'

mountOutlineStyles(document)

const outlineNumbering = OutlineNumbering.configure({
  types: { heading: { level: node => node.attrs.level } },
  levels: OUTLINE_PRESETS.legal,
})
```

Put `outlineNumbering` into your editor's `extensions` beside StarterKit. The headings then read
`Article I.`, `Section 1.01` and `(a)`. [Install outline numbering](/features/outline-numbering/install) has the registry
access and the complete editor.

## What stays the same

The numbers are not part of the document. The extension works them out from the headings
whenever the document changes, and CSS draws them. So `getJSON()` and `getHTML()` hold no numbers,
and you save, undo and share a document as before.

The document stores only what the user chose. `OutlineScheme` is a second extension you can
register. With it, a numbering scheme the user picks is stored in one hidden node at the end of
the document, so it travels with the document.

A list of clauses stores one attribute, `outlineList`, on the list. The scheme and that attribute change through
commands, so the user can undo them.

## With Page Layout

The extension works in any Tiptap editor, with or without Page Layout. On pages, a list of
clauses cut by a page boundary goes on counting on the next page, and a heading cut in two keeps
one number.
[Outline numbering in Page Layout](/features/page-layout/extension-behavior/outline-numbering)
says what changes there.

## Common tasks

| To                                            | Use                                                                                              |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Number StarterKit's headings                  | [`types: { heading: { level: node => node.attrs.level } }`](/features/outline-numbering/install#the-complete-example)     |
| Draw the numbers                              | [`mountOutlineStyles(document)`](/features/outline-numbering/display#the-stylesheet)                                      |
| Number as `Article I`, `Section 1.01`, `(a)`  | [`levels: OUTLINE_PRESETS.legal`](/features/outline-numbering/levels#words-numbering-schemes)                             |
| Write a numbering of your own                 | [`levels: ['Chapter {1}', '{1}.{2:a}']`](/features/outline-numbering/levels#templates)                                    |
| Number list items as clauses                  | [`lists: ['orderedList']` and `listItem: outlineListItem`](/features/outline-numbering/clauses#set-up)                    |
| Make the list at the cursor a list of clauses | [`editor.commands.setOutlineList(true)`](/features/outline-numbering/clauses#setoutlinelist)                              |
| Store the scheme in the document              | [`OutlineScheme` and `editor.commands.setOutlineLevels(levels)`](/features/outline-numbering/scheme#setoutlinelevels)     |
| Change one level of the stored scheme         | [`editor.commands.setOutlineLevel(2, 'Section {1}.{2:01}')`](/features/outline-numbering/scheme#setoutlinelevel)          |
| Leave headings in a blockquote unnumbered     | [`ignore: node => node.type.name === 'blockquote'`](/features/outline-numbering/what-is-numbered#leaving-nodes-out)       |
| List every heading with its number            | [`outlineNumbersIn(editor.state.doc, editor.storage.outlineNumbering)`](/features/outline-numbering/reading#every-number) |

## Words these pages use

| Word        | Meaning                                                                                                     |
| ----------- | ----------------------------------------------------------------------------------------------------------- |
| Level       | How deep a heading sits in the outline. `1` is the outermost, such as an article above its sections         |
| Template    | The text a level's number is written from, such as `'Section {1}.{2:01}'`. [Templates](/features/outline-numbering/levels#templates) |
| Scheme      | The templates of all levels together, such as `OUTLINE_PRESETS.legal`. [Scheme](/features/outline-numbering/scheme)                  |
| Label       | The number a heading shows, such as `(a)`                                                                   |
| Full number | The number that names a heading from anywhere in the document, such as `1.01(a)`                            |
| Clause      | An item of a numbered list that belongs to the outline. [Lists as clauses](/features/outline-numbering/clauses)                      |
| Gutter      | The margin before a node, where a clause's number is drawn                                                  |
