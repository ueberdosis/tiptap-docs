This configuration numbers headings and clauses with Word's legal scheme:

```js
import {
  OUTLINE_PRESETS,
  OutlineNumbering,
  outlineListItem,
} from '@tiptap-pro/extension-outline-numbering'

OutlineNumbering.configure({
  types: {
    heading: { level: node => node.attrs.level },
    listItem: outlineListItem,
  },
  levels: OUTLINE_PRESETS.legal,
  lists: ['orderedList'],
})
```

| Option         | Type                                    | Default  | Description                                                                                                    |
| -------------- | --------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------- |
| `types`        | `OutlineTypes`                          | `{}`     | The node types that carry a number. See [Choose what is numbered](/features/outline-numbering/what-is-numbered)                         |
| `levels`       | `OutlineLevel[]`                        | `[]`     | A template per level. See [Levels and templates](/features/outline-numbering/levels)                                                    |
| `skippedLevel` | `'zero' \| 'zeroEverywhere' \| 'first'` | `'zero'` | What a skipped level reads. See [Skipped levels](/features/outline-numbering/levels#skipped-levels)                                     |
| `lists`        | `string[]`                              | `[]`     | The list types that can hold clauses. See [Lists as clauses](/features/outline-numbering/clauses)                                       |
| `ignore`       | `OutlineIgnore \| null`                 | `null`   | Nodes left out of the numbering. See [Leaving nodes out](/features/outline-numbering/what-is-numbered#leaving-nodes-out)                |
| `lookupOf`     | `((doc) => object \| null) \| null`     | `null`   | What `level` functions read besides the node. See [Numbering by style](/features/outline-numbering/what-is-numbered#numbering-by-style) |

`OutlineNumberingOptions` is the type of the options, and `OutlineSkippedLevel` the type of
`skippedLevel`.
