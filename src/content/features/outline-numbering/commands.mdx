Outline numbering has four commands. Each one can be chained, and `editor.can()` tells whether it
can run. A command that cannot run returns `false` and changes nothing. Two cases throw an error
instead:

- `setOutlineLevel` on a stored scheme with a level that is not a template. See
  [Limitations](/features/outline-numbering/limitations#setoutlinelevel-on-a-scheme-with-a-broken-level).
- `setOutlineLevels` or `setOutlineLevel` storing a first scheme where no block at the end of the
  document can hold it.

The Needs column names what the command needs besides `OutlineNumbering`. `OutlineScheme` is an
extension you register beside it, which stores a scheme, the templates of all levels, in the
document. `lists` is the option that names the list types whose items can be clauses: list items
numbered as part of the outline, such as `(a)`, `(b)`. `setOutlineList(true)` makes the list at
the cursor such a list, and `false` makes it a plain list again.

| Command                            | What it does                                          | Needs           | Described in                                                |
| ---------------------------------- | ----------------------------------------------------- | --------------- | ----------------------------------------------------------- |
| `setOutlineLevels(levels)`         | Stores a scheme in the document, or removes it        | `OutlineScheme` | [setOutlineLevels()](/features/outline-numbering/scheme#setoutlinelevels)            |
| `setOutlineLevel(level, template)` | Stores one level of the document's scheme             | `OutlineScheme` | [setOutlineLevel()](/features/outline-numbering/scheme#setoutlinelevel)              |
| `setOutlineList(linked)`           | Makes the list around the selection a list of clauses | `lists`         | [setOutlineList()](/features/outline-numbering/clauses#setoutlinelist)               |
| `refreshOutlineNumbers()`          | Counts the numbers again with the document unchanged  | nothing         | [refreshOutlineNumbers()](/features/outline-numbering/reading#refreshoutlinenumbers) |

For example, a toolbar offers a Clauses button only where it would act. `editor` is the editor of
the [complete example](/features/outline-numbering/install#the-complete-example):

```js
const canLink = editor.can().setOutlineList(true)
```

`setOutlineLevels`, `setOutlineLevel` and `setOutlineList` change the document, so the user can
undo them. `refreshOutlineNumbers` changes only how the numbers are drawn.
