## Templates

`levels` is an array of templates, the first for level 1. In a template, `{n}` is the count at
level `n`, and everything else is text:

```js
import { OutlineNumbering } from '@tiptap-pro/extension-outline-numbering'

OutlineNumbering.configure({
  types: { heading: { level: node => node.attrs.level } },
  levels: ['Article {1:I}', 'Section {1}.{2:01}'],
})
```

The headings of level 1 then read `Article I`, `Article II`, and the level-2 headings under the
first read `Section 1.01`, `Section 1.02`. This builds on the
[complete example](/features/outline-numbering/install#the-complete-example).

- **A level past the end of `levels`** reads `{1}.{2}…` down to its own level. Without `levels`,
  headings read `1`, `1.1`, `1.1.1`.
- **A template `''`** draws no number for its level. Its headings still count.

## Placeholders

A format after a colon writes the count in another form:

| Placeholder       | Reads                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| `{2}` or `{2:1}`  | `1`, `2`, `3`                                                                                            |
| `{2:01}`          | `01`, `02`, … `10`                                                                                       |
| `{2:a}` / `{2:A}` | `a`, `b`, … `z`, `aa` / `A`, `B`, …                                                                      |
| `{2:i}` / `{2:I}` | `i`, `ii`, `iii` / `I`, `II`, `III`                                                                      |
| `{2:*}`           | `*`, `†`, `‡`, `§`, `**`, …                                                                              |
| `{2:lowerGreek}`  | Any [number format](/features/number-formats) by its name, one you defined included |

A placeholder that names a format neither your code nor the document defines, such as
`{2:clause}`, is written as it stands until one does.
[Number formats](/features/number-formats) says how to define a format, in
your code or in the document.

## A label and a full number

A level can be an object instead of a string. Its `label` is the number the heading shows, and
its `full` number names the heading from anywhere else in the document, such as in a
cross-reference that reads "see 1.01(a)":

```js
OutlineNumbering.configure({
  types: { heading: { level: node => node.attrs.level } },
  levels: ['Article {1:I}', 'Section {1}.{2:01}', { label: '({3:a})', full: '{1}.{2:01}({3:a})' }],
})
```

A level-3 heading then shows `(a)`, and its full number is `1.01(a)`. Without `full`, the full
number is the label. `OutlineLevel` is the type of a level: a string, or `{ label, full? }`.

## Word's numbering schemes

`OUTLINE_PRESETS` has the schemes of Word's _Outline Numbered_ gallery and `headings`, the
default, as a choice for a picker. Each has nine levels and is ready to pass as `levels`:

```js
import { OUTLINE_PRESETS, OutlineNumbering } from '@tiptap-pro/extension-outline-numbering'

OutlineNumbering.configure({
  types: { heading: { level: node => node.attrs.level } },
  levels: OUTLINE_PRESETS.legal,
})
```

| Preset          | Levels read                                                   |
| --------------- | ------------------------------------------------------------- |
| `parenthesized` | `1)`, `a)`, `i)`, then `(1)`, `(a)`, `(i)`, `1.`, `a.`, `i.`  |
| `decimal`       | `1.`, `1.1.`, `1.1.1.`                                        |
| `bullets`       | `❖`, `➢`, `▪`, then `●`, `◆`, `■`                             |
| `legal`         | `Article I.`, `Section 1.01`, `(a)`, then `(i)`, `(A)`, `(1)` |
| `headings`      | `1`, `1.1`, `1.1.1`: the same as no `levels`                  |
| `outline`       | `I.`, `A.`, `1.`, then `a)`, `(1)`, `(a)`, `(i)`              |
| `chapter`       | `Chapter 1`, and no number below it                           |

- **`legal`** gives a level-3 heading the full number `1.01(a)`.
- **A preset is an array**, so a scheme of your own can start from one:
  `[...OUTLINE_PRESETS.decimal.slice(0, 2), '{1}.{2}.{3:a}']`.
- **`OutlinePreset`** is the type of a preset's name, such as `'legal'`.

## Counting

A heading's count is the number of headings of its level since the last heading of an outer
level. So level 2 starts again at `1` under each new level-1 heading. Headings inside other
blocks, such as a blockquote or a list, count where they stand.

### Skipped levels

A level is skipped when a heading goes more than one level down, such as a level-3 heading
directly under a level 1. The `skippedLevel` option says what the skipped level reads, and
`'zero'` is the default:

| `skippedLevel`     | Headings at levels 1, 3, 2 read | A document that starts at level 2 reads |
| ------------------ | ------------------------------- | --------------------------------------- |
| `'zero'`           | `1`, `1.0.1`, `1.1`             | `1.1`, `1.2`, then `2`                  |
| `'zeroEverywhere'` | `1`, `1.0.1`, `1.1`             | `0.1`, `0.2`, then `1`                  |
| `'first'`          | `1`, `1.1.1`, `1.2`             | `1.1`, `1.2`, then `2`                  |

- **`'zero'`** writes `0` for a skipped level, except before the first number of a document,
  where the skipped levels count as their first.
- **`'zeroEverywhere'`** writes `0` there too, as Word does.
- **`'first'`** counts a skipped level as its first everywhere.
- **Cutting a heading and keeping the headings under it** skips a level. With `'zero'` and
  `'zeroEverywhere'`, the next heading of the cut heading's level takes its number.
- **The `0`** is padded in a format of digits, as in `1.00(a)`, and is the digit `0` in a format
  of letters or Roman numerals.

`OutlineSkippedLevel` is the type of the option.
