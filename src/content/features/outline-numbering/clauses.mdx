With Word's legal scheme, the items under `Section 1.01` read `(a)`, `(b)`, and an item indented
under `(b)` reads `(i)`.

## Set up

Name the list types that can hold clauses in the `lists` option, and register the list item as
`outlineListItem`. This builds on the [complete example](/features/outline-numbering/install#the-complete-example):

```js
import {
  OUTLINE_PRESETS,
  OutlineNumbering,
  outlineListItem,
} from '@tiptap-pro/extension-outline-numbering'

OutlineNumbering.configure({
  types: {
    heading: { level: node => node.attrs.level },
    listItem: outlineListItem,
  },
  lists: ['orderedList'],
  levels: OUTLINE_PRESETS.legal,
})
```

A list is then a list of clauses when its `outlineList` attribute is `true`. The user sets it with
[setOutlineList()](/features/outline-numbering/clauses#setoutlinelist), and content you load can hold it, as
[In HTML](/features/outline-numbering/clauses#in-html) shows.

- **`lists`** gives each of these list types a boolean `outlineList` attribute.
  `OUTLINE_LIST_ATTRIBUTE` is `'outlineList'`.
- **`outlineListItem`** numbers an item when its list has `outlineList`, draws the number in the
  gutter, the margin before the item, and leaves the items of other lists unnumbered.
- **A list type that is not in `lists`**, such as a bullet list inside a clause, stays as it is.
- **The setting is on the outermost list.** The lists inside it count as part of it, so an item
  the user indents with Tab is a clause too.

## In HTML

A list of clauses has the attribute `data-tt-outline-list`:

```html
<h2>Late payment</h2>
<ol data-tt-outline-list>
  <li><p>charge interest on the overdue amount; and</p></li>
  <li><p>suspend the services after giving notice.</p></li>
</ol>
```

## setOutlineList()

Makes the list around the selection a list of clauses, or a plain list again.

```js
editor.commands.setOutlineList(true)
editor.commands.setOutlineList(false)
```

| Argument | Type      | Description                             |
| -------- | --------- | --------------------------------------- |
| `linked` | `boolean` | Whether the list belongs to the outline |

The command sets the attribute on the outermost list of one of the `lists` types around the
selection, and clears it on the lists inside.

Returns `false` when the selection is not in a list of one of the `lists` types. So
`editor.can().setOutlineList(true)` tells a toolbar whether to offer the button.

## How clauses count

Clauses count together with the headings, in document order, with one count per level:

- **`(a)` starts again** under each heading of an outer level.
- **A second list under the same heading** goes on with `(c)` where the first stopped at `(b)`.
- **A level-3 heading after the clauses `(a)` and `(b)`** reads `(c)` with `legal`.
- **A list directly under a level-1 heading** is numbered at level 2. With `legal`, its items
  read `Section 1.01`, `Section 1.02`.

## How a clause is drawn

The number of a clause stands in the gutter, and the list's own marker is not drawn. The number
is no part of a line, so a label growing from `(vii)` to `(viii)` moves no text.

The list is indented by `--tt-outline-list-indent`, `2.5em` by default, to make room for the
number. A stylesheet of yours that sets the list's `padding-inline-start` more specifically wins.

## Read the list

A toolbar button that shows whether the list at the cursor is a list of clauses reads it with
`outlineListAt`:

```js
import { outlineListAt } from '@tiptap-pro/extension-outline-numbering'

const list = outlineListAt(editor.state.doc, editor.state.selection.from)
const isClauses = list?.linked ?? false
```

| Function                    | Arguments         | Returns                                                                                                             |
| --------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------- |
| `outlineListAt`             | `doc`, `pos`      | The outermost list of a `lists` type around `pos`, as `{ pos, node, linked }` (`OutlineListAt`), or `null`          |
| `setOutlineListTransaction` | `state`, `linked` | A transaction that does what `setOutlineList` does, for you to dispatch, or `null` outside a list of a `lists` type |

`linked` is `true` when the list belongs to the outline.
