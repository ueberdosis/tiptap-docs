## Install

The package is on Tiptap's private registry:

1. Set up access to the registry, as
   [The Pro registry](/features/page-layout/getting-started/install#the-pro-registry)
   describes.
2. Install the package:

```bash
npm install @tiptap-pro/extension-outline-numbering
```

The example also uses `@tiptap/starter-kit`. Install it too if your editor does not have it yet.

## The complete example

The extension numbers only the node types you register in `types`. StarterKit's heading keeps
its level in `node.attrs.level`, so the heading's entry reads it from there. `mountOutlineStyles`
adds the CSS that draws the numbers. Your page needs an element with the id `editor`:

```js
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { mountOutlineStyles, OutlineNumbering } from '@tiptap-pro/extension-outline-numbering'

mountOutlineStyles(document)

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    OutlineNumbering.configure({
      types: {
        heading: { level: node => node.attrs.level },
      },
    }),
  ],
  content: '<h1>Scope</h1><h2>Services</h2><h2>Fees</h2><h1>Term</h1>',
})
```

## What you see

The headings read `1 Scope`, `1.1 Services`, `1.2 Fees` and `2 Term`. When you insert a heading
between two others, the ones after it count on. Without `mountOutlineStyles`, the numbers are
counted but not drawn.

## What you need

| Package                                   | Kind                                             |
| ----------------------------------------- | ------------------------------------------------ |
| `@tiptap-pro/extension-outline-numbering` | The extension, from the private registry         |
| `@tiptap/core`, `@tiptap/pm`              | Peer dependencies, version 3.29.2 or a later 3.x |
| `@tiptap-pro/extension-number-formats`    | Dependency, installed with the extension         |

[Number formats](/features/number-formats) writes the counts, such as `IV`
or `01`.
