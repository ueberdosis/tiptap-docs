Slots are one of three parts of Composable Docs. [Variables](/composable-docs/variables/getting-started/overview) display values in the document and can stay in sync with Slots. [Content Protection](/composable-docs/content-protection/getting-started/overview) controls who may edit what around them.

<Callout title="Client-side only" variant="info">
  Slots currently work only client-side. If you're interested in filling slots on the server,
  [contact us](https://tiptap.dev/contact-sales?form=pilot-program).
</Callout>

## What you can do with it

- **Add fields to a document.** Insert block or inline Slots, configure them, fill them, and dissolve them again. [Add slots to the document](/composable-docs/slots/guides/add-slots)
- **Let users fill only the fields.** Protect everything outside the Slots with [Content Protection](/composable-docs/content-protection/getting-started/overview) and assign Slots by role. [Allow filling only](/composable-docs/slots/guides/fill-only)
- **Check what users entered.** Validate Slot values with built-in and custom rules, for example before saving. [Validate Slot values](/composable-docs/slots/guides/validate-submission)
- **Build fields into tables.** Fill table cells as fields while headers and columns stay fixed. [Table fields example](/composable-docs/slots/examples/table-fields)
- **Fill Slots from your application.** Commands insert, wrap, and fill Slots. [Commands](/composable-docs/slots/api-reference/commands)
- **Read the values.** `createSlotSnapshot()` and `getSlots()` return every Slot and its content. [Utilities](/composable-docs/slots/api-reference/utilities)
- **React to changes.** Events report updated Slots, the active Slot, and validation results. [Editor events](/composable-docs/slots/api-reference/events)
- **Render Slots your way.** Change their markup or use your own NodeViews. [Styling](/composable-docs/slots/api-reference/rendering)
- **Use one value in several places.** Bind Slots to a Variable. [Bind slots to variables](/composable-docs/variables/guides/bind-slots)

## Get started

1. [Contact our team](https://tiptap.dev/contact-sales?form=pilot-program) to join the Composable Docs pilot program.
2. Set up access to Tiptap's private npm registry with the [setup guide](/guides/pro-extensions).
3. Install the package:

```bash
npm install @tiptap/core @tiptap/starter-kit @tiptap-pro/extension-slot
```

4. Add the extension and pass a document with a Slot, or let users create them:

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Slot } from '@tiptap-pro/extension-slot'

const editor = new Editor({
  extensions: [StarterKit, Slot],
  content: {
    type: 'doc',
    content: [
      {
        type: 'blockSlot',
        attrs: {
          id: 'summary',
          config: { label: 'Summary', required: true },
        },
        content: [{ type: 'paragraph' }],
      },
    ],
  },
})
```
