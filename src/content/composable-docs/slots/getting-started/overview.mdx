With **Slots**, you can define editable fields inside your Tiptap documents. Turn your documents into templates and forms that users can fill.

Slots are placeholders for any Tiptap content, but you can also define validation rules and restrict who can edit them, and how.

## Install

First, [contact our team](https://tiptap.dev/contact-sales?form=pilot-program) to join the Tiptap Composable Docs pilot program.

Then, configure your package manager by following the [private registry guide](/guides/pro-extensions).

Then, install the package:

```bash
npm install @tiptap-pro/extension-slot
```

```ts
import { Slot } from '@tiptap-pro/extension-slot'

const editor = new Editor({
  extensions: [Slot],
  content: {
    type: 'doc',
    // Pass a document with slots, or let the user create them
    content: [
      // An example slot
      {
        type: 'blockSlot',
        attrs: {
          id: 'summary',
          config: { label: 'Summary', required: true },
        },
      },
    ],
  },
})
```
