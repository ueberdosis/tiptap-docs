Call the `insertSlot` command to add a new slot to the document.

```ts
// Inserts new slot at the selection
editor.commands.insertSlot()
```

There are two types of slots:

- **Inline slots** can contain inline content like text
- **Block slots** contain block content like one or more paragraphs, headings, etc.

To turn selected text into a slot while keeping its content, call [`wrapInSlot`](/composable-docs/slots/api-reference/commands#wrapinslot):

```ts
editor.commands.wrapInSlot({ kind: 'inline' })
```

Use `kind: 'block'` when selecting complete blocks. `insertSlot` replaces selected content instead of wrapping it.

When creating a slot, you can define its type and many properties, like a unique ID, a label, and a set of rules to restrict its allowed content.

```ts
editor.commands.insertSlot({
  kind: 'inline',
  id: 'customer',
  config: {
    label: 'Customer name',
    required: true,
    constraints: { maxLength: 120 },
  },
})
```

Then, a slot can be filled by typing inside it or calling the `fillSlot` command.

```ts
editor.commands.fillSlot({
  id: 'customer',
  // Tiptap JSON content
  content: [{ type: 'text', text: 'Ada Lovelace' }],
})
```

Other useful commands:

- `clearSlot({ id })` empties a field.
- `dissolveSlot({ id })` removes its wrapper and keeps its content.
- `removeSlot({ id })` removes both.

To create inline slots by typing delimiters, configure the `inline` input rule:

```ts
Slot.configure({
  shortcuts: { inline: { open: '{{', close: '}}' } },
})
```

Typing `{{Ada}}` creates an inline Slot containing “Ada”. This rule always creates an inline slot, including in an empty paragraph; it does not create block slots. Use `insertSlot({ kind: 'block', at })` to insert a block slot at a position that accepts blocks.
