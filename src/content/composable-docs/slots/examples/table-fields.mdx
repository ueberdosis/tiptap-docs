This example uses [Content Protection](TODO) to restrict what users can edit. Users are allowed to add and remove rows to the table, and edit its content, but they cannot edit content outside the table, add columns, or edit the headers.

The demo uses Slots to define table cells as fields: each table field contains a Slot that can be filled with content and validated afterwards.
