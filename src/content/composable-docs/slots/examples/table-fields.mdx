[Content Protection](/composable-docs/content-protection/getting-started/overview) restricts what users can edit: they cannot edit content outside the table, add columns, or edit the headers.

The demo uses Slots to define table cells as fields: each table field contains a Slot that can be filled with content and validated afterwards.
