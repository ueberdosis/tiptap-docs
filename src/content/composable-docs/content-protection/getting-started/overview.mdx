Content Protection controls which parts of a document users can edit or read. Define permissions for Nodes, Marks, attributes and content with a policy.

<Callout title="Client-side only" variant="info">
  Content protection is applied only client-side. For server-side content protection, [contact
  us](https://tiptap.dev/contact-sales?form=pilot-program).
</Callout>

## Install

First, [contact our team](https://tiptap.dev/contact-sales?form=pilot-program) for access to the Content Protection pilot program.

After gaining access, follow the [private registry setup guide](/guides/pro-extensions), then install the package:

```bash
npm install @tiptap-pro/extension-content-protection
```

Add the extension to your editor.

```ts
import { Editor } from '@tiptap/core'
import {
  ContentProtection,
  type ContentProtectionPolicy,
} from '@tiptap-pro/extension-content-protection'

const policy: ContentProtectionPolicy = {
  version: 1,
  rules: [
    {
      selector: { target: 'node', node: { types: ['heading'] } },
      permissions: { edit: false },
    },
  ],
}

const editor = new Editor({
  extensions: [ContentProtection.configure({ policy })],
})
```

Provide a [policy](/composable-docs/content-protection/api-reference/policy) that defines what can be edited.

You can also update the content protection rules while the editor is running:

```ts
editor.commands.setContentProtectionPolicy({ policy })
```

See the [API reference](/composable-docs/content-protection/api-reference/extension) and [policy language](/composable-docs/content-protection/api-reference/policy).
