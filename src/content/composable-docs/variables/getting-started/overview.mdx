**Variables** let you display values, such as a customer name or a calculated total, in your editor. When a value changes, every reference to it updates automatically.

The document stores a reference to the variable, while your application manages its value.

<Callout title="Client-side only" variant="info">
  Variables run inside each editor instance. They do not provide a server API or synchronize runtime
  values between clients.
</Callout>

## Install

First, [contact our team](https://tiptap.dev/contact-sales?form=pilot-program) to join the Tiptap Composable Docs pilot program.

Then, configure your package manager by following the [private registry guide](/guides/pro-extensions).

Then, install the package:

```bash
npm install @tiptap/core @tiptap/starter-kit @tiptap-pro/extension-variable
```

## Define and display a variable

First, import the editor and extensions:

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Variable } from '@tiptap-pro/extension-variable'
```

Define a variable called `customer` and add the extension to your editor:

```ts
const variable = Variable.configure({
  variables: { customer: 'Ada' },
})

const editor = new Editor({
  extensions: [StarterKit, variable],
  content: '<p></p>',
})
```

Insert a reference at the current selection. It displays **Ada**:

```ts
editor.commands.insertVariable({ name: 'customer' })
```

Update the value. Every reference to `customer` now displays **Grace**:

```ts
editor.commands.setVariable({ name: 'customer', value: 'Grace' })
```

## Values and resolvers

Define values directly or calculate them with a function, called a **resolver**. Use `get()` to read another variable. Replace the earlier `variable` configuration with this one:

```ts
const variable = Variable.configure({
  variables: {
    customer: 'Ada',
    quantity: 3,
    greeting: ({ get }) => `Hello, ${String(get('customer'))}!`,
  },
})
```

With this configuration, changing `customer` also updates `greeting`:

```ts
editor.commands.setVariable({ name: 'customer', value: 'Grace' })
// greeting becomes "Hello, Grace!"
```

Values can also be objects or arrays. Objects that are not Tiptap content display as JSON:

```ts
editor.commands.setVariable({
  name: 'customer',
  value: { name: 'Ada', company: 'Acme' },
})
```

Use Tiptap JSON to display formatted content:

```ts
editor.commands.setVariable({
  name: 'customer',
  value: { type: 'text', text: 'Ada', marks: [{ type: 'bold' }] },
})
```

## Connect variable values to external sources

A resolver can read data from your application. Create a customer object, a resolver that reads its name, and an editor that displays it:

```ts
let customer = { name: 'Ada' }

const customerVariable = Variable.configure({
  variables: {
    customer: () => customer.name,
  },
})

const refreshEditor = new Editor({
  extensions: [StarterKit, customerVariable],
  content: '<p></p>',
})
refreshEditor.commands.insertVariable({ name: 'customer' })
```

Listen for an application event and refresh the resolver:

```ts
const events = new EventTarget()
const refresh = () => refreshEditor.commands.refreshVariables({ names: ['customer'] })
events.addEventListener('customer-change', refresh)
```

After changing the data, send the event. The editor now displays **Grace**:

```ts
customer = { name: 'Grace' }
events.dispatchEvent(new Event('customer-change'))
```

Remove the listener when the editor is destroyed:

```ts
refreshEditor.on('destroy', () => events.removeEventListener('customer-change', refresh))
```

## What is saved

The document saves the variable's name, not its value. Each editor supplies its own values.

Text inside a [bound slot](/composable-docs/variables/guides/bind-slots) is saved as normal document content.
