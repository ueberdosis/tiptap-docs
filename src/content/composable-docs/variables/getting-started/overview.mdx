## What you can do with it

- **Show a value in the text.** The document stores a reference; your application supplies the value. [Get started](#get-started)
- **Calculate values.** A resolver function derives a value from other variables. [Values and resolvers](/composable-docs/variables/guides/define-variables#values-and-resolvers)
- **Add and remove variables at runtime.** You don't need to know every variable when you create the editor. [Add and manage variables at runtime](/composable-docs/variables/guides/define-variables#add-and-manage-variables-at-runtime)
- **Use data from your application.** Refresh a resolver when your data changes. [Connect variable values to external sources](/composable-docs/variables/guides/define-variables#connect-variable-values-to-external-sources)
- **Keep editable fields in sync.** Bind Variables to Slots, so a value and the fields that show it stay the same. [Bind slots to variables](/composable-docs/variables/guides/bind-slots)
- **Render references your way.** Style them or use your own NodeViews. [Styling](/composable-docs/variables/api-reference/rendering)

## Get started

1. [Contact our team](https://tiptap.dev/contact-sales?form=pilot-program) to join the Composable Documents pilot program.
2. Set up access to Tiptap's private npm registry with the [setup guide](/guides/pro-extensions).
3. Install the package:

```bash
npm install @tiptap/core @tiptap/starter-kit @tiptap-pro/extension-variable
```

Define a variable called `customer`, insert a reference to it, and change its value. Every reference to `customer` updates from **Ada** to **Grace**:

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Variable } from '@tiptap-pro/extension-variable'

const editor = new Editor({
  extensions: [
    StarterKit,
    Variable.configure({
      variables: { customer: 'Ada' },
    }),
  ],
  content: '<p></p>',
})

editor.commands.insertVariable({ name: 'customer' })
editor.commands.setVariable({ name: 'customer', value: 'Grace' })
```

[Define and manage variables](/composable-docs/variables/guides/define-variables) adds variables at runtime, calculates values with resolvers, and connects them to your application's data.

## What is saved

The document saves the variable's name, not its value. Each editor supplies its own values.

Text inside a [bound slot](/composable-docs/variables/guides/bind-slots) is saved as normal document content.

## Part of Composable Documents

Variables are one of three parts of Composable Documents. [Slots](/composable-docs/slots/getting-started/overview) are fields users fill, and Variables can stay in sync with them. [Content Protection](/composable-docs/content-protection/getting-started/overview) controls who may edit what.
