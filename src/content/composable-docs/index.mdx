## The three parts

| Part               | What it does                                                                                                        | Start with                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Slots              | Fields in the document that users fill, with rules for what is valid.                                               | [Slots](/composable-docs/slots/getting-started/overview)                           |
| Variables          | Values from your application, such as a customer name or a total, shown in the text and updated everywhere at once. | [Variables](/composable-docs/variables/getting-started/overview)                   |
| Content Protection | A policy that sets which Nodes, Marks, attributes, and content users may edit or read.                              | [Content Protection](/composable-docs/content-protection/getting-started/overview) |

## How they work together

- **A form that can only be filled.** Content Protection keeps everything outside the Slots fixed, and assigns Slots by role. [Allow filling only](/composable-docs/slots/guides/fill-only)
- **One value in several places.** Bind Slots to a Variable, so a value and every field that shows it stay the same. [Bind slots to variables](/composable-docs/variables/guides/bind-slots)
- **Fields in a table.** Fill table cells as Slots while headers and columns stay fixed. [Table fields example](/composable-docs/slots/examples/table-fields)

## Availability

- **Pilot program.** Composable Documents are in Tiptap's pilot program. [Contact our team](https://tiptap.dev/contact-sales?form=pilot-program) for access.
- **Client-side.** All three run in the editor. Filling Slots or checking permissions on the server is not available yet.
- **Alpha.** All three are alpha releases.
