## What you can do with it

- **Edit together in real time.** Every change syncs to everyone with the document open, built on the open source [Hocuspocus](/hocuspocus/getting-started/overview) server. [Provider](/collaboration/provider/integration)
- **Show who is there.** Awareness shows each user's cursor and selection. [Awareness](/collaboration/core-concepts/awareness)
- **Read and change documents from your backend.** The REST API returns documents as JSON and creates, updates, and deletes them. [REST API](/collaboration/documents/rest-api)
- **Change content during a session.** Inject content on the server while people edit. [Inject content](/collaboration/documents/content-injection)
- **Keep versions.** Snapshots store versions automatically or on demand, and users restore any of them. [Snapshots](/collaboration/documents/snapshot)
- **React to changes.** Webhooks tell your systems when documents, comments, or versions change. [Webhooks](/collaboration/core-concepts/webhooks)
- **Control access per document.** Tokens allow reading, writing, or commenting on specific documents. [Authenticate](/collaboration/getting-started/authenticate)
- **Add comments.** Threads are stored with the document. [Comments](/comments/getting-started/overview)
- **Operate it.** Change settings at runtime and read server and document statistics. [Configure runtime](/collaboration/operations/configure), [Metrics](/collaboration/operations/metrics)
- **Choose where it runs.** In Tiptap Cloud or on your own servers. [Hosting](/hosting)

## Get started

Install the Collaboration extension, Yjs, and the provider:

```bash
npm install @tiptap/extension-collaboration @tiptap/y-tiptap yjs y-protocols
npm install @tiptap-pro/provider
```

Bind the editor to a Yjs document, and connect that document to your Document Server:

```js
import { Editor } from '@tiptap/core'
import Collaboration from '@tiptap/extension-collaboration'
import { TiptapCollabProvider } from '@tiptap-pro/provider'
import * as Y from 'yjs'

const doc = new Y.Doc()

const provider = new TiptapCollabProvider({
  name: 'document.name', // The document to sync
  appId: 'YOUR_DOCUMENT_SERVER_ID', // Or `baseUrl` for on-premises
  token: 'YOUR_JWT',
  document: doc,
})

const editor = new Editor({
  extensions: [
    // …your other extensions
    Collaboration.configure({ document: doc }),
  ],
})
```

- **Undo and redo:** With StarterKit or the Undo/Redo extension, turn their history off; Collaboration manages history itself. [Install](/collaboration/getting-started/install#disable-default-undoredo)
- **Initial content:** Set it only once, or every client that loads the editor adds it again. [Install](/collaboration/getting-started/install#initialize-content-properly)

[Install](/collaboration/getting-started/install) walks through the whole setup.

## Things to know

- **The document model:** Your backend reads and writes documents as Tiptap JSON; the Document Server takes care of syncing them. [Tiptap Document](/document-model) explains how.
- **Coming from Hocuspocus:** [Move between them](/hosting#move-between-them) shows the steps. Swap the `HocuspocusProvider` for the `TiptapCollabProvider`; the rest of your setup stays. Import existing documents with the [batch import endpoint](/collaboration/documents/rest-api#batch-import-documents).
- **Schema changes:** Clients on different schema versions drop content the other side doesn't know. Handle it with [invalid schema handling](/editor/guides/invalid-schema).
