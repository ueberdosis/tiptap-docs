## What you can do with it

- **Discuss any part of a document.** Threads attach to text, to a node, or to a selection across nodes, and show inline or in a sidebar. [Manage threads](/comments/core-concepts/manage-threads)
- **Write rich comments.** Comments hold formatted text, emojis, and mentions of users.
- **Resolve, edit, and delete.** Threads may overlap. [Manage threads](/comments/core-concepts/manage-threads)
- **Style threads.** Inline and block threads get CSS classes you can style. [Style threads](/comments/core-concepts/style-threads)
- **Control who may comment.** A token can allow commenting without editing. With thread authentication, only the author of a thread or comment may change it. [Comment without editing](/collaboration/getting-started/authenticate#comment-without-editing), [Thread authentication](/comments/core-concepts/thread-authentication)
- **React in the editor.** Events tell your interface when threads are created, selected, or resolved. [Editor events](/comments/integrate/editor-events)
- **Manage comments from your backend.** Read and create threads with the REST API, and get webhooks when users are mentioned. [REST API](/comments/integrate/rest-api), [Webhook](/comments/integrate/webhook)
- **Comment on code.** Threads also attach to inline code and code blocks. [Comments on code](/comments/integrate/code)
- **Review together with Tracked Changes.** Suggestions and their discussions stay linked. [Tracked Changes with Comments](/tracked-changes/guides/comments-integration)
- **Compare versions.** Show what changed between two documents or versions. [Compare](/compare/getting-started/overview)

## Get started

<Requirements>
  <RequirementItem label="1. Choose a plan">
    Comments work on the Start plan; the REST API and webhooks need the Team plan. Start a [free
    trial](https://cloud.tiptap.dev/v2?trial=true) or [subscribe](https://cloud.tiptap.dev/v2/billing).
  </RequirementItem>
  <RequirementItem label="2. Start a Document Server">
    Threads are stored on the Document Server. [Add an
    environment](https://cloud.tiptap.dev/v2/configuration/document-server) in your dashboard, or
    run it [on-premises](/hosting/on-premises). [Hosting](/hosting) compares the options.
  </RequirementItem>
  <RequirementItem label="3. Access the private registry">
    Authenticate to Tiptap's private npm registry with the [setup guide](/guides/pro-extensions).
  </RequirementItem>
</Requirements>

Install the extension:

```bash
npm install @tiptap-pro/extension-comments
```

Add `CommentsKit` and pass it the [provider](/collaboration/getting-started/install) that connects the editor to the Document Server:

```js
import { CommentsKit } from '@tiptap-pro/extension-comments'

const editor = new Editor({
  extensions: [
    // …your other extensions
    CommentsKit.configure({
      provider: collabProvider, // your TiptapCollabProvider
    }),
  ],
})
```

[Install](/comments/getting-started/install) walks through the whole setup.
