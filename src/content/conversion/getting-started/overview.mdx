## What you can do with it

- **Import Word documents.** A DOCX file becomes Tiptap JSON with its content, formatting, and layout. [DOCX import](/conversion/import/docx/editor-extension)
- **Export to the formats people need.** DOCX, PDF, ODT, EPUB, legacy DOC, and Markdown. [DOCX export](/conversion/export/docx/editor-extension)
- **Convert without an editor.** The REST API imports and exports on your server. [Import REST API](/conversion/import/docx/rest-api), [Export REST API](/conversion/export/docx/rest-api)
- **Keep custom nodes and marks.** Map Word content onto your own node and mark types. [Node mapping](/conversion/import/docx/custom-node-mapping), [Mark mapping](/conversion/import/docx/custom-mark-mapping)
- **Bring images along.** Images in a DOCX file upload to your own server during import. [Image handling](/conversion/import/docx/image-handling)
- **Keep tracked changes.** Word insertions and deletions can import as [suggestions](/tracked-changes/getting-started/overview) and export back to Word. [Import](/conversion/import/docx/tracked-changes), [Export](/conversion/export/docx/tracked-changes)
- **Keep the page layout.** With [Pages](/pages/getting-started/overview), imported headers, footers, and page breaks render in the editor and export again.
- **Style the export.** Set fonts, styles, and list numbering for DOCX. [Styles](/conversion/export/docx/styles), [Fonts](/conversion/export/docx/fonts)

## How it works

1. **Import:** The conversion service parses the file and returns Tiptap JSON.
2. **Render:** The editor shows each node of that JSON for which it has an extension. Content without an extension needs [invalid schema handling](/editor/guides/invalid-schema).
3. **Export:** The export turns what the editor contains now into a file, not the original document.

Every request is processed synchronously and returns its result in the response. Conversion does not read scanned PDFs (no OCR) and has no job queue; plan timeouts for very large files. The conversion service runs in [Tiptap Cloud](/hosting/cloud) or [on-premises](/hosting/on-premises).

## Choose your extensions

| What you build | What you need |
| --- | --- |
| A content editor or CMS that accepts uploads | `ConvertKit` |
| A document editor with page layout | `ConvertKit` with `table: false`, `TableKit` from `@tiptap-pro/extension-pages-tablekit`, and `Pages` |
| A pipeline without an editor | The REST API only |

[ConvertKit](/conversion/import/docx/convertkit) brings a DOCX-aware schema: paragraphs, headings, lists, images, and marks. Use it instead of `StarterKit`.

## Get started

1. Start a [free trial or choose a plan](https://cloud.tiptap.dev/v2/billing).
2. Authenticate to Tiptap's private npm registry with the [setup guide](/guides/pro-extensions).
3. Sign a JWT for the Convert service. DOCX export works without one. [Install](/conversion/getting-started/install) lists the actions a token needs.

Install ConvertKit and the DOCX import extension:

```bash
npm install @tiptap-pro/extension-convert-kit @tiptap-pro/extension-import-docx
```

Add both to the editor, with the token:

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ImportDocx } from '@tiptap-pro/extension-import-docx'

const editor = new Editor({
  extensions: [
    ConvertKit,
    ImportDocx.configure({
      token: 'your-jwt', // a JWT for the Convert service
    }),
  ],
})
```

Import a file the user selected:

```ts
editor.chain().focus().importDocx({ file }).run()
```
