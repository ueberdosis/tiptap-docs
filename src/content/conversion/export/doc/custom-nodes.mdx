Describe how each custom node in your Tiptap schema renders in DOC exports. You write the rules once, with `customNodeDsl` on `ExportDocx`, and every export format uses them.

<Callout title="Requires Export DOCX extension" variant="warning">
  Custom node conversion for DOC export needs the `@tiptap-pro/extension-export-docx` extension in
  your editor. `ExportDoc` asks `ExportDocx` for a DOCX file first, then converts it to DOC. Without
  `ExportDocx`, your custom node rules have no effect.
</Callout>

`ExportDoc` no longer takes a `customNodes` option. Configure `customNodeDsl` on `ExportDocx` instead. See the [migration guide](/conversion/export/docx/migrate-to-v1#removed-customNodes).

## Export custom nodes to .doc

Pass your rules to the `customNodeDsl` option of `ExportDocx`, and add `ExportDoc` next to it:

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'
import { childrenInline, docxNode, paragraph } from '@tiptap-pro/extension-export-docx/dsl'
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

const editor = new Editor({
  extensions: [
    ConvertKit,
    ExportDocx.configure({
      customNodeDsl: {
        dslVersion: '1.0',
        nodes: [
          docxNode('hintbox')
            .block()
            .emit(paragraph({ style: 'Hintbox' }).children(childrenInline({ marks: 'default' })))
            .toJSON(),
        ],
      },
    }),
    ExportDoc.configure({
      token: 'YOUR_JWT',
      appId: 'YOUR_APP_ID',
      onCompleteExport(result) {
        // Handle the exported DOC
      },
    }),
  ],
})
```

`ExportDoc` passes its `token`, `appId`, `endpoint` and `region` on to `ExportDocx`, so you don't need to set them twice.

### Describe the custom node with the DSL

This example renders the `hintbox` node as a paragraph with the `Hintbox` style, and declares that style in `styleOverrides` on `ExportDocx`:

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import {
  multiplierToLineSpacingUnits,
  pixelsToHalfPoints,
  pointsToTwips,
} from '@tiptap-pro/extension-convert-kit/ooxml-registry'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'
import { childrenInline, docxNode, paragraph } from '@tiptap-pro/extension-export-docx/dsl'
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

import { Hintbox } from './hintbox'

const editor = new Editor({
  extensions: [
    ConvertKit,
    Hintbox,
    ExportDocx.configure({
      customNodeDsl: {
        dslVersion: '1.0',
        nodes: [
          docxNode('hintbox')
            .block()
            .emit(paragraph({ style: 'Hintbox' }).children(childrenInline({ marks: 'default' })))
            .toJSON(),
        ],
      },
      styleOverrides: {
        paragraphStyles: [
          {
            id: 'Hintbox',
            name: 'Hintbox',
            basedOn: 'Normal',
            next: 'Normal',
            quickFormat: false,
            run: {
              font: 'Aptos',
              size: pixelsToHalfPoints(16),
            },
            paragraph: {
              spacing: {
                before: pointsToTwips(12),
                after: pointsToTwips(12),
                line: multiplierToLineSpacingUnits(1),
              },
              border: {
                top: { style: 'single', size: 1, color: 'b8d8ff', space: 5 },
                bottom: { style: 'single', size: 1, color: 'b8d8ff', space: 5 },
                right: { style: 'single', size: 1, color: 'b8d8ff', space: 5 },
                left: { style: 'single', size: 1, color: 'b8d8ff', space: 5 },
              },
              shading: {
                type: 'solid',
                color: 'e6f3ff',
              },
            },
          },
        ],
      },
    }),
    ExportDoc.configure({
      token: 'YOUR_JWT',
      appId: 'YOUR_APP_ID',
      onCompleteExport: (result) => {
        const url = URL.createObjectURL(result)
        const link = document.createElement('a')
        link.href = url
        link.download = 'export.doc'
        link.click()
        URL.revokeObjectURL(url)
      },
    }),
  ],
})
```
