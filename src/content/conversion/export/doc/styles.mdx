<Callout title="Consider using DOCX instead" variant="info">
    The DOC format is a legacy format from Microsoft Word 97-2003. For modern use, we recommend exporting to [DOCX](/conversion/export/docx/styles) instead. Use DOC only when compatibility with older systems requires it.
</Callout>

<Callout title="Requires Export DOCX extension" variant="warning">
  Style overrides for DOC export require the `@tiptap-pro/extension-export-docx` extension to be installed and configured in your editor. The DOC export uses DOCX generation under the hood before converting to DOC. Without it, the `styleOverrides` and element override options will have no effect.
</Callout>
