<Callout title="Consider using DOCX instead" variant="info">
  The DOC format is a legacy format from Microsoft Word 97-2003. For modern use, we recommend
  exporting to [DOCX](/conversion/export/docx/headers-footers) instead. Use DOC only when
  compatibility with older systems requires it.
</Callout>

The headers and footers of your exported DOC come from the document's page layout. `ExportDoc` gets them through `ExportDocx`.

<Callout title="Requires Export DOCX extension" variant="warning">
  Headers and footers for DOC export need the `@tiptap-pro/extension-export-docx` extension in your
  editor. `ExportDoc` asks `ExportDocx` for a DOCX file first, then converts it to DOC. Only that
  path sends the document's page layout.
</Callout>

`ExportDoc` no longer takes the `headers` and `footers` options. See [`headers`](/conversion/export/docx/migrate-to-v1#removed-headers) and [`footers`](/conversion/export/docx/migrate-to-v1#removed-footers) in the migration guide.

## Export headers and footers to .doc

Add `ExportDocx` next to `ExportDoc`. To style header and footer content differently from the body, set `headerFooterOverrides` on `ExportDocx`:

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'
import { ExportDoc } from '@tiptap-pro/extension-export-doc'

const editor = new Editor({
  extensions: [
    ConvertKit,
    ExportDocx.configure({
      headerFooterOverrides: {
        textRunOverrides: { size: 18 },
      },
    }),
    ExportDoc.configure({
      token: 'YOUR_JWT',
      appId: 'YOUR_APP_ID',
      onCompleteExport(result) {
        // Handle the exported DOC
      },
    }),
  ],
})
```

`ExportDoc` passes its `token`, `appId`, `endpoint` and `region` on to `ExportDocx`, so you don't need to set them twice.

See [DOCX headers and footers](/conversion/export/docx/headers-footers) for how the page layout is exported and what `headerFooterOverrides` accepts.

## Set headers and footers on your server

To set header and footer text yourself, send `headers` and `footers` to the [DOC REST API](/conversion/export/doc/rest-api#headers-configuration).

## Limitations

- Headers and footers from the [Pages extension](/pages/getting-started/overview) aren't exported.
- Without `ExportDocx`, the DOC file has no headers or footers from the page layout.
