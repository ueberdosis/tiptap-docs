When exporting to `DOCX`, you can define custom styles that will be applied to the exported document. This is useful when you want to have a consistent look and feel across your documents.

<ExportStylesGuide />

## Overrides are plain objects

Every element override takes a plain object: `paragraphOverrides`, `textRunOverrides`, `tableOverrides`, `tableRowOverrides`, `tableCellOverrides`, `imageOverrides` and `headerFooterOverrides`. The same values apply to every matching element.

A function is no longer accepted. The extension leaves it out of the export and reports it through `onWarning` with the `unsupported` code. See [function overrides](/conversion/export/docx/migrate-to-v1#removed-function-overrides).

To set a value on one node, set it on the node's attributes in the editor. See [Node attribute inference](/conversion/export/docx/editor-extension#node-attribute-inference) for the attributes the export reads.
