The headers and footers of your exported PDF come from the document's page layout. `ExportPdf` gets them through `ExportDocx`.

<Callout title="Requires Export DOCX extension" variant="warning">
  Headers and footers for PDF export need the `@tiptap-pro/extension-export-docx` extension in your
  editor. `ExportPdf` asks `ExportDocx` for a DOCX file first, then converts it to PDF. Only that
  path sends the document's page layout.
</Callout>

`ExportPdf` no longer takes the `headers` and `footers` options. See [`headers`](/conversion/export/docx/migrate-to-v1#removed-headers) and [`footers`](/conversion/export/docx/migrate-to-v1#removed-footers) in the migration guide.

## Export headers and footers to .pdf

Add `ExportDocx` next to `ExportPdf`. To style header and footer content differently from the body, set `headerFooterOverrides` on `ExportDocx`:

```ts
import { Editor } from '@tiptap/core'
import { ConvertKit } from '@tiptap-pro/extension-convert-kit'
import { ExportDocx } from '@tiptap-pro/extension-export-docx'
import { ExportPdf } from '@tiptap-pro/extension-export-pdf'

const editor = new Editor({
  extensions: [
    ConvertKit,
    ExportDocx.configure({
      headerFooterOverrides: {
        textRunOverrides: { size: 18 },
      },
    }),
    ExportPdf.configure({
      token: 'YOUR_JWT',
      appId: 'YOUR_APP_ID',
      onCompleteExport(result) {
        // Handle the exported PDF
      },
    }),
  ],
})
```

`ExportPdf` passes its `token`, `appId`, `endpoint` and `region` on to `ExportDocx`, so you don't need to set them twice.

See [DOCX headers and footers](/conversion/export/docx/headers-footers) for how the page layout is exported and what `headerFooterOverrides` accepts.

## Set headers and footers on your server

To set header and footer text yourself, send `headers` and `footers` to the [PDF REST API](/conversion/export/pdf/rest-api#headers-configuration).

## Limitations

- Headers and footers from the [Pages extension](/pages/getting-started/overview) aren't exported.
- Without `ExportDocx`, the PDF file has no headers or footers from the page layout.
