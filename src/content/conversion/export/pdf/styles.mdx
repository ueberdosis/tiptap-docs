When exporting to PDF, you can define custom styles that will be applied to the exported document. This is useful when you want to have a consistent look and feel across your documents.

<Callout title="Works best with the Export DOCX extension" variant="warning">
  Style overrides for PDF export work best with the `@tiptap-pro/extension-export-docx` extension installed and registered in your editor. The PDF export then builds a DOCX file in the browser and converts it to PDF. That file uses the `styleOverrides` set on `ExportPdf`, or the ones on `ExportDocx` when `ExportPdf` has none, and the element override options set on `ExportDocx`. Without `ExportDocx`, the PDF export sends the document as JSON with the `styleOverrides` from `ExportPdf.configure` to the Convert service, and the element override options have no effect.
</Callout>
