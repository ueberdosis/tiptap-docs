The `ExportMarkdown` extension turns the editor's document into a Markdown string, the plain-text format that writes headings, emphasis, links and lists with characters such as `#` and `*`. It converts in the browser with the Markdown extension `@tiptap/markdown`, so it needs no Conversion token, no Conversion service and no network.

## Export the document

`ExportMarkdown` needs the Markdown extension in the editor. Install both packages. `@tiptap-pro/extension-export-markdown` comes from Tiptap's private registry, which [Set up the registry](/conversion/v3/getting-started/install#1-set-up-the-registry) connects your project to, even though the export needs no Conversion token:

```bash
npm install @tiptap-pro/extension-export-markdown @tiptap/markdown
```

`ExportMarkdown` needs `@tiptap/core`, `@tiptap/pm` and `@tiptap/markdown` in version 3.20.0 or a later Tiptap 3. Add `Markdown` and `ExportMarkdown` to the editor, and call `exportMarkdown()`:

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { Markdown } from '@tiptap/markdown'
import { ExportMarkdown } from '@tiptap-pro/extension-export-markdown'

const editor = new Editor({
  element: document.querySelector('#editor'),
  extensions: [
    StarterKit,
    Markdown,
    ExportMarkdown.configure({
      onCompleteExport: (markdown) => console.log(markdown),
    }),
  ],
  content: '<h1>Hello</h1><p>A <strong>bold</strong> word.</p>',
})

editor.commands.exportMarkdown()
```

The console shows `# Hello` and `A **bold** word.`, with a blank line between them.

## Save a file

`onCompleteExport` receives the Markdown as a string. To save it as a file, turn it into a `Blob` and download it. This call passes its own callback, which wins over the configured one for this export:

```ts
editor.commands.exportMarkdown({
  onCompleteExport: (markdown) => {
    const blob = new Blob([markdown], { type: 'text/markdown;charset=utf-8' })
    const url = URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    link.download = 'document.md'
    link.click()
    setTimeout(() => URL.revokeObjectURL(url), 1000)
  },
})
```

## exportMarkdown()

`exportMarkdown()` converts the whole document with `editor.getMarkdown()` from the Markdown extension, calls `onCompleteExport` with the string, and returns `true`. It runs synchronously, so the callback has run when the command returns.

The command takes an optional object with one option, `onCompleteExport: (result: string) => void`. `ExportMarkdown.configure()` takes the same option, and without it in either place the command throws an error.

The command never returns `false`. It throws an error instead if the editor has no Markdown extension, and passes on an error that the conversion or the callback throws.

## What the Markdown holds

Each extension in the editor decides how its node or mark is written in Markdown, through the Markdown extension. `ExportMarkdown` has no rules of its own, so a node type of yours needs its own Markdown rules, as [Custom Markdown Serializing](/editor/markdown/advanced-usage/custom-serializing) describes.

Markdown has no syntax for many things a Word file holds, such as page setup, headers and footers. For those, export a [Word file](/conversion/v3/docx/export) or a [PDF](/conversion/v3/pdf).

## Import Markdown

Tiptap Conversion has no extension that imports Markdown. The Markdown extension reads Markdown itself, such as with `editor.commands.setContent(markdown, { contentType: 'markdown' })`. [Introduction into Markdown with Tiptap](/editor/markdown) explains how.
