At the end of this guide, your editor exports and imports with 1.0 and reports anything left from 0.x as a warning. The guide has two parts, one for each package. An editor that uses only one of the packages needs only its part.

## Update the packages

First, update the packages. 1.0 needs Tiptap 3, `@tiptap/core` 3.0.7 or later:

```bash
npm install @tiptap-pro/extension-export-docx@^1.0.0 @tiptap-pro/extension-import-docx@^1.0.0
```

## Stay on Conversion v2

To stay on Conversion v2 for now, keep the 0.x packages. Pin Export DOCX to `0.34`, and install Import DOCX from its `maintenance` tag. The v2 REST endpoint, `POST /v2/convert/export/docx`, stays available, so a backend that calls it directly keeps working:

```bash
npm install @tiptap-pro/extension-export-docx@0.34 @tiptap-pro/extension-import-docx@maintenance
```

## Migrate export and import

After the update, change the code that uses each package:

- [Migrate export from Conversion v2](/conversion/v3/getting-started/migrate-from-v2/export): Export DOCX 1.0 builds the `.docx` file on the Conversion service, so it needs a token, and the options that ran code in the browser are gone.
- [Migrate import from Conversion v2](/conversion/v3/getting-started/migrate-from-v2/import): Import DOCX 1.0 writes into Page Layout, keeps content the editor has no extension for, and reports warnings and errors to their own callbacks.
