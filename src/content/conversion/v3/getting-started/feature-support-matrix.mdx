Check whether a Word feature survives a DOCX import or export with the 1.0 packages.

Import is what the editor receives from a `.docx` file. Export is what ends up in the `.docx` file.

A note explains each `Partly` and most `No` cells. Import returns Tiptap JSON, so the editor shows a node or mark only when it has the extension for it. When it doesn't, `onWarning` receives a warning.

## Text formatting

| Feature                     | Import | Export | Notes                                                                                                                                                                                                                                                                   |
| --------------------------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bold, italic, strikethrough | Yes    | Yes    |                                                                                                                                                                                                                                                                         |
| Underline                   | Yes    | Yes    | Underline styles such as double or dotted import as `underlineType`. The editor keeps it only with an extension that defines the attribute. See [underline styles](/conversion/v3/content-reference/text-and-formatting/bold-italic-underline-strike#underline-styles). |
| Subscript, superscript      | Yes    | Yes    |                                                                                                                                                                                                                                                                         |
| Inline code                 | Yes    | Yes    | Export writes Word's Code character style, and import reads it back.                                                                                                                                                                                                    |
| Text color                  | Yes    | Yes    |                                                                                                                                                                                                                                                                         |
| Highlight                   | Yes    | Yes    | Import also reads character shading as a highlight.                                                                                                                                                                                                                     |
| Font family, font size      | Yes    | Yes    |                                                                                                                                                                                                                                                                         |
| Letter spacing              | Yes    | Partly | Import sets `letterSpacing` on the `textStyle` mark. The editor keeps it only with an extension that defines it. Export ignores the attribute and writes the letter spacing it measures in the editor's CSS.                                                            |
| Tabs                        | Partly | Yes    | A tab imports as four spaces. Export writes a tab character as a Word tab.                                                                                                                                                                                              |
| Hard breaks                 | Yes    | Yes    |                                                                                                                                                                                                                                                                         |
| Right-to-left text          | No     | Yes    | Import ignores the text direction. Export writes it when the editor renders the text right to left.                                                                                                                                                                     |

## Links, bookmarks and fields

| Feature                                 | Import | Export | Notes                                                                                                                                                                                                                                                                                 |
| --------------------------------------- | ------ | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Links to a web address                  | Yes    | Yes    |                                                                                                                                                                                                                                                                                       |
| Links to a bookmark                     | Yes    | Yes    | An imported link to a bookmark has an `href` that starts with `#`. Export turns an `href` such as `#name` into an internal link.                                                                                                                                                      |
| Bookmarks                               | Partly | Partly | Import turns a bookmark into a zero-width `bookmark` node and loses the range it covered. Export writes only a node named `bookmark` with an `id` attribute. It drops the Bookmarks mark and `bookmarkPoint`. See [bookmark limitations](/pages/v2/extensions/bookmarks#limitations). |
| Cross-references                        | Partly | No     | Import keeps the text Word last showed for the reference as plain text. Export drops the `crossReference` node. See [Word fields](/pages/v2/extensions/cross-references/docx).                                                                                                        |
| Page number fields                      | Partly | Yes    | Import keeps the number Word last showed as plain text. Export writes `pageNumber` nodes as live page and page count fields.                                                                                                                                                          |
| Other fields, such as dates and authors | Partly | No     | Import keeps the value Word last showed as plain text. It no longer updates. Import drops some fields stored in Word's short form, with their value.                                                                                                                                  |

## Paragraphs and blocks

| Feature                             | Import | Export | Notes                                                                                                                                                                                                                                                                                          |
| ----------------------------------- | ------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Paragraphs                          | Yes    | Yes    |                                                                                                                                                                                                                                                                                                |
| Headings                            | Yes    | Yes    |                                                                                                                                                                                                                                                                                                |
| Blockquotes                         | Yes    | Yes    | Import reads Word's Quote style, and export writes it.                                                                                                                                                                                                                                         |
| Horizontal rules                    | Yes    | Yes    |                                                                                                                                                                                                                                                                                                |
| Code blocks                         | No     | No     | Export drops `codeBlock` with its text. A [custom node rule](/conversion/v3/export/docx/custom-nodes) can render it.                                                                                                                                                                           |
| Text alignment                      | Yes    | Yes    |                                                                                                                                                                                                                                                                                                |
| Line spacing                        | Yes    | Yes    | Export writes a multiple such as `1.5` as a minimum height scaled to the font size, and a length such as `24px` as an exact height.                                                                                                                                                            |
| Spacing before and after            | Yes    | Yes    | The editor keeps the value only with an extension that defines the attribute. See [paragraphs](/conversion/v3/content-reference/text-and-formatting/paragraphs#set-up-the-editor).                                                                                                             |
| Indentation                         | Yes    | Yes    | Left, right, first line and hanging indents. The editor keeps them only with an extension that defines the attributes.                                                                                                                                                                         |
| Keep with next, keep lines together | Yes    | Yes    | The editor keeps the flags only with an extension that defines the attributes.                                                                                                                                                                                                                 |
| Paragraph borders                   | No     | Partly | Import ignores them. Export measures borders from the editor's CSS and writes them.                                                                                                                                                                                                            |
| Named styles                        | Partly | Partly | Import reads headings, quotes and inline code, and applies the style's formatting to each paragraph. The experimental [`cssStyles`](/conversion/v3/import/docx/css-styles) option also extracts the style catalog as CSS. Export measures the editor's styles and turns them into Word styles. |

## Images and math

| Feature         | Import | Export | Notes                                                                                                                              |
| --------------- | ------ | ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| Inline images   | Yes    | Yes    | Import needs [`imageUploadConfig`](/conversion/v3/import/docx/image-handling). Without it, import skips each image with a warning. |
| Floating images | Partly | No     | Import adds a floating image inline and loses its position. It skips images set behind the text. Export writes every image inline. |
| Image size      | Yes    | Yes    |                                                                                                                                    |
| Image cropping  | Yes    | No     | Import sets the `cropTop`, `cropBottom`, `cropLeft` and `cropRight` attributes. Export writes the whole image.                     |
| Math            | No     | Yes    | Export writes `inlineMath` and `blockMath` nodes as Word equations.                                                                |
| Embedded fonts  | No     | Yes    | Export embeds fonts when you set [`embedFonts`](/conversion/v3/export/docx/usage#embed-fonts) or pass `fonts`.                     |

## Page layout

Headers, footers and page setup come from [Page Layout](/pages/v2/getting-started/overview) on export. Import returns them to you and doesn't write them into the editor.

| Feature                               | Import | Export | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Page breaks                           | Partly | Yes    | With Page Layout, a page break in the file can make the import fail. See [page breaks](/conversion/v3/content-reference/page-layout/page-breaks).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Page size, orientation and margins    | Partly | Yes    | Import returns one set as `pageLayout` in [`onImport`](/conversion/v3/import/docx/api#importcontext). Export writes them for every section.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Sections                              | No     | Yes    | Export writes next page and continuous sections. Import doesn't create section breaks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Section columns                       | Partly | Yes    | Import wraps a multi-column section in a `columns` node that holds one `column` with the whole section. The Columns extension can't hold that shape, so keeping it needs nodes of your own. Without them, import reports an `unsupported` warning and keeps the blocks as paragraphs. Export writes section columns from the [section setup](/pages/v2/core-concepts/section-columns). It has no output for imported `columns` and `column` nodes and leaves them out with their content. To keep that content through a re-export, define your own nodes and add a [custom node rule](/conversion/v3/export/docx/custom-nodes) for them. |
| Headers and footers                   | Partly | Yes    | Import returns the default (odd pages), first page and even versions in [`onImport`](/conversion/v3/import/docx/api#importcontext). Export writes each section's own headers and footers, including first page and even pages.                                                                                                                                                                                                                                                                                                                                                                                                            |
| Page number format, start and chapter | No     | Yes    |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Page color                            | No     | Yes    |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Footnotes, endnotes                   | Yes    | Yes    | With Page Layout, import writes notes into the source document. Without it, the note bodies come back in [`onImport`](/conversion/v3/import/docx/api#importcontext) only. Export reads notes from the Page Layout document, or from the `footnotes` and `endnotes` options without it.                                                                                                                                                                                                                                                                                                                                                    |

## Review

| Feature         | Import | Export | Notes                                                                                                                                                                                                    |
| --------------- | ------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Comments        | Yes    | Yes    | Import returns threads as [`commentThreads`](/conversion/v3/import/docx/api#importcontext). Export writes the threads of the comments extension.                                                         |
| Tracked changes | Partly | Partly | Insertions and deletions in the body round-trip as suggestions, which need the tracked changes extension. Import doesn't carry formatting changes or moves, and export doesn't write formatting changes. |

Set [`trackedChanges`](/conversion/v3/import/docx/tracked-changes) on import to `'preserve'`, `'accept'` or `'reject'`. With the default `'auto'`, import keeps suggestions when the editor has the tracked changes extension and accepts every change otherwise. Import accepts changes in headers, footers, notes and comments, and never keeps them as suggestions.

## Limitations

Conversion drops these features or carries only part of them.

| Feature                                      | What happens                                                                                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Table of contents                            | Import creates a `tableOfContents` node. The editor needs a node by that name to keep it. Export drops it.                                            |
| Column layout                                | Export drops `columnLayout` and `column` nodes with all their content. A [custom node rule](/conversion/v3/export/docx/custom-nodes) can render them. |
| Text boxes                                   | Import skips them and their content.                                                                                                                  |
| Shapes, SmartArt, WordArt                    | Import skips them.                                                                                                                                    |
| Content controls and form fields             | Import keeps the text and drops the control.                                                                                                          |
| Hidden text                                  | Import leaves it out.                                                                                                                                 |
| Document properties such as author and title | Import doesn't read them, and export doesn't write them.                                                                                              |
| Section text and accent colors               | Export drops them, because Word has no such setting.                                                                                                  |
| A page color on a later section              | Export drops it. Word has one page color per document.                                                                                                |
