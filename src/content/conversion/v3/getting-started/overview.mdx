Conversion moves documents between Word and your Tiptap editor. You import a `.docx` file into the editor, and you export the editor content back to `.docx`. Two editor extensions do the work, and both send the file to the Tiptap Convert service.

<Callout title="Looking for 0.x or another format?" variant="info">
  This section covers the 1.0 packages and DOCX. For the 0.x packages and the other formats, read
  the [Conversion documentation](/conversion/getting-started/overview).
</Callout>

## What 1.0 does

- `@tiptap-pro/extension-export-docx` adds the `exportDocx` command. It sends the document to Convert and gives you the finished DOCX file.
- `@tiptap-pro/extension-import-docx` adds the `importDocx` command. It sends a DOCX file to Convert and writes the result into the editor.

Export no longer builds the DOCX file in the browser. The Convert service builds it. Both commands need a network connection and a token.

## Formats

Conversion 1.0 covers DOCX, in both directions.

| Direction | Package                             | Command      |
| --------- | ----------------------------------- | ------------ |
| Export    | `@tiptap-pro/extension-export-docx` | `exportDocx` |
| Import    | `@tiptap-pro/extension-import-docx` | `importDocx` |

## Pages and Conversion

Import and export work with a plain Tiptap editor. They also work with [Page Layout](/pages/v2/getting-started/overview).

- On import, the document goes into the Page Layout source document, with its footnotes and endnotes. Without Page Layout, it goes into the editor with `setContent`.
- On export, the headers, footers and page setup come from the Page Layout setup of the document.
