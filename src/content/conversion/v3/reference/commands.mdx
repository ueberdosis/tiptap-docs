Tiptap Conversion adds commands to the editor that export the document as a Word file, import a Word file, and turn preserved content back into real nodes. Each one is described here, with a link to the page that explains it.

The export and import commands return `true` right away, because the Conversion service converts the file over the network. The result arrives later in a callback, and a failure reaches `onError`, as [Warnings and errors](/conversion/v3/reference/warnings-and-errors#errors) describes.

The examples run on an editor set up as in [Install Tiptap Conversion](/conversion/v3/getting-started/install), which has the complete example.

## exportDocx()

`exportDocx()` saves the editor's document as a `.docx` file and hands the file to `onCompleteExport`. It comes with the `ExportDocx` extension, as [Export DOCX](/conversion/v3/docx/export) shows. In this example, `upload` stands for your own function that sends the bytes to your server:

```ts
editor.commands.exportDocx({
  exportType: 'buffer',
  onCompleteExport: (bytes) => upload(bytes),
})
```

The command calls `onCompleteExport` with the file in the shape `exportType` sets, so `bytes` in this example is a `Uint8Array`.

Takes one optional object, of the type `ExportDocxCommandOptions`, with any option of [Export options](/conversion/v3/docx/export-options), `token` included. An option passed to the command wins for that export, and replaces the configured value as a whole, so an object option doesn't merge with the configured one.

Returns `true` right away, also when the export fails later. It doesn't return `false`.

The command sends the document to `POST <endpoint>/export/docx`, where `<endpoint>` is the base URL that [Region and endpoint](/conversion/v3/getting-started/install#region-and-endpoint) describes. The request holds the document, its page setup, comments, fonts, the images the Conversion service can't download, and the CSS the editor renders, which export measures in the browser. The token goes in an `Authorization: Bearer` header, and `appId`, when set, in an `X-App-Id` header.

## importDocx()

`importDocx()` opens a `.docx` file in the editor. It comes with the `ImportDocx` extension, as [Import DOCX](/conversion/v3/docx/import) shows. In this example, `file` is a `.docx` file the user picked:

```ts
editor.commands.importDocx({
  file,
  onImport: (context) => {
    if (context.error) return
    context.setEditorContent()
  },
})
```

Takes one object, of the type `ImportDocxCommandOptions`:

| Argument                                                                               | Type                                                       | Description                                                                                                                                                                        |
| -------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `file`                                                                                 | `File`                                                     | Required. The `.docx` file to import.                                                                                                                                              |
| `onImport`                                                                             | `((context: ImportContext) => void) \| null`               | Receives the document. With it, the import writes nothing until you call `context.setEditorContent()`. Without it, or with `null`, the import writes the document when it arrives. |
| `cssStyles`, `trackedChanges`, `taskLists`, `behindTextImages`, `onError`, `onWarning` | As in [Import options](/conversion/v3/docx/import-options) | The value for this import. It wins over the configured one, and `cssStyles` merges with the configured one.                                                                        |

`importDocx()` takes no `token`. It uses the one in `ImportDocx.configure()`, as [Get a Conversion token](/conversion/v3/getting-started/install#3-get-a-conversion-token) explains.

Returns `true` right away, and the import runs in the background. When a second import starts before the first finishes, the newer one wins and the older one fails with an `ImportDocxSupersededError`.

## restorePreservedContent()

`restorePreservedContent()` turns the preserved content of the editor's document back into the nodes, marks and attributes the editor now has, such as tables once you add the table extension. Preserved content is what an import kept because the editor had no extension for it.

The command comes with the `PreservedContent` extension, which `ImportDocx` adds to the editor and which installs with Import DOCX:

```ts
editor.commands.restorePreservedContent()
```

Run it for a document that is already open in the editor. A JSON document you pass as `content` is restored on its own when the editor opens, but a shared document, which Tiptap Collaboration syncs between users, never is. So for a shared document, run the command once, from one client, after you add the extension.

The restore is one step, so one undo takes it back. Content that still doesn't fit stays preserved, so it can come back after you add another extension. [Content the editor cannot show](/conversion/v3/docx/preserved-content) explains when to restore, and how to restore a document without an editor.

Takes no arguments.

Returns `true` when it restored content, and `false` when the document holds nothing to restore.

## Commands for other formats

The other formats have commands of their own, each described on its format's page:

| Command            | Saves the document as | Page                                             |
| ------------------ | --------------------- | ------------------------------------------------ |
| `exportPdf()`      | A PDF file            | [PDF](/conversion/v3/pdf)                        |
| `exportDoc()`      | A DOC file            | [DOC, ODT and EPUB](/conversion/v3/doc-odt-epub) |
| `exportOdt()`      | An ODT file           | [DOC, ODT and EPUB](/conversion/v3/doc-odt-epub) |
| `exportEpub()`     | An EPUB file          | [DOC, ODT and EPUB](/conversion/v3/doc-odt-epub) |
| `exportMarkdown()` | Markdown              | [Markdown](/conversion/v3/markdown)              |
