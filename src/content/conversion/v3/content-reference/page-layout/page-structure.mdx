Export writes the page setup of [Page Layout](/pages/v2/core-concepts/sections) as Word sections. Import turns each Word section into a Page Layout section with its own page setup.

## Set up the editor

Page Layout holds the page setup, one for each section. See [page format](/pages/v2/core-concepts/page-format) and [sections](/pages/v2/core-concepts/sections).

Without Page Layout, export writes one section with the `pageSize` and `pageMargins` options. The defaults are A4 with 2.54cm top and bottom margins and 3.17cm side margins. An editor without pages, or a pageless one, does the same.

## Import

Import puts a `sectionBreak` node in front of each section, the first one at the very start of the document. With Page Layout, `setEditorContent` writes them with the rest of the document. Each section break holds the setup of its section.

| Setting              | From Word                                                                               |
| -------------------- | --------------------------------------------------------------------------------------- |
| Paper size           | The page size                                                                           |
| Orientation          | Portrait or landscape                                                                   |
| Margins              | Top, right, bottom and left                                                             |
| Section break kind   | `nextPage` or `continuous`                                                              |
| Columns              | Count, gaps, widths and the line between columns                                        |
| Page numbering       | Format, start number and chapter prefix                                                 |
| Different first page | Per section                                                                             |
| Header and footer    | See [headers and footers](/conversion/v3/content-reference/page-layout/headers-footers) |

The page color of the document goes on the first section.

Import changes or leaves out a few settings, and `onWarning` receives a warning for each.

- A section that starts on an even or odd page starts on the next page instead, with `section-start-even-odd`.
- The binding gutter of the margins is left out, with `gutter-dropped`.
- A section break inside a table is ignored, with `section-in-table-cell`. Word doesn't end a section there.

Without Page Layout, import leaves the section breaks out with their setup. See [import without Page Layout](/conversion/v3/import/docx/without-page-layout).

### Section columns

Import keeps the columns of a section on its section break. The blocks of the section stay in the document flow. See [section columns](/pages/v2/core-concepts/section-columns).

## Export

Export reads the page setup of the first section and a `sectionBreak` node for each later section.

| Setting              | Word                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------- |
| Paper size           | The page size, from the format width and height                                         |
| Orientation          | Portrait or landscape                                                                   |
| Margins              | Top, right, bottom and left                                                             |
| Section break kind   | `nextPage` starts a new page, `continuous` stays on the sheet                           |
| Columns              | Count, gaps, widths and the line between columns                                        |
| Page numbering       | Format, start number and chapter prefix                                                 |
| Different first page | Per section                                                                             |
| Header and footer    | See [headers and footers](/conversion/v3/content-reference/page-layout/headers-footers) |

A continuous section takes the paper of the section above it, because paper can't change halfway down a sheet.

Page numbers use the number format of the section, such as `decimal` or `lowerRoman`. Export writes the start number and the chapter prefix with its separator. Export writes a format with no exact Word match as the closest one and reports a warning.

### Page color

Word has one page color for the whole document. Export writes the page color of the first section. To set it yourself, pass `pageColor`.

```ts
editor.commands.exportDocx({ pageColor: '#fff8e8' })
```

Export drops a different page color on a later section, and the text and accent colors of every section. Export reports an `unsupported` warning for each. Word prints the page color only when its print background setting is on.

### Options

[`pageSetup`](/conversion/v3/export/docx/usage#set-page-size-and-margins) sends a Page Layout setup other than the editor's. `pageSize` and `pageMargins` take a string with a unit, such as `'2cm'` or `'1in'`, or a number of twips. Top and bottom margins can be negative.

```ts
editor.commands.exportDocx({
  pageSize: { width: '21cm', height: '29.7cm' },
  pageMargins: { top: '2cm', bottom: '2cm', left: '2cm', right: '2cm' },
})
```

## Limitations

- Import leaves out the binding gutter, and starts an even or odd page section on the next page.
- Without Page Layout, import leaves out the page setup.
- Export keeps one page color for the whole document.
- Export drops section text and accent colors.
