Find out what happens to each kind of Word content on import and export, and which extensions keep it. Each page names the editor extensions you need, what import returns and what export writes.

For a one-page summary of what Conversion carries, see the [feature support matrix](/conversion/v3/getting-started/feature-support-matrix).

## What the editor keeps

Import returns your document as Tiptap JSON. The editor keeps only what its schema defines.

- Import leaves out a node or mark type the schema doesn't have, and `onWarning` receives an `unsupported` warning.
- The editor drops an attribute the schema doesn't define, without a warning.
- `onImport` gives you the JSON before it reaches the editor, so you can inspect it or change it.

Export reads the same attributes back from your editor. An attribute the editor never stored can't reach the `.docx` file.
