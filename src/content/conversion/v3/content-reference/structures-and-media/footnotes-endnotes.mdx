Footnotes and endnotes convert in both directions. With Page Layout, import writes the notes into the document and export reads them from it. Without it, import leaves the notes out, and export takes them as separate objects that you pass.

## Set up the editor

Page Layout is the supported route. It holds the body and the notes in one document. Add `@tiptap-pro/extension-footnotes` for the note nodes. See [footnotes](/features/footnotes).

Without Page Layout, import leaves the notes and their references out, and `onWarning` receives an `unsupported` warning for each node type.

## Import

Import returns the notes inside the document, as the footnotes extension holds them. With Page Layout, `setEditorContent` writes the body and the notes into the source document.

- Each reference becomes a `footnoteReference` node with a `footnoteId`.
- Each note becomes a `footnote` node inside a `footnoteCollection` at the end of the document, with a `placement` of `footnote` or `endnote`.
- When an endnote id is also a footnote id, the endnote gets the suffix `-endnote`.

The import leaves out a note without a reference, and a reference without a note. `onWarning` receives a `notes-dropped` warning.

Without Page Layout, `setEditorContent` writes the body only and leaves the notes and their references out. `context.content` still has them. See [import without Page Layout](/conversion/v3/import/docx/without-page-layout).

## Export

With Page Layout, export reads the notes from the document. Footnotes and endnotes follow the `placement` of each note. Export ignores the [`footnotes` and `endnotes` options](/conversion/v3/export/docx/usage#keep-notes-and-comments), and `onWarning` receives a warning for each one you pass. Export leaves out a note that no reference points at and reports an `unsupported` warning that names the note id.

Without Page Layout, pass the notes yourself. Each option maps a note id to a Tiptap JSON document, and the body needs a matching reference node with that id in `noteId`.

```ts
editor.commands.exportDocx({
  footnotes: {
    1: {
      type: 'doc',
      content: [{ type: 'paragraph', content: [{ type: 'text', text: 'Source: annual report.' }] }],
    },
  },
})
```

Export doesn't write a reference without a note body.

## Limitations

- Without Page Layout, import leaves the notes out.
- Import and export drop a note without a matching reference or body.
