A Word hyperlink imports as a `link` mark with an `href`, and exports back as a Word hyperlink. A link to a place in the same document uses an `href` that starts with `#`. The place it points to is a bookmark, and bookmarks only partly survive.

## Set up the editor

`StarterKit` has the `Link` mark. It adds `target` and `rel` attributes. Import doesn't set them and export doesn't write them.

A bookmark imports as a `bookmark` node. No stock extension has that node, so the editor needs an extension of your own that defines it. Without one, import leaves the bookmarks out and `onWarning` receives an `unsupported` warning. The links that point at them still import.

The [`prosemirrorNodes`](/conversion/v3/import/docx/custom-node-mapping) option of `ImportDocx` renames the node, if your extension uses another name.

```ts
ImportDocx.configure({
  token: 'CONVERT_TOKEN',
  prosemirrorNodes: { bookmark: 'myBookmark' },
})
```

## Import

Import turns a link into a `link` mark.

```json
{
  "type": "text",
  "text": "Visit the Tiptap website",
  "marks": [{ "type": "link", "attrs": { "href": "https://tiptap.dev" } }]
}
```

Word stores a link in a few ways. Import reads them all.

- A hyperlink with a web address.
- A hyperlink to a bookmark, which becomes `#name`.
- A `HYPERLINK` field, with or without the `\l` switch for a bookmark.

When a link has both a web address and a bookmark, the `href` joins them, such as `https://example.com#intro`. Formatting inside the link stays on each part of the text.

Import keeps links that start with `http`, `https`, `mailto`, `tel` or `ftp`, and links without a scheme. A link with another scheme, such as `javascript`, imports as plain text.

### Bookmarks

Import turns the start of each bookmark into a zero-width `bookmark` node that holds the name in `id`.

```json
{ "type": "bookmark", "attrs": { "id": "intro" } }
```

A link points at it with `#intro`. The node sits where the bookmark began, and import loses the range the bookmark covered. A bookmark between paragraphs moves to the start of the next paragraph.

Word adds bookmarks of its own, such as `_GoBack` and the `_Toc` entries behind a table of contents. Import returns them like any other bookmark.

## Export

A link to a web address, including `mailto:`, exports as a Word hyperlink with the Hyperlink style. A link whose `href` starts with `#` exports as an internal link to the bookmark with that name. A `#` alone has no target, so the text exports without a link. An address such as `https://example.com#intro` stays an external link.

Export writes a bookmark only for a node named `bookmark` that has an `id` attribute. It writes the bookmark where the node sits, with no range.

Export doesn't write the Bookmarks mark or the `bookmarkPoint` node from Page Layout. See [bookmarks in a .docx](/pages/v2/extensions/bookmarks#in-a-docx).

## Limitations

- A bookmark loses the range it covered. Import keeps only its start.
- Export drops the Bookmarks mark and the `bookmarkPoint` node. A link to one of them has no target in Word.
- Export doesn't write the `target` and `rel` attributes.
- Cross-references to bookmarks don't round-trip. See [Word fields](/pages/v2/extensions/cross-references/docx).
