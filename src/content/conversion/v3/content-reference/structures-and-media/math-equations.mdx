Export writes `inlineMath` and `blockMath` nodes as Word equations. Import doesn't read equations, so they are missing from the imported document.

## Set up the editor

`@tiptap/extension-mathematics` provides the two nodes. It isn't part of `StarterKit`. It renders with KaTeX, so install `katex` too.

```bash
npm install @tiptap/extension-mathematics katex
```

```ts
import { Mathematics } from '@tiptap/extension-mathematics'
import 'katex/dist/katex.min.css'

const extensions = [StarterKit, Mathematics]
```

Both nodes keep the formula as LaTeX in a `latex` attribute. `inlineMath` sits in a paragraph and `blockMath` is a block of its own.

## Import

Word stores equations in its own math markup. Import doesn't read it. The equation and its text aren't in the imported content, and no `inlineMath` or `blockMath` node comes back. Import doesn't warn about it.

## Export

Export reads the `latex` attribute and converts it to a Word equation.

- A `blockMath` node exports as a paragraph that holds the equation.
- An `inlineMath` node exports as an equation inside its paragraph, next to the other text.

Export converts these parts of LaTeX.

| LaTeX                               | Word equation             |
| ----------------------------------- | ------------------------- |
| `\frac{a}{b}`                       | Fraction                  |
| `\binom{n}{k}`                      | Binomial                  |
| `\sqrt{x}` and `\sqrt[n]{x}`        | Root                      |
| `x^{2}`, `x_{i}` and `x_{i}^{2}`    | Superscript and subscript |
| `\begin{matrix} ... \end{matrix}`   | Matrix                    |
| `\text{...}`                        | Plain text                |
| Greek letters, operators and arrows | The matching symbol       |

Export keeps the delimiter character after `\left` and `\right`. It writes a command it doesn't know as its name without the backslash. Environments other than `matrix`, such as `pmatrix`, aren't built.

If a formula can't be converted, export writes the raw LaTeX as text in the equation. Check your formulas in a Word file before you rely on them.

## Limits

- Import doesn't read equations.
- Export converts common LaTeX only.
