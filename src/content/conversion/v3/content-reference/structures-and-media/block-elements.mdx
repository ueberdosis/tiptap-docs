Blockquotes, horizontal rules and hard breaks convert in both directions. Code blocks only export. Page breaks have [their own page](/conversion/v3/content-reference/page-layout/page-breaks).

## Set up the editor

`StarterKit` has `Blockquote`, `HorizontalRule`, `HardBreak` and `CodeBlock`. No other extension or option is needed.

| Element         | Import | Export |
| --------------- | ------ | ------ |
| Blockquote      | Yes    | Yes    |
| Horizontal rule | Yes    | Yes    |
| Hard break      | Yes    | Yes    |
| Code block      | No     | Yes    |

## Blockquote

A paragraph with Word's Quote style imports as a `blockquote` that holds one `paragraph`. The match ignores case. Inline formatting inside the quote stays.

Export writes each paragraph inside a `blockquote` with the Quote style. Export expects paragraphs inside a blockquote. It leaves out other blocks in it, such as lists or tables.

## Horizontal rule

Word draws a horizontal rule as a line shape. Import turns these shapes into a `horizontalRule` node:

- The standard rule from Word's horizontal line command.
- A simple line shape, or a rectangle shape without text.

A shape that holds text isn't read as a rule.

Export writes a rule as a gray horizontal line shape that spans the text width.

## Hard break

A line break inside a paragraph imports as a `hardBreak` node. A break that ends a page or a column isn't a hard break. See [page breaks](/conversion/v3/content-reference/page-layout/page-breaks).

Export writes a `hardBreak` as a line break inside the paragraph.

## Code block

Export writes a `codeBlock` as one paragraph with a CodeBlock style: Courier New on a gray background. Each newline becomes a line break, so the block stays one paragraph in Word. With [document styles](/conversion/v3/export/docx/usage#match-your-editors-formatting), the style takes its font, colors and spacing from your editor's code block CSS.

Word has no setting for the language, so export leaves `language` out. Import has no Word style that turns into a `codeBlock`.

Inline code works. Export writes the `code` mark with Word's Code character style, and import reads it back.

## Limitations

- Import doesn't create a `codeBlock`.
- Export leaves out `language`.
