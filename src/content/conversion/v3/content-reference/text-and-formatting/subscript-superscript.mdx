Subscript and superscript text, such as H₂O or x², imports as the `subscript` and `superscript` marks and exports as Word's subscript and superscript.

## What you need

Add `Subscript` and `Superscript`, which aren't part of `StarterKit`:

```ts
import StarterKit from '@tiptap/starter-kit'
import Subscript from '@tiptap/extension-subscript'
import Superscript from '@tiptap/extension-superscript'

const extensions = [StarterKit, Subscript, Superscript]
```

Without one of them, import keeps that mark as preserved content, with a [`preserved` warning](/conversion/v3/import/docx/warnings-and-errors), and the text shows without the formatting until you add the extension. [What converts](/conversion/v3/content-reference/overview#what-the-editor-keeps) explains preserved content.

## Import

Import reads the vertical position of each Word run:

| Word setting | Mark          |
| ------------ | ------------- |
| Subscript    | `subscript`   |
| Superscript  | `superscript` |

Any other position, such as baseline, gives no mark.

## Export

Export writes `subscript` as Word's subscript and `superscript` as Word's superscript.

## Limits

Equations don't use these marks. [Math and equations](/conversion/v3/content-reference/structures-and-media/math-equations) covers them.
