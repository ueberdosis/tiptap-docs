Subscript and superscript text, such as H₂O or x², imports as marks and exports as Word's vertical alignment.

## Set up the editor

Add both marks. They aren't part of `StarterKit`.

```ts
import StarterKit from '@tiptap/starter-kit'
import Subscript from '@tiptap/extension-subscript'
import Superscript from '@tiptap/extension-superscript'

const extensions = [StarterKit, Subscript, Superscript]
```

Import leaves out a mark the editor doesn't have, and `onWarning` receives an `unsupported` warning.

## Import

Import reads the vertical alignment of a text run.

| Word setting | Mark          |
| ------------ | ------------- |
| Subscript    | `subscript`   |
| Superscript  | `superscript` |

Any other vertical alignment, such as baseline, produces no mark.

## Export

| Mark          | Word setting |
| ------------- | ------------ |
| `subscript`   | Subscript    |
| `superscript` | Superscript  |

## Limitations

- Math doesn't use these marks. See the [feature support matrix](/conversion/v3/getting-started/feature-support-matrix#images-and-math).
