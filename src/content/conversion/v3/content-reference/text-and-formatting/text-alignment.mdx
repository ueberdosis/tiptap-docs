Text alignment is a paragraph setting in Word and the `textAlign` attribute in the editor. Left, centered, right and justified paragraphs and headings convert in both directions.

## What you need

`TextAlign` from `@tiptap/extension-text-align` defines `textAlign` on the node types you list in its `types` option. `types` is empty by default, so list `heading` and `paragraph`:

```ts
import StarterKit from '@tiptap/starter-kit'
import TextAlign from '@tiptap/extension-text-align'

const extensions = [StarterKit, TextAlign.configure({ types: ['heading', 'paragraph'] })]
```

Without `TextAlign`, the editor shows every paragraph with its default alignment. Import keeps `textAlign` in the node's `preservedAttrs` attribute, from `@tiptap-pro/extension-preserved-content`, which the ImportDocx extension adds on its own. So the alignment comes back when you add `TextAlign`, and export still writes it.

## Import

Import reads the alignment of each Word paragraph and sets `textAlign` on the `paragraph` or `heading` node:

| Word alignment | `textAlign` |
| -------------- | ----------- |
| Left           | `left`      |
| Center         | `center`    |
| Right          | `right`     |
| Both           | `justify`   |

Any other Word value, such as `start` or `end`, passes through as it is. When a paragraph sets no alignment, the alignment of its named style applies.

## Export

Export writes the `textAlign` values `left`, `center`, `right` and `justify` as the matching Word alignment. It ignores any other value, such as `start`, so the paragraph takes the alignment of its Word style.

### Right-to-left text

Export takes the text direction from your editor's CSS. When the editor renders its paragraphs right to left, for example with `direction: rtl` on the editor, export marks every paragraph in the file as right to left. Export doesn't detect a single paragraph with a direction of its own.

## Limits

Import ignores the right-to-left setting of Word paragraphs and runs.

Import keeps the text inside Word's bidirectional embedding elements (`w:dir` and `w:bdo`), which right-to-left documents use, but not the text direction they set.
