Alignment is a paragraph attribute. A paragraph that is left, centered, right or justified in Word comes into the editor the same way, and goes back out the same way.

## Set up the editor

Add `TextAlign` from `@tiptap/extension-text-align`, and list the nodes that can hold an alignment. Its `types` option is empty by default, so alignment does nothing until you set it.

```ts
import StarterKit from '@tiptap/starter-kit'
import TextAlign from '@tiptap/extension-text-align'

const extensions = [StarterKit, TextAlign.configure({ types: ['heading', 'paragraph'] })]
```

Without it, the editor drops the `textAlign` attribute when the document loads, and no warning appears.

## Import

Import reads the paragraph's alignment from Word and sets `textAlign` on `paragraph` and `heading` nodes.

| Word alignment | `textAlign` |
| -------------- | ----------- |
| Left           | `left`      |
| Center         | `center`    |
| Right          | `right`     |
| Both           | `justify`   |

Any other Word value, such as `start` or `end`, passes through unchanged. The named style's alignment applies when the paragraph sets none.

## Export

Export reads `textAlign` from each paragraph and heading. It writes `left`, `center`, `right` and `justify` as the matching Word alignment. It ignores any other value, so the paragraph takes the alignment of its style.

### Right-to-left text

Import ignores the text direction of a Word paragraph. Export writes it. When the editor renders a paragraph right to left, export marks the paragraph as right to left and swaps `left` and `right`. The text then sits on the side the editor shows.

Set the direction in your CSS, for example `direction: rtl` on the editor.

## Limitations

- Import ignores right-to-left paragraphs and runs.
- Export ignores alignment values other than the four above.
