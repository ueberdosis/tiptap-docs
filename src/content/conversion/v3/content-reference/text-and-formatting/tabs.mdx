Import turns a Word tab into four spaces. Export writes a tab character in the editor as a Word tab. Word's tab stop positions don't come into the editor.

## Set up the editor

No extension is needed. A tab on import is plain text.

## Import

Each tab in a Word run becomes four space characters in the text. Import doesn't read tab stops, so left, center, right, decimal and bar stops are lost. A tab at the start of a paragraph and one in the middle give the same four spaces.

The editor shows those spaces. Tiptap's default editor styles set `white-space: break-spaces`, which keeps runs of spaces. If your CSS sets `white-space: normal` on paragraphs, the spaces collapse and an indent looks like it vanished.

## Export

Export writes a tab character in text as a Word tab. The four spaces that import produced stay four spaces.

The distance between default tab stops comes from the `defaultTabStop` option of the export command, in twips.

```ts
editor.commands.exportDocx({ defaultTabStop: 720 })
```

`720` twips is half an inch.

## Limits

- A tab doesn't round-trip. It imports as four spaces and exports as four spaces.
- Tab stop positions aren't read or written.
