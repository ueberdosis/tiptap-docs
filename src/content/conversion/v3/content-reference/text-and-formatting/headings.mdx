A Word heading is a paragraph in a heading style, such as Heading 2. It imports as a `heading` node with a `level`, and exports as the Word heading style of that level, for levels 1 to 6.

## What you need

`StarterKit` from `@tiptap/starter-kit` has the `Heading` node, with levels 1 to 6. A heading carries the same spacing, indent and line spacing attributes as a paragraph, which [Paragraphs](/conversion/v3/content-reference/text-and-formatting/paragraphs#what-you-need) lists. Alignment needs `TextAlign`, as [Text alignment](/conversion/v3/content-reference/text-and-formatting/text-alignment) shows.

The font, size and color of a heading style arrive on the `textStyle` mark. It needs `TextStyle`, `FontFamily`, `FontSize` and `Color`, which `TextStyleKit` from `@tiptap/extension-text-style` adds together:

```ts
import StarterKit from '@tiptap/starter-kit'
import { TextStyleKit } from '@tiptap/extension-text-style'

const extensions = [StarterKit, TextStyleKit]
```

Without `textStyle`, import keeps the mark as preserved content, with a [`preserved` warning](/conversion/v3/import/docx/warnings-and-errors), and the text shows without that formatting until you add the extensions. [What converts](/conversion/v3/content-reference/overview#what-the-editor-keeps) explains preserved content.

## Import

A paragraph becomes a heading when its style name is `Heading` followed by a number, such as `Heading 2`. The match ignores case and the space, so `heading2` matches too. The bold of the heading style arrives as a `bold` mark, and its font, size and color on a `textStyle` mark:

```json
{
  "type": "heading",
  "attrs": { "level": 2, "textAlign": "center" },
  "content": [
    {
      "type": "text",
      "text": "My heading",
      "marks": [
        { "type": "bold" },
        {
          "type": "textStyle",
          "attrs": { "fontFamily": "Arial", "fontSize": "19px", "color": "#2E74B5" }
        }
      ]
    }
  ]
}
```

Heading 7 to Heading 9 keep their number, so Heading 7 imports with `level: 7`.

`StarterKit` draws such a heading as `<h1>`, as [Limits](#limits) says, so you may want to lower the level in `onImport`. This example does it for the headings at the top level of the document, with `file` as a `.docx` file the user picked:

```ts
editor.commands.importDocx({
  file,
  onImport: (context) => {
    if (context.error) return
    context.content.content?.forEach((node) => {
      if (node.type === 'heading' && node.attrs && node.attrs.level > 6) node.attrs.level = 6
    })
    context.setEditorContent()
  },
})
```

Import decides by the style's own name. A paragraph in the style Title, Subtitle or any other style imports as a `paragraph`, also a custom style based on Heading 1. Its formatting still arrives as marks and attributes, but the style name isn't kept.

To import such a style as a heading, rename it to Heading 1 to Heading 6 in Word. You can also map the style name to a node type with the `prosemirrorNodes` option of `ImportDocx.configure()`, as [Custom node mapping](/conversion/v3/import/docx/custom-node-mapping) shows.

To make your editor's headings look like the file's, turn on the experimental `cssStyles` option of `ImportDocx.configure()`. It is off by default. When it is on, `onImport` receives the file's named styles as CSS in `context.cssStyles`, as [CSS styles](/conversion/v3/import/docx/css-styles) shows.

## Export

Export writes a heading with `level` 1 to 6 as a paragraph in the Word style Heading 1 to Heading 6, with its alignment and inline formatting.

Export also reads the styles the browser computes for `h1` to `h6` in your mounted editor and writes them into the Word heading styles.

A heading whose text has no `textStyle` mark looks like your editor in Word. An imported heading keeps the font, size and color of its marks, so it still looks like the file.

A headless or unmounted editor has nothing to read. Heading 1 to Heading 5 then start as bold Arial in the color `2E74B5`, at 16, 14, 13, 12 and 11pt. To set the heading styles yourself, see [Export styles and fonts](/conversion/v3/export/docx/styles).

Numbered headings from the Outline Numbering extension are covered in [Lists](/conversion/v3/content-reference/text-and-formatting/lists#outline-numbering).

## Limits

A numbered heading, which is a heading style linked to Word's numbering, imports as a list item. When the list item has to start with a paragraph, as the `ListItem` of `StarterKit` does, the heading becomes that paragraph, with a `restructured` warning. Its text is kept.

The `Heading` node of `StarterKit` allows levels 1 to 6. It draws any other level, such as an imported `level: 7`, as `<h1>`, unless you lower it on import as [Import](#import) shows. A heading with `level` 7 to 9 exports as a normal paragraph.
