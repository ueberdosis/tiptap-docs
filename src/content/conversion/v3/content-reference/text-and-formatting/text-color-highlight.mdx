Text color imports as an attribute on the `textStyle` mark. Highlight and character shading import as the `highlight` mark. Export writes both back as Word run formatting.

## Set up the editor

Text color needs `TextStyle` and `Color`. Highlight needs `Highlight` with `multicolor` on. Without it, the `color` attribute doesn't exist and every highlight imports as the default one.

```ts
import StarterKit from '@tiptap/starter-kit'
import Highlight from '@tiptap/extension-highlight'
import { Color, TextStyle } from '@tiptap/extension-text-style'

const extensions = [StarterKit, TextStyle, Color, Highlight.configure({ multicolor: true })]
```

`TextStyleKit` from `@tiptap/extension-text-style` adds `TextStyle`, `Color`, `BackgroundColor`, `FontFamily`, `FontSize` and `LineHeight` in one step.

A mark the editor doesn't have is left out of the import, and `onWarning` receives an `unsupported` warning.

## Import

| Word setting               | Result                                   |
| -------------------------- | ---------------------------------------- |
| Font color `FF0000`        | `textStyle` mark with `color: "#FF0000"` |
| Highlight `yellow`         | `highlight` mark with `color: "yellow"`  |
| Shading with fill `00FFFF` | `highlight` mark with `color: "#00FFFF"` |

Color and shading can also come from the run's character style, the paragraph's style and the document defaults.

- Import reads the hex value of a font color. A color of `auto` is skipped, and so are theme color attributes.
- Shading with a fill of `auto` or white is skipped.

## Export

Export turns a color into six hex digits. It accepts these forms.

- Hex, such as `#FF0000`, `#F00` or `#FF0000AA`. A fully transparent hex color is skipped.
- `rgb()` and `rgba()`. A fully transparent value is skipped.
- One of 20 color names, such as `red`, `blue`, `green`, `yellow`, `cyan` or `purple`.

A color it can't read is ignored, and a warning appears in the console.

A `highlight` mark exports in one of two ways.

- A color that is a Word highlight name, such as `yellow` or `cyan`, becomes that highlight.
- Any other readable color becomes solid character shading with that fill.
- A mark without a color becomes a yellow highlight.

A `backgroundColor` attribute on `textStyle`, from `BackgroundColor`, exports as character shading.

## Limits

- Import skips theme color attributes and the `auto` color.
