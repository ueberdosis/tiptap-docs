These four marks come from the formatting of a text run in Word. They import as marks on text, and export as the same formatting on Word runs.

## Set up the editor

`StarterKit` has `Bold`, `Italic`, `Underline` and `Strike`. You don't need anything else.

## Import

| Word formatting | Mark        |
| --------------- | ----------- |
| Bold            | `bold`      |
| Italic          | `italic`    |
| Underline       | `underline` |
| Strikethrough   | `strike`    |

Formatting from the run's character style, the paragraph's style and the document defaults applies when the run doesn't set it. A toggle that Word switches off, such as bold turned off inside a bold style, produces no mark.

### Underline styles

Import recognises 17 Word underline styles. It turns one into an `underlineType` attribute on the `underline` mark, for example `double`, `dotted` or `wave`. A plain underline has no attribute. An underline set to none has no mark.

The `Underline` extension from `StarterKit` doesn't define `underlineType`, so the editor drops it and every underline becomes plain. To keep the style, add the attribute.

```ts
import StarterKit from '@tiptap/starter-kit'
import Underline from '@tiptap/extension-underline'

const StyledUnderline = Underline.extend({
  addAttributes() {
    return {
      ...this.parent?.(),
      underlineType: { default: null },
    }
  },
})

const extensions = [StarterKit.configure({ underline: false }), StyledUnderline]
```

The attribute stores the style but doesn't draw it. Add `renderHTML` to the attribute if the editor should show it.

## Export

| Mark        | Word formatting |
| ----------- | --------------- |
| `bold`      | Bold            |
| `italic`    | Italic          |
| `underline` | Underline       |
| `strike`    | Strikethrough   |

An `underline` mark with an `underlineType` value from the list of Word styles exports with that style. Without one, or with an unknown value, it exports as a plain underline.

## Limits

- Double strikethrough isn't read or written.
- Without `underlineType` in the editor, underline styles collapse to a plain underline.
