Bold, italic, underline and strikethrough are run formatting in Word and marks in the editor. They convert in both directions, and import also reads Word's underline styles, such as double or wavy.

## What you need

`StarterKit` from `@tiptap/starter-kit` has `Bold`, `Italic`, `Underline` and `Strike`, so the four marks need no other extension.

An underline style is the `underlineType` attribute of the `underline` mark, which no Tiptap extension defines, so the editor shows a plain underline. Import keeps the style in the mark's `preservedAttrs` attribute, as [What converts](/conversion/v3/content-reference/overview#what-the-editor-keeps) explains, and export still writes it.

To show the style, define `underlineType` on the `underline` mark in an extension of your own. CSS has fewer line styles than Word, so this one draws each Word style with the closest CSS `text-decoration-style`. [Import](#import) lists the values:

```ts
import { Extension } from '@tiptap/core'

function cssUnderlineStyle(type: string) {
  if (type === 'double' || type === 'wavyDouble') return 'double'
  if (type.startsWith('dotted')) return 'dotted'
  if (type.startsWith('dash') || type.startsWith('dot')) return 'dashed'
  if (type.startsWith('wav')) return 'wavy'
  return 'solid'
}

const UnderlineStyle = Extension.create({
  name: 'underlineStyle',
  addGlobalAttributes() {
    return [
      {
        types: ['underline'],
        attributes: {
          underlineType: {
            default: null,
            renderHTML: ({ underlineType }) =>
              underlineType
                ? { style: `text-decoration-style: ${cssUnderlineStyle(underlineType)}` }
                : {},
          },
        },
      },
    ]
  },
})
```

## Import

Import turns Word's run formatting into marks:

| Word formatting | Mark        |
| --------------- | ----------- |
| Bold            | `bold`      |
| Italic          | `italic`    |
| Underline       | `underline` |
| Strikethrough   | `strike`    |

When a run, a stretch of text with the same formatting, doesn't set a format, the paragraph's style and the document defaults fill it in. A format Word switches off, such as bold turned off inside a bold paragraph style, gives no mark.

A plain underline gives an `underline` mark without `underlineType`, and an underline set to none gives no mark.

Word's 16 other underline styles set `underlineType` to the style's name: `words`, `double`, `thick`, `dotted`, `dottedHeavy`, `dash`, `dashedHeavy`, `dashLong`, `dashLongHeavy`, `dotDash`, `dashDotHeavy`, `dotDotDash`, `dashDotDotHeavy`, `wave`, `wavyHeavy` or `wavyDouble`.

To turn a Word character style into a mark, map its style id in the `prosemirrorMarks` option of `ImportDocx.configure()`.

Word shows a style's name, and the file stores an id for it. For Word's built-in styles, the id is the English name without spaces, such as `Strong`. Word's Code style needs no mapping, because it imports as the `code` mark.

In this example, every run in the style Strong gets the `bold` mark, and `CONVERSION_TOKEN` stands for your Conversion token:

```ts
import { ImportDocx } from '@tiptap-pro/extension-import-docx'

const importExtension = ImportDocx.configure({
  token: CONVERSION_TOKEN,
  prosemirrorMarks: { Strong: 'bold' },
})
```

[Custom node mapping](/conversion/v3/import/docx/custom-node-mapping) explains the option.

## Export

Export writes each mark back as the Word formatting in the [Import](#import) table. An `underline` mark with one of the `underlineType` values exports in that style. Without one, or with a value Word doesn't know, it exports as a single underline.

## Limits

Import doesn't apply the formatting of a Word character style, such as Strong or Emphasis, so its bold or italic is lost, without a warning. This is a known limit that is being fixed. Until then, map the style to a mark with `prosemirrorMarks`, as [Import](#import) shows.

Import doesn't read double strikethrough. A `strike` mark exports as a single line, unless your editor's CSS draws struck text with a double line, which export measures and writes into the Word style.
