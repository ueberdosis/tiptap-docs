A Word hyperlink imports as a `link` mark with an `href`, and exports back as a Word hyperlink. A link to a Word bookmark, a named place in the same document, has an `href` of `#` and the name. Links convert in both directions, bookmarks only partly.

## What you need

The `Link` mark from `StarterKit` holds links. Its `target` and `rel` attributes aren't set on import or written on export.

Export writes a Word bookmark only for a node named `bookmark` with an `id` attribute. [Bookmarks](/features/bookmark) (`@tiptap-pro/extension-bookmark`) has no such node: it has a `bookmark` mark and a `bookmarkPoint` node, which export doesn't write.

## Import

Import turns a hyperlink into a `link` mark on its text:

```json
{
  "type": "text",
  "text": "Visit the Tiptap website",
  "marks": [{ "type": "link", "attrs": { "href": "https://tiptap.dev" } }]
}
```

Import reads each form Word stores a link in:

- A hyperlink with a web address.
- A hyperlink to a bookmark, which becomes an `href` such as `#intro`.
- A `HYPERLINK` field, with or without the `\l` switch that points it to a bookmark.

A link with both a web address and a bookmark joins them, such as `https://example.com#intro`. Formatting inside the link stays.

Import keeps links that start with `http`, `https`, `mailto`, `tel` or `ftp`, and links without a scheme. A link with another scheme, such as `javascript`, imports as plain text.

Import leaves bookmarks out, with one `bookmarks-dropped` warning. A link to a bookmark keeps its `#name` `href`. A cross-reference, a Word field that repeats text from a bookmarked place, imports as the text Word last showed, as [Word fields](/features/cross-references/docx) describes.

## Export

A link to a web address, `mailto:` included, exports as a Word hyperlink with the Hyperlink style. `https://example.com#intro` stays external. An `href` of `#` and a name exports as an internal link to the bookmark with that name.

Export writes a `bookmark` node with an `id` as a Word bookmark where the node sits, without a range.

Export drops the `bookmark` mark of the Bookmarks extension, and its `bookmarkPoint` node with an `unsupported` warning, so links to them have no target in Word. A `crossReference` node is dropped with an `unsupported` warning too.

## Limits

- Import leaves bookmarks out, so a link to one has no target in the editor.
- Export drops the marks and points of the Bookmarks extension.
- Export doesn't write `target` and `rel`.
- Cross-references don't round-trip: import keeps their text, and export drops the `crossReference` node.
