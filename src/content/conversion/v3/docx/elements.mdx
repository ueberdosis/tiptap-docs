When the editor has no extension for some content, import keeps it as preserved content, a node the editor stores and shows as a placeholder, and export writes it back. [Content the editor cannot show](/conversion/v3/docx/preserved-content) explains it, and [Import DOCX](/conversion/v3/docx/import) and [Export DOCX](/conversion/v3/docx/export) show how to set up the editor.

## Not supported

Neither import nor export converts these Word features:

- [Theme colors and theme fonts](/conversion/v3/docx/elements/text-formatting#limits)
- [Hidden text](/conversion/v3/docx/elements/paragraphs#limits)
- [Bookmarks](/conversion/v3/docx/elements/links-and-bookmarks#bookmarks-and-cross-references)
- [The binding gutter of the margins](/conversion/v3/docx/elements/sections#settings-that-change-on-import)
- [Tracked formatting changes and tracked moves](/conversion/v3/docx/elements/tracked-changes#limits)
- [Tables of contents](/conversion/v3/reference/limitations#other-word-content), whose entries import as plain paragraphs
- [Text boxes](/conversion/v3/reference/limitations#other-word-content)
- [Shapes, SmartArt and WordArt](/conversion/v3/reference/limitations#other-word-content)
- [Content controls and form fields](/conversion/v3/reference/limitations#other-word-content), whose text imports without the control, apart from [checkboxes](/conversion/v3/docx/elements/lists#which-checkboxes-convert)
- [Document properties, such as author and title](/conversion/v3/reference/limitations#other-word-content)

[Limitations](/conversion/v3/reference/limitations) says what happens to each one, and what to do instead where there is a way.
