A Word hyperlink imports as a `link` mark with an `href`, and exports back as a Word hyperlink. A link to a Word bookmark, a named place in the same document, has the bookmark's name as its `href`, such as `#intro`.

Links convert in both directions. Word bookmarks don't convert yet: import leaves them out, and export doesn't write the bookmarks of the Bookmarks extension.

## What you need

Links need only `StarterKit`. Bookmarks and cross-references have extensions of their own, which don't convert yet:

| Element          | Extension                                                                                          | Node or mark                             |
| ---------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| Links            | `Link` from `StarterKit`                                                                           | `link`                                   |
| Bookmarks        | [Bookmarks](/features/bookmark), from `@tiptap-pro/extension-bookmark`                             | `bookmark` mark and `bookmarkPoint` node |
| Cross-references | [Cross-references](/features/cross-references/docx), from `@tiptap-pro/extension-cross-references` | `crossReference` node                    |

The `target` and `rel` attributes of `Link` aren't set on import or written on export.

## Import

Import turns a hyperlink into a `link` mark on its text:

```json
{
  "type": "text",
  "text": "Visit the Tiptap website",
  "marks": [{ "type": "link", "attrs": { "href": "https://tiptap.dev" } }]
}
```

Import reads every form Word stores a link in, including a `HYPERLINK` field. A link to a bookmark becomes an `href` such as `#intro`. A link with both a web address and a bookmark joins them, such as `https://example.com#intro`. Formatting inside the link stays.

Import keeps links that start with `http`, `https`, `mailto`, `tel` or `ftp`, and links without a scheme. A link with another scheme, such as `javascript`, imports as plain text.

### Bookmarks and cross-references

Import leaves bookmarks out, with one `bookmarks-dropped` warning. A link to a bookmark keeps its `#name` `href`.

A cross-reference, a Word field that repeats text from a bookmarked place, imports as the text Word last showed, as [Word fields](/features/cross-references/docx) describes.

## Export

An `href` such as `#intro` exports as an internal link to the bookmark with that name. Every other `href`, such as a web address, `mailto:`, `tel:` or `ftp:`, exports as a Word hyperlink with the Hyperlink style. `https://example.com#intro` stays external.

### Bookmarks and cross-references

The Bookmarks extension holds bookmarks in the editor: a `bookmark` mark over text and a `bookmarkPoint` node for a place without text. Import and export of these bookmarks come with a later version of the Conversion service and Export DOCX.

Export drops the `bookmark` mark of the Bookmarks extension without a warning, and keeps its text. It drops the extension's `bookmarkPoint` node with an `unsupported` warning. Links to either have no target in Word. Export drops the `crossReference` node of the Cross-references extension with an `unsupported` warning too.

## Limits

Links convert in both directions, but bookmarks and cross-references don't:

- Import leaves bookmarks out, so a link to one has no target in the editor.
- Export drops the marks and points of the Bookmarks extension.
- Export doesn't write `target` and `rel`.
- Cross-references don't round-trip: import keeps their text, and export drops the `crossReference` node.
