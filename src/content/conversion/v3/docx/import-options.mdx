`ImportDocx.configure()` sets the options of every import in an editor, and the `importDocx()` command takes the file and the options of one import. The extension, its types, helpers and error classes come from `@tiptap-pro/extension-import-docx`. For a walkthrough, start with [Import DOCX](/conversion/v3/docx/import).

Most editors set the token, an upload endpoint for images and the two callbacks. In this example, `CONVERSION_TOKEN` stands for your Conversion token, as [Install Tiptap Conversion](/conversion/v3/getting-started/install#3-get-a-conversion-token) shows how to get it:

```ts
import { ImportDocx } from '@tiptap-pro/extension-import-docx'

const importExtension = ImportDocx.configure({
  token: CONVERSION_TOKEN,
  imageUploadConfig: { url: 'https://example.com/upload' },
  onWarning: (warning) => console.warn(warning.code, warning.message),
  onError: (error) => console.error(error),
})
```

## ImportDocx options

`ImportDocx.configure()` takes `ImportDocxOptions`. `token` is required, and every other option is optional:

| Option              | Type                                           | Default     | Description                                                                                                                                                             |
| ------------------- | ---------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `token`             | `string`                                       | Required    | The Conversion token. Without it, the import fails before it sends a request.                                                                                           |
| `appId`             | `string`                                       | `undefined` | Your app ID, sent in the `X-App-Id` header. Only for a token from [Legacy authentication](/authentication/legacy).                                                      |
| `endpoint`          | `string`                                       | `undefined` | The base URL of your own Conversion service. It wins over `region`.                                                                                                     |
| `region`            | `'eu' \| 'us'`                                 | `'eu'`      | The Tiptap Cloud region, when you don't set `endpoint`.                                                                                                                 |
| `imageUploadConfig` | `ImageUploadConfig`                            | `undefined` | Where the Conversion service uploads the images. Without it, import skips every image. See [Images](/conversion/v3/docx/import#images).                                 |
| `prosemirrorNodes`  | `Record<string, string>`                       | `undefined` | Renames nodes. See [Custom nodes in Word files](/conversion/v3/docx/custom-nodes).                                                                                      |
| `prosemirrorMarks`  | `Record<string, string>`                       | `undefined` | Renames marks. See [Custom nodes in Word files](/conversion/v3/docx/custom-nodes).                                                                                      |
| `cssStyles`         | `ImportCssStylesOptions`                       | `undefined` | Extracts the Word styles as CSS. Off when unset. See [CSS styles](/conversion/v3/docx/import#css-styles).                                                               |
| `trackedChanges`    | `'auto' \| 'preserve' \| 'accept' \| 'reject'` | `'auto'`    | What happens to tracked changes. See [Tracked changes and comments](/conversion/v3/docx/tracked-changes-and-comments).                                                  |
| `taskLists`         | `'auto' \| 'import' \| 'ignore'`               | `'auto'`    | Whether checkbox lists become task lists. See [Checkbox lists](/conversion/v3/docx/import#checkbox-lists).                                                              |
| `behindTextImages`  | `'import' \| 'ignore'`                         | `undefined` | `'import'` keeps images behind the text, such as watermarks. Unset, import skips them. See [Images behind the text](/conversion/v3/docx/import#images-behind-the-text). |
| `onError`           | `(error: unknown) => void`                     | `undefined` | Receives the error when an import fails.                                                                                                                                |
| `onWarning`         | `(warning: ImportDocxWarning) => void`         | `undefined` | Receives every warning. Without it, warnings go to `console.warn`.                                                                                                      |

[Connection options](/conversion/v3/getting-started/install#connection-options) explains `token`, `appId`, `region` and `endpoint`, which the import takes only from `ImportDocx.configure()`. [Region and endpoint](/conversion/v3/getting-started/install#region-and-endpoint) lists the URLs the import calls.

## importDocx command options

`editor.commands.importDocx()` takes `ImportDocxCommandOptions`. Each option except `file` and `onImport` overrides the configured option of the same name for this import:

| Option             | Type                                           | Default             | Description                                                                                                                                                     |
| ------------------ | ---------------------------------------------- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `file`             | `File`                                         | Required            | The `.docx` file to import.                                                                                                                                     |
| `onImport`         | `((context: ImportContext) => void) \| null`   | `undefined`         | Receives the document. Without it, the import writes the document when it arrives. See [The onImport context](/conversion/v3/docx/import#the-onimport-context). |
| `cssStyles`        | `Partial<ImportCssStylesOptions>`              | `undefined`         | Merges over the configured `cssStyles` for this import.                                                                                                         |
| `trackedChanges`   | `'auto' \| 'preserve' \| 'accept' \| 'reject'` | The configured mode | Overrides the configured mode for this import.                                                                                                                  |
| `taskLists`        | `'auto' \| 'import' \| 'ignore'`               | The configured mode | Overrides the configured mode for this import.                                                                                                                  |
| `behindTextImages` | `'import' \| 'ignore'`                         | The configured mode | Overrides the configured mode for this import.                                                                                                                  |
| `onError`          | `(error: unknown) => void`                     | The configured one  | Receives the error. It wins over the configured `onError`.                                                                                                      |
| `onWarning`        | `(warning: ImportDocxWarning) => void`         | The configured one  | Receives every warning. It wins over the configured `onWarning`.                                                                                                |

The command returns `true` right away and imports in the background, as [Import a file](/conversion/v3/docx/import#import-a-file) explains.

## ImageUploadConfig

`imageUploadConfig` takes an `ImageUploadConfig`, which tells the Conversion service where to upload the images of the file:

| Field         | Type                     | Default     | Description                                                                                    |
| ------------- | ------------------------ | ----------- | ---------------------------------------------------------------------------------------------- |
| `url`         | `string`                 | Required    | The `http` or `https` address that receives each image.                                        |
| `headers`     | `Record<string, string>` | `undefined` | Headers the service adds to every upload. A plain object of strings, not a `Headers` instance. |
| `method`      | `string`                 | `'POST'`    | The HTTP method of the upload.                                                                 |
| `queryParams` | `Record<string, string>` | `undefined` | Query parameters the service adds to `url`.                                                    |

[Images](/conversion/v3/docx/import#images) shows the request your endpoint receives and the response it returns.

## ImportCssStylesOptions

`cssStyles` takes an `ImportCssStylesOptions`:

| Field        | Type      | Default     | Description                                                          |
| ------------ | --------- | ----------- | -------------------------------------------------------------------- |
| `enabled`    | `boolean` | Required    | Asks the Conversion service for the styles.                          |
| `autoInject` | `boolean` | `undefined` | When `true`, adds the rules to a `<style>` tag in the document head. |
| `selector`   | `string`  | `'.tiptap'` | The selector the rules sit under.                                    |

[CSS styles](/conversion/v3/docx/import#css-styles) shows what the service extracts and the helpers that apply it.

## Warnings and errors

`onWarning` receives an `ImportDocxWarning`, with a `code`, a `message` that is safe to log, and a `nodeType` or `markType` for the warnings of the editor. `onError` receives an `ImportDocxRequestError`, an `ImportDocxSupersededError`, an `ImageUploadConfigValidationError` or an `Error`. [Warnings and errors](/conversion/v3/reference/warnings-and-errors) lists every code and says when each error happens.
