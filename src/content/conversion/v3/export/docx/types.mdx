These are the types `@tiptap-pro/extension-export-docx` exports. A field marked `?` is optional. The [API reference](/conversion/v3/export/docx/api) describes behavior and defaults.

Some types build on the option types of the `docx` package, such as `IParagraphOptions`. The package's type declarations include them, so you don't need to install `docx`.

## Export options

### ExportDocxType

```ts
type ExportDocxType = 'blob' | 'base64' | 'string' | 'buffer'
```

### ExportDocxOptions

```ts
interface ExportDocxOptions extends ExportRequestInput {
  token?: string
  appId?: string
  endpoint?: string
  region?: 'eu' | 'us'
  exportType: ExportDocxType
  onCompleteExport: (result: Blob | string | Uint8Array) => void
  onError?: (error: unknown) => void
  onWarning?: OnExportDocxWarning
}
```

`token` is optional in the type, but every export needs it.

### ExportDocxCommandOptions

```ts
interface ExportDocxCommandOptions extends Partial<ExportDocxOptions> {}
```

### ExportRequestInput

The options that shape the request.

```ts
interface ExportRequestInput {
  pageSetup?: Record<string, unknown>
  outline?: {
    types: Record<string, unknown>
    levels: unknown
    ignore: unknown
  }
  numberingFormats?: readonly NumberingFormatDefinition[]
  listLevels?: ListLevels
  defaultTabStop?: number
  pageColor?: string
  pageSize?: { width?: PageMeasure; height?: PageMeasure }
  pageMargins?: {
    top?: SignedPageMeasure
    bottom?: SignedPageMeasure
    left?: PageMeasure
    right?: PageMeasure
    header?: PageMeasure
    footer?: PageMeasure
  }
  styleOverrides?: IStylesOptions
  cssStyles?: CssStylesOptions
  documentStyles?: boolean
  fonts?: readonly DocxFontDefinition[]
  tableOverrides?: TableOverrides
  tableRowOverrides?: TableRowOverrides
  tableCellOverrides?: TableCellOverrides
  paragraphOverrides?: ParagraphOverrides
  textRunOverrides?: TextRunOverrides
  imageOverrides?: ImageOverrides
  headerFooterOverrides?: HeaderFooterOverrides
  footnotes?: Record<string, JSONContent>
  endnotes?: Record<string, JSONContent>
  comments?: { threads: SourceThread[] }
  customNodeDsl?: CustomNodeDsl
  embedFonts?: boolean
  onImageError?: ImageErrorPolicy
}
```

`IStylesOptions` is the `docx` package's style options type.

### SourceThread

The thread shape `comments` takes. It has no named export.

```ts
interface SourceThread {
  id: string
  resolvedAt?: string | null
  comments: Array<{
    id: string
    content: JSONContent | string
    data?: {
      author?: string
      userName?: string
      initials?: string
      dateUtc?: string
      dateIso?: string
      createdAt?: string
      originalWId?: string
      originalDurableId?: string
    }
    createdAt?: string
  }>
}
```

`originalWId` and `originalDurableId` come from a DOCX import. Word uses them to match the comment again.

## Page and list types

### PageMeasure

```ts
type PageMeasure = PositiveUniversalMeasure | `${number}` | number
```

A measure with a unit, such as `'21cm'` or `'8.5in'`, or a number of twips.

### SignedPageMeasure

```ts
type SignedPageMeasure = UniversalMeasure | `${number}` | `-${number}` | number
```

Like `PageMeasure`, but it may be negative.

### NumberingBaseStyle

A Word numbering format string, such as `'decimal'`, `'lowerRoman'` or `'bullet'`.

### NumberingMarkerFont

```ts
type NumberingMarkerFont = Omit<IRunOptions, 'text' | 'children'>
```

### NumberingLevelDefinition and NumberingFormatDefinition

A `NumberingFormatDefinition` has a unique `id` and a `levels` array. A list points at it through its `numberingFormat` attribute. A depth deeper than the array reuses the levels in order.

```ts
interface NumberingFormatDefinition {
  id: string
  levels: NumberingLevelDefinition[]
}
```

Each level has these fields. `NumberingBaseStyle` is the format and `NumberingMarkerFont` is the marker font. Indents are twips or a measure with a unit.

| Field              | Type and default                      | Meaning                                                                      |
| ------------------ | ------------------------------------- | ---------------------------------------------------------------------------- |
| `baseStyle`        | `NumberingBaseStyle`                  | The counter format, such as `'decimal'`. Required.                           |
| `textTemplate`     | `string`                              | The marker text. `%1` to `%9` stand for the counter at that depth. Required. |
| `startAt`          | `number`, `1`                         | The first counter value.                                                     |
| `alignment`        | `'left' \| 'center' \| 'right'`, left | Marker alignment.                                                            |
| `numberIndent`     | `number \| PositiveUniversalMeasure`  | Distance from the page margin to the marker.                                 |
| `textIndent`       | `number \| PositiveUniversalMeasure`  | Distance from the page margin to the text.                                   |
| `markerFont`       | `NumberingMarkerFont`                 | Font formatting for the marker only.                                         |
| `suffix`           | `'tab' \| 'space' \| 'nothing'`, tab  | What follows the marker.                                                     |
| `isLegalNumbering` | `boolean`                             | Writes every referenced counter as a decimal number.                         |
| `linkedStyle`      | `string`                              | A Word style, such as `'Heading1'`, that numbers at this level.              |

### ListLevelGeometry

```ts
type ListLevelGeometry = {
  textIndent?: number | PositiveUniversalMeasure
  numberIndent?: number | PositiveUniversalMeasure
  rightIndent?: number | PositiveUniversalMeasure
  text?: string
  markerFont?: NumberingMarkerFont
  format?: NumberingBaseStyle
}
```

Indents are measured from the left margin. Numbers are twips. In `text`, `%1` stands for the level's number.

### ListLevels

```ts
type ListLevels = {
  bullet?: readonly ListLevelGeometry[]
  ordered?: readonly ListLevelGeometry[]
  task?: readonly ListLevelGeometry[]
}
```

One entry per list depth.

## Font types

### DocxFontCharacterSet

A Word charset code string, such as `'00'` for ANSI or `'01'` for the default charset.

### DocxFontDefinition

```ts
interface DocxFontDefinition {
  name: string
  data: Uint8Array | ArrayBuffer
  characterSet?: DocxFontCharacterSet
}
```

`name` is the family name the document uses. `data` holds TTF, OTF or WOFF2 bytes.

## Custom node types

`CustomNodeDsl` and the types it uses are exported from `@tiptap-pro/extension-export-docx`. Their JSON shape is described in [render custom nodes](/conversion/v3/export/docx/custom-nodes).

```ts
interface CustomNodeDsl {
  dslVersion: '1.0'
  nodes: CustomNodeRule[]
}

interface CustomNodeRule {
  type: string
  nodeKind?: 'block' | 'inline' | 'auto'
  render: RenderProgram | null
}

interface RenderProgram {
  emit?: RenderNode | RenderNode[] | null
}

type RenderNode = ElementNode | ChildrenOp | TextOp | FragmentOp | IfOp | SwitchOp | null
```

The other exported names are `ApplyMarksPolicy`, `ApplyMarksPolicyObject`, `ChildrenKind`, `DslVersion`, `ElementName`, `MarkOverride`, `MarkPolicy`, `MarkPolicyObject`, `MarkType`, `NodeKind`, `OpExpr`, `OpName`, `RefExpr`, `TemplateExpr`, `TransformName`, `UnitExpr`, `UnitName`, `ValueExpr` and `ValueSwitchExpr`.

`CustomNodeDslLimits` is also exported. It names the limits Convert applies. No export option takes it.

## CSS style types

### CssStylesOptions

Experimental.

```ts
interface CssStylesOptions {
  styles?: CssStylesInput
  extractFromDocument?: boolean
  baseFontSize?: number
}
```

`extractFromDocument` defaults to `false`. When `true`, the command reads `.tiptap` rules from the page's stylesheets, and `styles` wins per property. `baseFontSize` resolves `rem` and `em` values. Its default is 16 pixels.

### SupportedSelector

```ts
type SupportedSelector =
  | 'p'
  | 'h1'
  | 'h2'
  | 'h3'
  | 'h4'
  | 'h5'
  | 'h6'
  | 'blockquote'
  | 'a'
  | 'code'
  | 'ul li'
  | 'ol li'
  | 'strong'
  | 'em'
  | 'u'
  | 's'
```

### CssStylesInput

An object with one optional `CssPropertyMap` per `SupportedSelector` key.

```ts
const styles: CssStylesInput = {
  p: { color: 'red', fontSize: '16px' },
  h1: { fontFamily: 'Inter', 'font-size': '2rem' },
}
```

### CssPropertyMap

String values for these properties, in camelCase or kebab-case: `color`, `font-size`, `font-family`, `font-weight`, `font-style`, `line-height`, `text-align`, `margin-top`, `margin-bottom`, `background-color`, `text-decoration` and `letter-spacing`.
