## ExportDocx and the exportDocx command

`ExportDocx` is the editor extension named `'export-docx'`. It adds one command and no storage or events.

`editor.commands.exportDocx(options?: ExportDocxCommandOptions)` starts an export and returns `true` right away. It does three things.

1. Collects the document, page setup, numbering, comments, measured CSS, fonts and the images Convert can't download.
2. Sends them to `POST <endpoint>/export/docx` with the token in an `Authorization: Bearer` header, and `appId` in an `X-App-Id` header when set.
3. Calls `onCompleteExport` with the file, shaped by `exportType`.

Any failure while building or sending the export reaches `onError`. An error thrown inside `onCompleteExport` doesn't. Without `onError`, the command rethrows the error as an unhandled rejection.

`ExportDocxCommandOptions` is a partial `ExportDocxOptions`. Each option you leave out falls back to the value from `ExportDocx.configure`.

| `exportType` | `onCompleteExport` receives                   |
| ------------ | --------------------------------------------- |
| `'blob'`     | A `Blob` with the DOCX content type. Default. |
| `'buffer'`   | A `Uint8Array`.                               |
| `'base64'`   | A base64 string.                              |
| `'string'`   | A binary string, one character per byte.      |

Any other value fails the export through `onError`.

## Configuration

The command leaves an optional value without a default listed below out of the request.

### Connection

| Option     | Type and effect                                                                     |
| ---------- | ----------------------------------------------------------------------------------- |
| `token`    | `string`. The Convert JWT. Required. Without it the export fails through `onError`. |
| `appId`    | `string`. Your Tiptap app id, sent as `X-App-Id`.                                   |
| `region`   | `'eu' \| 'us'`. The Convert region when `endpoint` isn't set. Default `'eu'`.       |
| `endpoint` | `string`. A custom Convert base URL. It wins over `region`.                         |

The command resolves `endpoint` with `resolveConvertV3Endpoint`.

- A base that ends in `/v2` or `/v3` becomes `/v3`. One that ends in `/v2/convert` or `/v3/convert` becomes `/v3/convert`. A query string or hash stays.
- The command uses any other base as it is, with a one-time console warning.

### Callbacks

| Option             | Type and effect                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `exportType`       | `ExportDocxType`. The shape `onCompleteExport` receives. Default `'blob'`.                                                                                                                       |
| `onCompleteExport` | `(result: Blob \| string \| Uint8Array) => void`. Required. Receives the file. Set it here or on the command. The default throws an error once the file arrives, and `onError` doesn't catch it. |
| `onError`          | `(error: unknown) => void`. Receives the error when the export fails.                                                                                                                            |
| `onWarning`        | `OnExportDocxWarning`. Receives each warning. Without it, warnings go to the console.                                                                                                            |

### Document options

| Option                  | Type and effect                                                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `documentStyles`        | `boolean`, default `true`. Measures the mounted editor's CSS and sends it.                                                 |
| `styleOverrides`        | Word style definitions, typed as `IStylesOptions`.                                                                         |
| `cssStyles`             | `CssStylesOptions`. Experimental. Styles written as CSS properties.                                                        |
| `pageSetup`             | `Record<string, unknown>`. A Page Layout setup. Default: the editor's Page Layout setup.                                   |
| `pageSize`              | `{ width?: PageMeasure; height?: PageMeasure }`.                                                                           |
| `pageMargins`           | `top` and `bottom` as `SignedPageMeasure`. `left`, `right`, `header` and `footer` as `PageMeasure`.                        |
| `pageColor`             | `string`. The page background color.                                                                                       |
| `defaultTabStop`        | `number`. Twips between default tab stops.                                                                                 |
| `paragraphOverrides`    | `ParagraphOverrides`. Applied to every paragraph.                                                                          |
| `textRunOverrides`      | `TextRunOverrides`. Applied to every text run.                                                                             |
| `tableOverrides`        | `TableOverrides`. Applied to every table.                                                                                  |
| `tableRowOverrides`     | `TableRowOverrides`. Applied to every table row.                                                                           |
| `tableCellOverrides`    | `TableCellOverrides`. Applied to every table cell.                                                                         |
| `imageOverrides`        | `ImageOverrides`. Applied to every image.                                                                                  |
| `headerFooterOverrides` | `HeaderFooterOverrides`. The six overrides above, for header and footer content.                                           |
| `numberingFormats`      | `readonly NumberingFormatDefinition[]`. Added to the formats the editor registered.                                        |
| `outline`               | Outline numbering data. Default: the `outlineNumbering` storage of the editor.                                             |
| `listLevels`            | `ListLevels`. Bullet, ordered and task list positions.                                                                     |
| `footnotes`, `endnotes` | `Record<string, JSONContent>`. Note content by note id.                                                                    |
| `comments`              | `{ threads: SourceThread[] }`. Default: unarchived threads from the comments provider. An empty array exports no comments. |
| `customNodeDsl`         | `CustomNodeDsl`. JSON rules for custom nodes. See [render custom nodes](/conversion/v3/export/docx/custom-nodes).          |
| `fonts`                 | `readonly DocxFontDefinition[]`. Font files to embed.                                                                      |
| `embedFonts`            | `boolean`, default `false`. Embeds the page's `@font-face` files for the families the document uses.                       |
| `onImageError`          | `ImageErrorPolicy`. `'skip'` leaves an unusable image out. `'throw'` fails the export.                                     |

Each override option must be a plain object. The command drops a function and reports an `unsupported` warning.

The override types and `IStylesOptions` ship with the package's type declarations.

For how to use these options, see [control the output](/conversion/v3/export/docx/usage). Outline numbering comes from the [Outline Numbering](/pages/v2/extensions/outline-numbering) extension.

## Removed 0.x options

These options existed in 0.x. The command leaves them out and reports an `unsupported` warning that names the option. See [migrate export from 0.x](/conversion/v3/getting-started/migrate-export-from-0x).

| Removed option        | Use instead                                                        |
| --------------------- | ------------------------------------------------------------------ |
| `customNodes`         | `customNodeDsl`.                                                   |
| `customNodeDslLimits` | None. Convert applies its own limits.                              |
| `headers`, `footers`  | The header and footer content of the Page Layout setup.            |
| `placeholders`        | None.                                                              |
| Function overrides    | Plain objects. Describe node-specific output with `customNodeDsl`. |

## Warnings and errors

`ExportDocxWarning` describes content the export skipped. It has `code` and `message`. Depending on the code it also has `src`, `family`, `status`, `contentType`, `nodeType`, `attribute`, `value`, `path`, `formatId` or `noteId`.

| `code`                        | Meaning                                                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `image-missing-src`           | An image node has no `src`.                                                                                              |
| `image-request-failed`        | An image request didn't complete.                                                                                        |
| `image-fetch-failed`          | An image host returned a failure, the image is over 20 MB, or the export is over the 64-file limit.                      |
| `image-unsupported-type`      | DOCX can't embed the image format.                                                                                       |
| `font-fetch-failed`           | A font couldn't be read, isn't TTF, OTF or WOFF2, is over 25 MB, or the export is over the 64-file limit.                |
| `document-styles-failed`      | Measuring the editor's CSS failed. The export used default styles.                                                       |
| `unsupported`                 | DOCX can't hold a setting, Convert doesn't take an option, or a note has no reference. `attribute` or `noteId` names it. |
| `list-paragraph-path-missing` | A list paragraph path points at nothing, so its list styling was skipped.                                                |
| `numbering-format-invalid`    | Convert couldn't build a numbering format, so its lists use default numbering. `formatId` names it.                      |
| `warnings-truncated`          | Convert had more warnings than fit in its response.                                                                      |

`OnExportDocxWarning` is `(warning: ExportDocxWarning) => void`. An error thrown inside it is ignored.

Convert sends its warnings in the `X-Export-Warnings` response header. A browser can read the header only when CORS exposes it.

`ExportDocxRequestError` reaches `onError` when Convert refuses the export or the request never reaches it. It has `code: ExportDocxRequestErrorCode`, and optional `status`, `path` and `docsUrl`.

- `NETWORK_ERROR`: the request didn't reach Convert. `cause` holds the original error.
- `HTTP_ERROR`: Convert returned a failure status and no error code.
- Any other code comes from Convert. `path` names the option that caused it, when Convert names one.

With `onImageError: 'throw'`, an image the browser can't read fails the export with `ImageFetchError` or `ImageRequestError`. All image errors extend `ImageConversionError` and have `code`, `message`, and optional `src` and `cause`.

| Error class                 | `code`                   | Extra field            |
| --------------------------- | ------------------------ | ---------------------- |
| `ImageMissingSrcError`      | `image-missing-src`      |                        |
| `ImageRequestError`         | `image-request-failed`   |                        |
| `ImageFetchError`           | `image-fetch-failed`     | `status: number`       |
| `UnsupportedImageTypeError` | `image-unsupported-type` | `contentType?: string` |

## Endpoint helpers

`CONVERT_V3_REGION_ENDPOINTS` maps each region to its Convert base.

- `eu`: `https://api.tiptap.dev/v3/convert`
- `us`: `https://api-us.tiptap.dev/v3/convert`

`resolveConvertV3Endpoint({ endpoint?, region? }): string` returns the base the command uses, following the rules in [connection](#connection).

```ts
import { resolveConvertV3Endpoint } from '@tiptap-pro/extension-export-docx'

resolveConvertV3Endpoint({ endpoint: 'https://convert.example.com/v2' })
// 'https://convert.example.com/v3'
```

## CSS helpers

`extractTiptapCssStyles({ scope? }?): CssStylesInput` reads supported rules from the page's stylesheets. `scope` defaults to `'.tiptap'`. It returns an empty object outside a browser and skips stylesheets it can't read.

`getDocumentCss({ editor, listDepth?, adjustProbe? }): Promise<DocumentCss>` reads the editor's rendered CSS after web fonts are ready. This is what `documentStyles` measures.

- `listDepth` is 1 to 9. Default 9.
- `adjustProbe(probe: HTMLElement)` lets you adapt the temporary DOM used for the measurement.

It throws outside a browser, or when the editor is destroyed, not mounted or not laid out.

See the [types](/conversion/v3/export/docx/types) for every shape named on this page.
