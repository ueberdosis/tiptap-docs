Import these values and types from `@tiptap-pro/extension-export-docx/dsl`. They create the JSON you pass as `customNodeDsl`. They don't call Convert or create a file.

Read [render custom nodes](/conversion/v3/export/docx/custom-nodes) first for a complete export.

## Rule and element factories

`docxNode(type)` starts a rule. `block()`, `inline()` and `auto()` select its node kind. `emit()` supplies the output, `emitNothing()` emits nothing for the node, and `drop()` drops the node with its descendants. `toJSON()` returns a `CustomNodeRule`. A rule needs one of `emit()`, `emitNothing()` or `drop()` before `toJSON()`, or `toJSON()` throws.

`paragraph`, `textRun`, `externalHyperlink`, `table`, `tableRow` and `tableCell` take an optional object of typed properties. `externalHyperlink` requires `link`. `pageBreak()` emits a page break. Container builders accept children of the matching kind. `applyMarks` is available on `textRun` and `externalHyperlink`.

`applyMarks` accepts only `'node'`. Passing `marks('default')` to it throws.

Every chained method returns a fresh builder. A method never changes an earlier builder.

## Children and conditional factories

`childrenInline`, `childrenBlock`, `childrenTableRow` and `childrenTableCell` render the children of the source node by kind. Inline children accept a mark policy. Block children can wrap inline runs in a paragraph when you enable it.

`fragment` groups render nodes. `iff` picks a branch from a value expression. `switch_` picks a render branch by exact string match. `textOp` emits text with an optional fallback and mark handling. A missing branch emits nothing.

## Value factories

`ref` reads a permitted node path, with an optional default and transforms. `template` fills node paths into a string. `op` applies a named arithmetic, comparison, logical or coalescing operation. `unit` converts a measurement or a color. `switchValue` picks a value by exact match.

`marks('default' | 'node')` creates a mark policy builder. `overrides()` adjusts selected marks. `disable(...marks)` skips selected marks. `toJSON()` returns the mark policy.

The builders don't validate anything. Convert checks expressions and resource limits when it builds the file. See [render custom nodes](/conversion/v3/export/docx/custom-nodes#value-expressions) for the allowed paths, transforms, operators, units and mark names.

## Factory signatures and supported properties

The property interfaces below list every accepted field. Each `Prop<T>` takes either a literal value or a JSON value expression. Numbers follow Word units. Font sizes are half-points, paragraph spacing and indents are twips, and border sizes are eighth-points.

The `*ChildSpec` types define which children each container takes. The builder interfaces list every chained method and what it returns.
