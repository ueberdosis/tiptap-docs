Footnotes and endnotes round-trip through DOCX. Import gives you the notes, [Pages](/pages/getting-started/overview) renders them in the editor, and export writes them back as real Word notes.

## Support overview

| | Import | Editor | Export |
| --- | --- | --- | --- |
| Footnotes | REST API and editor extension | [Pages footnotes](/pages/core-concepts/footnotes) | REST API and editor extension |
| Endnotes | REST API and editor extension | [Pages endnotes](/pages/core-concepts/endnotes) | REST API and editor extension |

## How notes are stored

Each reference in the body is a `footnoteReference` or `endnoteReference` node with a `noteId` attribute. The note content lives outside the body, in a `footnotes` or `endnotes` object keyed by that id. Every value is a Tiptap JSON document (`{ type: "doc", content: [...] }`).

## Import

The [REST API](/conversion/import/docx/rest-api) returns `footnotes` and `endnotes` next to the document content.

The [editor extension](/conversion/import/docx/editor-extension#footnotes--endnotes) passes the same objects to your `onImport` callback. When Pages is installed with footnotes or endnotes enabled, `setEditorContent` applies them for you.

## Editor

Turn on [footnotes](/pages/core-concepts/footnotes) and [endnotes](/pages/core-concepts/endnotes) in Pages to render and edit the notes. Footnotes sit at the bottom of the page that references them. Endnotes collect at the end of the document.

Without Pages, the reference nodes need a [custom extension](/editor/extensions/custom-extensions/extend-existing) to render, and you keep the note content yourself.

## Export

Both export paths turn `footnoteReference` and `endnoteReference` nodes into real Word notes.

With the REST API, send the `footnotes` and `endnotes` objects from the import response to [`/export/docx`](/conversion/export/docx/rest-api#footnotes-and-endnotes) unchanged. PDF, ODT, DOC, and EPUB exports accept the same fields.

With the [editor extension](/conversion/export/docx/editor-extension), the `exportDocx` command reads the notes from Pages when footnotes or endnotes are enabled. You can also pass them through its `footnotes` and `endnotes` options.

## Limitations

- The export skips any reference without a matching note.
- If you upload a pre-built DOCX to the PDF, ODT, DOC, or EPUB REST API, the `footnotes` and `endnotes` fields are ignored. The notes are already in the file.
- Endnotes always collect at the end of the document. Pages doesn't support Word's end-of-section placement.

<Callout title="Using notes without Pages" variant="hint">
  You can still keep the notes from the import response next to your document and send them back
  on export. The round trip works even when the editor never renders them.
</Callout>
