## Known issues

- This example builds its decorations with a ProseMirror plugin instead of the Tiptap [decorations API](/editor/core-concepts/decorations), that’s why this is a lot of ProseMirror work. Before we’ll publish that example, we’d need to find a few ways to make it more Tiptap-like. For example, it would be great to use Vue/React components for the widget.
