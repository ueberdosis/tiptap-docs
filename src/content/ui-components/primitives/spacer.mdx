A flexible space component used for layout spacing.

## Install

You can add the primitive via Tiptap CLI

```bash
npx @tiptap/cli@latest add spacer
```

## Usage

```tsx
import { Spacer } from '@/components/tiptap-ui-primitive/spacer'

export default function MyComponent() {
  return (
    <div style={{ display: 'flex' }}>
      <button>Left Button</button>
      <Spacer />
      <button>Right Button</button>
    </div>
  )
}
```

A horizontal spacer fills the available space in a flex row. Set `size` to a CSS length or a number for a fixed width. Use `orientation="vertical"` with `size` to set its height.
