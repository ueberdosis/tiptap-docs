The Tiptap CLI copies React components and templates into your project and installs their dependencies. Use `pnpm dlx @tiptap/cli@latest` or `npx @tiptap/cli@latest` to run it. To see which commands your version supports, run it with `--help`.

## Start a project

Run this command from the directory where you want to create your project.

```sh
pnpm dlx @tiptap/cli@latest init
```

Choose **Next.js**, enter a project name, then select **Simple Editor** from the templates. Open the project directory and run `pnpm dev`. In a Next.js App Router project, open `/simple` on the local development server. An individual component such as `mark-button` has no route of its own. Import it into the page or toolbar where you want it to appear.

For other setups, follow the [Vite guide](/ui-components/install/vite) or the installation guide for your framework in the sidebar.

## Commands

### `init`

In a directory without a project, `init` creates a Next.js or Vite project in a new subdirectory. In an existing project, run it from the directory containing `package.json`. Set up your framework's import alias first so the CLI can resolve paths such as `@/components`.

```sh
pnpm dlx @tiptap/cli@latest init simple-editor
```

Pass `--framework next` or `--framework vite` to select the scaffold. For a new Next.js app, `--src-dir` puts the app under `src/` and `--react-compiler` enables React Compiler. Use `--cwd <directory>` to choose a working directory. The `--silent` flag mutes output. Interactive prompts still require input.

### `add`

Run `add` in an existing project. Use the install name on the component or template page. You can install several items together.

```sh
pnpm dlx @tiptap/cli@latest add mark-button heading-dropdown-menu
```

The CLI installs the requested files and their registry dependencies. Register the Tiptap extensions listed on the component page when you configure your editor. Use `--cwd <directory>` to select another project or `--path <directory>` to change the component destination. The `--overwrite` flag replaces existing component files, including your edits. Commit local changes before using it so you can review and recover them.

### `info`

Run `pnpm dlx @tiptap/cli@latest info` from the project, or pass `--cwd <directory>` to inspect another project.

### `login`

Run `pnpm dlx @tiptap/cli@latest login` to sign in with the Tiptap account that has access to a paid item. When a project needs private npm packages, run `login --write-config` in the project to configure its package manager. Keep credentials out of version control.

### `status`

Run `pnpm dlx @tiptap/cli@latest status` to see which account and plans the CLI recognizes.

### `license`

Run `pnpm dlx @tiptap/cli@latest license` to check the local license acceptance status. The CLI asks you to accept the [Tiptap Pro License](https://tiptap.dev/pro-license) when you first install a paid item.

### `logout`

Run `pnpm dlx @tiptap/cli@latest logout` to sign out.

## Registry search and install previews

CLI 3.19.5 does not include these commands and options. Check the output of `--help` for `search` and `view` before using the examples below.

| Command and arguments | What you can check |
| --- | --- |
| `search --type template` | List templates in the registry. Add search terms to match names or descriptions, or pass `--json` for structured results. |
| `view simple-editor` | See the template's files, App Router routes, plan, and direct dependencies. Use `--source` to read the files. Paid source requires account access and prior license acceptance. |
| `add simple-editor --dry-run` | See which files and dependencies the CLI would install in the current project. |
| `add simple-editor --diff` | Review the proposed file changes. Pass a destination path after `--diff` to inspect one file. |
| `info --json` | Read project settings, aliases, and detected package versions as JSON. |
| `init simple-editor --framework next --name my-app --defaults` | Create a Next.js project named `my-app` from a parent directory with the default choices. |

## When pnpm reports an ignored build

If pnpm asks which packages to build before the Tiptap banner appears, the prompt comes from pnpm while it prepares the CLI. A separate error can occur inside a new Next.js project when pnpm installs Sass and reports `ERR_PNPM_IGNORED_BUILDS` for `@parcel/watcher`. Next.js can compile the editor styles without running that optional watcher's install script.

With pnpm 11.7 or later, change into the generated project after that error. The `!` prefix tells pnpm to skip the watcher script. Then retry the template install. [pnpm build approvals](https://pnpm.io/cli/approve-builds)

```sh
pnpm approve-builds '!@parcel/watcher'
pnpm dlx @tiptap/cli@latest add simple-editor
```

Run `pnpm build` in the project directory. If the build reports `Math.random()` while prerendering `/simple`, follow the [Next.js guide](/ui-components/install/next#render-the-editor) to wrap the editor in `Suspense`.
