The Tiptap CLI helps you scaffold editors, install UI components or primitives, and configure Tiptap faster. It removes much of the manual work so you can start building editor features faster.

It’s designed for Vite or Next.js projects. If you use another framework, you’ll need to integrate Tiptap manually from the [open-source repository](https://github.com/ueberdosis/tiptap-ui-components).

## Usage

```bash
npx @tiptap/cli@latest [command] [options]
```

## Commands

### `init`

Initialize your project and install dependencies. This command sets up your project configuration and adds any specified components as editable source files.

Run in an empty directory, it scaffolds a new Vite or Next.js project; run in an existing project, it configures it. Either way, the components are copied into your `components/` folder — you then import and render them in your own page. They are not wired into a page for you, so a freshly scaffolded app still shows the framework's default starter page until you render a component. See the [Next.js](/ui-components/install/next) or [Vite](/ui-components/install/vite) guide for the full flow.

```bash
npx @tiptap/cli@latest init
```

Pass `--with <id>` to install one optional feature with a template. This example starts a Simple Editor project with Collaboration.

```bash
npx @tiptap/cli@latest init simple-editor --with collaboration
```

#### Arguments

- components: the components to add

#### Options

```bash
Usage: @tiptap/cli@latest init [options] [components...]

Options:
-f, --framework <framework>   The framework to use (next, vite)
-c, --cwd <cwd>               The working directory (defaults to current directory)
-s, --silent                  Mute output
--src-dir                     Use the src directory when creating a new project
--with <id>                   Install one registry feature
```

### `add`

Add a Tiptap UI component or template to your project.

```bash
npx @tiptap/cli@latest add [components...]
```

#### Example

```bash
npx @tiptap/cli@latest add button
```

To add a feature to an existing React editor, pass its ID to `add --with`. Pass one feature ID per command.

```bash
npx @tiptap/cli@latest add --with collaboration
```

#### Preview an installation

Run `add` with `--dry-run` in your project to list the destination files and package changes. Use `--diff` to see line-by-line changes. Both previews leave your project files and dependencies untouched.

```bash
npx @tiptap/cli@latest add simple-editor --dry-run
npx @tiptap/cli@latest add simple-editor --diff
```

To inspect one file, copy its path from the dry run and pass it after `--diff`. This example uses a Next.js project with a root `app` directory.

```bash
npx @tiptap/cli@latest add simple-editor --diff app/simple/page.tsx
```

#### Options

```bash
Usage: @tiptap/cli@latest add [options] [components...]

Arguments:
  components                    The components to add

Options:
  -o, --overwrite              Overwrite existing files
  -c, --cwd <cwd>              The working directory (defaults to current directory)
  -p, --path <path>            The path to add the component to
  -s, --silent                 Mute output
  --with <id>                  Install one registry feature
  --dry-run                    List planned file and package changes
  --diff [path]                Show file changes for all destinations or one path
```

### `view`

Use `view <name>` to inspect a registry item before installing it. For a template, the CLI lists its files, routes, direct dependencies, and any optional or built-in features. Pass `--json` for structured output or `--source` to read the item's source files. Paid source requires an account with access and an accepted license.

```bash
npx @tiptap/cli@latest view simple-editor
npx @tiptap/cli@latest view --features
npx @tiptap/cli@latest view collaboration
```

`view --features` lists feature IDs. Pass an ID to `view` to see what the feature installs and how to set it up. To inspect the file changes for a feature in your project, run `add --with <id> --diff`.

### `info`

Get information about your project configuration and setup.

```bash
npx @tiptap/cli@latest info
```

#### Options

```bash
Usage: @tiptap/cli@latest info [options]

Options:
  -c, --cwd <cwd>              The working directory (defaults to current directory)
```

### `login`

Log in to your Tiptap Cloud account to access paid components and templates.

```bash
npx @tiptap/cli@latest login
```

#### Options

```bash
Usage: @tiptap/cli@latest login [options]

Options:
  -e, --email <email>          Your account email
  -p, --password <password>    Your account password
  --write-config               Write the auth token to your package manager config
  -c, --cwd <cwd>              The working directory (defaults to current directory)
```

### `logout`

Log out from your Tiptap Cloud account.

```bash
npx @tiptap/cli@latest logout
```

### `status`

Review your Tiptap Cloud authentication status and active plans.

```bash
npx @tiptap/cli@latest status
```

#### Options

```bash
Usage: @tiptap/cli@latest status [options]

Options:
  -c, --cwd <cwd>              The working directory (defaults to current directory)
```
