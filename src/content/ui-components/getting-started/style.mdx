## Add styles

Components import their own styles. When an item uses shared styles, the CLI also installs the files under the project's styles alias. `_variables.scss` defines CSS custom properties for colors, corner radii, and transition durations. `_keyframe-animations.scss` defines animations used by the controls.

The CLI looks for an existing global stylesheet and adds the shared imports there. If your app uses a different entry, add the imports to the stylesheet your app loads. Use paths relative to that file.

| Framework | Global stylesheets the CLI checks |
| --- | --- |
| Next.js App Router | `app/globals.css` or `app/globals.scss`, under `src/` if the app lives there |
| Next.js Pages Router | `styles/globals.css` or `styles/globals.scss`, under `src/` if the app lives there |
| Vite and React Router | `src/index.css`, `src/main.css`, `src/App.css` |
| Astro | `src/styles/main.css`, `src/styles/global.css` |
| Laravel | `resources/css/app.css` |

For example, when `app/` and `styles/` share a parent directory, add these imports at the top of `app/globals.css`.

```css
@import '../styles/_variables.scss';
@import '../styles/_keyframe-animations.scss';
```

In a Vite project with `src/index.css` and `src/styles/`, use `./styles/` for both imports.

## Sass and Bun

The CLI installs the Sass dependency when an item declares it. If you copy SCSS files by hand, install Sass in your project with `pnpm add -D sass` or the equivalent command for your package manager.

When the project contains both `bun.lock` and `bunfig.toml`, the CLI compiles the component SCSS into CSS during installation and updates the imports. Use the generated `.css` filenames when adding imports to a custom entry.
