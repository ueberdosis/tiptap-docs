## Installation

### For existing projects

```bash
npx @tiptap/cli@latest add simple-editor
```

### For new projects

```bash
npx @tiptap/cli@latest init simple-editor
```

## Styling

The template uses shared styles for colors and animations. Load them in your application stylesheet. [Style setup](/ui-components/getting-started/style)

## Usage

In a Next.js App Router project, start the development server and open `/simple`. To mount the editor on another route or in a Vite app, import the installed component using your project alias. [Next.js setup](/ui-components/install/next) · [Vite setup](/ui-components/install/vite)

```tsx
import { SimpleEditor } from '@/components/tiptap-templates/simple/simple-editor'

export default function App() {
  return <SimpleEditor />
}
```

## Features

The toolbar supports keyboard undo and redo, light and dark themes, and a compact layout for small screens.

- Format text with bold, italic, strike, inline code, underline, superscript, subscript, and highlights.
- Choose heading levels 1 through 4, turn paragraphs into lists and task lists, and align text left, center, right, or justified.
- Insert and edit links, blockquotes, and code blocks.
- Find and replace text with match options. [Find and Replace extension](/editor/extensions/functionality/find-and-replace)
- Insert images through the upload node. The sample `handleImageUpload` returns a placeholder image. Replace it with a handler that stores the file and returns its URL. The sample document and handler load their image from `template.tiptap.dev`. Change the URL in `data/content.json` and `lib/tiptap-utils.ts` to use your own image.

#### Extensions

The template configures StarterKit for headings, marks, links, and history. It adds Image, TaskList and TaskItem, TextAlign, Typography, Highlight, Subscript, Superscript, Selection from `@tiptap/extensions`, and FindAndReplace from `@tiptap/extension-find-and-replace`. The horizontal rule and image upload nodes come from the installed node components.
