UI components run editor commands. Node components render content inside the document. Use primitives such as buttons, menus, and popovers to build your own controls.

## Additional editor controls

The registry also includes the following controls. Pass the install name to the CLI from your project directory.

```bash
npx @tiptap/cli@latest add font-size-dropdown-menu
```

| Install name | Plan | What it does |
| --- | --- | --- |
| `color-menu` | Start | Sets text color, text highlight, or the background color of a block. |
| `comment-button` | Start | Opens the comment composer for the current selection. |
| `font-family-dropdown-menu` | Open source | Applies a font family to the selected text. |
| `font-size-dropdown-menu` | Open source | Applies a font size to the selected text or clears the size override. |
| `image-caption-button` | Start | Toggles the caption field on the selected image. |
| `image-download-button` | Start | Downloads the selected image. |
| `indent-button` | Start | Increases or decreases the indentation of the current block. |
| `line-spacing-dropdown-menu` | Start | Sets line height and spacing before or after a paragraph. |
| `mathematics-button` | Start | Inserts a formula or a pair of math delimiters at the cursor. |
| `text-align-dropdown-menu` | Open source | Aligns the current text block to the left, center, or right, or justifies it. |

## Additional primitives

Install these with the same `add` command. For example, use `npx @tiptap/cli@latest add checkbox` to copy the checkbox and its dependencies.

| Install name | Plan | What it does |
| --- | --- | --- |
| `bubble` | Open source | Groups message bubbles and positions reactions beside a bubble. |
| `button-group` | Open source | Arranges related buttons horizontally or vertically. |
| `checkbox` | Open source | Renders a checkbox with checked, unchecked, and indeterminate states. |
| `empty` | Open source | Displays a title, description, and optional action when a list has no items. |
| `input-group` | Open source | Places labels or action buttons beside an input or textarea. |
| `message` | Open source | Arranges a conversation row with an avatar and message content. |
| `message-scroller` | Open source | Keeps a message list at the newest entry and lets readers scroll back. |
| `select` | Open source | Displays a list of options and tracks the selection. |
| `sidebar` | Start | Adds a collapsible side panel with an optional resize handle. |
| `sonner` | Open source | Displays toast notifications using Sonner. |
| `switch` | Open source | Toggles a setting between two states. |
| `textarea` | Open source | Renders a multiline text field. |
