## Create a React Router project

```bash
npx create-react-router@latest my-app
cd my-app
```

The default framework template maps `~/*` to `./app/*` in `tsconfig.json`. Keep that alias when you install Tiptap components.

## Install the editor

```bash
npx @tiptap/cli@latest add simple-editor
```

Register the generated page in `app/routes.ts`. This example keeps the default index route and adds `/simple`.

```ts
import { type RouteConfig, index, route } from '@react-router/dev/routes'

export default [
  index('routes/home.tsx'),
  route('simple', 'routes/simple.tsx'),
] satisfies RouteConfig
```

To render the editor on an existing route, import `SimpleEditor` from `~/components/tiptap-templates/simple/simple-editor`.

## Add styles

The default starter loads `app/app.css` from `app/root.tsx`. Add both imports to `app/app.css`.

```css
@import './styles/_variables.scss';
@import './styles/_keyframe-animations.scss';
```

Run `npm run dev` and open `/simple`. [Style setup](/ui-components/getting-started/style)
