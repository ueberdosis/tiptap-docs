## Create a Laravel project

Create a project with the Laravel React starter kit.

```bash
laravel new my-app --react
cd my-app
npm install
```

The starter kit maps `@/*` to `resources/js/*` in `tsconfig.json`.

## Install the editor

```bash
npx @tiptap/cli@latest add simple-editor
```

The CLI creates the Inertia page `resources/js/pages/simple.tsx`. Register `/simple` in `routes/web.php` alongside your existing routes.

```php
Route::inertia('/simple', 'simple');
```

To use the editor on another page, import `SimpleEditor` from `@/components/tiptap-templates/simple/simple-editor`.

## Add styles

The CLI looks for `resources/css/app.css`. With the starter kit alias, the shared style imports in that file point to `../js/styles/`. [Style setup](/ui-components/getting-started/style)

Run `composer run dev` and open `/simple`.
