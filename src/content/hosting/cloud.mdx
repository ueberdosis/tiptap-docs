## What Tiptap runs for you

- **The [Document Server](/collaboration/getting-started/overview)** syncs documents in real time and stores them.
- **The [REST API](/collaboration/documents/rest-api)** reads, creates, and changes documents from your backend.
- **[Webhooks](/collaboration/core-concepts/webhooks)** tell your systems when documents change.
- **[Snapshots](/collaboration/documents/snapshot)** keep versions of every document.
- **[Comments](/comments/getting-started/overview)** store threads with the document.
- **The [AI Toolkit](/ai/ai-toolkit/install) and [Conversion](/conversion/getting-started/install) services** run next to it.

Tiptap operates, updates, and scales all of it.

## Get started

1. Start a [free trial or choose a plan](https://cloud.tiptap.dev/v2/billing).
2. In the [dashboard](https://cloud.tiptap.dev/), add an environment. Pick the region closest to your users.
3. Copy the document server ID from the [configuration page](https://cloud.tiptap.dev/v2/configuration/document-server).
4. Install the provider from Tiptap's [private registry](/guides/pro-extensions):

```bash
npm install @tiptap-pro/provider
```

5. Connect the editor to your Document Server, with its ID as `appId`:

```js
import { TiptapCollabProvider } from '@tiptap-pro/provider'

const provider = new TiptapCollabProvider({
  name: 'document-name', // The document to open
  appId: 'YOUR_DOCUMENT_SERVER_ID',
  token: 'YOUR_JWT',
  document: doc, // The Y.Doc the Collaboration extension uses
})
```

The [install guide](/collaboration/getting-started/install) walks through the whole editor setup.

## Authenticate users

- For testing, copy a JWT from the [configuration page](https://cloud.tiptap.dev/v2/configuration/document-server).
- For production, sign a JWT on your server for each user. [Authenticate](/collaboration/getting-started/authenticate) shows how to limit it to certain documents or to read-only access.

## Reach your documents from your backend

Every environment has its own API address:

```text
https://YOUR_DOCUMENT_SERVER_ID.collab.tiptap.cloud/
```

- The [REST API](/collaboration/documents/rest-api) returns documents as JSON and changes them, also while people edit.
- The [runtime configuration API](/collaboration/operations/configure) changes secrets, webhook URLs, and versioning without a restart.
- The [metrics API](/collaboration/operations/metrics) reports server and document statistics. The dashboard shows a short version.

## Environments

Each environment runs its own Document Server with its own documents, secrets, and settings.

- Use one environment per stage, such as development, staging, and production.
- Pick each environment's region by where its users are.

## Dedicated cloud

A dedicated cloud runs your Document Server on infrastructure reserved for your organization, still operated by Tiptap.

- Choose it when you need isolation from other customers but don't want to run servers yourself.
- It offers the same APIs and features as the shared cloud.
- [Talk to sales](https://tiptap.dev/contact-sales) to set one up.

## Move to your own servers later

Documents in Tiptap Cloud can move to an [on-premises](/hosting/on-premises) Document Server, with their versions: [export and import a document](/collaboration/documents/rest-api#export-and-import-a-document). The editor setup stays the same; you pass `baseUrl` instead of `appId`.
