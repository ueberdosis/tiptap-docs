## Which one to choose

- **Tiptap Cloud, to start.** The fastest path to production. Tiptap runs, updates, and scales the Document Server, the AI Toolkit, and Conversion for you, in the region you choose. [Tiptap Cloud](/hosting/cloud) shows how to start.
- **Dedicated cloud, for isolation and an SLA.** Your own single-tenant server on Tiptap's infrastructure, with guaranteed uptime, still run by Tiptap. [Dedicated cloud](/hosting/cloud#dedicated-cloud) has the details.
- **On-premises, when documents must stay with you.** The same Document Server in your own infrastructure, from Tiptap's Docker images, for compliance or data residency. [On-premises](/hosting/on-premises) covers deployment, configuration, scaling, and support. [Talk to sales](https://tiptap.dev/contact-sales) to set it up.
- **Hocuspocus, for real-time sync only.** The free, open source WebSocket server that the Document Server builds on. Your team owns storage, authentication, and operations. [Hocuspocus](/hocuspocus/getting-started/overview) gets you started, and you can move to the Document Server later.

## Move between them

The editor setup stays the same. Only the provider changes:

- `HocuspocusProvider` connects to a Hocuspocus server.
- `TiptapCollabProvider` connects to the Document Server, in Tiptap Cloud with `appId` or on-premises with `baseUrl`.

To move documents to the Document Server, import them with the [batch import endpoint](/collaboration/documents/rest-api#batch-import-documents). Documents in Tiptap Cloud can move to an on-premises server later, with all their versions: [export and import a document](/collaboration/documents/rest-api#export-and-import-a-document).
