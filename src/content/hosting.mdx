## Compare the options

| | Tiptap Cloud | On-premises | Hocuspocus |
| --- | --- | --- | --- |
| Who runs it | Tiptap | You, with Tiptap's Docker images and support | You |
| Where documents are stored | Tiptap Cloud, in the region you choose | Your infrastructure | Your infrastructure |
| Real-time sync and awareness | Yes | Yes | Yes |
| Storage | Included | Included | You add it with the [Database](/hocuspocus/server/extensions/database), [SQLite](/hocuspocus/server/extensions/sqlite), or [S3](/hocuspocus/server/extensions/s3) extension |
| Authentication | [Tiptap authentication](/collaboration/getting-started/authenticate) with JWTs | [Tiptap authentication](/collaboration/getting-started/authenticate) with JWTs | You write an [`onAuthenticate` hook](/hocuspocus/guides/authentication) |
| Read and change documents from your backend | [REST API](/collaboration/documents/rest-api) and [content injection](/collaboration/documents/content-injection) | [REST API](/collaboration/documents/rest-api) and [content injection](/collaboration/documents/content-injection) | You build it |
| Webhooks | [Webhooks](/collaboration/core-concepts/webhooks) | [Webhooks](/collaboration/core-concepts/webhooks) | [Webhook extension](/hocuspocus/server/extensions/webhook) |
| Version history | [Snapshots](/collaboration/documents/snapshot) | [Snapshots](/collaboration/documents/snapshot) | You build it |
| Comments | [Comments](/comments/getting-started/overview) | [Comments](/comments/getting-started/overview) | Not available |
| AI Toolkit and Conversion services | Included in Cloud | Run on your servers | Not available |
| Scaling | Run by Tiptap | High-availability cluster | You scale it with the [Redis extension](/hocuspocus/server/extensions/redis) |
| Support | By plan | Dedicated support | Community |
| Cost | Paid [plan](https://tiptap.dev/pricing) | [Talk to sales](https://tiptap.dev/contact-sales) | Free, MIT licensed |

**Use Tiptap Cloud** for the fastest path to production: Tiptap runs and scales the Document Server for you.

**Use On-premises** when documents must stay in your infrastructure, for compliance or data residency.

**Start with Hocuspocus** when you only need real-time sync and your team wants to own storage, authentication, and operations. You can move to Cloud or On-premises later.

## Tiptap Cloud

1. Start a [free trial or choose a plan](https://cloud.tiptap.dev/v2/billing).
2. In the [dashboard](https://cloud.tiptap.dev/), add an environment in the region closest to your users.
3. Copy the document server ID from the [configuration page](https://cloud.tiptap.dev/v2/configuration/document-server).
4. Pass it as `appId` to the `TiptapCollabProvider`, as the [install guide](/collaboration/getting-started/install) shows.

## On-premises

On-premises runs the same Document Server as Tiptap Cloud, deployed from Tiptap's Docker images into your own stack.

- **Connect:** Pass your server's URL as `baseUrl` instead of `appId` to the [`TiptapCollabProvider`](/collaboration/provider/integration).
- **Configure:** Change secrets, webhook URLs, and other settings at runtime through the [runtime configuration API](/collaboration/operations/configure).
- **Scale:** Run a high-availability cluster; the provider's `shardKey` option routes documents in it.
- **More services:** The [AI Toolkit](/ai/ai-toolkit/install) and [Conversion](/conversion/getting-started/install) services can run on your servers too.

[Talk to sales](https://tiptap.dev/contact-sales) to get access.

## Hocuspocus

[Hocuspocus](/hocuspocus/getting-started/overview) is the open source WebSocket server that the Document Server builds on. It syncs Yjs documents and leaves storage, authentication, and the rest to you.

## Move between them

The editor setup stays the same. Only the provider changes:

- `HocuspocusProvider` connects to a Hocuspocus server.
- `TiptapCollabProvider` connects to the Document Server, in Tiptap Cloud with `appId` or on-premises with `baseUrl`.

To move documents to the Document Server, import them with the [batch import endpoint](/collaboration/documents/rest-api#batch-import-documents). Documents in Tiptap Cloud can move to an on-premises server later.
