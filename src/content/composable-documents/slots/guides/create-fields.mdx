---
title: Create document fields
meta:
  description: Insert, configure, fill and dissolve editable Slot fields.
---

Use a block Slot for a region such as a summary. Supply its ID when another part of your application needs to address it.

```ts
editor.commands.insertSlot({
  kind: 'block',
  id: 'summary',
  at: editor.state.doc.content.size,
  config: {
    version: 1,
    label: 'Summary',
    required: true,
    constraints: { maxLength: 600 },
  },
})
```

Use an inline Slot for a name, date or order number inside a sentence. Wrap an existing text selection to preserve its words:

```ts
editor.commands.wrapInSlot({
  kind: 'inline',
  id: 'customer',
  config: { version: 1, label: 'Customer name' },
})
```

Fill by ID rather than by position:

```ts
editor.commands.fillSlot({
  id: 'customer',
  content: [{ type: 'text', text: 'Ada Lovelace' }],
})
```

`clearSlot({ id })` empties a field. `dissolveSlot({ id })` removes its wrapper and keeps its content. `removeSlot({ id })` removes both.

To enable typed creation, configure delimiter pairs:

```ts
Slot.configure({
  shortcuts: { inline: { open: '{{', close: '}}' } },
})
```

Typing `{{Ada}}` creates an inline Slot containing “Ada”. The text is a value, not a configuration ID. See [all authoring commands](/composable-documents/slots/api-reference#commands).
