---
title: Selection awareness
intro: 'Selection awareness tells the AI agent which content is selected in the editor, so it understands the request and edits only the selection.'
meta:
  title: Selection awareness | Tiptap Content AI
  description: Make the AI agent aware of the selected content in the editor.
  category: Content AI
---

To activate selection awareness, set the `addSelection` option to `true`. This will send the selected content as [context](/ai/deprecated/agent/features/context) to the AI agent.

```ts
provider.addUserMessage('Summarize the selected document', {
  addSelection: true, // Defaults to false
})
```
