## Tiptap Cloud

Using the AI Agent extension with Tiptap Cloud is the fastest way to get started. It eliminates the need to build and maintain your own server.

Tiptap Cloud's AI agent is highly configurable:

- Customize how the AI agent behaves, by editing the [system prompt](/ai/deprecated/agent/configure/system-prompt). Define multiple AI Agents, each with their own rules and personality.
- [Provide context](/ai/deprecated/agent/features/context) to the user messages.
- [Customize the AI model](/ai/deprecated/agent/use-with-content-ai-cloud#customize-the-openai-model). Only OpenAI models are supported in Tiptap Cloud.

For new projects, use the [AI Toolkit](/ai/ai-toolkit/overview) instead. To get started with Tiptap Cloud's AI agent, [follow this guide](/ai/deprecated/agent/use-with-content-ai-cloud).

## Custom AI agent

<Callout title="Beginner's tip" variant="info">
  Building an AI agent for the first time? Start with the [AI Toolkit](/ai/ai-toolkit/overview),
  which replaces the AI Agent extension.
</Callout>

A custom AI agent gives you more control over the AI model and tools. Use it in these situations:

- If you've already built an AI agent and want to add text-editing capabilities to it.
- To use an AI model that is not supported in Tiptap Cloud.
- To create an AI agent with [custom tools](/ai/deprecated/agent/custom-llms/tools) that interact with external data sources. For example, a tool that searches the web for information.

However, a custom AI agent requires more work to set up and maintain. You need to build and maintain your own backend.

To get started with a custom AI agent, [follow this guide](/ai/deprecated/agent/custom-llms/get-started).
