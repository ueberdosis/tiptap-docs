## AI Changes features

- Integrates seamlessly with our [Basic AI Generation extension](/ai/basic/text-generation) and [AI Agent extension](/ai/deprecated/agent/overview)
- Supports rich text formatting, including images, links, and mentions
- Enables users to [accept and reject individual changes](/ai/deprecated/changes/features/review-changes) or make adjustments to generated content
- Provides a [fully customizable UI](/ai/deprecated/changes/features/display-changes) for displaying changes

<Callout title="When to use AI Changes?" variant="warning">
  The AI Changes extension displays changes **after** they are applied to the document. To preview
  changes before they are applied, use the [AI
  Suggestion](/ai/deprecated/suggestion/overview) extension. Follow the [diff
  view](/ai/deprecated/suggestion/features/diff-view) guide.
</Callout>

## How it works

The AI Changes extension adapts to your specific text editing workflow. Integrate it in four simple steps:

1. [Install](/ai/deprecated/changes/install) and [configure](/ai/deprecated/changes/configure) the extension
2. Edit the editor's content (for example, by inserting AI-generated text)
3. [Display changes](/ai/deprecated/changes/features/display-changes) in the editor
4. [Review changes](/ai/deprecated/changes/features/review-changes) made by AI
