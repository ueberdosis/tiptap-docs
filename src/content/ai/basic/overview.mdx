## What you can do with it

- **Apply prebuilt commands.** Adjust the tone, translate, and more on the selected text. [Built-in commands](/ai/basic/text-generation/built-in-commands)
- **Autocomplete as you type.** Press Tab for a suggestion and Tab again to accept it. [Autocompletion](/ai/basic/text-generation/autocompletion)
- **Write your own commands.** Extend the extension with your own prompts. [Custom commands](/ai/basic/text-generation/custom-commands)
- **Give the AI context.** Add context to prompts and commands to fine-tune the response. [Provide context](/ai/basic/text-generation/provide-context)
- **Get formatted answers.** Responses arrive as rich text with lists and more. [Formatted responses](/ai/basic/text-generation/format)
- **Keep and reuse responses.** Save, regenerate, and insert responses. [Manage responses](/ai/basic/text-generation/manage-responses)
- **Stream into the document.** A low-level API streams content straight into the editor. [Stream content](/ai/basic/text-generation/stream)
- **Generate images.** Create images on your server with the OpenAI API and insert them with the Image extension. [Image generation](/ai/basic/image-generation)
- **Use your own LLM.** Override the resolver functions to call your model. [Integrate your LLM](/ai/basic/custom-llms)
- **Edit together.** AI responses work in [collaborative documents](/collaboration/getting-started/overview). [With Collaboration](/ai/basic/collaboration)

## How it works

1. A user selects text in the editor and applies an AI command.
2. The selection, the command, and its options go to Tiptap's AI service.
3. The service builds a prompt and calls OpenAI with your API key.
4. The response is inserted or streamed into the editor.

With a [custom LLM](/ai/basic/custom-llms), your own backend takes the place of Tiptap's service. [Privacy](/ai/basic/privacy) explains how Tiptap handles your content.

## Which AI product to use

For AI agents that read and edit whole documents, use the [Server AI Toolkit](/ai/ai-toolkit/overview) instead, or the [Client AI Toolkit](/ai/ai-toolkit/client/overview) to run agents in the browser.

Install the extension:

```bash
npm install @tiptap-pro/extension-ai
```

Add it to the editor with a token you sign on your server:

```js
import StarterKit from '@tiptap/starter-kit'
import Ai from '@tiptap-pro/extension-ai'

const editor = new Editor({
  extensions: [
    StarterKit,
    Ai.configure({
      token: 'TOKEN_HERE', // your signed token, never the OpenAI API key
      autocompletion: true,
    }),
  ],
})
```

[Install](/ai/basic/install) shows how to sign the token.
