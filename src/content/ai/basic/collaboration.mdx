## Content only the current user sees

To preview AI responses before they are inserted, [store them in the extension storage](/ai/basic/text-generation/manage-responses) of the [Basic AI Generation](/ai/basic/overview) extension. While in that state, other connected users do not see them. When the user accepts a response, it is added to the editor content.

Likewise, [autocompletion suggestions](/ai/basic/text-generation/autocompletion) are only visible to the user who triggered them, and they are not displayed to other users until the user accepts them.
