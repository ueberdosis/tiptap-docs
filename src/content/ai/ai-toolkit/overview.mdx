The Server AI Toolkit is the right choice for most AI agents that edit the [Tiptap Document](/document-model). The [Client AI Toolkit](/ai/ai-toolkit/client/overview) runs its tools in the browser instead, with your backend calling the model, and [Basic AI Generation](/ai/basic/overview) adds prebuilt AI commands such as autocompletion to the editor.

## What you can do with it

- **Chat with an agent that edits the document.** The agent reads the document and changes it as you talk. [AI agent chatbot](/ai/ai-toolkit/agents/ai-agent-chatbot)
- **Review AI edits before they land.** Edits appear as [tracked changes](/tracked-changes/getting-started/overview) that users accept or reject one by one. [Use with Tracked Changes](/ai/ai-toolkit/agents/tracked-changes)
- **Let agents comment.** Agents read, write, and edit [comments](/comments/getting-started/overview), fully server-side, in a Tiptap Cloud document. [Server comments](/ai/ai-toolkit/agents/comments)
- **Edit what the user selected.** The agent reads and edits a collaborator's live selection. [Selection awareness](/ai/ai-toolkit/agents/selection-awareness)
- **Stream edits as they are generated.** Edits reach the Tiptap Cloud document over a live connection, so every collaborator sees them happen. [Streaming](/ai/ai-toolkit/agents/streaming)
- **Find and change content with queries.** Tiptap Query (alpha) selects content, such as every heading, and applies an action to it. [Tiptap Query](/ai/ai-toolkit/api-reference/tiptap-query)
- **Keep token costs low.** Tiptap Shorthand encodes documents in a compact format and cuts token costs by up to 50%. [Tiptap Shorthand](/ai/ai-toolkit/advanced-guides/tiptap-shorthand)
- **Support your own nodes.** Describe custom nodes and marks so the model generates them correctly. [Custom nodes](/ai/ai-toolkit/advanced-guides/custom-nodes)
- **Use your own model and framework.** The REST API works with any agent framework and model. [REST API](/ai/ai-toolkit/api-reference/rest-api); the [Client AI Toolkit](/ai/ai-toolkit/client/agents/tools) has tool definitions for the Vercel AI SDK, LangChain.js, OpenAI, Anthropic, and Mastra.
- **Run it in the cloud or on your servers.** The Server AI Toolkit is a [Tiptap Cloud](/hosting/cloud) service that you can also deploy [on-premises](/hosting/on-premises).

Install the package:

```bash
npm install @tiptap/ai-toolkit
```

In the browser, add the `ServerAiToolkit` extension and get the editor context:

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { getEditorContext, ServerAiToolkit } from '@tiptap/ai-toolkit'

const editor = new Editor({
  extensions: [StarterKit, ServerAiToolkit],
})

const editorContext = getEditorContext(editor) // send this with every request
```

On your server, fetch the tools for your agent:

```ts
const response = await fetch('https://api.tiptap.dev/v4/ai/toolkit/fetch-tools', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${jwt}`, // your signed Tiptap Access Control JWT
  },
  body: JSON.stringify({
    editorContext,
    tools: { tiptapRead: true, tiptapEdit: true },
  }),
})
```

[Install](/ai/ai-toolkit/install) covers authentication and every step in detail.
