## The `readSelection` tool

With the `readSelection` tool, the AI can read the user's selection. This tool only works with Tiptap Cloud collaborative documents.

Enable it in the `fetch-tools` request alongside the other tools:

```ts
const response = await fetch(`${apiBaseUrl}/v4/ai/toolkit/fetch-tools`, {
  method: 'POST',
  headers: await getAuthHeaders(),
  body: JSON.stringify({
    editorContext,
    tools: {
      readSelection: true,
      // Other tools
      tiptapRead: true,
      tiptapEdit: true,
    },
  }),
})
```

The `readSelection` tool reads the selection of a single user. This is usually the user who prompts the AI. Pass the user ID as the `tool.config.user` parameter when the tool is executed. The developer passes this parameter, so the AI does not generate it.

```ts
const response = await fetch(`${apiBaseUrl}/v4/ai/toolkit/execute-tool`, {
  method: 'POST',
  headers: await getAuthHeaders(documentId),
  body: JSON.stringify({
    editorContext,
    document: { type: 'cloud', id: documentId },
    tool: {
      name: 'readSelection',
      // The AI calls the readSelection tool with no input parameters
      input: {},
      // The user's ID is passed by the developer
      config: { user: 'user-1' },
    },
  }),
})
```

See the [REST API reference](/ai/ai-toolkit/api-reference/rest-api#readselection) for more details about the tool.

## Publish the selection to awareness

Selection awareness is included in `ServerAiToolkit` from `@tiptap/ai-toolkit`. Configure its
`selectionAwareness` option with your provider and user ID; no additional extension is needed. It publishes
selection data specifically for the AI Toolkit and keeps it when the editor loses focus. Users can
select text, click into chat, and ask the AI to edit that selection.

Collaborative editors require the peer dependencies `@tiptap/y-tiptap` and `yjs`:

```bash
npm install @tiptap/ai-toolkit @tiptap/y-tiptap yjs
```

Pass the collaboration provider and a `userId` matching `tool.config.user`. Create the editor once
the provider exists, and use the same Yjs document for the provider and `Collaboration`.
`CollaborationCaret` is optional: keep it if you want to display other users' cursors.

```tsx
import { ServerAiToolkit } from '@tiptap/ai-toolkit'
import { Collaboration } from '@tiptap/extension-collaboration'
import { useEditor } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

const editor = useEditor({
  extensions: [
    StarterKit.configure({ undoRedo: false }),
    Collaboration.configure({ document: doc }),
    ServerAiToolkit.configure({
      selectionAwareness: { provider, userId: 'user-1' },
    }),
  ],
})
```

## Preserving the selection

The server reads awareness at the moment the tool runs. Blurring the editor leaves the AI selection
intact, so sending a message requires no editor focus call:

```tsx
const handleSubmit = () => {
  if (!input.trim()) return
  sendMessage({ text: input })
  setInput('')
}
```

The selection uses Yjs relative positions, so it follows collaborative edits while the user is in
chat. Changing the selection, including collapsing it to a cursor, replaces the previous selection.
Destroying the editor clears its field's selection. This is live awareness, not durable storage:
the selection is unavailable once the provider disconnects and the server removes its awareness state.

## Multiple collaborative fields

Each editor publishes its own field, inferred from the fragment bound by `Collaboration`. Editors
can share one provider and retain independent selections:

```ts
const titleExtensions = [
  StarterKit.configure({ undoRedo: false }),
  Collaboration.configure({ document: doc, field: 'title' }),
  ServerAiToolkit.configure({ selectionAwareness: { provider, userId: 'user-1' } }),
]

const bodyExtensions = [
  StarterKit.configure({ undoRedo: false }),
  Collaboration.configure({ document: doc, field: 'body' }),
  ServerAiToolkit.configure({ selectionAwareness: { provider, userId: 'user-1' } }),
]
```

Pass the field at the top level of every tool execution request for that editor, including subsequent
read and edit calls. Omit it to use `default`. The field is chosen by your application, not the model:

```ts
const body = {
  editorContext: getEditorContext(bodyEditor),
  document: { type: 'cloud', id: documentId },
  field: 'body',
  tool: {
    name: 'readSelection',
    input: {},
    config: { user: 'user-1' },
  },
}
```

## Existing Collaboration Caret integrations

The server prefers AI Toolkit selection awareness for the requested user and field. If no matching
AI Toolkit entry exists, it falls back to `CollaborationCaret`'s `user.id` and cursor for the `default`
field. Existing integrations continue to work without changes, including their existing blur behavior.

To migrate, configure `ServerAiToolkit.selectionAwareness` with the same user ID and remove any chat-submit workaround
that refocuses the editor. An empty or cleared AI Toolkit selection takes precedence over a legacy
caret selection. The caret fallback is not used for non-default fields because caret awareness does
not identify its field.

Deploy the server update before enabling the new extension. An older server only reads caret
awareness, so retain `CollaborationCaret` during a staggered rollout if older servers still need it.

## Limitations

### Requires live collaborative documents

The `readSelection` tool reads live awareness from Tiptap Cloud collaborative documents. Documents
provided inline have no awareness and are not supported. A missing user or field, a collapsed
selection, or positions that can no longer be resolved returns `{ success: true, isEmpty: true }`.

### AI model behavior

`readSelection` tells AI what content is selected, but it does not force it to edit only the
selection. Smaller, less capable AI models may rewrite the surrounding paragraph instead of
just the selected span, especially for a sub-sentence selection.

In our testing, models with reasoning enabled (for example, `gpt-5.6-luna` with reasoning effort set
to `low`) keep their edits scoped to the selection more reliably. A clear instruction such as "edit
only the selected text" also helps.
