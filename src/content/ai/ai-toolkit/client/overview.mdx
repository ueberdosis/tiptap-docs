For most use cases, the [AI Toolkit](/ai/ai-toolkit/overview) on the server is the better choice. Choose this client-only package when everything should run in the browser, or when AI changes must not sync with the document. For prebuilt AI commands such as autocompletion, see [Basic AI Generation](/ai/basic/overview).

Ask the agent in the demo to read or change the document. The [live demo](/ai/ai-toolkit/client/advanced-guides/live-demo) explains how it's built.

## What you can do with it

- **Chat with an agent that edits the document.** [AI agent chatbot](/ai/ai-toolkit/client/agents/ai-agent-chatbot)
- **Give your agent tools.** Tool definitions for the Vercel AI SDK, LangChain.js, OpenAI, Anthropic, Mastra, and other providers. [Tool definitions](/ai/ai-toolkit/client/agents/tools)
- **Review AI changes.** Show them as suggestions or tracked changes that users accept or reject. [Review changes](/ai/ai-toolkit/client/agents/review-changes)
- **Stream tool calls.** Users see what the AI is doing while it works. [Streaming](/ai/ai-toolkit/client/agents/streaming)
- **Work with the selection.** Pass only the selected content to the model. [Selection awareness](/ai/ai-toolkit/client/agents/selection-awareness)
- **Work across documents.** One agent creates, switches, and edits several documents. [Multi-document AI agent](/ai/ai-toolkit/client/agents/multi-document)
- **Add comments.** Agents read, write, and edit comments. [Comments](/ai/ai-toolkit/client/agents/comments)
- **Teach the model your schema.** The model learns your nodes, marks, and attributes. [Schema awareness](/ai/ai-toolkit/client/agents/schema-awareness)
- **Run single-task workflows.** Insert content, proofread, edit with Tiptap Edit, or manage comments. [Workflows](/ai/ai-toolkit/client/workflows)
- **Use any backend language.** A CLI outputs the tool definitions and workflow configurations as JSON for Python, Go, Ruby, and others. [Non-TypeScript backends](/ai/ai-toolkit/client/advanced-guides/non-typescript-backends)

## Get started

<Requirements>
  <RequirementItem label="1. Get access">
    The client AI Toolkit comes with the paid AI Toolkit add-on.{' '}
    <a href="https://tiptap.dev/contact-sales?form=ai-toolkit">Contact our team</a>.
  </RequirementItem>
  <RequirementItem label="2. Access the private registry">
    Authenticate to Tiptap's private npm registry with the [setup guide](/guides/pro-extensions).
  </RequirementItem>
</Requirements>

Install the package:

```bash
npm install @tiptap-pro/client-ai-toolkit
```

Add the extension to your editor and get the toolkit:

```tsx
import { AiToolkit, getAiToolkit } from '@tiptap-pro/client-ai-toolkit'

const editor = new Editor({
  extensions: [AiToolkit],
})

const toolkit = getAiToolkit(editor)
```

<Callout title="Required Tiptap version" variant="warning">
  All `@tiptap/*` packages need version `3.12.0` or higher.
</Callout>

[Install](/ai/ai-toolkit/client/install) continues with your first agent or workflow.
