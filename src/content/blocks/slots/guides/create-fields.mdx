Use the `insertSlot` command to add a new slot to the document.

```ts
editor.commands.insertSlot({
  kind: 'block',
  id: 'summary',
  at: editor.state.doc.content.size,
  config: {
    version: 1,
    label: 'Summary',
    required: true,
    constraints: { maxLength: 600 },
  },
})
```

There are two types of slots:

- **Inline slots** can contain inline content like text
- **Block slots** contain block content like one or more paragraphs, headings, etc.

Then, a slot can be filled by typing inside it or calling the `fillSlot` command

```ts
editor.commands.fillSlot({
  id: 'customer',
  // Tiptap JSON content
  content: [{ type: 'text', text: 'Ada Lovelace' }],
})
```

`clearSlot({ id })` empties a field. `dissolveSlot({ id })` removes its wrapper and keeps its content. `removeSlot({ id })` removes both.

To enable typed creation, configure delimiter pairs:

```ts
Slot.configure({
  shortcuts: { inline: { open: '{{', close: '}}' } },
})
```

Typing `{{Ada}}` creates an inline Slot containing “Ada”. The text is a value, not a configuration ID. See [all authoring commands](/blocks/slots/api-reference/commands).
