## What you can do with it

- **Suggest instead of edit.** Turn suggestion mode on and off per user. [Basic usage](/tracked-changes/usage/basic-usage)
- **Accept and reject.** One suggestion at a time, all at once, by range, or by user. [Commands](/tracked-changes/api-reference/commands)
- **Create suggestions from code.** Insert, delete, or replace content as a suggestion without turning suggestion mode on. [Commands](/tracked-changes/api-reference/commands)
- **Show a list of suggestions.** Find, filter, and inspect suggestions to build a review panel. [Build a suggestion list](/tracked-changes/guides/suggestion-list), [Utilities](/tracked-changes/api-reference/utilities)
- **Discuss a suggestion.** Link suggestions to comment threads. [Tracked Changes with Comments](/tracked-changes/guides/comments-integration)
- **Edit together.** Suggestions sync through Yjs-based real-time collaboration. [With Collaboration](/tracked-changes/examples/collaboration)
- **Track more than text.** Images and other atom nodes, tables, and custom node views. [Using NodeViews](/tracked-changes/guides/nodeview-support)
- **Carry suggestions into Word.** Import and export tracked changes with DOCX. [Import](/conversion/import/docx/tracked-changes), [Export](/conversion/export/docx/tracked-changes)

## What it tracks

| Change | Type | What it is |
| --- | --- | --- |
| Insertion | `add` | New content |
| Deletion | `delete` | Content marked for removal |
| Replacement | `replace` | Content deleted and replaced in one edit |
| Mark change | `markChange` | Formatting added to or removed from existing text |
| Attribute change | `attributeChange` | A changed node attribute, such as an image's `src` |
| Block split | `split` | A block split in two; `splitKind` is `insertion` at the end of a block and `structural` inside it |
| List indent | `sink` | A list item moved one level in with Tab |
| List outdent | `lift` | A list item moved one level out with Shift-Tab |

- **Grouping:** Continuous edits merge into one suggestion.
- **Nesting:** An edit by another author inside a pending suggestion becomes its own suggestion instead of overwriting it.

  </RequirementItem>

Install the extension:

```bash
npm install @tiptap-pro/extension-tracked-changes
```

Add it to the editor with the current user:

```js
import { Editor } from '@tiptap/core'
import { TrackedChanges } from '@tiptap-pro/extension-tracked-changes'

const editor = new Editor({
  extensions: [
    TrackedChanges.configure({
      enabled: true, // start in suggestion mode
      userId: 'user-123',
      userMetadata: { name: 'John Doe' },
    }),
  ],
})
```

[Install](/tracked-changes/getting-started/install) lists every setting.
